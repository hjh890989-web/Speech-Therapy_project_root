## 2. 한국어 후보 1차 — `또박또박` 1순위

- **🏆 또박또박** — "또박또박 말해봐"는 부모 일상어 → 설명 없이 '명확한 발음' 연상, 의료색 0, 놀이+신뢰 균형. (리스크: 일반 의성어라 상표 식별력 보강 필요)
- 테마별 보조: **말씨앗**(말+씨앗, 나무 성장 서사 일체화) · **도담도담**(아이 건강히 자람, 안심 톤) · **조잘조잘**(발랄) · **말이음**(부모-아이 잇다).
- 정리 최종추천: 메인 **또박또박** + 성장 서사용 서브 **말씨앗**.

## 3. 한국어 후보 2차 (추가 요청) — `또랑` 1순위

- **🏆 또랑(또랑또랑)** — "또렷하고 밝다", 단일 워드마크/마스코트("또랑이")로 브랜딩 유리, 또박또박 결 유지.
- 보조: **말랑**(말+말랑말랑, 귀여움·캐릭터) · **소리쑥쑥**(소리+성장) · **말쑥**(중의: 깔끔) · **말동무/말벗**(동행·안심) · **가나다**(즉시 이해) · **모음모음**(언어유희).

## 4. 영어 후보 1차 (영어 요청) — `SoundSprout` 1순위

- ⚠️ 영어권 경쟁 앱 존재(Speech Blubs, Lingokids) → 상표·도메인 충돌 확인 중요.
- **🏆 SoundSprout** — Sound(발음)+Sprout(성장) 일체화, 한국어 '말씨앗'의 영어 대응, 두운(S-S), 비의료색.
- 보조: **TinyTalk(s)**(유아 직관·두운) · **Chatty/Talkie**(발랄) · **WordSprout/Sproutly**(성장) · **TalkBuddy/SpeechPal**(동행·B2B) · **Toki**(식별력·마스코트) · **Voca**(데이터 톤).

## 5. 'Toki' 의미 해설 (사용자 질문)

- Toki = 사전 단어 아님, **코인드 네임**. 의도한 3중 연상:
  1. **또**렷/또박/또랑 → "또"의 영문화(명확한 발음).
  2. **토끼(rabbit)** → 귀여운 마스코트 확장.
  3. **Talk + -i** → 말하기 친구 어감.
- 솔직 평가: 장점=짧음·식별력·마스코트성 / 주의=뜻이 자동 전달 안 됨(브랜드 스토리 동반 필요), 일본어 とき(時) 등 중의성·상표 충돌 확인 필요.

## 6. 영어 후보 2차 (추가 요청) — `Sori` 1순위

- **🏆 Sori** — 한국어 "소리(sound/목소리)" 그대로 → Toki와 달리 **뜻 자명**, 짧음·영문 자연스러움·한국 부모 100% 이해, SoundSprout 'Sound'와 직결.
- 보조: **Torang**(또랑 영문) · **Ssaki**(새싹) · **Dori**(도리도리 놀이·귀여움) · **Sayo/Voki**(말·음성) · **TalkSprout/PlayTalk/FirstWords/BrightTalk**(서술형).

## 7. 'Sori' 브랜드화/마스코트화 검토 (사용자 우려) — "괜찮다" 결론

- 사용자 우려: Sori 가 마음엔 들지만 추상명이라 브랜드/마스코트화 어렵지 않은가.
- **결론: 괜찮음.** 마스코트는 이름 글자 뜻에서 나올 필요 없음 — Duolingo(부엉이 Duo)·카카오(라이언)·토스 모두 추상명+별도 디자인 마스코트. 추상명은 오히려 설계 자유도.
- **🏆 추천 조합**: 브랜드 **"Sori" + 노래하는 작은 새(songbird) 마스코트** — 새소리=목소리 의미 연결, 유아 친화, 발음 테마 정합.
- 마스코트 방향 4: 노래하는 새 / 사운드 스프라이트(음파·말풍선) / 레터마크 페이스('o'=벌린 입) / 소리+새싹 결합(발음+성장).
- 편의(이름 내 생물) 꼭 원하면 변형 제시: Sorae, Chiri, Birdie+Sori.
