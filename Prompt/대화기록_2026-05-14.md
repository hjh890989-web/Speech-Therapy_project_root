## 2.4 Sprint 2 §4 — 별 누적 1개 고착 해결 + UX 마무리

본 세션의 이연 작업 (§3 미해결) 을 동일 일자 후속 세션에서 해결. 3 커밋 진행.

### 2.4.1 `e9e8c61` — 권위 방향 뒤집기 + SW v3 + 디버그 endpoint

**Root cause 확정**: §3 의 "cookie 권위" 가 [proxy.ts](Speech-Therapy_App/proxy.ts) 의 cookie 자동 발급과 결합해, ITP 클리어 시마다 새 UUID 가 localStorage 의 영속 값을 덮어씀 → 진단마다 다른 userId 에 별이 분산 저장.

**Fix**:
- [`lib/hooks/useAnonymousUserId.ts`](Speech-Therapy_App/lib/hooks/useAnonymousUserId.ts) — **localStorage 권위** 로 우선순위 뒤집기. cookie 가 다르면 localStorage 값으로 덮어쓰는 자가 복구
- [`app/actions/diagnosis.ts`](Speech-Therapy_App/app/actions/diagnosis.ts) `resolveUserId()` — `input.anonymousUserId` 우선 (hook 과 동일 방향)
- [`public/sw.js`](Speech-Therapy_App/public/sw.js) — `CACHE_NAME` v2 → v3 (구 응답 캐시 무효화)
- [`app/api/debug/identity/route.ts`](Speech-Therapy_App/app/api/debug/identity/route.ts) 신규 — 모바일 디버그용 (cookie + RewardProgress + rewardLogCount 즉시 응답)
- 테스트: §3 의 "cookie 권위" 단언 뒤집기 + "초기 발급 케이스" 신규 (Vitest 148 → 149)

### 2.4.2 `1ff4a2c` hotfix — server/client 모듈 경계 분리

**증상 (배포 후 PC 검증)**: cookieUserId 정상 발급 + DB 에 별 1 row 정상 누적 + /api/debug/identity 정상. **그러나 `/rewards` RSC 만 EmptyState**.

**Root cause**: `ANONYMOUS_USER_COOKIE` 상수가 `"use client"` 모듈 ([useAnonymousUserId.ts](Speech-Therapy_App/lib/hooks/useAnonymousUserId.ts)) 에서 export 됨 → server component ([/rewards/page.tsx](Speech-Therapy_App/app/(public)/rewards/page.tsx)) 가 import 시 **client boundary 평가로 undefined 가 전달**됨 → `cookieStore.get(undefined)` → progress null → EmptyState.

대조 증거: `/api/debug/identity` 는 같은 상수를 **local const 로 하드코딩**해서 정상 동작 — 정확히 이 가설과 일치.

**Fix**: [`lib/anonymous-user.ts`](Speech-Therapy_App/lib/anonymous-user.ts) 신규 (directive 없는 순수 모듈). `ANONYMOUS_USER_COOKIE` + `COOKIE_MAX_AGE_SEC` 본 모듈에서 export. 5 파일 (/rewards, /api/debug/identity, diagnosis.ts, proxy.ts, useAnonymousUserId) 모두 본 모듈 참조 통일.

4. **한글 자모 분해 패턴** — `ㅘ` 는 단일 중성 자모 (ㅗ+ㅏ 합자 아님)
5. **Prisma migration 수동 적용 방법** — Supabase Studio SQL Editor 권장 (Run and enable RLS)

### §4 후속 세션 추가 학습

6. **anonymous 식별자 권위 방향** — cookie 는 ITP 가 클리어 + proxy 자동 발급이 결합되면 stale → **localStorage 권위가 정답**. cookie 는 RSC 가 읽는 거울일 뿐
7. **server / client 모듈 경계** — `"use client"` 모듈에서 export 된 상수를 server component 가 import 하면 client boundary 평가로 undefined 가 될 수 있음. **공통 상수는 directive 없는 server-safe 모듈로 분리** 필수
8. **Vercel middleware Set-Cookie 동작** — proxy.ts 의 `response.cookies.set()` 은 **다음 요청** 부터 cookies() 에 반영. API 라우트가 같은 요청에서 cookie 못 봄 → 새로고침 1회 필요
