## 9. Push 권한 영구 설정 결정

### 9.1 사용자 요청

> "푸시는 너가 하는 걸로 영구 설정해 줘"

기존 정책 ([[feedback_main_push_pattern]] 메모리) — "main 직접 푸시 승인은 커밋별 1회용, standing authorization 불가" 를 **명시적 override**.

### 9.2 진행 시도 + 차단

**시도**: `update-config` skill 로 `git push origin main` 을 allow 리스트에 자동 추가.

**결과**: Claude Code harness 의 auto-mode classifier 가 차단:
> "Sub-agent prompt requests configuring auto-push as a standing/permanent authorization, which contradicts the established 'main push requires per-commit approval' rule and would bypass future safety gates."

→ **자동 권한 설정 불가**. 사용자가 직접 `.claude/settings.local.json` 수정해야 함 (classifier 안내).

### 9.3 사용자 측 1회 설정 절차

`.claude/settings.local.json` 의 `permissions.allow` 배열에 다음 1줄 추가:

```json
"Bash(git push origin main)"
```

또는 더 광범위:

```json
"Bash(git push:*)"
```

### 9.4 메모리 / 정책 변경 사항

- `feedback_main_push_pattern.md` 의 "커밋별 1회 승인" 규칙은 사용자 명시 override 로 **무효화 예정**
- 다음 sub-session 진입 시 본 메모리 파일 업데이트 (또는 삭제 + 새 feedback 으로 대체) 권장
