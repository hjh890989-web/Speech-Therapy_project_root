### 10.2 진단 — Stale Closure

`startAudioPhase` 의 `setTimeout` 콜백이 호출하는 `finishAudioPhase` 안의 `audioStatus === "recording"` 체크가 **stale closure**. setTimeout 시점의 `audioStatus` 가 콜백 실행 시점과 불일치 → `stopAudio()` 누락 → `handleSubmit` 의 fallback 이 9.66초 후 stop → duration 폭증.

### 10.3 Fix

```typescript
const finishAudioPhase = () => {
    if (audioTimeoutRef.current) {
      clearTimeout(audioTimeoutRef.current);
      audioTimeoutRef.current = null;
    }
    // stopAudio() 는 analyzerRef null 시 empty features 반환 (idempotent).
    // audioStatus 체크 시 setTimeout 콜백 stale closure 회피.
    acousticFeaturesRef.current = stopAudio();
    setAudioPhase("done");
};
```

### 20.4 진단 — FFT bin 분해능 본질 한계

```

```

- 117Hz 음 → bin 5 (107Hz) 또는 bin 6 (129Hz)
- "사자" 단음 발음 → 모든 frame 이 같은 bin 으로 정렬 → pitch_std = 0 자연스러움
- 파라미터 (sample interval / noise floor / silence) 조정으로는 본질 해결 불가
