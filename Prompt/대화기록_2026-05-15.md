### 6.2 적응 (원본 SEC-004 vs §E-1)

| 영역 | 원본 | §E-1 (본 세션) |
|---|---|---|
| Storage | Upstash Redis | **in-memory** `Map` (Hobby single instance) |
| 응답 | 429 + Retry-After | **graceful fallback** (SAFE_CUSHION_FALLBACK) |
| 알림 | Slack 80% 임계 | 미구현 (§E-2 이연) |

다중 인스턴스 안전성은 Sprint 4+ (Upstash Redis 어댑터로 교체).

### 6.3 산출물

| 파일 | 내용 |
|---|---|
| `lib/ratelimit.ts` (신규) | sliding window — 글로벌 RPM 14 + 사용자 일 50회 + `checkRateLimit` + `recordCall` + `RateLimitedError` |
| `lib/ai/gemini.ts` | `generateJson` / `generatePlainText` 에 `userId?` 옵션. 호출 전 check, 성공 후 record. `RateLimitedError` 재export |
| `app/actions/cushion.ts` | `row.userId` SELECT 추가 + `generatePlainText({ userId })` 전달 + `RateLimitedError` catch → `SAFE_CUSHION_FALLBACK` |
| `__tests__/lib/ratelimit.test.ts` (신규) | 11 케이스 — 초기 / RPM 한도 / sliding window 회복 / 부분 회복 / 사용자 일 / 24h 리셋 / Error / reset |

Vitest **203 → 214 (+11)**.

### 6.4 호출 측 graceful 처리

`generatePlainText` 의 catch:
```typescript
if (err instanceof RateLimitedError) {
  console.warn(`Gemini rate limited: ${err.reason} retry in ${err.retryAfterSec}s`);
  return SAFE_CUSHION_FALLBACK;
}
```

→ 사용자는 일반 안내 카피만 보임 (429 throw 없이).

## 13. Magic Link PKCE 핫픽스 — 코드 완료, 푸시 대기 (`fed9769`)

### 13.1 증상

`/login` → 이메일 입력 → 메일 클릭 시:

```
/login?error=PKCE%20code%20verifier%20not%20found%20in%20storage.
```

LoginForm 이 URL `?error=` 미렌더링 → 사용자에겐 빈 로그인 페이지로 보임 → 추적 어려움.

### 13.2 원인 분석

`exchangeCodeForSession` 가 cookie 에서 PKCE verifier 검출 못 함. DevTools 진단:
- cookies: `anonymous_user_id` 만 (sb-* 0개)
- localStorage: `anonymousUserId` 만 (sb-* 0개)

추정: `createBrowserClient(url, anonKey)` 옵션 미지정 → @supabase/ssr 0.10.3 기본 storage 가 PKCE verifier 를 localStorage 또는 다른 위치에 저장 → server.ts 의 cookies 어댑터로는 검출 불가.

### 13.3 해결

`client.ts` 에 명시적 cookies (getAll/setAll) 어댑터 추가 (server.ts 와 동일 패턴):
- `readAllCookies()` — `document.cookie` 파싱 → `{name, value}[]`
- `writeCookie()` — `samesite=lax` + `secure` (HTTPS) 기본 + path/maxAge/expires/domain 옵션 지원
- verifier + session 모두 cookie 통일 저장 → server callback 이 동일 cookie store 에서 검출 가능

### 13.4 검증

- ✅ tsc clean / lint clean / vitest 214/214 pass
- 🟡 로컬 커밋만 (`fed9769`) — **푸시 대기 중**
- 🟡 프로덕션 재검증 미진행 (rate limit 우려 + Google OAuth 트랙 우선)
