## 5. Sprint 3 §2 C — linguistic + STT confidence (`d793fbf`)

### 5.1 동기

Sprint 3 §1 의 linguistic-score 는 음절 일치도만. Web Speech API 의 **인식 자신도 (confidence)** 도 점수에 직접 반영하면 인식 환경 (잡음 / 발음 명료성) 차별화 가능.

### 5.2 설계

| 입력 | Sprint 3 §1 | **Sprint 3 §2 C** |
|---|---|---|
| 음절 일치도 | 100% | 50% (base) |
| STT confidence | 미사용 | 50% (신규) |

confidence null/undefined 시 (jsdom 또는 기존 데이터) → 기존 동작 (음절 100%) 폴백.

### 5.3 변경 파일

- `lib/schemas/diagnosis.ts` — `sttConfidence: number(0~1).nullable().optional()` 추가
- `lib/linguistic-score.ts` — 3번째 인자로 confidence 받음, NaN/out-of-range defensive
- `app/(public)/diagnose/DiagnosisForm.tsx` — `useSpeechRecognition.confidence` → `analyzeDiagnosis` 전달
- `app/actions/diagnosis.ts` — `input.sttConfidence` 를 `computeLinguisticScore` 에 전달
- `__tests__/lib/linguistic-score.test.ts` — 10 케이스 추가

Vitest **193 → 203 (+10)**.

### 5.4 점수 다양화 효과

| 시나리오 | confidence | 음절 일치 | linguistic |
|---|---|---|---|
| 정확 발화 + 깔끔 인식 | 0.95 | 100% | 98 |
| 정확 발화 + 잡음 (낮은 confidence) | 0.5 | 100% | 75 |
| 짧은 발화 | 0.9 | 50% | 70 |
| 잡음 + 짧음 | 0.4 | 50% | 45 |

= 동일 transcript 라도 인식 환경 따라 점수 변동.

## 6. Sprint 3 §2 E — SEC-004 Gemini rate limiter (`c732c2b`)

### 6.1 동기

`generateCushion` 이 유일하게 남은 Gemini 호출 진입점 (Sprint 2 §2 에서 `analyzeDiagnosis` Gemini 제거). 다음 보호 필요:
- Google 무료 RPM 15 (G5 가드레일)
- 사용자당 일 누적 비용 (REQ-NF-018 ≤ ₩5,250/월)

### 6.2 적응 (원본 SEC-004 vs §E-1)

| 영역 | 원본 | §E-1 (본 세션) |
|---|---|---|
| Storage | Upstash Redis | **in-memory** `Map` (Hobby single instance) |
| 응답 | 429 + Retry-After | **graceful fallback** (SAFE_CUSHION_FALLBACK) |
| 알림 | Slack 80% 임계 | 미구현 (§E-2 이연) |

다중 인스턴스 안전성은 Sprint 4+ (Upstash Redis 어댑터로 교체).

### 6.3 산출물

| 파일 | 내용 |
|---|---|
| `lib/ratelimit.ts` (신규) | sliding window — 글로벌 RPM 14 + 사용자 일 50회 + `checkRateLimit` + `recordCall` + `RateLimitedError` |
| `lib/ai/gemini.ts` | `generateJson` / `generatePlainText` 에 `userId?` 옵션. 호출 전 check, 성공 후 record. `RateLimitedError` 재export |
| `app/actions/cushion.ts` | `row.userId` SELECT 추가 + `generatePlainText({ userId })` 전달 + `RateLimitedError` catch → `SAFE_CUSHION_FALLBACK` |
| `__tests__/lib/ratelimit.test.ts` (신규) | 11 케이스 — 초기 / RPM 한도 / sliding window 회복 / 부분 회복 / 사용자 일 / 24h 리셋 / Error / reset |

Vitest **203 → 214 (+11)**.

### 6.4 호출 측 graceful 처리

`generatePlainText` 의 catch:
```typescript
if (err instanceof RateLimitedError) {
  console.warn(`Gemini rate limited: ${err.reason} retry in ${err.retryAfterSec}s`);
  return SAFE_CUSHION_FALLBACK;
}
```

→ 사용자는 일반 안내 카피만 보임 (429 throw 없이).
