### 16.1 발견 — bundle-analyze 가 build 깨짐 노출

`9bac2cf` Performance 2차로 셋업한 `npm run analyze` 첫 실행 시도가 **production build 자체가 깨져있음** 을 노출.
이전엔 `next dev` + vitest 통과로 가려져 있었음. 두 가지 root cause:

#### Root cause #1 — Client Component 가 Prisma transitively import

```
#4 [Client Component Browser]
   lib/db.ts → lib/notifications/preference.ts → NotificationPreferenceForm.tsx
#5 [Client Component SSR]
   lib/db.ts → lib/offline-entry/repo.ts → OfflineEntryForm.tsx
```

Client Component 가 상수/타입만 import 해도 ESM 그래프상 prisma 까지 끌려가
Turbopack chunking failure (`node:module` 외부 모듈 미지원).

#### Root cause #2 — `"use server"` 룰 위반 21건

Next.js 16 + Turbopack 의 strict 룰:
> `"use server"` 파일은 async function 외 export 금지 (const / type / interface / class 불허)

error trace 의 `at <unknown> (./app/actions/X.ts:N:1)` 의 line N 이 정확히
각 파일의 **첫 non-async export 위치** — 확정 근거.

21개 영향 파일: change-email / classroom-cushion / complete-parent-signup /
consent-sign / cushion-note / cushion / delete-account / disable-totp /
enroll-totp / export-user-data / mark-onboarding-completed / offline-entry /
onboarding-save-child / parent-invite / regenerate-backup-codes /
