## 1. 검사 개요

| 항목 | 내용 |
|---|---|
| 정식 명칭 | 영유아 언어발달 선별검사 (Sequenced Language Scale for Infants) |
| 개발자 | 김영태, 김경희, 윤혜련, 김화수 (2003) |
| 출판 | 서울장애인종합복지관 / 도서출판 특수교육 |
| 적용 연령 | **만 4개월 ~ 35개월** (4~35개월) |
| 검사 시간 | 약 10~15분 |
| 시행 방식 | **양육자 보고(parent report)** + 임상가 일부 직접 관찰 |
| 자격 | 언어재활사, 특수교사, 임상심리사 등 |
| 검사 성격 | **선별검사(Screening Test)** — 진단검사가 아님 |

**개발 배경의 의미**
SELSI는 **한국 최초의 영유아 대상 표준화 언어 선별검사**임. 그 이전까지 한국 임상에서는 만 2세 이상부터 적용 가능한 PRES, REVT 등이 주된 도구였고, **2세 미만 영유아의 언어발달 지연을 객관적으로 선별할 수 있는 표준화된 한국 도구가 부재**한 상태였음. SELSI는 4개월부터 35개월까지의 시기를 1~2개월 단위로 세밀하게 구간화하여, **조기 발견(early identification) → 조기 중재(early intervention)** 흐름을 가능하게 한 도구로서 임상적 의의가 큼.

**선별검사의 의미**
SELSI는 **진단검사가 아닌 선별검사**라는 점이 중요함. 즉, "이 아동이 언어발달지연 위험군인지 아닌지"를 빠르게 가려내는 1차 스크리닝 도구이며, **확진(diagnosis)을 위해서는 PRES, REVT, 자유발화 분석 등 진단검사로 후속 평가가 필요**함.

## 2. 검사 구조

### 2.1 전체 구성

SELSI는 **수용언어**와 **표현언어** 두 영역으로 구성됨.

```
SELSI
├─ 수용언어 영역 (56문항)
│   ├─ 인지 (의미·개념 이해)
│   ├─ 의미 (어휘·문장 이해)
│   ├─ 음운 (소리 변별·음성 반응)
│   └─ 구문·화용 (지시 따르기, 의도 이해)
│
└─ 표현언어 영역 (56문항)
    ├─ 인지 (의도적 의사소통)
    ├─ 의미 (어휘 산출, 문장 산출)
    ├─ 음운 (옹알이, 발성)
    └─ 구문·화용 (요구·거절·질문 등 의사소통 기능)
```

총 **112문항**이며, 수용/표현 각각 56문항으로 대칭 구조를 이룸.

### 2.2 발달 구간(연령대별 문항 배치)

SELSI의 핵심 설계 원리는 **4~35개월을 세밀하게 구간화**하여, 각 구간에 대표적인 발달 지표 문항을 배치한 것임.

| 발달 단계 | 대략적 연령 구간 | 주요 측정 지표 |
|---|---|---|
| 초기 영아기 | 4~9개월 | 소리 반응, 옹알이, 사회적 미소, 친숙한 사람 인식 |
| 후기 영아기 | 10~14개월 | 첫 단어, 간단한 지시 이해, 손짓·몸짓 사용 |
| 초기 유아기 | 15~20개월 | 어휘 폭발기, 두 단어 조합 시작, 간단한 질문 이해 |
| 중기 유아기 | 21~26개월 | 두세 단어 문장, 부정·의문 형태 출현, 일상 어휘 확장 |
| 후기 유아기 | 27~35개월 | 단순문 산출, 조사·어미 사용, 대화 주고받기 |

문항은 **연령이 올라갈수록 난이도가 점진적으로 상승**하며, 각 문항은 **해당 연령 또래 아동의 약 50~75%가 통과할 수 있는 수준**으로 설계됨.

### 2.3 영역별 평가 비중

수용/표현 각각 56문항이 다음 하위 영역에 분산됨.

| 하위 영역 | 측정 내용 | 비중 |
|---|---|---|
| 인지 | 사물 영속성, 의도성, 상징적 사고 등 의사소통의 인지적 기반 | 약 20% |
| 의미 | 어휘 이해/산출, 개념 형성 | 약 35% |
| 음운 | 소리 변별, 발성 패턴, 음운 산출 | 약 20% |
| 구문·화용 | 문장 이해/산출, 의사소통 기능, 대화 | 약 25% |

영유아기는 어휘·음운 영역의 비중이 상대적으로 높고, 구문·화용은 후기 구간(20개월 이후)에서 비중이 늘어나는 구조임.

## 3. 시행 절차 (실제 검사 흐름)

### 3.1 시행 방식의 특수성

SELSI는 다른 한국 언어검사(PRES, REVT)와 달리 **양육자 보고가 주된 자료원**임. 이유는

1. 영유아는 검사 상황에서 협조가 어렵고
2. 가정 환경에서의 자연스러운 언어 행동이 가장 정확한 정보이며
3. 영유아 발달은 일관성이 낮아 단일 시점 관찰로 판단하기 어렵기 때문.

따라서 임상가는 **양육자(주로 어머니)에게 각 문항을 읽어 주고, 아동이 그 행동을 평소에 보이는지 질문**하는 방식으로 진행함. 일부 문항은 임상가가 검사 상황에서 직접 관찰·시도해 확인하기도 함.

### 3.2 시작점(Start Point) 결정

SELSI는 **아동의 생활연령에 해당하는 구간보다 한 단계 아래**에서 시작하는 것이 일반적임.

- 예: 18개월 아동 → 14~15개월 구간 문항부터 시작
- 이는 기초선 확보를 안정적으로 하기 위한 보수적 접근

### 3.3 기초선과 최고한계선

- **기초선(Basal)**: 연속 8문항 통과 (이 아래 문항은 모두 통과로 간주)
- **최고한계선(Ceiling)**: 연속 8문항 실패 (이 위 문항은 모두 실패로 간주)

기초선과 최고한계선이 확보되면 검사를 중단함. 정확한 기준은 매뉴얼 우선.

### 3.4 시행 순서

일반적으로 **수용언어 → 표현언어** 순으로 시행함. 다만 SELSI는 양육자 보고 방식이라 두 영역을 교차 시행하거나 한꺼번에 질문 흐름으로 진행하는 것도 가능함.

### 3.5 사용 도구

- **SELSI 검사지**: 수용/표현 문항이 인쇄된 양식
- **매뉴얼(지침서)**: 시행·채점·해석 기준
- **연령별 환산표·규준표**: 등가연령·발달 수준 산출용
- **양육자 면담용 질문 가이드**: 문항을 일상 언어로 풀어 질문하기 위한 보조 자료

SELSI는 PRES·REVT와 달리 **그림 자극·실물 도구가 거의 필요 없음**. 양육자 보고 중심이기 때문.

### 3.6 문항 유형 (예시 수준)

각 문항이 측정하는 발달 지표 유형을 설명함 (실제 문항 표현은 저작권으로 보호되므로 일반적 유형만 제시).

**수용언어 문항 유형 예시**

- 초기 (4~9개월): 큰 소리에 놀라기, 친숙한 사람 목소리에 반응, 자기 이름에 반응
- 중기 (10~18개월): "안 돼"에 행동 멈추기, 익숙한 사물 이름 듣고 쳐다보기, 간단한 지시("이리 와") 따르기
- 후기 (19~35개월): 신체 부위 이름 듣고 가리키기, 두 단계 지시 따르기, 간단한 질문("어디 있어?") 이해

**표현언어 문항 유형 예시**

- 초기 (4~9개월): 옹알이, 다양한 발성, 의도적 발성으로 관심 끌기
- 중기 (10~18개월): 첫 단어 산출, 손짓·몸짓으로 의사 표현, 의미 있는 단어 5~10개 사용
- 후기 (19~35개월): 두 단어 조합("엄마 가"), 일상 어휘 폭발적 증가, 간단한 질문·요구 표현, 단순문 산출

### 3.7 양육자 면담 시 유의사항

SELSI의 신뢰도는 **양육자 보고의 정확성**에 크게 의존하므로, 임상가는 다음을 유의해야 함.

- 문항을 일상 언어로 쉽게 풀어 질문하기
- 양육자가 모호하게 답할 때는 **구체적 예시**를 요청 (예: "최근에 그런 모습을 본 게 언제였나요?")
- 양육자의 과대평가/과소평가 가능성 고려
- 의심 문항은 임상가가 검사 상황에서 직접 시도·관찰하여 교차 검증
- 다문화·다언어 가정의 경우 가정 내 사용 언어 확인

## 4. 채점 방식

### 4.1 문항별 채점

**+ / - / NO 3원 채점**이 일반적임 (정확한 표기는 매뉴얼 기준).

- **+ (통과)**: 아동이 해당 행동을 일관되게 보임
- **- (실패)**: 해당 행동을 보이지 않음
- **NO (관찰 기회 없음)**: 양육자가 판단 불가하거나 검사 상황에서 확인 불가

NO 처리 시에는 임상가가 직접 관찰을 시도하거나, 다음 회기로 미루어 재확인하는 것이 권장됨.

### 4.2 원점수 산출

수용/표현 각각의 통과 문항(+) 개수를 합산함.

```
수용언어 원점수 = 수용 통과 문항 수
표현언어 원점수 = 표현 통과 문항 수
```

기초선 이전 문항은 자동 통과 처리됨.

### 4.3 환산점수 종류

SELSI는 다음 환산점수를 제공함.

| 환산점수 | 설명 |
|---|---|
| **수용언어 등가연령** | 수용 원점수에 해당하는 평균적 연령 (개월) |
| **표현언어 등가연령** | 표현 원점수에 해당하는 평균적 연령 (개월) |
| **백분위(Percentile)** | 동일 연령 집단 내 상대적 위치 |
| **언어발달 수준 분류** | 정상 발달 / 약간 지연 / 언어발달 지연 |

### 4.4 진단 기준 (선별 기준)

SELSI는 선별검사이므로, 진단을 내리기보다는 **위험군(at-risk) 분류**를 목적으로 함.

| 분류 | 일반적 기준 | 의미 |
|---|---|---|
| **정상 발달** | -1SD 이내 또는 백분위 16%ile 이상 | 또래 평균 범위 내 발달 |
| **약간 지연** | -1 ~ -2SD 또는 백분위 약 2~16%ile | 모니터링 권장, 추후 재평가 |
| **언어발달 지연** | -2SD 이하 또는 백분위 2%ile 미만 | **진단검사로 정밀 평가 필요** |

**중요한 점**: SELSI 결과만으로 "언어발달장애"를 확진할 수 없음. SELSI에서 "언어발달 지연" 분류가 나오면, **PRES·REVT·자유발화 분석 등 진단검사로 후속 평가 진행**이 표준 절차임.

### 4.5 수용-표현 격차 해석

영유아기는 발달 변동성이 크지만, 다음 패턴은 임상적 의미를 가짐.

- **수용 = 표현 (둘 다 정상)**: 정상 발달
- **수용 정상 / 표현 지연**: **late talker** 가능성. 특히 24개월에 표현 어휘 50개 미만 또는 두 단어 조합 없는 경우 추적 필요
- **수용 지연 / 표현 지연**: 전반적 언어발달 지연 가능성. 청력·인지 평가 추가 권고
- **수용 지연 / 표현 정상**: 매우 드물며, 검사 신뢰도부터 점검

## 5. 결과 보고서 구성

SELSI 시행 후 작성되는 평가 보고서는 보통 다음 항목을 포함함.

```
1. 의뢰 정보 (Referral Info)
   - 아동 인적사항, 생활연령(개월), 의뢰 사유

2. 양육자 면담 정보
   - 출생력, 발달력 (운동·인지·사회성 발달)
   - 가정 언어 환경 (다문화·이중언어 여부, 주 양육자)
   - 양육자 우려 사항

3. 검사 시 행동 관찰
   - 임상가 직접 관찰 부분 (눈맞춤, 주의집중, 발성, 의사소통 의도)

4. 검사 결과 (정량 지표)
   - 수용언어 원점수 / 등가연령 / 백분위
   - 표현언어 원점수 / 등가연령 / 백분위
   - 언어발달 수준 분류
   - 수용-표현 격차

5. 영역별 분석 (정성 분석)
   - 인지·의미·음운·구문화용 영역별 강점/약점
   - 의사소통 기능(요구·거절·질문 등) 사용 양상
   - 발성·옹알이·첫 단어 등 발달 이정표 도달 여부

6. 진단적 결론
   - 정상 / 약간 지연 / 언어발달 지연 분류
   - 위험 요인 분석 (출생력, 가족력, 청력 등)

7. 권고사항
   - 진단검사 의뢰 필요 여부 (PRES, REVT 등)
   - 의료적 평가 필요성 (청력, 발달의학)
   - 부모교육·가정 자극 권고
   - 재평가 시점 (보통 3~6개월)
```

## 6. 트랙 2 초기 평가에서의 활용

### 6.1 SELSI의 임상적 위치

SELSI는 트랙 2 초기 상담·평가 단계에서 **2세 미만 영유아에게 가장 먼저 적용되는 표준화 도구**임. 트랙 2 흐름에서의 위치는 다음과 같음.

```
초기 상담 → SELSI(선별) → 결과에 따른 분기
                              │
                              ├─ 정상: 추적 관찰
                              ├─ 약간 지연: 부모교육 + 3~6개월 후 재평가
                              └─ 지연: 진단검사로 확장
                                       │
                                       ├─ PRES (24개월 이후 가능)
                                       ├─ M-B CDI-K (어휘 정밀 측정)
                                       ├─ K-Bayley/K-ASQ (전반적 발달)
                                       └─ 청력·발달의학 의뢰
```

### 6.2 다른 도구와의 보완 관계

| 영역 | 보완 도구 |
|---|---|
| 어휘 정밀 측정 (영유아) | M-B CDI-K (한국판 맥아더-베이츠 의사소통 발달 평가) |
| 종합 언어 (24개월 이후) | PRES |
| 어휘력 (30개월 이후) | REVT |
| 전반적 발달 | K-ASQ, K-Bayley, K-DST |
| 자폐 스펙트럼 의심 | M-CHAT-R, ADOS-2 |
| 청력 | 객관적 청력검사 (이비인후과) |

### 6.3 연령별 권장 평가 패키지

| 아동 연령 | 1차 도구 | 2차 도구 (지연 의심 시) |
|---|---|---|
| 4~17개월 | SELSI | M-B CDI-K, K-ASQ, 청력검사 |
| 18~23개월 | SELSI + M-B CDI-K | 자유발화 관찰, K-ASQ |
| 24~35개월 | SELSI 또는 PRES | PRES + REVT(30개월 이후) + 자유발화 |

24개월 이후는 SELSI와 PRES가 적용 연령이 겹치는데, 이 경우 **임상가 판단**으로 다음과 같이 선택하는 것이 일반적임.

- 양육자 보고 중심 빠른 선별이 필요할 때 → **SELSI**
- 직접 검사로 종합 언어 프로파일이 필요할 때 → **PRES**
- 둘 다 시행해 교차 검증할 때 → **SELSI + PRES 병행**

### 6.4 SELSI의 강점과 한계

**강점**

- **2세 미만 영유아 적용 가능** — 한국 표준화 검사 중 거의 유일한 영역 커버
- 양육자 보고 중심 → 시행 시간 짧고(10~15분) 아동 부담 없음
- 가정 환경의 자연스러운 언어 행동 반영
- 조기 발견·조기 중재의 진입점 역할
- 수용/표현 분리 측정으로 late talker 식별 가능

**한계**

- **선별검사이므로 진단 불가** — 후속 진단검사 필수
- 양육자 보고 신뢰도에 의존 (과대·과소 보고 가능성)
- 1995~2003년 표준화 자료라 규준 노후화 우려 존재
- 다문화·다언어 가정에서는 해석 주의 필요
- 청각장애·자폐스펙트럼 등 동반 장애 식별 기능은 제한적

---

## 7. 정리: 실무 관점에서의 핵심

트랙 2 초기 평가에서 SELSI를 활용할 계획이라면, 다음 세 가지를 의사결정 기준으로 잡으면 됨.

1. **SELSI는 "위험군 선별" 도구이지 진단 도구가 아니다.** "지연" 분류가 나오면 반드시 PRES·REVT 등 진단검사로 확장하라.
2. **양육자 보고의 신뢰도가 검사 결과의 신뢰도다.** 면담 시 구체적 예시 요청, 임상가 직접 관찰 병행으로 보고 신뢰도를 점검하라.
3. **수용-표현 격차 패턴이 조기 분기점**이다. late talker(수용 정상 / 표현 지연)와 전반적 지연(둘 다 지연)을 구분해 후속 경로를 다르게 설정하라.

---

## 8. 추가 탐색 방향

다음 주제들이 후속 정리 후보임.

- SELSI 결과를 부모교육·가정 자극 가이드로 연결하는 실무 흐름
- SELSI + M-B CDI-K 통합 해석 (영유아 어휘 평가 정밀화)
- late talker 추적 관리 프로토콜 (24개월 SELSI → 36개월 PRES 추적)
- SELSI에서 자폐 스펙트럼 위험 신호 포착하는 부가 관찰 지표
- 다문화·다언어 가정에서 SELSI 해석 가이드라인

## 부록 A. 검사 전 준비 체크리스트

### A-1. 의뢰·접수 단계

- [ ] 의뢰 사유 확인 (양육자 우려, 영유아검진 결과 등)
- [ ] 아동 생활연령 정확히 산출 (개월 수까지)
- [ ] 적용 연령(4~35개월) 범위 내 여부 확인
  - [ ] 4개월 미만 → 다른 발달검사(K-ASQ 등) 검토
  - [ ] 36개월 이상 → PRES 등 진단검사로 직행 검토
- [ ] 출생력 확인 (조산, 저체중, 출생 합병증)
- [ ] 발달력 확인 (운동·인지·사회성 이정표)
- [ ] 가족력 확인 (언어발달지연 가족력)
- [ ] 청력 관련 정보 확인 (영유아검진 청력 결과)
- [ ] 가정 언어 환경 확인 (다문화·이중언어 여부)
- [ ] 주 양육자 확인 (어머니/조부모/어린이집 등)

### A-2. 검사 환경 준비

- [ ] 양육자가 편안하게 대화할 수 있는 면담실
- [ ] 아동이 놀 수 있는 안전한 공간 (장난감, 매트)
- [ ] 양육자-아동 상호작용 관찰 가능한 배치
- [ ] 외부 소음 차단

### A-3. 검사 도구 준비

- [ ] SELSI 검사지 (수용/표현)
- [ ] SELSI 매뉴얼
- [ ] 연령별 환산표
- [ ] 양육자 면담용 질문 가이드
- [ ] 직접 관찰용 보조 도구 (장난감, 그림책, 공 등)
- [ ] 필기구
- [ ] 녹화·녹음 장비 (선택, 사전 동의 필수)

### A-4. 검사자 준비

- [ ] 매뉴얼 시행 절차 재숙지
- [ ] 발달 이정표(milestone) 재확인
- [ ] 양육자 면담 기술 점검 (개방형 질문, 구체적 예시 요청)
- [ ] 자폐·청각장애 위험 신호 관찰 포인트 사전 정리

## 부록 B. 검사 시행 체크리스트

### B-1. 양육자 라포 형성

- [ ] 검사 목적과 절차 양육자에게 명확히 안내
- [ ] **선별검사임을 명시** (진단검사가 아님)
- [ ] 양육자 우려 충분히 청취
- [ ] 양육자 긴장 완화

### B-2. 아동 관찰 (병행)

- [ ] 아동의 자발적 발성·옹알이 관찰
- [ ] 눈맞춤·공동주의(joint attention) 관찰
- [ ] 양육자-아동 상호작용 관찰
- [ ] 의사소통 의도(요구·거절·관심 끌기) 관찰
- [ ] 사회적 미소·반응 관찰
- [ ] 자폐 스펙트럼 위험 신호 관찰 (눈맞춤 부족, 호명 무반응, 반복 행동 등)

### B-3. 시작점 결정

- [ ] 아동 생활연령 기준 시작점 설정
- [ ] 보수적 접근 (한 단계 아래에서 시작)
- [ ] 매뉴얼 시작 문항 위치 확인

### B-4. 양육자 면담 진행

- [ ] 문항을 일상 언어로 풀어 질문
- [ ] 모호한 답변 시 구체적 예시 요청
  - [ ] "최근에 그런 모습을 본 게 언제였나요?"
  - [ ] "예를 들면 어떤 상황이었나요?"
- [ ] 통과/실패 판단 기준 명확히 적용
- [ ] NO(관찰 기회 없음) 문항 별도 표기
- [ ] 양육자 답변과 아동 실제 행동 일치 여부 점검

### B-5. 임상가 직접 관찰·시도

- [ ] 양육자 보고 의심 문항 직접 관찰 시도
- [ ] 일부 행동 유발 과제 시행 (호명 반응, 사물 가리키기 등)
- [ ] 직접 관찰 결과와 양육자 보고 비교

### B-6. 기초선·최고한계선 확보

- [ ] 기초선 (연속 8문항 통과 기준) 확보
- [ ] 미확보 시 한 단계 아래로 하향
- [ ] 최고한계선 (연속 8문항 실패 기준) 확보
- [ ] 확보 시점 기록지에 명시

### B-7. 검사 종료

- [ ] 모든 문항 반응 기록 확인
- [ ] NO 문항 후속 처리 계획 (다음 회기 재확인 등)
- [ ] 양육자에게 종료 안내
- [ ] 결과 해석은 별도 일정으로 안내 (즉석 해석 지양)

## 부록 F. 자주 놓치는 함정 체크리스트

SELSI 검사·해석 과정에서 임상가가 자주 놓치는 지점을 별도로 정리.

- [ ] 생활연령 산출 오류 (개월 수 계산 실수)
- [ ] 양육자 과대보고를 그대로 신뢰 (직접 관찰로 교차 검증 누락)
- [ ] 양육자 과소보고 가능성 미고려 (양육자 불안·우울 영향)
- [ ] 다문화·이중언어 가정 영향 미반영
- [ ] **선별검사를 진단으로 보고 (보고서에 "장애" 표현 사용 등)**
- [ ] 후속 진단검사 의뢰 누락 (지연 분류임에도 단순 모니터링만 권고)
- [ ] 청력 위험 신호 무시 (옹알이 감소, 호명 무반응 등)
- [ ] 자폐 스펙트럼 위험 신호 간과 (눈맞춤 부족, 공동주의 결여)
- [ ] 출생력·가족력 위험 요인 통합 분석 누락
- [ ] late talker(수용 정상 / 표현 지연)를 무조건 "정상 변이"로 해석
- [ ] 24개월 이후 SELSI만 시행하고 PRES 진단검사 생략
- [ ] NO 문항에 대한 후속 확인 절차 생략
- [ ] 양육자 정서 케어 없이 결과 통보
