## 0. 사전 확인: 두 가지 검사 구분

한국 임상에서는 표기가 비슷한 두 검사가 혼용되는 경우가 많아 먼저 구분이 필요함.

- **PRES (1995)**: 김영태·성태제·이윤경. 2~6세 대상. 원판.
- **SELSI (영유아 언어발달검사)**: 4~36개월. PRES와는 별개의 검사.
- 임상가들이 "PRES"라고 부를 때는 보통 **원판 PRES (1995, 학지사)** 를 의미함.

이하 설명은 원판 PRES를 기준으로 하되, 현재 임상 활용 시 유의점도 함께 정리함.

> **주의**: PRES의 구체적 검사 문항 자체는 저작권으로 보호되는 평가도구이므로, 본 문서에서는 **문항이 측정하는 능력·구성 원리·시행 절차·채점 방식**까지만 다룸. 이는 표준화 검사의 신뢰도를 보호하기 위한 일반적 원칙임.

## 1. 검사 개요

| 항목 | 내용 |
|---|---|
| 정식 명칭 | 취학전 아동의 수용언어 및 표현언어 발달척도 (Preschool Receptive-Expressive Language Scale) |
| 개발자 | 김영태, 성태제, 이윤경 (1995) |
| 출판 | 서울장애인종합복지관 |
| 적용 연령 | **만 2세 0개월 ~ 6세 11개월** (24~83개월) |
| 검사 시간 | 약 30~40분 |
| 시행 방식 | 1:1 개별 검사, 임상가 대면 시행 |
| 자격 | 언어재활사, 특수교사, 임상심리사 등 표준화 검사 시행 자격자 |

**개발 배경의 의미**
PRES는 1995년 한국에서 개발된 **최초의 학령전기 표준화 종합 언어검사**임. 그 이전까지는 미국 검사를 번안해 사용하다 보니 한국어 언어발달 특성(조사, 어순, 종결어미 등)이 반영되지 않는 한계가 있었고, PRES는 이를 한국 아동 규준으로 표준화했다는 점에서 임상적 의의가 큼.

## 2. 검사 구조

### 2.1 전체 구성

PRES는 **수용언어(RLA)** 와 **표현언어(ELA)** 두 영역으로 나뉨.

```
PRES
├─ 수용언어 영역 (45문항)
│   ├─ 인지개념·의미론
│   ├─ 음운·구문론
│   └─ 화용론
└─ 표현언어 영역 (45문항)
    ├─ 인지개념·의미론
    ├─ 음운·구문론
    └─ 화용론
```

총 **90문항**이며, 각 영역(수용/표현)은 다시 세 가지 언어학적 하위 영역을 교차하여 측정함.

### 2.2 영역별 평가 비중

PRES의 핵심 설계 원리는 **수용/표현을 동일한 문항 수로 대칭 구성**하면서, **각 문항이 의미·구문·화용 중 하나의 영역을 측정**하도록 한 것임. 음운 영역은 구문 영역과 결합되어 측정됨.

대략적 비중은 다음과 같음 (정확한 문항 수는 연령 구간에 따라 달라짐):

| 하위 영역 | 측정 내용 | 비중 |
|---|---|---|
| 인지개념·의미론 | 어휘 이해/표현, 개념 형성, 범주화, 관계어, 위치·시간·수량 개념 등 | 약 40% |
| 음운·구문론 | 문장 이해/산출, 조사·어미 활용, 문장 구조 복잡성, 음운 변별 | 약 40% |
| 화용론 | 의사소통 의도 이해/표현, 상황 맥락 이해, 대화 기능, 추론 | 약 20% |

화용 영역은 다른 두 영역보다 비중이 작은데, 이는 표준화 측정의 한계(상황적 변수 통제 어려움) 때문이며, 임상에서는 **PRES 화용 점수만으로 화용 능력을 단정하지 않고 자유발화 분석이나 다른 도구로 보완**하는 것이 일반적임.

## 3. 시행 절차 (실제 검사 흐름)

### 3.1 시작점 결정

PRES는 **연령에 따른 시작점(start point)** 이 정해져 있음. 검사를 1번 문항부터 시작하지 않고, 아동의 생활연령에 해당하는 구간에서 시작함.

- 예: 4세 0개월 아동이라면 4세에 해당하는 시작 문항부터 시행
- 시작점에서 **연속 3문항을 통과하지 못하면 한 단계 아래 연령 구간으로 내려가서** 기저선(basal)을 확보

### 3.2 기저선과 천장점

표준화 검사의 일반 원칙을 따름.

- **기저선(Basal)**: 연속 정답이 일정 개수 이상 나오는 지점. 이 아래 문항은 모두 정답으로 간주.
- **천장점(Ceiling)**: 연속 오답이 일정 개수 이상 나오는 지점. 이 위 문항은 모두 오답으로 간주.

이 방식 덕분에 90문항을 모두 시행하지 않고도 아동의 실제 능력 수준을 효율적으로 측정할 수 있음.

### 3.3 시행 순서

일반적으로 **수용언어 검사를 먼저, 표현언어 검사를 나중에** 시행함. 이유는

1. 수용 과제는 가리키기·고르기 등 비언어적 반응으로 가능해 부담이 적고
2. 아동이 검사 상황에 적응한 뒤 산출 과제(표현)에 들어가는 것이 라포 형성에 유리하기 때문.

### 3.4 사용 도구

- **검사 그림책 (자극 그림판)**: 각 문항에 대응하는 그림 자극 제시
- **검사 도구 세트**: 실물 장난감, 사물 모형 등 일부 문항에서 조작 과제용
- **검사 기록지**: 문항별 반응을 기록하는 프로토콜
- **지침서(매뉴얼)**: 시행·채점·해석 기준

### 3.5 문항 유형 (예시 수준)

각 문항이 어떤 능력을 측정하는지 **유형 단위**로 설명함 (실제 문항 표현은 아님).

**수용언어 문항 유형 예시**

- 어휘 이해: "○○를 가리켜 보세요" 형태로 그림에서 해당 사물·행동·속성을 가리키기
- 위치 개념: "○○ 위에/아래에 있는 것을 가리켜 보세요"
- 문장 이해: 두 자극 그림 중 들려준 문장에 맞는 그림 고르기 (예: 능동/피동, 부정문, 복문 이해)
- 지시 따르기: 단순 지시 → 복합 지시 → 순서 지시
- 추론·화용: 상황 그림을 보고 인과관계나 등장인물의 의도 이해

**표현언어 문항 유형 예시**

- 어휘 산출: 그림 보고 이름 말하기, 기능 묘사하기
- 문장 산출: 그림 보고 문장으로 설명하기, 문장 완성하기
- 문법 형태소: 조사·어미 적절히 사용하여 문장 만들기
- 이야기 산출: 짧은 그림 시퀀스 보고 사건 설명하기
- 화용 표현: 특정 상황에서 어떻게 말할지 답하기 (예: 거절, 요청, 사과 표현)

## 4. 채점 방식

### 4.1 문항별 채점

대부분 **0/1 이분 채점** (정답=1, 오답=0)임. 일부 표현 문항은 부분점수가 가능하지만 원판 PRES는 기본적으로 이분 채점 위주.

표현 문항 채점 시에는 **수용 가능한 반응의 범위**가 매뉴얼에 제시되어 있어, 아동의 다양한 표현이 정답으로 인정되는지 임상가가 매뉴얼을 참조하여 판단함.

### 4.2 원점수 → 환산점수

1. **원점수(Raw Score) 산출**: 수용/표현 각각의 정답 합산
2. **언어연령(Language Age) 산출**: 원점수를 환산표를 통해 개월 단위 언어연령으로 변환
   - 수용언어연령 (RLA, Receptive Language Age)
   - 표현언어연령 (ELA, Expressive Language Age)
   - 통합언어연령 (CLA, Combined Language Age)
3. **백분위(Percentile) 산출**: 생활연령 기준 또래 집단에서의 상대적 위치
4. **언어지수**: 일부 해석에서 (언어연령/생활연령) × 100 형태로 산출하기도 함

### 4.3 진단 기준

임상에서 일반적으로 사용하는 해석 기준임.

| 차이 (생활연령 - 언어연령) | 해석 |
|---|---|
| -6개월 이내 | 정상 발달 범위 |
| -6 ~ -12개월 | 약간 지연, 모니터링 필요 |
| -12 ~ -18개월 | 언어발달지연 의심, 중재 권고 |
| -18개월 이상 | 명확한 언어발달지연/장애 가능성, 중재 필수 |

또한 **수용-표현 점수 차이**도 중요한 임상 정보임.

- 수용 ≫ 표현: 표현언어 특정 지연 가능성 (예: 표현언어장애)
- 수용 = 표현 (둘 다 낮음): 전반적 언어발달지연
- 표현 > 수용: 드물지만 자폐스펙트럼·반향어 패턴 등을 의심해볼 단서

## 5. 결과 보고서 구성

PRES 시행 후 작성되는 평가 보고서는 보통 다음 항목을 포함함.

```
1. 의뢰 정보 (Referral Info)
   - 아동 인적사항, 생활연령, 의뢰 사유

2. 검사 시 행동 관찰
   - 라포 형성, 주의집중, 협조도, 반응 양상

3. 검사 결과 (정량 지표)
   - 수용언어연령(RLA): __개월
   - 표현언어연령(ELA): __개월
   - 통합언어연령(CLA): __개월
   - 백분위 점수
   - 생활연령 대비 차이

4. 영역별 분석 (정성 분석)
   - 의미론적 강점/약점
   - 구문·문법 특성
   - 화용 영역 관찰
   - 오반응 패턴 분석 (어떤 유형에서 일관되게 실패하는가)

5. 진단적 결론
   - 정상/경계선/지연/장애 분류
   - 수용-표현 프로파일 해석

6. 권고사항
   - 추가 평가 필요 여부 (조음, 청력, 인지 등)
   - 중재 방향
   - 재평가 시점
```

## 6. 트랙 2 초기 평가에서의 활용

### 6.1 PRES가 단독으로 충분한가

**결론부터: PRES만으로는 부족함.** PRES는 **종합 언어능력의 표준화된 정량 지표**를 제공하지만, 다음 영역은 별도 도구로 보완해야 함.

| 영역 | 보완 도구 (예시) |
|---|---|
| 어휘력 정밀 측정 | REVT (수용·표현 어휘력 검사) |
| 조음·음운 | U-TAP, APAC |
| 화용·자발화 | 자유발화 표본 분석 (MLU, TTR 등) |
| 사회적 의사소통 | CCC-2 한국판 등 |
| 영유아(2세 미만) | SELSI, M-B CDI-K |

### 6.2 일반적 평가 패키지

학령전 언어평가 트랙에서 흔히 사용되는 조합:

```
1차 스크리닝 → 2차 종합평가 → 3차 정밀평가
                    │
                    ├─ PRES (종합 언어)
                    ├─ REVT (어휘)
                    ├─ U-TAP/APAC (조음)
                    └─ 자유발화 분석 (화용·구문 정밀)
```

### 6.3 PRES의 임상적 강점과 한계

**강점**

- 한국 아동 규준 기반 표준화
- 수용-표현 대칭 구조로 프로파일 비교 용이
- 30~40분으로 시행 시간 적절
- 종합 언어 지수 제공

**한계**

- **규준 노후화**: 1995년 표준화 자료라 현재 아동의 언어환경(미디어 노출, 다문화 등) 변화를 반영하지 못함. 임상 현장에서 가장 많이 지적되는 부분.
- 화용 영역 측정의 표면성
- 일부 어휘·소재가 시대상과 맞지 않을 수 있음
- 6세 11개월까지만 적용 (학령기는 다른 검사 필요)

이 한계 때문에 최근 임상에서는 **PRES 결과를 절대적 기준이 아닌 참고 지표**로 보고, 다른 도구·자유발화 분석과 교차 검증하는 흐름이 강해지고 있음.

## 7. 정리: 실무 관점에서의 핵심

트랙 2 초기 평가에서 PRES를 활용할 계획이라면, 다음 세 가지를 의사결정 기준으로 잡으면 됨.

1. **PRES는 "종합 언어 프로파일"을 빠르게 잡는 도구**다. 어휘·조음·화용 정밀 측정은 별도 도구로 보완하라.
2. **수용-표현 점수 차이의 패턴 해석이 진단의 핵심**이다. 단일 점수보다 프로파일이 더 많은 정보를 준다.
3. **규준 노후화를 인지하고 해석하라**. 경계선 점수일 경우 다른 도구 결과와 교차 검증이 필수다.

## 8. 추가 탐색 방향

다음 주제들이 후속 정리 후보임.

- PRES 결과를 IEP/중재 계획서로 연결하는 실무 흐름
- PRES와 REVT, U-TAP을 함께 쓸 때의 통합 해석 방법
- PRES 대안·후속 검사들의 비교 (현재 임상에서 PRES를 대체하거나 보완하는 검사들)
- 자유발화 분석과 PRES 결과를 교차 검증하는 절차

# 부록: 단계별 체크리스트

> 실제 검사 시행과 해석 시 단계별로 확인해야 할 항목을 체크리스트로 정리함.
> 인쇄하거나 디지털로 체크해 가며 사용 가능.

---

## 부록 A. 검사 전 준비 체크리스트

### A-1. 의뢰·접수 단계

- [ ] 의뢰 사유 확인 (부모/교사/타기관 의뢰서 검토)
- [ ] 아동 생활연령 정확히 산출 (생년월일 기준 개월 수까지)
- [ ] 적용 연령(2;0 ~ 6;11) 범위 내 여부 확인
  - [ ] 24개월 미만 → SELSI/M-B CDI-K로 대체 검토
  - [ ] 7세 이상 → 학령기용 검사로 대체 검토
- [ ] 보호자 면담 자료 확보 (발달력, 가족력, 의료력)
- [ ] 청력검사 결과 확인 (없으면 청력 스크리닝 필요)
- [ ] 다문화·이중언어 배경 여부 확인 (해석 시 반영 필요)
- [ ] 사전 정보지/발달 체크리스트 수령

### A-2. 검사 환경 준비

- [ ] 조용하고 산만하지 않은 검사실 확보
- [ ] 아동용 책상·의자 (검사자와 마주 앉기 가능한 배치)
- [ ] 보호자 동석 여부 결정 (어린 아동은 동석 권장)
- [ ] 보호자 동석 시 개입 최소화에 대한 사전 안내
- [ ] 외부 소음·시각 자극 차단 확인

### A-3. 검사 도구 준비

- [ ] PRES 검사 그림책 (자극 그림판)
- [ ] PRES 검사 도구 세트 (실물 자극)
- [ ] PRES 매뉴얼(지침서)
- [ ] 검사 기록지 (수용/표현 각 1부)
- [ ] 환산표·규준표
- [ ] 필기구 (연필, 빨간펜)
- [ ] 초시계 (필요 시)
- [ ] 녹음기 (선택사항, 사전 동의 필수)
- [ ] 강화제·아동 친화 도구 (스티커, 간단한 보상물 등)

### A-4. 검사자 준비

- [ ] 매뉴얼 시행 절차 재숙지
- [ ] 시작점·기저선·천장점 규칙 재확인
- [ ] 표준 지시문 정확히 암기 (변형 금지)
- [ ] 채점 기준(매뉴얼상 수용 가능한 반응 범위) 사전 검토

---

## 부록 B. 검사 시행 체크리스트

### B-1. 라포 형성 단계 (시작 전 5~10분)

- [ ] 아동 이름 부르며 친근하게 인사
- [ ] 가벼운 대화로 긴장 완화 (검사 외 주제)
- [ ] 검사실·검사 도구에 대한 자연스러운 노출
- [ ] 아동의 컨디션 관찰 (피로·배고픔·졸림·불안)
- [ ] 컨디션 부적절 시 검사 연기 검토

### B-2. 시작점 결정

- [ ] 생활연령 기준 시작점 확인
- [ ] 매뉴얼 시작 문항 위치 확인
- [ ] 수용언어 검사부터 시행 (원칙)

### B-3. 시행 중 일반 원칙

- [ ] 표준 지시문 그대로 제시
- [ ] 동일 문항 반복 제시는 매뉴얼 허용 범위 내에서만
- [ ] 정답 여부 즉각 알려주지 않기 (일반 강화만)
- [ ] 아동 반응 즉시 기록 (메모리 의존 금지)
- [ ] 비전형 반응(무반응, 반향어, 회피 등) 별도 메모
- [ ] 행동 관찰 기록 병행 (주의집중, 충동성, 좌절 반응 등)

### B-4. 기저선 확보

- [ ] 시작점에서 연속 정답 기준 충족 여부 확인
- [ ] 미충족 시 한 단계 아래 연령 구간으로 하향
- [ ] 기저선 확보 시점 기록지에 명시

### B-5. 천장점 확인

- [ ] 연속 오답 기준 도달 시 검사 중단
- [ ] 천장점 확보 시점 기록지에 명시
- [ ] 중단 후 아동 정서 상태 확인 (좌절감 케어)

### B-6. 수용언어 → 표현언어 전환

- [ ] 수용언어 검사 완료 확인
- [ ] 짧은 휴식 제공 (필요 시)
- [ ] 표현언어 검사 시작점 결정
- [ ] 표현언어 검사 시행 (B-3~B-5 동일 적용)

### B-7. 검사 종료

- [ ] 모든 문항 반응 기록 확인
- [ ] 누락 문항·기록 오류 점검
- [ ] 아동에게 종료 알림 및 격려·강화
- [ ] 보호자에게 검사 종료 안내 (결과는 별도 일정으로 안내)

---

## 부록 C. 채점·해석 체크리스트

### C-1. 원점수 산출

- [ ] 수용언어 정답 개수 합산
- [ ] 표현언어 정답 개수 합산
- [ ] 기저선 이하 문항 자동 정답 처리 확인
- [ ] 천장점 이상 문항 자동 오답 처리 확인
- [ ] 채점 의문 문항은 매뉴얼 재확인 후 확정

### C-2. 환산점수 산출

- [ ] 수용언어연령(RLA) 환산표 적용
- [ ] 표현언어연령(ELA) 환산표 적용
- [ ] 통합언어연령(CLA) 산출
- [ ] 백분위 점수 산출
- [ ] 언어지수 산출 (필요 시)

### C-3. 진단적 해석

- [ ] 생활연령 - 언어연령 차이 계산
- [ ] 진단 기준표(±6/12/18개월)에 따른 분류
- [ ] 수용-표현 프로파일 패턴 분석
  - [ ] 수용 ≫ 표현 (표현 특정 지연?)
  - [ ] 수용 = 표현 둘 다 저하 (전반적 지연?)
  - [ ] 표현 > 수용 (자폐 스펙트럼·반향어 의심?)
- [ ] 하위 영역(의미·구문·화용) 강점/약점 분석
- [ ] 오반응 패턴 분석 (특정 유형 반복 실패 여부)

### C-4. 행동 관찰 통합

- [ ] 검사 중 주의집중 수준 기록
- [ ] 협조도·동기 수준 기록
- [ ] 점수 신뢰도 평가 (협조 부족 시 점수 보수적 해석)
- [ ] 비전형 행동(반향어, 회피, 충동성) 결과 해석에 반영

### C-5. 교차 검증

- [ ] 보호자 면담 정보와 검사 결과 일관성 확인
- [ ] 다른 검사(REVT, U-TAP, 자발화 등) 결과와 비교
- [ ] 불일치 시 원인 분석 (도구 한계 vs 검사 상황 변수)
- [ ] 규준 노후화 영향 가능성 검토 (특히 경계선 점수)

## 부록 D. 보고서 작성 체크리스트

### D-1. 필수 포함 항목

- [ ] 의뢰 정보 (성명, 생년월일, 생활연령, 검사일, 의뢰 사유)
- [ ] 검사자 정보 및 자격
- [ ] 검사 시 행동 관찰
- [ ] 정량 지표 (RLA, ELA, CLA, 백분위, 차이)
- [ ] 영역별 정성 분석
- [ ] 진단적 결론
- [ ] 권고사항
- [ ] 재평가 시점 권고

### D-2. 작성 시 점검

- [ ] 전문용어와 일반 설명 균형 (보호자 가독성)
- [ ] 단정적 표현 지양 (특히 경계선 사례)
- [ ] PRES 결과를 절대 기준으로 제시하지 않기
- [ ] 보완 평가 필요성 명시
- [ ] 강점도 함께 기술 (약점만 나열 지양)
- [ ] 개입 방향성 구체적으로 제시

### D-3. 권고사항 항목별 점검

- [ ] 추가 평가 필요 여부 (청력, 인지, 조음, 화용 등)
- [ ] 의료적 의뢰 필요 여부 (이비인후과, 발달의학, 신경과 등)
- [ ] 중재 시작 권고 (시기, 빈도, 형태)
- [ ] 가정 내 언어 자극 권고
- [ ] 어린이집/유치원 협력 권고
- [ ] 재평가 시점 (보통 6개월~1년)

## 부록 E. 결과 피드백(보호자 상담) 체크리스트

### E-1. 상담 사전 준비

- [ ] 보호자 수준에 맞는 용어로 결과 재구성
- [ ] 시각 자료 준비 (그래프, 발달 지표 비교 등)
- [ ] 예상 질문·우려에 대한 답변 준비
- [ ] 다음 단계(추가 평가·중재) 옵션 정리

### E-2. 상담 중 점검

- [ ] 검사 결과를 구체적 숫자만이 아닌 발달 의미로 설명
- [ ] 보호자 정서적 반응 관찰 및 케어
- [ ] 일방 통보 아닌 대화형 진행
- [ ] 보호자 관찰·우려와 검사 결과 연결
- [ ] 강점과 약점을 균형 있게 전달
- [ ] 중재 가능성과 예후에 대해 현실적 안내

### E-3. 상담 후 후속 조치

- [ ] 보고서 사본 전달 (요청 시)
- [ ] 다음 일정 확정 (재평가, 중재 시작 등)
- [ ] 필요 시 타기관 연계 의뢰서 작성
- [ ] 보호자가 추가 질문할 수 있는 채널 안내

## 부록 F. 자주 놓치는 함정 체크리스트

검사·해석 과정에서 임상가가 자주 놓치는 지점을 별도로 정리.

- [ ] 생활연령 산출 오류 (개월 수 계산 실수)
- [ ] 표준 지시문 임의 변형
- [ ] 정답 단서 비의도적 제공 (시선·표정·강조)
- [ ] 비전형 반응을 단순 오답 처리 (반향어·회피 등은 별도 의미)
- [ ] 협조 부족 사례에서 점수 그대로 해석
- [ ] 다문화·이중언어 배경 미반영
- [ ] 규준 노후화 영향 무시
- [ ] PRES 단독 결과로 진단 단정
- [ ] 수용-표현 격차 패턴 분석 누락
- [ ] 보호자 면담 정보와 검사 결과 교차 검증 생략
