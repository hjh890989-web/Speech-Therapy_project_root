## Executive Summary

> **결론**: 본 사업은 Unit Economics 관점에서 **조건부 Medium-High 매력도**를 가진다.
> 핵심 조건: `LTV ≥ CAC × 3` + `M3 유지율 ≥ 40%` + `전문가 1인당 커버리지 ≥ 200가정`

| 보강 영역 | 기존 판단 | 보강 판단 |
|:----------|:---------|:---------|
| 대체재 위협 | "매우 높음" (정성) | 대체재 사용률 70~80% → 유료 전환 가능 풀은 TAM의 20~30% |
| 구매자 협상력 | "높음" (정성) | CAC 5~8만원, 예상 LTV 36~72만원 → LTV:CAC = 4.5~9.0x (조건 충족 시) |
| 공급자 협상력 | "중간" (정성) | 전문가 총 ~17,000명, 확보 가능 풀 ~500명 → AI 레버리지 필수 |
| 산업 매력도 | "중간~높음" (정성) | **Medium-High** (수익성·확장성 조건부 충족) |

## 1. 대체재 위협 — 정량화

### 1.1 대체재별 사용 구조 추정

| 대체재 | 예상 사용 비율 | 유료 전환율 | 평균 사용 지속 기간 | 전환 트리거 |
|:-------|:-------------:|:----------:|:------------------:|:-----------|
| 부모 직접 교육 | 40~50% | 5~8% | 지속적 (포기 전까지) | 발달 지연 인지, 또래 비교 불안 |
| 유튜브/무료 콘텐츠 | 25~35% | 3~5% | 2~4주 (비체계적) | 효과 미확인에 대한 불안감 |
| 일반 유아교육 프로그램 | 15~20% | 8~12% | 6~12개월 (구독 기반) | 언어 특화 니즈 미충족 |
| 오프라인 센터/방문 | 5~10% | 15~20% | 3~6개월 | 비용·접근성 부담 |

> **산출 근거**: 유아 사교육 참여율 47.6%(통계청 2024), 교육 앱 D30 리텐션 ~2%(BusinessOfApps), 유아교육 앱 무료→유료 전환율 3~5%(업계 벤치마크)

### 1.2 핵심 질문에 대한 답변

**Q1: 무료/직접 교육이 실제로 얼마나 시장을 잠식하는가?**

| 지표 | 수치 | 시사점 |
|:-----|:----:|:------|
| 대체재 사용 비율 합계 | 70~80% | TAM의 대부분이 대체재에 의해 흡수 |
| 유료 전환 가능 풀 | TAM의 **20~30%** | 전체 타깃 중 실질 SAM |
| 전환 불가능 풀 | TAM의 70~80% | 가격 의지 없음 or 니즈 미인지 |

**Q2: 어떤 조건에서 유료 전환이 발생하는가?**

```
전환 조건 공식:
유료 전환 = f(불안 인지 × 효과 체감 × 접근 편의 × 가격 수용)

구체 조건:
① 부모가 "우리 아이 발달이 또래보다 느리다"를 인지 (불안 트리거)
② 무료 진단 후 객관적 발달 수준 리포트 수령 (효과 체감)
③ 앱으로 즉시 시작 가능 (접근 편의)
④ 월 3~5만원 수준 가격대 (사교육비의 10~15%) (가격 수용)

→ 4개 조건 중 3개 이상 충족 시 전환 확률 급상승
```

### 1.3 대체재 위협 재정의

> **기존**: "대체재 위협이 매우 높다" (감 기반)
> **보강**: 대체재 사용률 70~80%이나, **전환 트리거(발달 불안 인지)가 작동하면 유료 전환율 8~15%까지 상승 가능**. 핵심은 트리거를 인위적으로 작동시킬 수 있는 "무료 진단" 기능의 설계.

## 2. 구매자 협상력 — Unit Economics 기반 재정의

### 2.1 핵심 가정 (B2C 기준)

| 지표 | 보수적 | 기본 | 낙관적 | 산출 근거 |
|:-----|:------:|:----:|:------:|:---------|
| **월 구독료** | 29,900원 | 39,900원 | 49,900원 | 사교육비 33.2만원의 10~15% |
| **CAC** | 80,000원 | 60,000원 | 50,000원 | 교육앱 벤치마크 + 맘카페 마케팅 |
| **무료→유료 전환율** | 5% | 8% | 12% | 교육앱 벤치마크 3~5% + 진단 부스트 |
| **월간 이탈률(Churn)** | 10% | 7.4% | 5% | 교육앱 평균 7.4% |
| **평균 구독 기간** | 10개월 | 13.5개월 | 20개월 | 1/Churn |
| **LTV** | 299,000원 | 538,650원 | 998,000원 | 구독료 × 평균 기간 |
| **LTV:CAC** | 3.7x | 9.0x | 20.0x | — |

### 2.2 고객 행동 가설

**언제 구매하는가? (전환 퍼널)**

```
[인지] 맘카페 후기/검색 → [관심] 앱 다운로드 → [체험] 무료 진단
→ [충격] "우리 아이 발음 정확도 62%" → [구매] 유료 구독 시작

핵심 전환 지점: 무료 진단 결과 리포트 수령 직후 (D0~D3)
예상 전환 집중 시점: 체험 후 72시간 이내 (60%), 7일 이내 (25%), 이후 (15%)
```

**언제 이탈하는가? (이탈 퍼널)**

| 이탈 시점 | 비율 | 사유 | 대응 |
|:---------|:----:|:-----|:-----|
| **D7 이내** | 30~40% | 아이 흥미 부족, UI 불편 | 온보딩 개선, 캐릭터/게임화 |
| **M1~M2** | 20~25% | 효과 미체감 | 주간 발달 리포트, 마일스톤 알림 |
| **M3~M6** | 15~20% | 콘텐츠 소진, 관성 이탈 | 신규 콘텐츠 업데이트, 전문가 코칭 |
| **M6 이후** | 5~10% | 아이 성장으로 졸업 | 상위 프로그램 업셀, B2B 전환 |

### 2.3 LTV > CAC 구조 성립 판단

| 시나리오 | LTV:CAC | 판단 | 비고 |
|:---------|:-------:|:----:|:-----|
| 보수적 | 3.7x | ✅ 최소 기준 충족 | M3 유지율 30% 이상 필요 |
| 기본 | 9.0x | ✅ 건강한 구조 | M3 유지율 40% 이상 필요 |
| 낙관적 | 20.0x | ✅ 매우 우수 | M3 유지율 50% 이상 필요 |

> **판단**: LTV > CAC × 3 구조는 **M3 유지율 ≥ 30%** 조건에서 성립. 교육앱 평균 D30 리텐션 2~3%를 감안하면, **차별화된 리텐션 전략 없이는 구조 붕괴 위험**

### 2.4 리텐션 브레이크 포인트

```
[위험 임계값]
M1 유지율 < 50% → 옐로우 플래그 (온보딩 재설계 필요)
M3 유지율 < 30% → 레드 플래그 (사업 모델 재검토)
M6 유지율 < 15% → 사업 실패 구간 (LTV:CAC < 3x 진입)
```

| **확보 가능 풀** | **~500~1,000명** | 활동 인원 × 참여 의향 |

### 3.2 비용 구조

| 투입 형태 | 단가 (추정) | 월 비용 구조 |
|:----------|:----------:|:------------|
| 전문가 자문/콘텐츠 감수 | 시간당 5~10만원 | 고정비 (월 300~500만원, 5인 기준) |
| 전문가 1:1 화상 코칭 (30분) | 건당 3~5만원 | 변동비 (사용자 수 비례) |
| AI 음성 분석 API | 호출당 10~50원 | 변동비 (극히 낮음) |
| 콘텐츠 제작 (영상/인터랙티브) | 건당 50~200만원 | 초기 투자 + 월 업데이트 |

### 3.3 확장 시 병목 시뮬레이션

| 사용자 규모 | 전문가 코칭 모델 | 필요 전문가 수 | 병목 여부 |
|:-----------|:---------------|:-------------:|:---------:|
| 1,000가정 | 월 1회 × 30분 | 5~10명 | ✅ 가능 |
| 5,000가정 | 월 1회 × 30분 | 25~50명 | ⚠️ 주의 |
| 10,000가정 | 월 1회 × 30분 | 50~100명 | ⚠️ 주의 |
| 50,000가정 | 월 1회 × 30분 | 250~500명 | ❌ 병목 |
| 100,000가정 | 월 1회 × 30분 | 500~1,000명 | ❌ 심각 |

### 3.4 핵심 판단: "전문가 의존형" vs "기술 스케일형"

| 모델 | 확장성 | 신뢰도 | 비용 구조 | 판단 |
|:-----|:------:|:------:|:---------:|:-----|
| **A. 전문가 의존형** (센터 복제) | ❌ 낮음 | ✅ 높음 | 변동비 비례 증가 | 5,000가정 이상에서 병목 |
| **B. 순수 기술형** (AI Only) | ✅ 높음 | ❌ 낮음 | 고정비 중심 | 부모 신뢰 확보 실패 리스크 |
| **C. 하이브리드형** ⭐ | ⭐ 중-높음 | ⭐ 중-높음 | 혼합 | **최적 모델** |

**하이브리드 모델 설계 공식**:

```
서비스 구성 = AI 일상 학습 (95%) + 전문가 개입 (5%)

전문가 개입 포인트:
① 최초 진단 리포트 해석 (1회, 15분)
② 월간 발달 리포트 코멘트 (비동기, 텍스트)
③ 분기 1회 화상 상담 (30분)

→ 전문가 1인당 커버리지: 150~250가정/월
→ 10만 가정 도달 시 필요 전문가: 400~670명 (확보 가능 풀 내)
```

> **판단**: 하이브리드 모델 채택 시 **10만 가정까지 확장 가능**. 단, 전문가 개입을 "비동기 텍스트 코멘트" 중심으로 설계해야 병목 회피 가능.

## 5. 핵심 리스크 3가지 (정량 기반)

### Risk #1: 리텐션 붕괴

| 지표 | 위험 임계값 | 발생 시 결과 |
|:-----|:----------|:------------|
| M1 유지율 | < 50% | CAC 회수 불가, 마케팅 비용 소실 |
| M3 유지율 | < 30% | LTV:CAC < 3x, 사업 모델 비성립 |
| M6 유지율 | < 15% | 사업 실패 |

**검증 방법**: 파일럿 100가정 → M1/M3/M6 유지율 실측 → Go/No-Go 판단

### Risk #2: 전환율 부진

| 지표 | 위험 임계값 | 발생 시 결과 |
|:-----|:----------|:------------|
| 무료 진단 완료율 | < 30% | 전환 퍼널 붕괴 |
| 진단→유료 전환율 | < 5% | CAC 급등, 수익 모델 비성립 |
| 체험→구독 전환 소요일 | > 14일 | 이탈 확률 급증 |

**검증 방법**: A/B 테스트 — 진단 리포트 제공 여부에 따른 전환율 차이 측정

### Risk #3: 전문가 수급 실패

| 지표 | 위험 임계값 | 발생 시 결과 |
|:-----|:----------|:------------|
| 전문가 확보 수 | 사용자/200 미만 | 서비스 품질 저하, 코칭 대기 발생 |
| 전문가 이탈률 | > 20%/분기 | 서비스 안정성 붕괴 |
| 전문가 1인당 부담 | > 300가정/월 | 번아웃, 품질 저하 |

**검증 방법**: 전문가 10인 파일럿 → 만족도·지속 의향 측정 → 확장 모델 설계

## 6. 핵심 성공 방정식

### 6.1 필수 조건식 (AND 조건)

```
┌─────────────────────────────────────────────────────┐
│              성공 방정식 (Success Equation)            │
├─────────────────────────────────────────────────────┤
│                                                     │
│  조건 1:  LTV  ≥  CAC × 3                           │
│           (538,650원 ≥ 60,000원 × 3 = 180,000원) ✅  │
│                                                     │
│  조건 2:  M3 유지율  ≥  40%                          │
│           (교육앱 평균 대비 약 15x 초과 달성 필요)       │
│                                                     │
│  조건 3:  무료→유료 전환율  ≥  8%                     │
│           (진단 리포트 부스트 효과 전제)                 │
│                                                     │
│  조건 4:  전문가 커버리지  ≥  200가정/인               │
│           (하이브리드 모델 필수)                        │
│                                                     │
│  조건 5:  월간 이탈률  ≤  7.4%                        │
│           (교육앱 평균 이하 유지)                       │
│                                                     │
│  → 5개 조건 중 4개 이상 충족 시 = 사업 성립             │
│  → 조건 1,2 미충족 시 = 즉시 사업 중단 검토            │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 6.2 최소 생존 조건 (Minimum Viable Business)

```
MVB 공식:

유료 사용자  ≥  3,000가정
× 월 ARPU   ≥  29,900원
× M3 유지율  ≥  30%
= 월 매출    ≥  약 9,000만원
- 고정비     ≤  약 6,000만원 (인건비 + 인프라 + 전문가)
= 월 영업이익 ≥  약 3,000만원

→ 손익분기 달성 시점: 런칭 후 12~18개월 (기본 시나리오)
```

### 6.3 Go/No-Go 판단 기준 (파일럿 후)

| 판단 | 조건 |
|:-----|:-----|
| ✅ **GO** | M3 유지율 ≥ 40% AND 전환율 ≥ 8% AND NPS ≥ 60 |
| ⚠️ **PIVOT** | M3 유지율 30~40% OR 전환율 5~8% | 
| ❌ **NO-GO** | M3 유지율 < 30% OR 전환율 < 5% OR NPS < 40 |

## 7. 실행 시사점 요약

| 영역 | 기존 시사점 | 보강 시사점 |
|:-----|:----------|:----------|
| **대체재 대응** | "차별화 필요" | 무료 진단으로 전환 트리거 설계 → 전환율 8%+ 달성 |
| **구매자 관리** | "효과 보여줘야 함" | M3 유지율 40% 이상을 KPI로 설정, 주간 리포트로 효과 가시화 |
| **공급자 관리** | "전문가 확보 필요" | 비동기 코칭 중심 하이브리드 모델, 전문가 1인당 200가정 커버리지 |
| **수익 구조** | "구독 모델" | 월 3~5만원, LTV:CAC ≥ 3x 검증 후 스케일업 |
| **검증 순서** | "MVP → 마케팅" | 100가정 파일럿 → M3 유지율·전환율 실측 → Go/No-Go |
