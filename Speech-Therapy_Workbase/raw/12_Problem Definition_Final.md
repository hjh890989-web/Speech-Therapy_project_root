# 1. 산업과 시장영역 분석

**한국 온라인 영유아 언어발달·발음교정 교육 서비스 시장**에 대한 분석 결과, 이 영역은 다음과 같다.

---

### 1) 기초 리서치 — 시장의 본질

이 시장은 **'전문가 독점 서비스의 대중화 전환기'** 에 있다.

과거 심리상담(→Talkspace), 법률자문(→로톡), 피트니스(→Noom) 시장이 걸어온 경로와 동일한 패턴이 나타나고 있다. 전문가(언어재활사)만 할 수 있다고 여겨지던 서비스의 80%가, 실은 정보·도구·데이터만 있으면 부모가 가정에서 직접 수행할 수 있는 활동이다. 실제 사설 센터 세션의 핵심은 아이를 직접 가르치는 것이 아니라, **부모에게 "이렇게 말을 걸어보세요"라고 코칭**하는 것이다.

| 팩트 | 수치 | 의미 |
|:-----|:-----|:-----|
| 센터 대기 기간 | 3~6개월 | **대기 중 부모의 불안** = 우리 서비스의 시장 |
| 센터 비용 | 회당 3~6만원 (월 12~24만원) | 앱 구독 월 3~5만원이면 가격 경쟁력 확보 |
| 무료 대체재 사용률 | 70~80% (유튜브, 맘카페) | 최대 리스크이자 최대 기회. 이 부모는 "관심은 있지만 체계적 해법을 못 찾은" 잠재 고객 |
| 언어재활사 1급 합격률 | 17% | 전문가 풀이 구조적으로 부족. 앱의 확장성이 유일한 해법 |
| 교육 앱 D30 리텐션 | 2~3% | 우리는 40%가 필요. **리텐션이 사업의 생사를 결정** |
| 실질 TAM (비의료 교육 앱) | 연 1,080~1,800억원 | 전체 언어재활 시장이 아닌, "교육 앱"으로 좁히면 이 규모 |

---

### 2) Porter 분석 — 지금 이 순간의 기회 구조

경쟁도가 **구조적으로 낮고**(B2C 교육 리더 부재), 브랜드 충성도는 **사실상 제로**이며, 다음과 같은 비대칭 구조가 존재한다.

| Force | 강도 | 핵심 판단 |
|:------|:----:|:---------|
| **기존 경쟁** | 중 | 8개 기업이 활동하지만, "교육" 포지션에서 싸우는 기업은 **사실상 0개**. 전쟁터가 비어 있음 |
| **대체재** | ★★★★★ | 유튜브 70~80%. 그러나 유튜브는 개인화 없고 효과 추적 불가. "점수"를 줄 수 없음 |
| **구매자(부모)** | ★★★★ | "효과 없으면 즉시 삭제." 유일한 Lock-in은 축적된 발달 데이터 |
| **공급자(전문가)** | ★★★★ | 구조적 희소. 비동기 코칭(1인 200가정)으로 병목 관리 가능 |
| **진입 장벽** | 중~높 | 아동 음성 AI + 임상 검증. 데이터 축적이 진짜 해자(Moat) |

**핵심 발견**: 경쟁사 대부분(네오폰스, 두부, 송앤스타크)이 DTx 인허가에 2~3년 리소스를 묶고 있다. 이 규제가 경쟁사 시선을 "의료" 방향으로 고정하는 동안, **"교육" 방향의 B2C 카테고리 리더십은 18~24개월간 비어 있다.** 이것이 유일한 타이밍 근거이며, 이 윈도우를 놓치면 기회는 사라진다.

### 3) Value Chain 분석 — 돈이 되는 구간

핵심 가치 활동은 **2개**다. 나머지는 이 2개를 지탱하는 보조 활동이다.

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [핵심 #1]                        [핵심 #2]
  무료 AI 진단                      연속 발달 리포트
  ───────────                      ─────────────
  "우리 아이 62점"                   "이번 주 62→71점"
  → 불안에 이름을 붙여줌              → 효과를 눈으로 보여줌
  → 유일한 고객 유입 엔진             → 유일한 고객 유지 엔진

      ↓ 전환                            ↑ 유지

         [보조] 맞춤 AI 커리큘럼
         [보조] 비동기 전문가 코멘트

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

| 구간 | 현재 시장 상태 | 전략적 의미 |
|:-----|:-------------|:-----------|
| **무료 AI 진단** | 송앤스타크가 B2B로만 제공. B2C 무료 진단 부재 | 진단→교육 밸류체인 단절이 최대 기회 |
| **연속 발달 리포트** | 제공 기업 **0개**. 1회성 진단만 존재 | 경쟁사 대비 가장 명확한 차별점 |
| 맞춤 커리큘럼 | 에이치투케이가 한글 특화로 부분 제공 | 필요하지만 차별화 요소는 아님 |
| 전문가 코칭 | 전체 시장 미개척 (비동기 모델) | 신뢰 보조 수단. 비용이지 수익이 아님 |

# 2. 해결하고자 하는 문제

---

### 누구의 문제인가

> **자녀(만 2~7세)의 말이 또래보다 늦는 것 같아 불안하지만, 센터에 갈 정도인지 판단이 안 서거나, 센터 치료를 결정했지만 대기 중인 부모.**

"센터 가기엔 이른 것 같고, 그냥 두기엔 불안한" 회색지대의 부모와, "센터 예약을 걸어두고 불안 속에 몇 달을 기다리는" 대기자 부모 **연 30~50만 가구**.

이 부모의 심리 상태는 단순한 불편이 아니다. **'좋은 부모가 되지 못하고 있다'는 죄책감과 무력감의 혼합물**이다. 이것을 이해하지 못하면, 기능만 좋은 앱을 만들고 왜 안 팔리는지 모르게 된다.

---

### 어떤 상황에서

> 아이가 "사과"를 "타과"로 말하거나, 어린이집 선생님이 "말이 좀 느린 것 같다"고 할 때. 센터 전화를 걸었더니 3개월 대기. "일단 지켜보자"고 접지만 밤마다 **"골든타임을 놓치는 건 아닌지"** 불안에 잠 못 이루는 상황.

```
맘카페 검색 → 불안 증가 → 센터 전화 → "3개월 대기요" 
→ "일단 기다리자" → 유튜브 → 효과 모름 → 다시 불안 → (반복)
```

---

### 핵심 불편함 — 하나의 뿌리, 세 가지 가지

> **뿌리 문제: "우리 아이가 정상인지 아닌지 모른다."**

모든 불편함은 이 한 가지에서 파생된다. 기준선(Baseline)이 없으니 방법을 모르고, 기준선이 없으니 변화를 확인할 수 없다.

| 파생 불편함 | 부모의 말 | 비즈니스 대응 | 핵심 지표 |
|:-----------|:---------|:------------|:---------|
| **① 진단 부재** | "또래 대비 몇 점인지 모르겠어" | 무료 AI 진단 → 전환 트리거 | 전환율 ≥ 8% |
| **② 방법론 부재** | "뭘 어떻게 시켜야 하는지 모르겠어" | 진단 기반 맞춤 커리큘럼 → 구독 핵심 가치 | 주간 완료율 ≥ 60% |
| **③ 효과 확인 불가** | "한 달째인데 나아진 건지 모르겠어" | 주간 발달 추이 리포트 → 리텐션 엔진 | M3 유지율 ≥ 40% |

을 **해결하는 것이 이 사업의 핵심 문제**이다.

# 3. 문제의 사업적 유효성

"이 문제가 돈이 되는가?"에 대한 검증이다.

| 검증 질문 | 답변 | 판정 |
|:----------|:-----|:----:|
| 부모가 이 문제에 돈을 내는가? | 센터 월 12~24만원을 이미 지불 중 | ✅ |
| 기존 대안이 부족한가? | 센터=비싸고 대기 김. 유튜브=개인화 없고 효과 추적 불가 | ✅ |
| 경쟁사가 이미 풀고 있지 않은가? | DTx에 매달리는 중. B2C 교육은 방치 상태 | ✅ |
| M3 유지율 40%가 가능한가? | **미검증.** 교육 앱 평균의 15~20배. 파일럿 필수 | ❌ |
| 전환율 8%가 가능한가? | **미검증.** 실측 데이터 없음 | ❌ |

> **결론: 문제는 존재하고, 지불의사도 있다. 그러나 "불안이 구독으로 전환되는가"는 파일럿으로만 답할 수 있다.**

# 4. 해결 방향 — 한 문장 정의

> **"아이 말이 늦는 것 같아 불안한 부모에게, 무료로 진단해주고, 맞춤 훈련을 제공하고, 매주 나아지는 걸 보여주는 서비스."**

이것을 3단계 가치 퍼널로 구현한다.

```
[STEP 1] 무료 AI 진단        →  "우리 아이 /ㅅ/ 발음 정확도 62점"
         (고객 유입)               불안에 이름을 붙여준다

[STEP 2] 맞춤 구독 교육       →  "이번 주는 /ㅅ/ 소리 훈련이에요"
         (핵심 수익원)              부모에게 방법론을 준다

[STEP 3] 주간 발달 리포트     →  "이번 주 62점 → 71점 (+9점)"
         (리텐션 엔진)              효과를 눈으로 보여준다

[선택] 전문가 비동기 코멘트    →  "전문가도 확인했습니다"
       (신뢰 보완)                  혼자가 아니라는 안심
```

**포지셔닝**: "치료(Therapy)"가 아니라 **"홈 랭귀지 코칭(Home Language Coaching)"**이라는 새 카테고리를 정의하고 소유한다. DTx 기업들과는 경쟁이 아닌 보완적 관계(진단 연계, 치료 전후 훈련)를 설계한다.

# 5. Go/No-Go 판단 기준

**100가정 파일럿**에서 아래 지표를 실측한다.

| 지표 | Go | Pivot | Kill |
|:-----|:---|:------|:-----|
| 무료진단 → 유료 전환율 | ≥ 8% | 5~8% | < 5% |
| M3 유지율 | ≥ 40% | 30~40% | < 30% |
| LTV:CAC | ≥ 3.0x | 2.0~3.0x | < 2.0x |
| 부모 NPS | ≥ 50 | 30~50 | < 30 |
| 3개월 발음 정확도 변화 | 유의미한 향상 | 미미한 향상 | 변화 없음 |

# 6. 실행 로드맵

| 단계 | 기간 | 할 일 | 완료 기준 |
|:----:|:----:|:------|:---------|
| **Phase 0** | 0~3개월 | 무료 진단 MVP + 100가정 파일럿 모집 + 지표 측정 시작 | 전환율·유지율 실측 데이터 확보 |

| **Phase 3** | 12개월+ | 전문가 네트워크 확장 + 대학 공동연구 + 카테고리 리더십 확보 | LTV:CAC ≥ 3.0x 안정적 달성 |
