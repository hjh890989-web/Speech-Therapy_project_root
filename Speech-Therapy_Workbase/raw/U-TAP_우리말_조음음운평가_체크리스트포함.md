## 0. 사전 확인: U-TAP과 U-TAP2

한국 임상에서 "U-TAP"이라고 부를 때는 두 가지 버전이 혼용됨.

- **U-TAP (2004)**: 김영태·신문자. 원판. 학지사 출판. 그림 자극 30개 단어 기반.
- **U-TAP2 (2020)**: 김영태·신문자·김수진·하지완. 개정판. 단어 수준 + **문장 수준** 검사가 추가되어 자발화에 가까운 평가 가능. 규준도 갱신.

본 문서는 **원판 U-TAP을 기준**으로 정리하되, U-TAP2의 주요 변경점도 함께 표시함. 현재 임상에서는 두 버전이 모두 사용되며, 신규 표준화 자료가 필요한 경우 U-TAP2를 권장하는 흐름으로 가고 있음.

> **주의**: U-TAP의 구체적 검사 단어와 문항은 저작권으로 보호되는 평가도구이므로, 본 문서에서는 **검사가 측정하는 능력·구성 원리·시행 절차·채점 방식**까지만 다룸.

## 1. 검사 개요

| 항목 | 내용 |
|---|---|
| 정식 명칭 | 우리말 조음·음운평가 (Urimal Test of Articulation and Phonology) |
| 개발자 | 김영태, 신문자 (2004) / U-TAP2: 김영태·신문자·김수진·하지완 (2020) |
| 출판 | 학지사심리검사연구소 |
| 적용 연령 | **만 2세 6개월 ~ 6세 11개월** (원판) / U-TAP2는 만 2;6 ~ 7세 |
| 검사 시간 | 약 15~30분 (단어검사 기준) |
| 시행 방식 | 1:1 개별 검사, 임상가 대면 시행 |
| 자격 | 언어재활사, 특수교사 등 표준화 검사 시행 자격자 |

**개발 배경의 의미**
U-TAP 이전까지 한국 임상에서는 영어권 검사(GFTA 등)를 번안하거나 비표준화 도구를 사용했으나, **한국어 음운 체계(자음 19개, 모음 21개, 종성 제약, 음운 변동 규칙)** 를 정확히 반영한 표준화 도구가 필요했음. U-TAP은 한국어 음소 출현 빈도·습득 시기·음운 변동 패턴을 체계적으로 반영하여 표준화한 첫 본격적 한국어 조음·음운 검사임.

**조음과 음운의 차이**
U-TAP의 명칭에 "조음·음운"이 모두 포함된 이유는 두 측면을 구분해 측정하기 때문.

- **조음(Articulation)**: 개별 음소를 정확히 산출하는 운동적 능력 (어떤 음소를 못 내는가)
- **음운(Phonology)**: 음소 체계 안에서 규칙적으로 나타나는 변동 패턴 (어떤 패턴으로 오류가 나오는가)

같은 오류라도 조음 관점과 음운 관점의 해석이 다르며, 중재 방향도 달라짐.

## 2. 검사 구조

### 2.1 전체 구성 (원판 U-TAP)

```
U-TAP (원판)
├─ 단어 수준 검사 (Word-level Test)
│   ├─ 그림 자극 30개 (목표 단어)
│   ├─ 자음 43개 검사 위치 (어두초성·어중초성·종성)
│   └─ 모음 7개 검사
│
└─ 문장 수준 검사 (Sentence-level Test)
    └─ 짧은 문장 산출 과제 (보조적, 비중 낮음)
```

**U-TAP2의 주요 변경점**

- 단어 수준 검사 자극 갱신 및 그림 현대화
- **문장 수준 검사가 본격 보완**되어 단어 vs 문장 수준 정확도 비교 가능
- 규준 자료 갱신
- 채점 시스템 디지털화 지원

### 2.2 검사 단위

U-TAP은 **자음의 위치별 정확도**를 핵심 측정 단위로 삼음.

| 자음 위치 | 설명 | 예시 (음소 위치 표시) |
|---|---|---|
| **어두초성** | 단어 첫음절의 초성 | "곰"의 ㄱ |
| **어중초성** | 단어 중간 음절의 초성 | "거북이"의 ㅂ |
| **종성** | 음절 끝의 받침 | "곰"의 ㅁ |

한국어 자음 19개 각각이 위치별로 1~3회씩 출현하도록 단어가 설계되어, 총 **자음 검사 위치 43개**가 측정됨. 모음은 단모음 7개를 측정.

### 2.3 음운 변동 평가

U-TAP은 단순히 음소별 정확도뿐 아니라, **오류가 어떤 음운 변동 패턴을 따르는지**를 분석함. 한국어 임상에서 흔히 평가되는 음운 변동 범주는 다음과 같음.

| 범주 | 변동 유형 | 예시 |
|---|---|---|
| **음절 구조 변동** | 종성 생략, 음절 생략, 자음군 단순화 등 | "곰" → "고", "사탕" → "탕" |
| **대치 변동 (조음 위치)** | 전방화, 후방화 | "고기" → "도디" (연구개음의 전방화) |
| **대치 변동 (조음 방법)** | 파열음화, 마찰음화, 파찰음화 등 | "사" → "타" (마찰음의 파열음화) |
| **대치 변동 (긴장도/기식도)** | 경음화, 격음화, 평음화 | "ㄱ" → "ㄲ" |
| **동화 변동** | 인접 음소에 영향받아 동화 | "토끼" → "코끼" (역행동화) |
| **첨가/탈락** | 음소 첨가 또는 탈락 | "아기" → "아긱이" |

각 변동의 **출현 빈도**와 **출현률(%)** 을 산출해 아동의 음운 패턴을 프로파일링함.

### 2.4 한국어 자음 발달 순서 참고

U-TAP 해석 시 임상가는 한국어 자음 발달 순서를 함께 고려함. 일반적 한국 아동의 자음 습득 순서는 대략 다음과 같음 (임상에서 흔히 참고되는 발달 순서이며, 연구마다 약간씩 차이 있음).

| 발달 단계 | 일반적 습득 시기 | 음소 |
|---|---|---|
| 초기 | ~3세 | ㅁ, ㄴ, ㅇ, ㅂ, ㅍ, ㅃ, ㄷ, ㅌ, ㄸ, ㅎ |
| 중기 | 3~5세 | ㄱ, ㅋ, ㄲ, ㅈ, ㅊ, ㅉ |
| 후기 | 5~6세 이후 | ㅅ, ㅆ, ㄹ |

따라서 5세 아동이 ㅅ, ㄹ 오류를 보이는 것은 발달 범위 내일 수 있으나, ㅁ, ㄴ 오류를 보인다면 임상적으로 의미 있는 지연으로 해석됨.

## 3. 시행 절차 (실제 검사 흐름)

### 3.1 시행 순서

일반적으로 **단어 수준 검사를 먼저, 문장 수준 검사를 나중에** 시행함. U-TAP2에서는 문장 검사 비중이 커졌으므로 둘 다 시행하는 것이 권장됨.

### 3.2 단어 수준 검사 진행

**핵심 절차**

1. 임상가가 검사 그림판을 펼쳐 1개의 그림을 보여줌
2. 임상가가 표준 지시문 제시 (예: "이게 뭐예요?")
3. 아동이 단어로 답함
4. 임상가는 아동의 산출을 **음소 단위로 전사(transcription)** 하여 기록
5. 산출 단어가 목표 단어와 다르면 단서 제공 가능 (의미 단서, 문장 완성 단서 등 매뉴얼 허용 범위)

**단서 제공 위계 (일반적)**

```
1단계: 그림 보여주고 "이게 뭐예요?"
2단계: 의미 단서 ("동물이에요. 우유를 줘요.")
3단계: 문장 완성 단서 ("음매~ 하고 우는 건 ___")
4단계: 모방 산출 ("따라 해보세요. 소.")
```

모방 산출은 자발 산출과 별도로 표기해야 함 (자발 vs 모방의 정확도가 다른 경우 임상적 의미 있음).

### 3.3 문장 수준 검사 진행

원판 U-TAP은 문장 검사가 보조적이지만, U-TAP2에서는 본격 시행됨. 주된 방식은 **짧은 그림 시퀀스를 보여주고 정해진 문장으로 산출하도록 유도**하는 형태.

문장 수준 검사의 임상적 의미는

- 단어 수준에서 정확하지만 문장 수준에서 오류가 늘어나는 패턴 식별
- 운율·연결발화에서의 조음 안정성 평가
- 자발화에 더 가까운 환경에서의 정확도 측정

### 3.4 사용 도구

- **U-TAP 검사 그림책** (단어 자극용)
- **U-TAP 매뉴얼**
- **검사 기록지 (전사용)**: 음소별 산출 기록
- **음운 변동 분석지**: 오류 패턴 분류용
- **녹음 장비** (필수에 가까움): 정확한 전사를 위해 강력 권장
- **연령별 환산표·규준표**

### 3.5 전사(transcription) 원칙

U-TAP의 신뢰도는 **임상가의 전사 정확도**에 결정적으로 의존함. 전사 시 유의사항:

- **국제음성기호(IPA)** 또는 **한글 전사** 모두 가능하나, 일관성 유지
- 산출된 그대로 기록 (해석·교정 금지)
- 왜곡(distortion), 대치(substitution), 생략(omission), 첨가(addition)를 구분 표기
- 의심스러운 경우 녹음 후 재청취하여 확정
- 자발 산출(S)과 모방 산출(I) 구분 표기

### 3.6 자극 단어의 특성

U-TAP의 검사 단어는 다음 원칙에 따라 선정됨.

- 만 2;6 아동도 친숙한 단어 (인지·어휘 영향 최소화)
- 한국어 자음 19개 × 위치(어두/어중/종성)를 균형 있게 포함
- 그림으로 표상 가능한 구체 명사 위주
- 단음절~3음절 위주

따라서 어휘력 부족 때문에 단어를 모르는 경우, 단서 제공·모방 산출로 보완할 수 있음.

## 4. 채점 방식

### 4.1 음소별 채점

각 검사 위치(자음 43개 + 모음 7개)에 대해 **정조음 / 오조음** 판정.

- **정조음**: 목표 음소를 정확히 산출
- **오조음**: 다음 4가지 유형 중 하나로 분류
  - **대치(Substitution)**: 다른 음소로 바꿔 산출 (예: ㅅ → ㄷ)
  - **생략(Omission)**: 음소를 빼고 산출 (예: 곰 → 고)
  - **왜곡(Distortion)**: 음소 비슷하지만 부정확한 산출 (예: 측음화된 ㅅ)
  - **첨가(Addition)**: 음소를 더해 산출 (예: 사과 → 사강가)

### 4.2 핵심 산출 지표

U-TAP의 가장 중요한 산출 지표는 **자음정확도(PCC)** 와 **모음정확도(PVC)** 임.

#### 자음정확도 (PCC: Percentage of Consonants Correct)

```
PCC = (정조음한 자음 수 / 검사한 전체 자음 수) × 100
```

- 전체 자음정확도, 어두초성 PCC, 어중초성 PCC, 종성 PCC를 각각 산출 가능

#### 모음정확도 (PVC: Percentage of Vowels Correct)

```
PVC = (정조음한 모음 수 / 검사한 전체 모음 수) × 100
```

#### PCC 해석 기준 (일반적 임상 기준)

| PCC 범위 | 일반적 해석 |
|---|---|
| 85~100% | 경도 또는 정상 범위 |
| 65~84% | 경도-중등도 |
| 50~64% | 중등도-중도 |
| 50% 미만 | 중도 |

이 기준은 Shriberg & Kwiatkowski(1982)의 영어권 분류를 한국 임상에서 참고용으로 사용하는 것으로, **한국 아동 연령별 규준표(U-TAP 매뉴얼)의 표준편차 기준이 더 정확한 진단 근거**임.

### 4.3 환산점수

U-TAP은 다음 환산점수를 제공함.

- **자음정확도(PCC)**: 백분율
- **모음정확도(PVC)**: 백분율
- **연령별 백분위**: 또래 대비 위치
- **표준점수 또는 -편차**: -1SD, -2SD 등 진단 기준
- **음운 변동 출현률**: 각 변동별 출현 빈도(%)

### 4.4 진단 기준

| 기준 | 해석 |
|---|---|
| 평균 -1SD 이내 | 정상 발달 범위 |
| -1 ~ -2SD | 조음·음운 발달 지연 의심, 모니터링 또는 중재 권고 |
| -2SD 이하 | 명확한 조음·음운 장애, 중재 필수 |

또한 **연령에 부적절한 음운 변동의 지속**도 진단 근거가 됨.

- 4세 이후: 종성 생략, 자음군 단순화 등이 지속되면 비전형
- 5세 이후: 파찰음화, 전방화 등이 지속되면 비전형
- 6세 이후: ㅅ·ㄹ 외 음소 오류가 지속되면 비전형

### 4.5 음운 변동 분석

U-TAP의 강점 중 하나는 **음운 변동 패턴 분석**임. 채점 후 다음 정보를 산출함.

- 각 음운 변동의 **출현 빈도** (몇 회 나타났는가)
- 각 음운 변동의 **출현률** (해당 변동이 적용 가능한 환경 중 몇 %에서 실제 나타났는가)
- 어떤 변동이 **지배적 패턴**인가
- 어떤 변동이 **연령 부적절**한가

이 분석을 통해 **조음 중재의 우선순위**를 결정함. 예를 들어 출현률이 높은 패턴부터 중재 목표로 설정.

---

## 5. 결과 보고서 구성

U-TAP 시행 후 작성되는 평가 보고서는 보통 다음 항목을 포함함.

```
1. 의뢰 정보 (Referral Info)
   - 아동 인적사항, 생활연령, 의뢰 사유

2. 양육자 면담·발달력
   - 조음 문제 출현 시기, 가족력
   - 청력·구강구조·운동 발달 정보

3. 검사 시 행동 관찰
   - 라포 형성, 협조도, 발성 의지
   - 구강 구조 관찰 (혀·입술·구개 형태)
   - 자발화 발성 양상

4. 검사 결과 (정량 지표)
   - 자음정확도(PCC): __% (전체/어두초성/어중초성/종성)
   - 모음정확도(PVC): __%
   - 연령별 백분위 또는 -편차
   - 자발 vs 모방 산출 정확도 비교

5. 오류 패턴 분석 (정성 분석)
   - 음소별 오류 정리 (어떤 음소에서 어떤 오류가 나오는가)
   - 음운 변동 출현률
   - 지배적 변동 패턴
   - 연령 적절성 평가

6. 진단적 결론
   - 정상/경계선/지연/장애 분류
   - 조음 vs 음운 장애 분류
   - 동반 문제 가능성 (언어발달, 청각, 구강 등)

7. 권고사항
   - 추가 평가 필요 여부 (청력, 구강기능, 언어 등)
   - 중재 방향 (목표 음소·변동 우선순위)
   - 중재 빈도·기간 권고
   - 재평가 시점
```

## 6. 트랙 2 초기 평가에서의 활용

### 6.1 U-TAP의 임상적 위치

U-TAP은 트랙 2 초기 평가에서 **조음·음운 영역의 표준 진단 도구**임. 다음과 같은 의뢰 사례에 핵심적으로 사용됨.

- "발음이 부정확하다"는 의뢰
- 가족·교사가 아동의 말을 알아듣기 어려움
- 또래보다 어휘는 비슷한데 명료도(intelligibility)가 떨어짐
- 언어발달 평가(PRES, REVT) 시행 중 조음 문제 발견

### 6.2 다른 도구와의 보완 관계

| 영역 | 보완 도구 |
|---|---|
| 조음·음운 (대안) | APAC (아동용 발음평가) |
| 자발화 명료도 | 자발화 표본 분석, 명료도 평가 |
| 구강운동 기능 | 구강운동검사(OMA), 마비말장애 검사 |
| 음운 인식 | 음운 인식 검사 (학령기 이후) |
| 언어 능력 | PRES, REVT, LSSC |
| 청력 | 객관적 청력검사 |

특히 U-TAP과 APAC는 **경쟁 관계**에 가까움. 두 검사 모두 한국 표준화 조음·음운 검사이며, 임상가의 선호와 기관 정책에 따라 선택됨.

| 비교 항목 | U-TAP | APAC |
|---|---|---|
| 개발 | 김영태·신문자 (2004) | 김민정·배소영·박창일 (2007) |
| 검사 단어 수 | 약 30개 | 약 37개 |
| 자극 형태 | 그림 보고 단어 산출 | 그림 보고 단어 산출 |
| 음운 변동 분석 | 가능 | 가능 (더 세밀한 분석 제공) |
| 임상 활용 | 광범위, 표준화 검사의 대표 | APAC는 음운 변동 정밀 분석 강점 |

### 6.3 트랙 2에서의 일반적 평가 패키지

```
조음 의심 의뢰 → 1차 진단 평가
                   │
                   ├─ U-TAP 또는 APAC (조음·음운)
                   ├─ 자발화 명료도 평가
                   ├─ 구강 구조·운동 관찰
                   ├─ 청력 스크리닝
                   └─ 동반 언어 문제 의심 시: PRES, REVT
```

### 6.4 조음 vs 음운 vs 마비말장애 감별

U-TAP 결과 해석 시 중요한 임상적 감별:

| 유형 | 특징 | U-TAP 결과 양상 |
|---|---|---|
| **조음장애 (Articulation Disorder)** | 특정 음소를 운동적으로 못 냄. 일관된 오류. | 특정 음소에 일관된 대치/왜곡, 음운 변동은 단순 |
| **음운장애 (Phonological Disorder)** | 음소 체계 자체의 오류 패턴. 규칙적 변동. | 다수 음소가 동일 패턴으로 오류, 음운 변동 출현률 높음 |
| **마비말장애 (Dysarthria)** | 신경학적 손상으로 운동 통제 어려움 | 음소 일관성 낮고, 호흡·발성·운율 동반 문제 |
| **말실행증 (Apraxia)** | 운동 계획 장애. 비일관성 두드러짐. | 같은 단어를 시도마다 다르게 산출, 단어 길어질수록 악화 |

U-TAP 단독으로는 위 감별이 완전하지 않으므로, **자발화 분석·구강운동 평가·필요시 신경학적 평가**를 병행해야 함.

### 6.5 U-TAP의 강점과 한계

**강점**

- 한국어 자음·모음 체계 전반을 체계적으로 평가
- 음소별 정확도 + 음운 변동 패턴 동시 분석
- PCC, PVC라는 명확한 정량 지표 제공
- 시행 시간 적절 (15~30분)
- 한국 임상에서 가장 널리 알려진 표준화 도구
- U-TAP2로 갱신되어 문장 수준 평가 보완

**한계**

- **단어 수준 평가 중심**: 자발화·연결발화에서의 명료도와 다를 수 있음
- 그림 자극 의존 → 어휘력 부족 아동에게 단서 제공 부담
- 원판 U-TAP은 규준 노후화 우려 (U-TAP2로 보완)
- 음운 변동 분석은 임상가의 전사 정확도에 크게 의존
- 다문화·이중언어 아동 해석 시 주의 필요
- 마비말장애·말실행증 감별은 별도 평가 필요

---

## 7. 정리: 실무 관점에서의 핵심

트랙 2 초기 평가에서 U-TAP을 활용할 계획이라면, 다음 세 가지를 의사결정 기준으로 잡으면 됨.

1. **U-TAP은 "조음·음운"을 모두 측정하는 도구다.** 음소별 정확도(PCC)만 보지 말고 음운 변동 패턴까지 분석해야 중재 방향이 잡힌다.
2. **단어 수준 결과는 자발화 명료도와 다를 수 있다.** U-TAP 단독으로 판단하지 말고 자발화 분석·문장 수준 검사(U-TAP2)로 보완하라.
3. **조음장애와 음운장애의 감별이 중재 전략을 바꾼다.** 조음장애는 개별 음소 훈련, 음운장애는 변동 패턴 단위 훈련이 효과적이므로 진단적 분류가 실무적으로 중요하다.

## 8. 추가 탐색 방향

다음 주제들이 후속 정리 후보임.

- U-TAP 결과를 조음 중재 목표 설정으로 연결하는 실무 흐름 (음소 위계 vs 변동 위계)
- U-TAP과 APAC 결과를 통합 해석하는 방법
- 자발화 명료도 평가(percent intelligibility)와 U-TAP 결과 교차 검증
- U-TAP에서 마비말장애·말실행증 의심 신호 포착 가이드
- 조음 + 언어발달 동반 사례에서 평가·중재 우선순위 설정

- [ ] 검사 시 행동 관찰 (구강 구조 포함)
- [ ] 정량 지표 (PCC, PVC, 백분위/편차)
- [ ] 위치별 PCC (어두초성/어중초성/종성)
- [ ] 음소별 오류 양상
- [ ] 음운 변동 출현률 표
- [ ] 자발 vs 모방 산출 비교
- [ ] 단어 vs 문장 수준 비교 (해당 시)
- [ ] 진단적 결론 (조음/음운 장애 분류)
- [ ] 권고사항
- [ ] 재평가 시점

### D-2. 작성 시 점검

- [ ] 정량 지표와 정성 분석 균형 있게 제시
- [ ] 음운 변동 분석을 보호자가 이해 가능하도록 풀이
- [ ] 단정적 표현 지양 (특히 경계선 사례)
- [ ] 동반 평가 필요성 명시
- [ ] 강점 영역도 함께 기술
- [ ] 중재 목표·우선순위 구체화

### D-3. 권고사항 항목별 점검

- [ ] 추가 평가 필요 여부 (청력, 구강기능, 언어, 신경학)
- [ ] 의료적 의뢰 필요 여부 (이비인후과, 치과, 신경과)
- [ ] 중재 시작 권고 (시기, 빈도, 형태)
- [ ] 중재 목표 음소·변동 우선순위
- [ ] 중재 접근법 권고 (음소 단위 vs 변동 단위)
- [ ] 가정·교육기관 협력 권고
- [ ] 재평가 시점 (보통 3~6개월)

## 부록 E. 결과 피드백(보호자 상담) 체크리스트

### E-1. 상담 사전 준비

- [ ] 보호자 수준에 맞는 용어로 결과 재구성
- [ ] PCC를 일상 언어로 설명할 표현 준비 ("100개 자음 중 몇 개를 정확히")
- [ ] 음운 변동 개념을 쉽게 풀어낼 예시 준비
- [ ] 시각 자료 준비 (음소 정확도 그래프 등)
- [ ] 중재 방향·예후 안내 자료 준비

### E-2. 상담 중 점검

- [ ] 현재 명료도 수준을 객관적·일상적으로 설명
- [ ] 또래 발달과 비교한 위치 안내
- [ ] 발달 범위 내 오류와 비전형 오류 구분 설명
- [ ] 보호자 정서적 반응 관찰·케어
- [ ] 일방 통보 아닌 대화형 진행
- [ ] 강점·약점 균형 있게 전달
- [ ] 중재 효과·예후 현실적 안내
- [ ] 가정에서 적용 가능한 자극 방법 제시

### E-3. 상담 후 후속 조치

- [ ] 보고서 사본 전달 (요청 시)
- [ ] 다음 일정 확정 (재평가, 중재 시작)
- [ ] 의료적 의뢰서 작성 (필요 시)
- [ ] 가정 자극 자료·연습 카드 제공
- [ ] 보호자 추가 질문 채널 안내

## 부록 F. 자주 놓치는 함정 체크리스트

U-TAP 검사·해석 과정에서 임상가가 자주 놓치는 지점을 별도로 정리.

- [ ] 생활연령 산출 오류 (개월 수 계산 실수)
- [ ] **녹음 없이 즉석 전사만으로 채점** (정확도 저하의 가장 큰 원인)
- [ ] 자발 산출과 모방 산출을 구분하지 않고 채점
- [ ] 단어 수준 결과만 보고 명료도 단정 (자발화 명료도와 차이 무시)
- [ ] 단서 제공 위계를 생략하고 모방으로 직행
- [ ] 음소별 정확도(PCC)만 산출하고 음운 변동 분석 생략
- [ ] **조음장애와 음운장애 감별 누락** → 중재 전략 부정확
- [ ] 마비말장애·말실행증 의심 신호 무시
- [ ] 청력 평가 미확보 상태에서 진단 확정
- [ ] 구강 구조 관찰 누락 (구개열·설소대 등)
- [ ] 다문화·이중언어 가정 영향 미반영
- [ ] 연령 부적절 vs 발달 범위 내 오류 구분 모호
- [ ] 동반 언어발달 문제 의심 시 PRES·REVT 의뢰 누락
- [ ] 전사 일관성 부족 (검사자 내·검사자 간 차이)
