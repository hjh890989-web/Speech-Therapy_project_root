# Core-1. 이지수 (34세, 전업주부)
**"검색만 하다가 3개월이 지났어요"** | Seg A — 불안형 탐색자

| **단계** | 고객 행동 | 고객 생각 | 감정 | Pain Point | 개선 기회 |
|:---------|:---------|:---------|:----:|:-----------|:---------|
| **문제 인식** | 아들이 또래보다 말이 느리다는 것을 육아 모임에서 비교하며 처음 느낌 | "내가 너무 예민한 건가? 남들은 다 괜찮아 보이는데…" | 불안 + 죄책감 | 정상/비정상 기준선 없음. 내 아이를 어디에 비교해야 할지 모름 | "만 3세 평균 언어 발달 기준표" 콘텐츠 + 자가 체크리스트 무료 제공 |
| **탐색** | 맘카페에 "아이 말 늦음" 검색 → 유튜브 "언어발달 느린 아이" 채널 구독 → 소아과 검진 시 의사에게 질문 | "센터에 가야 하나? 근데 아직 이른 것 같기도 하고… 일단 유튜브 더 봐야겠다" | 정보 과부하 + 피로감 | 유튜브·맘카페 정보가 범용적이어서 내 아이에게 맞는지 알 수 없음 | 무료 AI 진단 배너 노출: "우리 아이 맞춤 발음 검사 — 3분 완성, 무료" |
| **의사결정** | 무료 AI 진단 페이지 진입 → 1~2분간 망설임 → "개인정보는 얼마나 받나?" 확인 후 시작 | "검사 결과가 나쁘게 나오면 어떡하지? 그냥 안 하는 게 나을까?" | 진단 회피 불안 | 진단 결과가 '장애' 판정처럼 느껴질까봐 두려움. 공개 진단에 대한 부담 | 랜딩 카피 변경: "치료 판정이 아니에요. 발달 위치 확인이에요" + 익명 진단 옵션 |
| **사용** | AI 진단 완료 → 리포트 수령 → "62점/100점"이라는 결과 확인 → 유료 구독 가입 고민 | "62점이 낮은 건가? 이걸 어떻게 해석해야 하지? 그래서 뭘 하면 되지?" | 당혹감 + 막막함 | 점수는 받았는데 의미 해석과 다음 행동이 연결되지 않음 | 리포트 내 "이 점수의 의미" + "오늘부터 할 수 있는 3가지 활동" 자동 제안 |
| **유지** | 주간 "오늘의 언어 자극 활동" 알림 → 아이와 함께 5분 활동 → 다음 주 재측정 | "지난주보다 2점 올랐네. 계속 해봐야겠다" | 소소한 성취감 | 아이가 활동을 거부하거나 점수 변화가 미미하면 포기 유혹 발생 | 3주 무변화 시 "이 나이 아이들은 다 이래요" 격려 푸시 + 전문가 코멘트 1회 무료 제공 |

**전략적 핵심**: 이지수는 **진입 장벽이 가장 높은 동시에 볼륨이 가장 큰 타깃**. 진단 결과의 무서움을 낮추는 언어 선택과, 62점이라는 숫자를 "행동 처방전"으로 즉시 연결하는 UX가 이탈 방지의 핵심.

# Core-2. 박민정 (31세, 마케터)
**"데이터로 확인해야 직성이 풀려요"** | Seg A→B — 데이터 집착형

| **단계** | 고객 행동 | 고객 생각 | 감정 | Pain Point | 개선 기회 |
|:---------|:---------|:---------|:----:|:-----------|:---------|
| **문제 인식** | 어린이집 담임 "발음이 좀..." 피드백 수령 → 즉시 발달 관련 앱 2개 다운로드 | "정확히 어느 음소가 문제야? 얼마나 심각해? 숫자로 보여줘" | 분석 욕구 + 조급함 | 담임의 주관적 피드백이 데이터가 아님. 수치화된 기준 없음 | "음소별 정확도 리포트" 예시 화면을 광고 소재로 활용 |
| **탐색** | 앱 스토어에서 발달 앱 검색 → 2개 설치 후 리텐션 없어서 삭제 → 소아청소년과 발달 검사 예약 | "이 앱들은 다 그냥 동영상이잖아. 내 아이 데이터가 없어" | 실망 + 비교 피로 | 기존 앱들이 개인화 데이터 없이 범용 콘텐츠만 제공 | 앱 스토어 키워드: "발음 정확도 측정" + "음소별 분석 리포트" 강조 |
| **의사결정** | 음소별 분석 리포트 샘플 확인 → "이건 다르다" 인식 → 무료 진단 즉시 실행 | "이 데이터면 내가 직접 관리할 수 있겠는데. 해볼만하다" | 자기효능감 상승 | 샘플 데이터가 없으면 기능만으로는 신뢰하기 어려움 | 랜딩 페이지에 실제 샘플 리포트(익명) 공개 + "/ㅅ/ 72% → 89% 4주 변화" 사례 |
| **사용** | 주간 음소별 추이 그래프 모니터링 → "/ㅅ/ 이번 주 75%, 지난주 68%" 확인 → 활동 완료율 추적 | "오 이 부분이 올랐네. 근데 /ㄹ/은 왜 안 오르지? 활동 방식이 잘못된 건가?" | 몰입 + 분석 욕구 | 데이터는 보이는데 "왜 이 음소가 더 어려운지" 원인 설명이 없으면 답답함 | 음소별 "발달 연령 특성" 설명 툴팁 + 전문가 코멘트 자동 트리거 |
| **유지** | 월간 발달 리포트 PDF 저장 → 어린이집 선생님에게 공유 → 남편에게도 보여줌 | "이걸 선생님한테 보내면 좀 더 체계적으로 같이 케어할 수 있겠다" | 자부심 + 통제감 | 리포트가 외부 공유 불가능하면 활용성 저하 | PDF 내보내기 + 어린이집 선생님 공유 링크 기능 → Viral 트리거 |

**전략적 핵심**: 박민정은 **고LTV 사용자**. 월간 리포트가 외부 공유(어린이집, 남편)로 이어지면 Word-of-Mouth의 시작점이 됨. 데이터 리포트의 공유 기능이 마케팅 채널이 되는 플라이휠 설계 필요.

# Core-3. 최수현 (36세, 초등교사)
**"전문가 말을 들어야 안심이 돼요"** | Seg C — 센터 대기자

| **단계** | 고객 행동 | 고객 생각 | 감정 | Pain Point | 개선 기회 |
|:---------|:---------|:---------|:----:|:-----------|:---------|
| **문제 인식** | 직업 특성상 학교 아이들과 비교하여 내 아이(만 5세)의 언어 지연을 조기 인지 | "다른 애들이랑 비교하면 확실히 느린데. 이건 기다리면 안 돼" | 조급함 + 전문가적 우려 | 일반 부모보다 빨리 알아챘지만, 방법을 모르는 딜레마 | "교사·전문직 부모를 위한 조기 개입 가이드" 콘텐츠 타깃팅 |
| **탐색** | 센터에 바로 전화 → "4개월 대기" 통보 → 유튜브 언어치료사 채널 정주행 → 학교 특수교사 동료에게 비공식 조언 요청 | "4개월 동안 아무것도 안 하면 골든타임을 놓치는 건데. 지금 당장 뭔가 해야 해" | 공황 수준의 조급함 | 대기 기간 동안 공백을 채울 공신력 있는 도구가 없음 | "센터 대기 중인 부모님을 위한 브릿지 프로그램" — 구글 광고 키워드 |
| **의사결정** | 무료 진단 + "전문 언어재활사가 주간 코멘트 제공" 메시지 확인 → 빠르게 결제 | "전문가가 직접 확인해준다면 믿을 수 있다. 센터보다 훨씬 저렴하기도 하고" | 신뢰 + 안도 | 전문가 자격증 정보나 코멘트 예시가 없으면 "진짜 전문가가 보는 건지" 의심 | 코멘트 작성 전문가 프로필(자격증, 경력) 공개 + 실제 코멘트 예시 2~3개 노출 |
| **사용** | 매주 AI 진단 → 전문가 코멘트 수령 → 코멘트 기반으로 가정 활동 실행 | "선생님이 '이번 주는 /ㅈ/ 음소에 집중하세요'라고 했으니 이걸 연습시켜야겠다" | 안정감 + 목표 의식 | 코멘트가 너무 전문 용어 중심이면 이해하기 어려움 | 코멘트 작성 가이드라인: "부모 눈높이 언어 + 오늘 할 수 있는 활동 1가지 필수 포함" |
| **유지** | 센터 치료 시작 후에도 병행 사용 고민 → 센터 치료사에게 우리 앱 데이터 공유 | "선생님도 이 데이터 보고 좋다고 했어요. 센터 다니면서도 계속 써야겠다" | 통합 관리 만족감 | 센터 치료 시작 후 "이제 앱 필요 없잖아?" 인식으로 이탈 위험 | "센터 + 앱 병행 가이드" 콘텐츠 + 치료사 공유 리포트 기능 → 이탈 방지 |

**전략적 핵심**: 최수현은 **이탈 시점이 예측 가능(센터 치료 시작 시점)**. 이 시점에 "병행 사용의 가치"를 선제적으로 전달하고, 치료사와의 데이터 공유 기능으로 Lock-in을 강화해야 함.

# Core-4. 김태희 (38세, 간호사)
**"치료비가 너무 부담스러운데 효과는 원해요"** | Seg A~B — 비용 민감형

| **단계** | 고객 행동 | 고객 생각 | 감정 | Pain Point | 개선 기회 |
|:---------|:---------|:---------|:----:|:-----------|:---------|
| **문제 인식** | 쌍둥이 모두 언어 발달 지연 확인 → 센터 비용 계산 → 월 40~60만원 현실적으로 불가 | "두 아이 모두 센터 보내면 한 달 월급이 날아가네. 한 명은 어떻게 해야 하지?" | 죄책감 + 비용 압박 | 두 아이를 동시에 케어할 수 없는 경제적 제약 | "쌍둥이 플랜 할인" 또는 "두 자녀 등록 시 추가 혜택" 패키지 설계 |
| **탐색** | 바우처 신청 → 소득 기준 초과 탈락 → "국가 지원 없이 어떻게 하지?" → 앱 검색 | "앱으로 어느 정도 효과가 있을까? 헛돈 쓰는 건 아닐까?" | 의구심 + 희망 | 효과가 검증되지 않은 앱에 돈 쓰는 것이 부담. ROI 확신 필요 | 비용 효과 비교 인포그래픽: "센터 월 12만 vs 앱 월 3만, 발음 개선 비교" |
| **의사결정** | 무료 진단으로 두 아이 모두 검사 → 점수 비교 → 낮은 아이를 센터, 높은 아이를 앱으로 결정 | "진단 점수로 봐서는 이 아이가 더 급하니까 센터 보내고, 얘는 앱으로 해보자" | 결단 + 약간의 죄책감 | 무료 진단으로 두 아이의 긴급도를 정확히 비교할 수 있어야 Triage 가능 | 두 아이 동시 진단 → 비교 리포트 → "우선순위 Triage 가이드" 자동 생성 |
| **사용** | 3교대 근무로 피곤한 상태 → "오늘의 5분 활동" 알림 → 잠자리에서 아이와 함께 실행 | "5분이면 할 수 있네. 쉽다. 매일 할 수 있겠는데?" | 할 수 있다는 안도 | 활동이 10분 넘거나 준비물이 필요하면 즉시 포기. 간결함이 생명 | 활동 시간 상한 5분 고정 + 준비물 없는 구어 활동 위주 설계 |
| **유지** | 주간 변화 확인 → "앱 쪽 아이도 조금씩 나아지는 것 같다" | "이 정도 효과면 계속 써도 되겠다. 오히려 센터보다 효율이 좋은 것 같기도 하고" | 자기효능감 + 비용 정당화 | 발전이 느리면 "역시 앱으론 안 되나?" 불안 재발 | 3개월 발달 데이터 요약 리포트: "이 기간 동안 변화한 것들" 시각화 |

**전략적 핵심**: 김태희는 **Triage 기능(두 아이 비교 진단)의 핵심 사용자**. 이 기능이 없으면 진입조차 안 되는 구조. 간결한 UX와 5분 활동은 이 페르소나를 기준으로 설계해야 함.

# Core-5. 정유나 (33세, 프리랜서 디자이너)
**"아이 성장 기록을 남기고 싶어요"** | Seg A — 예방적 니즈형

| **단계** | 고객 행동 | 고객 생각 | 감정 | Pain Point | 개선 기회 |
|:---------|:---------|:---------|:----:|:-----------|:---------|
| **문제 인식** | 인스타 육아 일기를 쓰다가 "언어 발달 기록도 남기면 좋겠다" 생각 | "아이가 처음 말한 단어, 첫 문장… 체계적으로 기록하고 싶은데 기준이 없어" | 호기심 + 기록 욕구 | 언어 발달 기록의 "정량적 기준"이 없어서 일기 형태로만 남길 수 있음 | 인스타 광고: "아이 언어 성장 포트폴리오, 앱으로 만들어드려요" |
| **탐색** | 아이 성장 앨범 앱 확인 → 언어 발달 기능 없음 → 소아과 정기 검진 활용 | "소아과에서는 1년에 한 번밖에 안 하고, 그것도 의사가 간단히 봐주는 수준이라 아쉬워" | 아쉬움 + 탐색 지속 | 언어 발달을 정기적으로 추적하는 도구가 시중에 없음 | "월별 언어 발달 스냅샷" 기능 강조. 소아과 사이 공백을 채우는 포지셔닝 |
| **의사결정** | UI 스크린샷 확인 → 발달 곡선 그래프 디자인에 반함 → 무료 진단 시작 | "이거 예쁘다. 이런 걸로 아이 성장 기록 남기면 나중에 보여줄 수 있겠다" | 심미적 만족 + 설렘 | 디자인이 평범하거나 데이터 시각화가 조잡하면 이탈 | 앱 UI에 최우선 투자. 발달 곡선은 "예쁜 인포그래픽" 수준으로 제작. 인스타 공유 포맷 |
