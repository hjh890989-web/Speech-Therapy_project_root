# 경쟁사 가치사슬(Value Chain) 분석
## 한국 온라인 언어발달·발음교정·의사소통 훈련 교육 서비스

> **작성 기준**: 2026년 5월 | **프레임워크**: Porter's Value Chain (주요활동 + 지원활동)

---

# Part 1. 경쟁사별 개별 분석

---

## 1. 네오폰스 (토키랜드)

**유형**: DTx 지향 AI 언어재활 | **고객**: 자폐·언어지연 아동, 특수학교 | **수익원**: B2C 앱 구독 + B2B 기관 + DTx 인허가 후 처방 수익

### 주요활동

| 활동 | 내용 |
|:-----|:-----|
| **투입/조달** | 자체 음성 AI 엔진 (내재화), 경북대병원 임상 데이터, 삼성 C-Lab 기술지원. 핵심 자산: 아동 장애음성 DB |
| **운영/생산** | AI 자동 분석(70%) + 전문가 화상 매칭(30%). 레벨테스트 → 맞춤 콘텐츠 → 성취도 시각화의 자동화 파이프라인 |
| **산출/배송** | 모바일 앱(TalkyLand) + 센터용 솔루션(TalkyTalky). 아동용·보호자용 이원 인터페이스 |
| **마케팅/영업** | 특수학교 실증 → 공교육 레퍼런스 확보 → B2G 확장. 의료진 네트워크 활용 |
| **서비스** | 일간/주간 학습 리포트(LMS), 보호자 대시보드 |

### 지원활동

| 활동 | 내용 |
|:-----|:-----|
| **인프라** | 소규모 스타트업, 대구 본사. R&D + 임상 중심 의사결정 |
| **인적자원** | AI 엔지니어 + 임상 연구원 중심. 언어재활사 외부 연계 |
| **기술개발** | 음성 AI 엔진 자체 개발(높은 내재화). 식약처 DTx 임상시험 계획 승인 |
| **조달** | 클라우드 인프라(외부), 임상 파트너(경북대병원) |

### 수익창출 포인트
앱 구독료가 현재 매출 중심이나, **DTx 인허가 완료 시 병원 처방 → 건강보험 수가 적용**이 장기 수익 폭발 지점

### 강점 / 약점
- **강점**: 식약처 임상승인이라는 규제 해자(Moat), 자체 음성 AI, 공교육 실증 레퍼런스
- **약점**: DTx 인허가에 과도한 리소스 집중 → 일반 교육 시장 B2C 마케팅 부재. 소규모 조직으로 확장 속도 제한

## 2. 와우키키 (하이동동)

**유형**: 멀티모달 AI 언어교육 | **고객**: 2~7세 언어발달 지연 아동 + 부모 + 교사 | **수익원**: B2C 앱 구독 (삼자 연동)

### 주요활동

| 활동 | 내용 |
|:-----|:-----|
| **투입/조달** | 멀티모달 AI(입모양+발성 동시 분석) 자체 개발. 이대목동병원 임상 협력. 핵심 자산: 멀티모달 아동 데이터 |
| **운영/생산** | AI 실시간 분석 중심(80%+). 부모용 조기진단 → 교사용 관리 → 아동용 콘텐츠의 삼자 연동 프로세스 |
| **산출/배송** | 3개 앱 동시 운영(부모용, 교사용, 아동용). 가정+교육기관 동시 커버 |
| **마케팅/영업** | 병원 임상(이대목동) 레퍼런스 → 맘카페/육아 커뮤니티. 대교CNS 등 교육기업 파트너십 |
| **서비스** | 개별화 관리 리포트, 교사-부모 간 데이터 공유 |

### 지원활동

| 활동 | 내용 |
|:-----|:-----|
| **인프라** | 초기 스타트업, 서울 본사. 기술+임상 협업 구조 |
| **인적자원** | AI/CV 엔지니어 + UX 디자이너 중심. 의료진은 외부 자문 |
| **기술개발** | 멀티모달 AI(음성+영상) 자체 개발 → 높은 기술 내재화. 딥테크 차별화 |
| **조달** | 병원 임상 파트너(이대목동), 교육 콘텐츠(대교CNS 협력) |

### 수익창출 포인트
**삼자 연동 모델**(부모-교사-아동)이 핵심. 가정에서 시작해 교육기관으로 확산되는 바이럴 구조 자체가 수익 엔진

### 강점 / 약점
- **강점**: 멀티모달 AI라는 독보적 딥테크. 부모·교사·아동 삼자 연동으로 네트워크 효과 가능
- **약점**: 2025년 매출 30억 목표이나 미달 리스크. Seed/Pre-A 단계로 자본력 취약. 3개 앱 동시 운영의 개발 부담

## 3. 두부 (舊 두브레인)

**유형**: 디지털 헬스케어 (인지+언어 발달) | **고객**: 발달 지원 필요 아동 + 병원 | **수익원**: B2C 구독(두부팡) + B2B 병원연계(두부홈즈) + DTx

### 주요활동

| 활동 | 내용 |
|:-----|:-----|
| **투입/조달** | 메타버스 기반 사회성 중재 기술, D-kit 인지발달 소프트웨어. 다수 병원 임상 데이터. 핵심 자산: 아동 인지발달 데이터 |
| **운영/생산** | AI 기반 콘텐츠(60%) + 전문가 1:1 코칭(40%). 병원 진단 → 가정 훈련 → 병원 모니터링의 순환 구조 |
| **산출/배송** | 두부팡(아동 앱) + 두부홈즈(부모 코칭 클래스) + 병원용 대시보드. 디지털 홈스피탈 시스템 |
| **마케팅/영업** | 병원 파트너십 → 의사 추천 채널. 부모 커뮤니티. 시리즈B 210억 유치로 마케팅 여력 확보 |
| **서비스** | 병원-가정 연계 리포트, 전문가 부모 코칭 프로그램 |

### 지원활동

| 활동 | 내용 |
|:-----|:-----|
| **인프라** | ~50명+, 시리즈B 210억 유치. 시장 내 가장 큰 조직·자본력 |
| **인적자원** | AI 개발 + 콘텐츠 기획 + 임상 연구팀의 삼각 구조 |
| **기술개발** | 메타버스/VR 기반 사회성 중재 + 인지발달 알고리즘. 기술 내재화 높음 |
| **조달** | 병원 네트워크(다수 협력), 투자금 기반 R&D 집중 |

### 수익창출 포인트
**병원 처방 → 가정 구독**의 O2O 순환. 병원이 환자를 유입시키고, 가정에서 구독 매출 발생. DTx 승인 시 처방 수익 추가

### 강점 / 약점
- **강점**: 210억 자본력(시장 최대), 병원-가정 연계 O2O 완성도, 인지+언어 통합 솔루션
- **약점**: 언어발달 "특화"보다 인지발달 "범용"에 가까움. 번 레이트 부담. 의료기기 등록 미완료

## 4. 송앤스타크 (스피치맵)

**유형**: AI 언어발달 진단 특화 | **고객**: 언어재활센터(B2B) → 가정(B2C 예정) | **수익원**: B2B 센터 솔루션 + 데이터 분석 서비스

### 주요활동

| 활동 | 내용 |
|:-----|:-----|
| **투입/조달** | AI 음성 분석 알고리즘(내재화). 언어학적·조음학적·음향학적 데이터 통합 분석 모델. 핵심 자산: 진단 알고리즘+데이터 |
| **운영/생산** | AI 완전 자동 진단(90%+). 음성 입력 → 5분 내 발달 수준 예측 → 리포트 생성. 인력 의존도 극히 낮음 |
| **산출/배송** | 현재 센터용 웹/앱(B2B). 2027년 가정용 B2C 앱 출시 계획 |
| **마케팅/영업** | 언어재활센터 직접 영업 + 임팩트 투자사 네트워크. 센터 원장 대상 PoC |
| **서비스** | 센터-부모 간 객관적 진단 데이터 공유, 추적 관리 |

### 지원활동

| 활동 | 내용 |
|:-----|:-----|
| **인프라** | 초기 스타트업(2022년 설립). 린(Lean) 조직 |
| **인적자원** | AI/NLP 엔지니어 + 언어병리학 전문가 소수 정예 |
| **기술개발** | 진단 알고리즘 자체 개발. 식약처 2등급 의료기기 인허가 추진(2026 목표) |
| **조달** | 클라우드 인프라(외부), 임상 데이터(센터 파트너) |

### 수익창출 포인트
**"진단의 게이트키퍼"** 역할. 센터가 진단 도구로 채택 → 센터 수만큼 반복 매출. 향후 B2C 전환 시 "무료 진단 → 유료 교육 연계" 퍼널의 입구

### 강점 / 약점
- **강점**: 진단 특화로 명확한 포지션. AI 자동화율 90%+ → 한계비용 극히 낮음. 매출 7억/가입자 2,000명 달성
- **약점**: 진단 "만" 제공 → 교육/치료 밸류체인 부재. B2C 전환 2027년 예정으로 시간 소요. 센터 영업 의존

## 5. 에이치투케이 (소중한글)

**유형**: AI 유아 한글/언어교육 앱 | **고객**: 미취학 아동(난독증 포함) + 부모 | **수익원**: B2C 구독/이용권 + B2G 교구

### 주요활동

| 활동 | 내용 |
|:-----|:-----|
| **투입/조달** | 자체 아동 음성인식 AI, 소리 중심 한글 파닉스 교육법. KAIST 기술 기반. 핵심 자산: 아동 음성 데이터+교육 커리큘럼 |
| **운영/생산** | AI 완전 자동화(85%+). 진단 → 맞춤 커리큘럼 → 게임형 자가학습. 부모/교사 도움 불필요 설계 |
| **산출/배송** | 모바일 앱(iOS, Android). 초등학교 방과 후 교구 |
| **마케팅/영업** | 사회적 벤처 포지셔닝 → ESG 펀드 유치(카카오-SKT). 맘카페·육아 커뮤니티 |
| **서비스** | 학습 성취도 리포트, 선호도 기반 콘텐츠 추천 |

### 지원활동

| 활동 | 내용 |
|:-----|:-----|
| **인프라** | ~16명, 대전 본사. KAIST 출신 기술 중심 조직 |
| **인적자원** | AI 개발자 + 교육 콘텐츠 기획자 중심 |
| **기술개발** | 아동 음성인식 자체 개발. 파닉스 알고리즘 내재화 |
| **조달** | 투자금(25억+) 기반 R&D. 콘텐츠 제작(내부) |

### 수익창출 포인트
**"아이 혼자서도 가능한 자가학습"**이 핵심 가치. 부모 개입 최소화 → 사용 빈도 증가 → 구독 유지. B2G 교구는 안정적 반복 매출

### 강점 / 약점
- **강점**: 한글 파닉스 특화 니치 확보. AI 자동화율 높아 한계비용 낮음. ESG 투자 유치로 사회적 가치 인정
- **약점**: "한글 학습"에 특화 → 언어발달 지연 "진단/치료"와는 거리. 대전 기반으로 수도권 네트워크 약함

# Part 3. 시장 내 가치사슬 구조 유형 3가지

### 유형 A: "진단 게이트키퍼" (송앤스타크)

```
[음성 입력] → [AI 자동 진단] → [리포트 출력] → (끝)
```
- **특징**: 밸류체인의 최상류(진단)만 점유. 교육/치료는 타 기업에 의존
- **수익 구조**: 센터당 SaaS 구독료. 한계비용 극히 낮아 마진률 높음
- **리스크**: 교육/치료 연계 없이는 고객 Lock-in 약함

### 유형 B: "풀스택 O2O" (두부, 네오폰스)

```
[병원 진단] → [AI 교육/훈련] → [전문가 개입] → [병원 모니터링] → (순환)
```
- **특징**: 진단→교육→치료→관리의 전 과정을 커버. 병원-가정 연계
- **수익 구조**: 구독료 + 전문가 코칭료 + (향후) DTx 처방료. 다층 수익
- **리스크**: 전문가 의존도 높아 확장 시 병목. 번 레이트 부담

### 유형 C: "AI 자가학습 플랫폼" (에이치투케이, 와우키키)

```
[AI 진단] → [맞춤 커리큘럼] → [게임형 자가학습] → [리포트] → (반복)
```
- **특징**: 전문가 개입 최소화. AI 자동화율 80%+. 아이 혼자 사용 가능
- **수익 구조**: B2C 구독 중심. 한계비용 낮아 스케일업 유리
- **리스크**: 학습 효과 검증 약함 → 부모 신뢰 확보 난이도 높음

### 최적 포지션: "진단-교육 브릿지" 모델

| 포지션 | 전략 | 경쟁 강도 |
|:-------|:-----|:---------:|
| **무료 AI 진단 → 유료 맞춤 교육** | 송앤스타크의 진단 가치를 전환 트리거로, 에이치투케이의 자가학습을 교육 엔진으로 결합 | 낮음 |
| **부모 코칭 레이어 추가** | 모든 경쟁사가 "아동 대상 앱"에 집중. 부모 교육·비동기 코칭은 미개척 | 매우 낮음 |
| **주간/월간 발달 데이터 리포트** | 송앤스타크의 1회성 진단 vs 우리의 연속 추적 리포트로 차별화 | 낮음 |

# Part 5. 가장 취약한 경쟁사 유형

### 결론: **"진단 게이트키퍼" 유형 (송앤스타크)**

| 취약 요인 | 상세 |
|:----------|:-----|
| **밸류체인 단절** | 진단 후 교육/치료 연계 없음 → 고객이 진단 후 이탈 |
| **B2C 전환 지연** | 가정용 앱 2027년 예정. 2년의 시간 공백 |
| **Lock-in 부재** | 1회성 진단 → 반복 사용 동기 약함 |
| **공격 전략** | "무료 AI 진단 + 유료 맞춤 교육"을 결합한 풀 퍼널 서비스로 진입 시, 송앤스타크의 진단 가치를 흡수하면서 교육까지 확장 가능 |

> **핵심 시사점**: 송앤스타크가 2027년 B2C 전환을 완료하기 전, "진단+교육" 통합 모델로 시장에 진입하면 진단 영역의 선점 기회를 확보할 수 있음. 단, 진단 알고리즘의 과학적 검증(Evidence-Based)은 필수 조건.
