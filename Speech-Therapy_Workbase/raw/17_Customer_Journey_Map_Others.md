# Part 1. 확장 사용자 (Adjacent Users)

## Adjacent-1. 오한솔 (42세, 유치원 원장)
**"원아 스크리닝 도구가 필요해요"** | B2B2C

| **단계** | 고객 행동 | 고객 생각 | 감정 | Pain Point | 개선 기회 |
|:---------|:---------|:---------|:----:|:-----------|:---------|
| **문제 인식** | 매년 2~3명의 언어 지연 아이 발견. 부모에게 어떻게 말 꺼낼지 고민 | "교사 주관으로 '말이 느려요' 하면 부모가 기분 나빠할 수 있어" | 책임감 + 갈등 회피 | 객관적 기준 없이 교사 주관으로만 판단해야 함 | "기관용 스크리닝 패키지" B2B 영업 자료 제작 |
| **탐색** | 지역 아동센터 의뢰 시도 → 대기 길고 절차 복잡 → 특수교사 자문 | "더 쉽고 빠른 방법이 없을까? 연 1회라도 전체 아이들 검사하고 싶은데" | 답답함 + 필요성 인식 | 단체 스크리닝을 위한 기관용 도구가 시장에 없음 | 교육부/보건복지부 관련 컨퍼런스에서 기관용 제품 데모 |
| **의사결정** | 기관용 패키지 데모 요청 → 원아 전체 적용 가능 여부 확인 → 계약 협의 | "원아 80명에 연 1회 스크리닝이면 1인당 단가가 많이 낮아지겠네. 해볼만해" | 타산적 판단 + 기대 | 개인정보 처리와 부모 동의 절차가 복잡하면 도입 포기 | 부모 동의서 템플릿 제공 + PIPA 준수 데이터 처리 보증 문서 |
| **사용** | 연 1회 전체 원아 AI 진단 실시 → 결과 리포트 부모에게 배포 | "부모들이 '객관적 데이터'라니까 훨씬 잘 받아들이네. 이거 꽤 유용하다" | 안도 + 효능감 | 진단 결과 해석을 원장이 직접 부모에게 설명해야 하는 부담 | 결과 리포트에 "전문가 해석문" 자동 생성 + 부모 FAQ 템플릿 |
| **유지** | 이듬해 재계약 + 주변 원장들에게 추천 | "이거 우리 원 차별화 포인트가 됐어. '언어발달 검사 실시 유치원'으로 홍보할 수 있겠다" | 자부심 + 입소문 의지 | 연간 계약이라 한 번 이탈하면 복구 어려움 | 중간 점검 리포트(연 2회) + 재계약 시 할인 제공 |

**전략 포인트**: 원장 1명 설득 = 80가구 노출. B2B 영업이 가장 낮은 CAC를 만드는 채널.

## Adjacent-2. 손지훈 (35세, 아동심리상담사)
**"언어치료도 같이 연계하고 싶어요"** | 전문가 파트너

| **단계** | 고객 행동 | 고객 생각 | 감정 | Pain Point | 개선 기회 |
|:---------|:---------|:---------|:----:|:-----------|:---------|
| **문제 인식** | 내담 아동 30%가 언어 문제 동반. 언어치료 연계 시도 → 대기 4~6개월 | "심리치료 하는 동안 언어는 방치되는 게 너무 아깝다" | 전문가적 안타까움 | 심리와 언어를 동시에 커버하는 통합 솔루션 부재 |  "전문가 파트너 프로그램" 별도 제안서 발송 |
| **탐색** | 개별 언어재활사와 비공식 네트워크 구축 시도 → 지속성 없음 | "내가 신뢰하고 추천할 수 있는 검증된 앱이 있으면 좋겠다" | 파트너십 니즈 | 추천 후 결과를 추적할 방법이 없음 | 파트너 전용 추천 링크 + 내담 아동 진행 현황 공유 대시보드 |
| **의사결정** | 파트너 프로그램 제안 검토 → 임상 검증 자료 확인 | "이 앱이 실제 언어재활사 검토 기반이라면 내 내담 아동에게 추천해도 되겠다" | 신뢰 + 협력 의지 | 임상 근거 없는 앱은 전문가로서 추천 불가 | 파트너 전용 임상 근거 자료 + "전문가 추천 앱" 공식 배지 |
| **사용** | 내담 부모에게 앱 추천 → 사용 현황 간접 확인 | "부모들이 집에서 뭔가 하고 있으니 상담에도 시너지가 나는 것 같다" | 만족 + 협업 효과 | 부모 동의 없이는 진행 데이터 확인 불가 | 선택적 데이터 공유 동의 → 파트너 상담사에게 요약 데이터 제공 |
| **유지** | 파트너 상담사로 장기 관계 유지 → 학회·컨퍼런스에서 앱 소개 | "이게 내 서비스 품질도 높여주는 도구가 됐다" | 전문성 강화 만족 | 파트너 혜택이 유지되지 않으면 추천 중단 | 파트너 전용 월간 인사이트 레터 + 학술 발표 공동 기회 |

**전략 포인트**: 전문가 파트너는 "신뢰 앵커" 역할. 이들의 추천은 광고보다 10배 강한 전환력을 가짐.

## Adjacent-3. 이미란 (29세, 다문화 가정 어머니)
**"이중언어 환경에서 어떻게 해야 할지 모르겠어요"** | Seg A

| **단계** | 고객 행동 | 고객 생각 | 감정 | Pain Point | 개선 기회 |
|:---------|:---------|:---------|:----:|:-----------|:---------|
| **문제 인식** | 아이가 두 언어 모두 또래보다 느림 확인 | "이게 이중언어라서 그런 건지, 진짜 문제가 있는 건지 모르겠어" | 혼란 + 고립감 | 이중언어 환경과 언어지연의 구분 기준이 없음 | 랜딩 페이지에 "이중언어 가정을 위한 특별 진단" 섹션 |
| **탐색** | 다문화가족지원센터 방문 → 대기 길고 한국어로만 설명 | "내가 한국어가 완벽하지 않아서 설명을 다 이해못했어" | 소외감 | 지원 서비스의 언어 장벽 | 다국어 UI(베트남어·중국어·영어 등) + 쉬운 한국어 가이드 |
| **의사결정** | 앱 UI가 쉬운 한국어로 되어 있음 확인 → 이중언어 전용 진단 옵션 발견 | "이 앱은 우리 같은 가정도 생각해준 것 같다" | 소속감 + 신뢰 | 자신의 상황이 반영된 서비스인지 확인이 안 되면 이탈 | 다문화 가정 사례 후기 + "이중언어 환경 아이 발달 가이드" 무료 제공 |
| **사용** | 한국어 음소 중심 진단 → 이중언어 고려 맞춤 활동 수행 | "한국어 /ㅅ/ 발음 연습인데 집에서도 할 수 있네" | 자신감 회복 | 베트남어 발음 간섭이 한국어 발음에 미치는 영향 설명 없음 | 이중언어 전용 "모국어 간섭 패턴" 분석 + 극복 활동 |
| **유지** | 지속 사용 + 다문화 커뮤니티 카카오톡 방에 공유 | "나같은 엄마들한테 알려줘야겠다" | 커뮤니티 기여 욕구 | 커뮤니티 바이럴이 없으면 다문화 세그먼트 도달 어려움 | 다문화 맘카페 파트너십 + 추천 리워드 프로그램 |

# Part 2. 극단 사용자 (Extreme Users)

## Extreme-1. 황보름 (40세, 워킹맘 + ASD 경계선)
**"앱이 우리 아이를 이해 못해요"**

| **단계** | 고객 행동 | 고객 생각 | 감정 | Pain Point | 개선 기회 |
|:---------|:---------|:---------|:----:|:-----------|:---------|
| **문제 인식** | ASD 경계선 진단 후 언어치료 병행 필요 인식. 월 치료비 80만원 | "치료는 받는데 집에서 뭘 더 해줄 수 있을까" | 과부하 + 탐구 | 비전형 발화를 가진 아이에게 맞는 가정 케어 도구가 없음 | ASD 경계선 아동 전용 진단 트랙 개발 |
| **탐색** | 여러 앱 시도 → "우리 아이 발화를 앱이 못 인식해요" 반복 경험 | "정형적인 발화 기준으로 만든 앱이라 우리 아이한텐 안 맞는 거야" | 좌절 + 높은 전문성 | AI 음성인식이 비전형 발화를 오류로 처리 | 비전형 발화 모델 학습 데이터 수집 + 수동 치료사 리뷰 레이어 추가 |
| **의사결정** | "치료사 직접 리뷰 가능" 기능 확인 → 관심 | "AI가 못 잡으면 치료사가 직접 보는 구조면 써볼 수 있겠다" | 조건부 기대 | 치료사 리뷰 응답 속도와 전문성이 불확실 | 전담 치료사 매칭 + 48시간 내 리뷰 보장 SLA 명시 |
| **사용** | 발화 녹음 업로드 → 치료사 리뷰 수령 → 현재 센터 치료사와 데이터 공유 | "우리 센터 선생님이 이 데이터 보고 치료 계획 조정했어. 이게 진짜 도움이 되네" | 통합 케어 만족 | 센터와 앱 데이터가 연동되지 않으면 매번 수동 공유 필요 | PDF 리포트 + 치료사 공유 링크 원클릭 생성 |
| **유지** | ASD 경계선 부모 커뮤니티에서 앱 공유 | "이 앱은 우리 같은 아이들도 생각해줘서 달라" | 소속감 + 전도 의지 | 이 세그먼트는 소수지만 강한 커뮤니티. 만족 시 강력한 WOM | ASD 경계선 부모 온라인 커뮤니티 파트너십 |

**설계 핵심**: 이 사용자를 만족시키는 수준의 AI와 치료사 레이어가 구현되면, 일반 사용자는 자동으로 만족.

## Extreme-2. 강지방 (28세, 강원도 농촌 거주)
**"센터가 차로 2시간 거리예요"**

| **단계** | 고객 행동 | 고객 생각 | 감정 | Pain Point | 개선 기회 |
|:---------|:---------|:---------|:----:|:-----------|:---------|
| **문제 인식** | 읍내에 언어치료센터 없음. 시내 왕복 4시간 + 비용 = 사실상 불가 | "도시 애들은 쉽게 받는 치료를 우리 아이는 못 받아" | 박탈감 + 체념 | 지리적 접근성 격차. 온라인 대안도 인터넷 속도·기기 문제 | "농어촌 가정 무료 지원 프로그램" — 사회적 가치 마케팅 |
| **탐색** | 보건소 상담(비정기) → 유튜브 → 온라인 앱 탐색 | "앱이 있다던데 우리 폰으로 잘 돌아갈까? 데이터 요금도 걱정되고" | 기대 반 의심 반 | 구형 스마트폰에서 앱 구동 불안정. 음성 업로드 실패 반복 | PWA(경량 웹앱) 버전 제공 + 오프라인 캐시 기능 |
| **의사결정** | 경량 앱 버전 확인 → Wi-Fi 연결 시 활동 다운로드 가능 확인 | "Wi-Fi 있을 때 미리 받아두면 되겠다. 할 수 있겠는데?" | 안도 | 설치 및 설정이 복잡하면 포기 | 원클릭 설치 + 초기 셋업 5단계 이내. 전화 고객지원 옵션 |
| **사용** | Wi-Fi 연결 시간에 활동 다운로드 → 오프라인 상태로 아이와 활동 | "인터넷 없어도 되니까 편하다. 결과만 나중에 올리면 되고" | 실용적 만족 | 음성 녹음 파일 업로드 실패 시 좌절 | 저용량 음성 압축 + 업로드 실패 시 자동 재시도 + 진행 상태 표시 |
| **유지** | 보건소 간호사에게 앱 소개 → 지역 맘카페에 공유 | "우리 지역 엄마들도 이런 게 있는지 몰라. 알려줘야겠다" | 지역 커뮤니티 기여 | 농어촌 지역 마케팅 채널 부재 | 지역 보건소·육아종합지원센터 파트너십으로 접근 |

# Part 3. 비활성 사용자 (Non-users)

> **중요**: Non-user는 전통적 여정(사용→유지)까지 진행하지 않음.
> "이탈 지점"과 "접근 전략"에 초점을 맞춰 작성.

## Non-user-1. 윤성민 (41세, 아버지)
**"아내한테 맡기면 되는 거 아닌가요?"**

| **단계** | 고객 행동 | 고객 생각 | 감정 | Pain Point | 진입 전략 |
|:---------|:---------|:---------|:----:|:-----------|:---------|
| **문제 인식** | 아이 언어 지연을 인지. 하지만 아내가 알아서 할 거라 생각 | "남자 애들은 원래 늦어. 크면 다 해" | 무관심 + 근거 없는 낙관 | 아버지가 육아 문제의 당사자라는 인식 없음 | "아빠가 해주는 5분 언어 놀이" — 아버지 역할 중심 콘텐츠 |
| **탐색** | 아내 요청에 앱 화면 한 번 봄 → "이게 뭐야" 하고 덮음 | "3만원짜리 앱이라고? 그냥 말 걸어주면 되는 거 아니야?" | 비용 저항 + 무관심 | 앱의 가치를 체감할 기회 없음 | 무료 체험판에 "아빠 전용 활동" 포함 + "아빠 참여 시 효과 2배" 데이터 |

| **접근 전략** | — | — | — | 직접 타깃 불가 | 아내를 통한 간접 설득. 리포트에 "배우자 공유 버튼" 필수 탑재 |

## Non-user-2. 송혜경 (45세, 외할머니 — 실질 양육자)
**"옛날엔 다 알아서 컸어요"**

| **단계** | 고객 행동 | 고객 생각 | 감정 | Pain Point | 진입 전략 |
|:---------|:---------|:---------|:----:|:-----------|:---------|
| **문제 인식** | 손자가 말이 느리다는 걸 인지. 하지만 "크면 다 해"라는 경험적 확신 | "우리 때는 다 이렇게 컸어. 요즘 엄마들이 너무 예민한 거야" | 전통적 자부심 + 기술 거부감 | AI 진단이라는 개념 자체에 대한 불신 | 소아과 의사의 추천이라는 신뢰 앵커를 먼저 확보 |
| **탐색** | 딸(엄마)이 앱 소개 → "스마트폰 많이 보면 나쁜 거 아니야?" | "기계가 어떻게 애를 알아? 내가 직접 말 걸어주는 게 낫지" | 불신 + 거부감 | 디지털 리터러시 부족 + AI에 대한 근본적 불신 | "소아과 선생님도 권장하는 앱" + 화면 노출 최소 활동 위주 설계 |
| **⚠️ 이탈 지점** | 앱 설치 자체를 거부하거나 설치 후 방치 | "이게 뭔지도 모르겠고, 그냥 내가 동요 불러줄게" | 완전한 기술 회피 | 실질 양육자가 조부모인 20% 가정에서 서비스 침투 장벽 | 앱 없이도 가능한 "오늘의 가정 활동 카드" 인쇄물 형태로 배포 |
| **접근 전략** | — | — | — | 직접 타깃 불가 | 딸(엄마)을 설득한 후, "할머니도 할 수 있는 쉬운 활동" 별도 설계 |

## Non-user-3. 김민지 (32세, 워킹맘 — 유튜브 자가해결형)
**"유튜브 보여주니까 괜찮아진 것 같아요"**

| **단계** | 고객 행동 | 고객 생각 | 감정 | Pain Point | 진입 전략 |
|:---------|:---------|:---------|:----:|:-----------|:---------|
| **문제 인식** | 아이 말이 약간 느리지만 유튜브 언어발달 채널 틀어줌. 효과 있는 듯 느낌 | "유튜브 보여주니까 말이 좀 느는 것 같던데. 크면 다 하겠지" | 막연한 낙관 | 유튜브가 효과 있다는 착각(거짓 안심). 실제 개선인지 알 수 없음 | 콘텐츠 마케팅: "유튜브 시청과 직접 상호작용의 언어발달 효과 차이" |
| **탐색** | 앱 광고 접촉 → "유튜브로 충분한데 굳이?" | "유튜브는 공짜인데 이건 월 3만원이잖아. 다른 게 뭐야?" | 대체재 편향 + 비용 저항 | 무료 대체재 편향이 가장 강한 집단. SAM의 70~80% | 무료 진단으로 "유튜브만 봤을 때의 발달 궤적"과 비교 데이터 제시 |
| **⚠️ 이탈 지점** | 무료 진단 클릭 → "내 아이 데이터 넣기 싫다"며 이탈 | "굳이 이 앱에 아이 정보까지 줘야 해?" | 프라이버시 불안 + 귀찮음 | 진단 진입 장벽(개인정보 입력)이 이탈 트리거 | 익명 진단 옵션 + 진단 결과에 "유튜브만 했을 경우 vs 맞춤 훈련 시" 비교 시뮬레이션 |
| **전환 가능 시나리오** | 진단 결과 "우리 아이 발음 정확도가 또래 하위 25%입니다" 확인 | "생각보다 많이 낮네. 유튜브로 된다고 생각했는데…" | 충격 → 불안 → 행동 | 충격 요법이 과하면 거부감 발생 | 결과 화면에 "이 점수가 의미하는 것" + "유튜브 시청만으로는 이 부분이 개선되지 않아요" 데이터 |

**전략 포인트**: 김민지를 전환시키는 유일한 방법은 **"유튜브로 충분하다"는 믿음을 데이터로 깨는 것**. 이것이 모든 마케팅 메시지의 출발점이 되어야 함.
