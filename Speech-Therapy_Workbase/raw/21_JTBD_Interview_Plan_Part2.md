# 4. 심층 인터뷰 질문지

## 4-0. 질문 설계 원칙 (JTBD 가이드 기반)

인터뷰 가이드에 따라 다음 원칙을 엄수합니다:

1. **표면적 답변 피하기**: "왜 전환했나요?"라고 직설적으로 묻지 않음. 대신 **전환 사건(Switch Event)**의 맥락과 감정을 스토리텔링으로 유도
2. **4가지 전환 동인 경청**: 모든 질문은 Push(밀어내는 힘) / Pull(끌어당기는 힘) / Habits(발목 잡는 습관) / Anxieties(새 솔루션에 대한 불안) 중 하나를 발굴하도록 설계
3. **연상 유도**: "그때 몇 시였나요?", "집에서였나요?", "누구와 함께였나요?" 등 감각적 기억을 환기하여 깊은 스토리를 이끌어냄

## 4-1. 공통 질문 (모든 인터뷰이 대상, 15분)

### 도입 및 라포 형성

| # | 질문 | 목적 |
|:-:|:-----|:-----|
| Q1 | "아이의 나이와 현재 언어 상태를 편하게 말씀해 주세요. 예를 들어, 요즘 아이가 가장 많이 하는 말이 뭔가요?" | 라포 형성 + 아이의 현재 수준 파악 |
| Q2 | "아이의 말에 대해 '어? 이게 좀 느린 건가?' 하고 처음 느끼신 순간이 있으셨나요? 그때 상황을 가능하면 자세히 이야기해 주세요." | **Push** 발굴: 문제 인식의 트리거 순간 |
| Q2-F | *(후속)* "그때 하루 중 몇 시쯤이었나요? 집이었나요, 밖이었나요? 누구와 함께 있었나요?" | 연상 유도로 기억의 구체적 디테일 회수 |
| Q3 | "그 느낌을 받고 나서 처음으로 하신 행동이 뭐였나요?" | 최초 행동(first action) 파악 → 대체 솔루션 진입점 |

## 4-2. 대안 및 맥락 파악 질문 (20분)

### 현재 "고용(Hiring)" 중인 솔루션 탐색

| # | 질문 | 대응 전환 동인 |
|:-:|:-----|:------------|
| Q4 | "아이 언어 문제에 대해 지금까지 해보신 것들을 시간 순서대로 말씀해 주세요. 맘카페 검색, 유튜브, 소아과 질문, 앱 설치, 센터 문의… 뭐든 괜찮아요." | 대체 솔루션 Timeline 구성 |
| Q5 | "그중에서 가장 도움이 됐다고 느끼신 건 뭐였나요? 왜 그렇게 느끼셨나요?" | 현재 솔루션의 **Pull** 요소 |
| Q5-F | *(후속)* "그 방법이 해결해주지 못한 부분은 뭐였나요?" | 현재 솔루션의 한계 = 우리의 기회 |
| Q6 | "혹시 언어 관련 앱을 설치해 보신 적 있으신가요? 있다면 어떤 앱이었고, 지금도 쓰고 계신가요?" | 경쟁사 경험 파악 |
| Q6-F | *(후속)* "설치했다가 삭제하신 적이 있다면, 삭제한 순간을 떠올려 보세요. 어떤 생각이 드셨나요?" | **"해고(Firing)"** 순간의 감정과 맥락 |
| Q7 | "주변에 비슷한 고민을 하는 부모님이 계신가요? 그분들은 어떻게 하고 계신다고 들으셨나요?" | 사회적 맥락 + 입소문 경로 파악 |
| Q8 | "만약 지금 쓰고 계신 방법(유튜브, 맘카페 등)을 더 이상 쓸 수 없다면, 대신 뭘 하실 것 같으세요?" | 진짜 대체재의 위계 파악 |

## 4-3. 감정 및 전환 동인 심층 질문 (25분)

### 진단(Diagnosis) 수요 및 Push & Pull 발굴 (MVP 핵심 검증)

이 섹션은 MVP의 핵심 가설인 **"진단 부재로 인한 불안"**과 **"AI 진단 리포트의 가치"**를 검증하는 가장 중요한 파트입니다.

| # | 질문 | 대응 전환 동인 및 검증 목적 |
|:-:|:-----|:------------------------|
| Q9 | "우리 아이가 또래보다 느린 건지, 아니면 기다리면 될지 헷갈렸을 때, 그걸 확인하기 위해 구체적으로 어떤 행동을 해보셨나요?" | **대체 진단 수단 파악**: (예: 영유아검진 문진표, 인터넷 자가진단표, 지인 아이와 비교 등) |
| Q9-F | *(후속)* "그 방법으로 확인해보셨을 때, 충분히 안심이 되거나 결론이 나셨나요? 부족했다면 어떤 점이 답답하셨나요?" | **Push**: 기존 진단 방식의 한계 (주관성, 모호함, 의사의 "지켜보자"는 말에 대한 불신 등) |
| Q10 | "아이의 언어 상태에 대해 전문가가 아닌 부모님 스스로 평가를 내리는 데 있어 가장 두렵거나 망설여지는 부분은 무엇인가요?" | **Anxiety**: 진단 회피의 진짜 이유 (내 잘못일까 봐, 장애 판정 받을까 봐 등 심리적 장벽) |
| Q11 | "만약 스마트폰으로 아이의 목소리를 1분 정도 녹음해서, **'우리 아이 발음 정확도 62% (또래 하위 25%)'** 와 같이 수치화된 결과를 바로 볼 수 있다면 어떨 것 같으세요?" | **Pull**: 데이터 기반 AI 진단에 대한 수용도 및 기대 가치 측정 |
| Q11-F | *(후속)* "결과를 본 직후에 가장 먼저 드는 감정은 어떨 것 같으세요? 그리고 그 다음으로 어떤 행동을 하실 것 같으세요?" | **행동 전환 트리거**: 진단이 단순한 충격을 넘어, 후속 행동(솔루션 구독/센터 방문)으로 이어지는지 검증 |
| Q12 | "반대로 '정상 범위 (또래 상위 40%)'라는 결과를 받으신다면요? 그 결과를 누구에게 가장 먼저 보여주고 싶으신가요?" | **Pull / 사회적 맥락**: 안심 진단의 가치 및 가족 내 공유(남편, 시댁 등) 니즈 파악 |
| Q13 | "'진단만 해주고 끝나는 앱'과 '진단 결과에 맞춰 집에서 할 수 있는 주간 놀이 미션을 주는 앱' 중, 부모님께는 어떤 것이 더 가치 있나요? 왜 그렇게 생각하시나요?" | **MVP 스펙 검증**: 진단 단독 가치 vs 진단+교육 브릿지 가치 비교 |

### Habits & Anxieties 발굴 (전환 장벽)

| # | 질문 | 대응 전환 동인 |
|:-:|:-----|:------------|
| Q14 | "새로운 언어 진단/교육 앱을 써보려 할 때, 가장 먼저 드는 걱정이 뭔가요?" | **Anxiety** 직접 질문 |
| Q14-F | *(후속)* "아이 음성을 녹음해서 앱에 올린다고 하면 프라이버시 측면에서 어떠세요?" | 데이터 수집에 대한 거부감 측정 |
| Q15 | "지금까지 해오신 방법(유튜브 시청, 맘카페 눈팅)을 계속 유지하고 싶은 이유가 있다면 뭘까요?" | **Habits**: 기존 행동 패턴의 관성 |
| Q16 | "진단과 맞춤 놀이 가이드를 포함해 월 3만원 정도의 구독 서비스라면 어떻게 느끼시나요?" | 가격 수용 임계점 + 비용 불안 |
| Q16-F | *(후속)* "그 금액을 배우자에게 설명하고 결제 동의를 구해야 한다면 뭐라고 말씀하시겠어요?" | 가정 내 구독 정당화 로직 (B2C 구매 결정권) |

## 4-4. 페르소나별 추가 질문 (선택, 10분)

### 센터 대기자 전용 (최수현 유형)

| # | 질문 | 목적 |
|:-:|:-----|:-----|
| QC1 | "센터 대기 기간 동안 어떤 감정이 드셨나요? '기다리면서 뭔가 하고 있다'는 느낌과 '아무것도 못 하고 있다'는 느낌 중 어느 쪽에 더 가까우셨나요?" | 대기 기간 불안의 실제 강도 |
| QC2 | "만약 대기하는 동안 앱으로 주간 진단 + 가이드를 받을 수 있다면, 센터 치료가 시작된 후에도 계속 쓰실 것 같으세요?" | 센터 치료 시작 후 이탈 리스크 검증 |

### 유튜브 자가해결형 전용 (김민지 유형)

| # | 질문 | 목적 |

| QN1 | "유튜브 영상을 틀어줄 때, 아이가 실제로 따라 말하나요? 아니면 그냥 보고만 있나요?" | "유튜브 = 효과 있다"는 착각의 실체 검증 |
| QN2 | "혹시 '유튜브만으로는 부족할 수도 있겠다'고 느끼신 적이 있으세요? 있다면 어떤 순간이었나요?" | 거짓 안심이 흔들리는 전환 트리거 발굴 |

### 유치원 원장 전용 (오한솔 유형)

| # | 질문 | 목적 |
|:-:|:-----|:-----|
| QI1 | "원아의 언어 문제를 부모님께 말씀드린 적이 있으세요? 있다면 부모님 반응은 어땠나요?" | 기관→부모 소통의 실제 갈등 수준 |
| QI2 | "AI 진단 리포트를 원에서 제공하고 부모님께 공유하는 형태라면, 도입을 고려하시겠어요? 결정 과정은 어떻게 되나요?" | B2B 의사결정 구조 파악 |

### ⭐ 홈 트레이닝 방법론 전용 — Job-Story #3 검증 (이지수·박민정 유형)

*해당 페르소나: 집에서 아이를 도와주고 싶지만 방법을 모르는 부모*

| # | 질문 | 목적 |
|:-:|:-----|:-----|
| QM1 | "집에서 아이 말을 도와주기 위해 구체적으로 어떤 것들을 해보셨나요? 예를 들어, 책 읽어주기, 따라 말하기 놀이, 특정 단어 반복…" | 현재 부모가 시도하는 홈 트레이닝의 실체 파악 |
| QM1-F | *(후속)* "그 방법이 '제대로 된 방향'인지 확신이 있으셨나요? 어떻게 판단하셨나요?" | **Push**: 방법론 불확실성에서 오는 불안 강도 측정 |
| QM2 | "만약 '이번 주는 /ㅅ/ 발음 연습을 위해, 목욕 시간에 이 게임을 해보세요'처럼 아이 진단 결과에 맞춘 구체적인 주간 미션이 앱으로 온다면, 실제로 해볼 것 같으세요? 어떤 점이 마음에 드시거나, 반대로 부담스럽게 느껴지시나요?" | **Pull/Anxiety**: 맞춤 커리큘럼의 수용도와 실행 장벽 동시 파악 |
| QM3 | "비전문가인 부모가 집에서 아이 말 훈련을 잘못 시키면 오히려 역효과가 날까봐 걱정해보신 적 있으세요?" | 부모가 느끼는 '개입의 두려움'과 전문가 가이드에 대한 필요성 측정 |

### ⭐ 효과 확인·리텐션 전용 — Job-Story #4 검증 (박민정·최수현 유형)

*해당 페르소나: 훈련 효과를 수치로 확인하고 싶은 부모, 구독 유지 의지 확인*

| # | 질문 | 목적 |
|:-:|:-----|:-----|
| QR1 | "아이 언어 훈련을 한 달 이상 해보신 적이 있으세요? 있다면, '좋아지고 있다'는 걸 어떻게 알 수 있었나요?" | 현재 부모가 효과를 확인하는 방식(체감 vs 수치 vs 타인 평가) 파악 |
| QR1-F | *(후속)* "그 확인 방법이 충분히 만족스러우셨나요? 부족하다면 어떤 점이 아쉬웠나요?" | **Push**: 효과 불확실성의 실제 답답함 수준 측정 |
| QR2 | "'이번 달 /ㄹ/ 발음 정확도가 48%에서 67%로 올랐어요. 또래 평균(55%)을 넘었습니다'와 같은 주간 리포트를 받는다면 어떠세요? 그 리포트가 앱을 계속 쓰게 만드는 이유가 될 것 같으신가요?" | **Pull**: 발달 리포트의 리텐션 동기 강도 직접 측정 |
| QR2-F | *(후속)* "그 리포트를 가장 먼저 보여주고 싶은 사람은 누구인가요? (배우자, 부모님, 친구…)" | 리포트의 사회적 공유 니즈 → 바이럴 가능성 파악 |
| QR3 | "반면에 한 달을 써봤는데 수치 변화가 거의 없다면 어떻게 하실 것 같으세요? 계속 쓰시겠어요, 끊으시겠어요?" | **이탈 트리거 확인**: 리텐션 붕괴 조건과 그 임계점 파악 |

## 4-5. 페르소나별 인터뷰 전략 카드 (사전 정렬)

> **원칙**: 인터뷰 대상별로 인터뷰 전략을 한 단계 정리한 뒤, **해당 전략이 특정 페르소나에 정확히 맞춰져 있는지 검토하는 단계**를 거친다. 아래 전략 카드를 인터뷰 전 반드시 확인한다.

### 전략 카드 ① — 이지수 유형 (불안형 탐색자 / Seg A 대표)

| 항목 | 내용 |
|:-----|:-----|
| **핵심 검증 가설** | Job-Story #1(진단 공백), #3(방법론 부재) |
| **이 페르소나의 핵심 심리** | "호들갑인지 진짜인지 모른다" → 진단 회피 + 죄책감 |
| **인터뷰 전략** | 감정의 깊이를 파고들기. "처음 느꼈을 때"로 돌아가 스토리텔링 유도. 유튜브·맘카페를 "고용"한 이유와 한계를 자연스럽게 드러내도록 함 |
| **우선 질문 세트** | 공통(Q1~Q8) → 진단 심층(Q9~Q13) → 방법론(QM1~QM3) → 가격(Q16) |
| **주의사항** | 절대로 "진단이 필요하시죠?"식으로 유도하지 않음. 부모 스스로 진단의 필요를 말하게 해야 함 |

### 전략 카드 ② — 최수현 유형 (센터 대기자)

| 항목 | 내용 |
|:-----|:-----|
| **핵심 검증 가설** | Job-Story #2(대기 공백), #4(효과 확인) |
| **이 페르소나의 핵심 심리** | "골든타임을 놓치고 있다" → 응급성 + 무력감 |
| **인터뷰 전략** | 대기 기간의 감정적 강도를 수치화(1~10). 센터 치료 시작 후에도 앱을 계속 쓸지 여부를 통해 리텐션 가설 동시 검증 |

| **주의사항** | 센터 치료를 부정하는 뉘앙스 절대 금지. "보완 서비스"로만 포지셔닝 |

| 항목 | 내용 |

## 5-1. 모집 방법 (페르소나 기반 스크리닝 연계)

## 6-2. 데이터 분석 방법

### Step 1: Push/Pull/Habits/Anxieties 코딩

모든 녹취록에서 4가지 전환 동인 관련 발언을 태깅하고 빈도를 집계합니다.

| 전환 동인 | 예상 태그 예시 | 분석 목적 |
|:---------|:------------|:---------|
| **Push** | "어린이집 선생님이 말이 좀 느리다고...", "명절에 시어머니가..." | 마케팅 메시지의 트리거 포인트 결정 |
| **Pull** | "데이터로 보여주면 안심이 될 것 같아요", "전문가가 봐준다니까..." | MVP 핵심 기능 우선순위 결정 |
| **Habits** | "유튜브가 편해서...", "맘카페 보는 게 습관이라..." | 전환 장벽 제거 전략 결정 |
| **Anxieties** | "앱에 아이 정보 넣기 싫어요", "효과 없으면 돈 아까울 것 같아요" | 온보딩 UX 및 안심 장치 설계 |

### Step 2: Job Map 작성

인터뷰 결과를 종합하여 고객의 전체 Job 수행 과정을 8단계 Job Map으로 구조화합니다.

```
정의 → 위치 파악 → 준비 → 확인 → 실행 → 모니터링 → 수정 → 결론
```

### Step 3: Outcome-Driven Innovation (ODI) 매핑

각 Job 단계에서 고객이 원하는 **Desired Outcome(기대 결과)**을 도출하고, 현재 솔루션의 충족 수준과 비교하여 **과소 충족(Underserved)** 영역을 식별합니다.

## 6-3. MVP 반영 계획

| 인터뷰 결과 시나리오 | MVP 반영 방향 | 영향 범위 | 대응 Job-Story |
|:-----------------|:-----------|:---------|:-------------|
| **진단 회피가 "장애 공포"로 확인** | 랜딩 카피를 "치료 판정이 아니라 발달 위치 확인"으로 변경. 결과 화면에 "정상 범위" 강조 | 랜딩 페이지, 진단 UX | #1 |
| **유튜브 안심의 균열이 "또래 비교 순간"** | 진단 리포트에 "또래 평균 대비 포지션" 시각화 추가 | 리포트 UI | #6 |
| **WTP가 3만원 미만** | 프리미엄(전문가 코칭)과 베이직(AI only) 2-tier 요금제 도입 | 가격 모델 | #5 |
| **전문가 코멘트가 필수** | MVP에 비동기 전문가 코멘트 기능 포함 (KSF #3 조기 구현) | 기능 로드맵 | #1, #3 |
| **B2B 도입에 학부모 동의 필요** | 기관용 패키지에 "학부모 동의서 템플릿" 포함 | B2B 세일즈 자료 | #7 |
| **⭐ "뭘 해야 하는지 모른다"는 Pain이 강함** | 맞춤 커리큘럼을 MVP 핵심 기능으로 격상. 주간 미션 카드 UI 선기획 | 기능 로드맵, 온보딩 UX | **#3** |

## 6-4. Go/No-Go 판단 기준

인터뷰 결과가 다음 조건을 충족하면 **Go**, 미충족 시 **Pivot 또는 No-Go**로 판단합니다.

| 조건 | 대응 Job-Story | Go 기준 | No-Go 신호 |
|:-----|:-------------|:--------|:----------|
