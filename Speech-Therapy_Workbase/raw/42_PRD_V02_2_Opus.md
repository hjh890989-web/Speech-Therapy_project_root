## 1. 개요·목표
- 문제 정의(Pain지표 포함):
  - **Seg A (불안형 탐색자)**: 진단 기준의 부재. 맘카페 정보 탐색 *월 20시간 이상*, 오프라인 초진 대기 *최소 2~3개월*. (실패 KPI: 주관적 불안감 지수 최고조, 즉각 진단율 0%)
  - **Seg C (센터 대기자)**: 골든타임 증발. 대기 중 언어 지연 방치 기간 *평균 4.5개월*. (실패 KPI: 치료 개입 없는 방치율 100%)
  - **Seg B (데이터형)**: 노력의 가시화 실패. 기존 교육 앱/홈케어 리텐션 *1개월 내 80% 이탈*. (실패 KPI: M1 리텐션 20% 미만)
  - **Seg D-1 (원장)**: 학부모 발달 민원 발생 *연 3~5건*, 갈등으로 인한 원아 연쇄 퇴소 *1~2명/분기*. (실패 KPI: 기관 책임 전가 비율 증가)
- 목표(Desired Outcome 수치화):
  - **Seg A**: 맘카페 탐색 시간 월 20시간 → **0분**, 진단 리드타임 3개월 → **5분**.
  - **Seg C**: 대기 중 언어 지연 방치 기간 **0시간 (즉시 개입)**, 오프라인 센터 초기 파악기간 4주 → **1주 단축**.
  - **Seg B**: 홈케어 연속 유지 기간 1개월 미만 → **3개월 이상 (리텐션 극대화)**.
  - **Seg D-1**: 악성 민원 건수 **연 0건**, 발달 갈등 연쇄 퇴소 방어로 **1,100% ROI 달성**.
- 성공 지표(북극성/보조 KPI):
  - **북극성 KPI (North Star)**: 유료 결제 전환율(Conversion) **≥ 8%** (기준선: 2%, 타겟: 8%, 월간 측정), M3 리텐션 유지율 **≥ 40%** (기준선: 10%, 타겟: 40%, 분기 측정).
  - **보조 KPI (Secondary)**: 마케팅 유입 단가(CAC) **≤ 30,000원**, B2B 기관용 대시보드 무상 도입 수락률 **≥ 20%**.

## 2. 사용자와 페르소나
- **Seg A (불안형 탐색자)**: 맘카페 의존도가 높으며, 객관적 진단 수치 확인을 통한 즉각적인 안도감이 필요. (12~15만 가구)
- **Seg C (센터 대기자)**: 오프라인 3~6개월 대기 중 골든타임을 허비한다는 죄책감 방어를 원함. (2~3만 가구)
- **Seg B (데이터형 개입자)**: 노력의 가시적인 성과 증명(시계열 데이터 점수화)을 통해 가족을 설득하고자 함. (3~5만 가구)
- **Seg D-1 (유치원 원장)**: 학부모 민원 방어 및 원아 퇴소 예방 목적의 공신력 있는 외부 증명 데이터가 필요함. (B2B 결제자)
- **Seg D-2 (보육 교사)**: 학부모와 상담 시 감정 소모를 피하고, 추가 업무 가중 없이 시스템을 사용하길 원함. (B2B 게이트키퍼)

## 3. 사용자 스토리와 수용 기준(AC, Acceptance Criteria)

### Story 1: 초기 진단 및 훅(Hook)
- **Story**: As a 불안형 부모(Seg A), I want 웹 브라우저에서 5분 내로 발달 진단을 완료하기를, so that 긴 센터 대기나 앱 설치 없이 즉각적으로 불안을 해소할 수 있다.
- **AC 1**: Given 부모가 맘카페 등에서 진단 링크를 클릭했을 때 / When 앱 다운로드 없이 웹뷰가 실행되면 / Then 진단부터 결과 확인까지의 총 소요 시간은 **5분(±1분)** 이내여야 한다.
- **AC 2**: Given 진단을 마치고 결과를 생성할 때 / When AI 엔진 처리가 완료되면 / Then 결과 데이터는 동년배 백분위 위치로 산출되어 응답 시간 **≤ 2초** 이내에 화면에 시각화되어야 한다.
- **AC 3**: Given 진단 결과를 사용자에게 노출할 때 / When 결과 페이지가 로드되면 / Then "의료적 판단이 아님"을 명시하는 Disclaimer 문구가 **100% 화면 최상단**에 노출되어 동의를 받아야 한다.

### Story 2: 홈 랭귀지 코칭 (미션 수행)
- **Story**: As a 센터 대기자(Seg C), I want 아이의 수준에 맞는 데일리 맞춤 미션을 제공받기를, so that 대기 기간 중 골든타임을 낭비하지 않고 체계적인 홈케어 기록을 쌓을 수 있다.
- **AC 1**: Given 아이가 데일리 미션을 시작할 때 / When 세션을 진행하면 / Then 각 미션은 완료 시점까지 **≤ 1분** 소요되도록 숏폼 형태로 최소 3개가 연속 제공되어야 한다.
- **AC 2**: Given 아이가 미션(발화)에 3회 연속 실패할 때 / When 백엔드 엔진이 이를 감지하면 / Then 아이가 인지하지 못하도록 실패 피드백 표시 없이 **1초 내**에 난이도를 1단계 하향 조정한 미션으로 우회 라우팅해야 한다.
- **AC 3**: Given 주간 단위 훈련을 마쳤을 때 / When 사용자가 PDF 내보내기를 누르면 / Then **3초 이내**에 주간 발달 추이와 음소별 성장 데이터가 담긴 PDF가 무손실로 출력되어야 한다.

### Story 3: B2B 기관 Zero-touch 데이터 수집
- **Story**: As a 보육 교사(Seg D-2), I want 자유 놀이 시간에 마이크만 켜두는 것으로 아이들의 발화 데이터가 분리 수집되기를, so that 내 업무 가중 없이 객관적인 스크리닝 리포트를 확보할 수 있다.
- **AC 1**: Given 교실 환경에서 / When 태블릿의 앱을 실행해 두면 / Then 교사의 수동 입력이나 타이핑이 **0회**인 상태에서 패시브 음성 수집이 시작되어야 한다.
- **AC 2**: Given 수집된 음성 데이터를 처리할 때 / When 화자 분리(Diarization) 엔진이 동작하면 / Then 백색 소음 속에서도 성인과 아동의 음성을 **90% 이상**의 정확도로 분류해야 한다.
- **AC 3**: Given 학부모 알림장 작성 시점이 되었을 때 / When 교사가 [알림장 복사] 버튼을 누르면 / Then AI 쿠션어가 적용된 안내 텍스트 초안이 **≤ 2초** 내에 생성되어 클립보드에 복사 가능해야 한다.

## 5. 비기능 요구사항(NFR, Non-Functional Requirement)
- **성능 (Performance)**: 
  - 진단 리포트 생성 및 화면 렌더링 응답: **p95 ≤ 2,000 ms**.
  - 앱 부팅 속도 및 숏폼 미션 간 화면 전환: **≤ 500 ms**.
- **신뢰성 (Reliability)**:
  - 시스템 월 가용성 **≥ 99.9%**.
  - 음성 데이터 처리, 분석, 저장 중 시스템 오류율 **≤ 0.5%**.
  - AI 엔진의 진단 스코어링 성공률 **≥ 95%**.
- **보안/비용 (Security/Cost)**:
  - 법정대리인 데이터 수집 동의 기록 전자서명 및 100% 암호화 보존 처리.
  - 클라우드 기반 STT 및 분석 파이프라인 처리 비용 건당 **5원 이하**로 최적화 통제.
- **모니터링 항목 (Monitoring)**:
  - **로그**: 유입-가입 퍼널 이탈 구간 트래킹, 데일리 숏폼 미션 중도 포기/실패 로그 적재.
  - **대시보드**: 5분 진단 완료율 실시간 모니터링, 페이월 유료 결제 전환 퍼널 추적.
  - **알림 기준**: AI 분석 엔진 API 응답 지연 (Timeout > 3s) 시 Slack / PagerDuty 즉시 경고 알림 연동.

## 6. 데이터·인터페이스 개요
### 핵심 엔터티(Entity)
- `User`: id, role (Parent/Director/Teacher), status, created_at
- `Child`: id, parent_user_id, institution_id (B2B 연동용), birth_date, gender
- `Diagnosis`: id, child_id, linguistic_score, articulation_score, acoustic_score, percentile_rank, audio_url
- `MissionSession`: id, child_id, mission_type, duration_seconds, success_count, final_difficulty_level
- `Institution`: id, name, director_id, active_child_count

### 외부/내부 API 개요
- **내부 분석 API (`POST /api/v1/analyze-speech`)**: 
  - **Input**: audio/wav, child_age, gender
  - **Output**: JSON (언어/조음/음향 3축 스코어, 보정 난이도 제안)
- **외부 연동 API**:
  - 알림장 포맷 변환 API (키즈노트 등의 B2B 시스템 연동).
  - 카카오 알림톡 API (B2B 결과지 발송 및 앱 설치 유도).
  - 전자서명 API (음성 수집 전 법정대리인 동의서 획득).

## 7. 범위(In/Out), 리스크·가정·의존성
### 범위 명시 (In/Scope vs Out-of-Scope)
- **In-Scope**: 비의료/교육 목적 언어 발달 스크리닝 웹뷰, 구독형 주간 맞춤 홈 코칭 미션, B2B 기관용 무입력 스크리닝 대시보드.
- **Out-of-Scope**: 식약처 인가 목적의 의료기기(DTx) 확정 진단, 실시간 전문가 화상 대면 치료, 7세 초과 아동 대상 교정 커리큘럼.

### 리스크(Risk) 및 방어 전략(Mitigation)
1. **AI 오진 및 의료법 위반 리스크**
   - *Mitigation*: 앱 화면 최상단 'Disclaimer(의료 판단 불가)' 문구 강제 표기. 초기 런칭 시 전문가(언어재활사) 비동기 감수 프로세스 병행.
2. **보육 교사(게이트키퍼)의 업무 가중 우려에 따른 거부**
   - *Mitigation*: 교사의 수동 평가를 배제하고 화자 분리 기술 기반 '완전 Zero-touch 마이크 패시브 수집' 시스템을 Must-have로 보장.
3. **아동 음성 데이터 수집 시 법적 침해 논란**
   - *Mitigation*: 모든 진입점에 전자서명을 활용한 '법정대리인 개인정보 및 음성수집 동의' 강제 퍼널 설계.

### 가정·의존성
- 맘카페를 통한 초기 5분 무료 진단 웹뷰 바이럴 마케팅이 유효하게 작동할 것이다.
- 화자 분리(Diarization) 및 STT 알고리즘이 유아의 부정확한 발음과 백색소음 환경에서도 요구 성능(정확도 90%)을 달성할 수 있다. (ADR 링크 추후 연동 필요)

### 롤아웃 및 실험 계획 (Design & Metrics)
- **베타 채널**: 수도권 지역 타겟 맘카페 5곳 링크 배포 (Phase 0), 친분 유치원 3곳 B2B PoC 테스트 진행.
- **실험 설계(Design)**:
  1. *무료 진단 훅 (Hook) A/B 테스트*: 마케팅 카피 ("언어 발달 점검" vs "내 아이만 뒤처질까 두려울 때") 배포.
     - **Metrics**: 링크 클릭률(CTR), 진단 완료율. 성공 기준: CTR 15% 이상 달성.
  2. *결제 전환(Conversion) 테스트*: 첫 주 발달 리포트 제공 후 구독 전환 팝업의 효과성 검증 (n=500).
     - **Metrics**: 페이월 노출 대비 정기 구독 전환율. 성공 기준: 8% 이상.
  3. *보육 교사 Zero-touch 수용성 실험*: 실제 유치원 교실 환경에서 대시보드 자동화 만족도 조사.
     - **Metrics**: 교사 개입 투입 시간(0분 여부), 시스템 추천 알림장 문구 채택률, 사용 편의성(5점 척도).

### 벤치마크
- **리텐션 방어**: 타 유아 단순 교육 앱의 평균 M1 리텐션 20% 대비, 본 솔루션은 리포트 시각화 및 누적 보상을 활용해 **40% 이상**을 달성.
