### 3-2. 고객 세그먼트 피라미드

```
                    ▲
                   /  \
                  / 1% \    ← [A] 임상적 장애 진단 (자폐, 지적장애 등)
                 /──────\      → 병원·전문기관 치료 대상. 우리 서비스 범위 밖
                / 3~5%   \   ← [B] 건강검진 심화평가 권고
               /──────────\     → 센터 치료 필요. 우리 서비스의 보완재 역할
              / 10~15%     \  ← [C] 경계선 / 부모 체감 우려 ★ 핵심 타깃
             /──────────────\    → "센터 갈 정도인지 모르겠는" 회색지대
            / 30~40%         \ ← [D] 일반적 관심 / 예방적 니즈
           /──────────────────\   → "잘하고 있는지 확인하고 싶은" 부모
          / 100% (만0~7세 전체) \← [E] 전체 영유아 (약 240만 명)
         /______________________\
```

### 3-3. 고객 행동 단계 (Customer Journey)

| 단계 | 행동 | 추정 비율 | 비즈니스 기회 |
|:-----|:-----|:---------:|:------------|

| **②탐색** | 맘카페 검색, 유튜브 시청, 센터 전화 | 20~25% | 무료 AI 진단 랜딩 |
| **③시도** | 센터 예약 or 앱 다운로드 | 10~15% | 무료 진단 완료 → 리포트 |
| **④전환** | 유료 서비스 결제 (센터 or 앱) | 5~8% | 구독 전환 |

| **⑥추천** | 맘카페·지인에 후기 공유 | 1~2% | NPS 50+ 달성 시 바이럴 |

# 4. TAM → SAM → SOM 산정

### 4-1. 산정 로직

```
TAM (전체 가용 시장)
 └─ 만 0~7세 아동 약 240만 명 × 언어 관심/우려 부모 30~40%
    = 72~96만 가구

SAM (유효 시장)
 └─ 그 중 "경계선 + 심화 우려" (세그먼트 B+C) = 10~15%
    = 24~36만 가구
 └─ × 온라인 서비스 수용 의향 ~70% (스마트폰 보유·디지털 친화)
    = 17~25만 가구

SOM (획득 가능 시장, 3년 내)
 └─ SAM의 3~5% 시장 점유 목표
    = 5,000~12,500 가구
```

### 4-2. 금액 환산

| 구분 | 가구 수 | 월 ARPU | 연 매출 |
|:-----|:------:|:------:|:------:|
| **TAM** | 72~96만 | 3.5만원 | **3,024~4,032억원** |
| **SAM** | 17~25만 | 3.5만원 | **714~1,050억원** |
| **SOM (3년)** | 0.5~1.25만 | 3.5만원 | **21~52.5억원** |

> **VC 관점 검증**: 이전 문서(#9)에서 "TAM 연 1,080~1,800억원"으로 추산했는데, 이번 데이터 기반 재계산 결과 SAM이 **714~1,050억원** 수준으로 수렴. 대체로 일관된 범위 내에 있어 가설의 신뢰도가 확인됨.
