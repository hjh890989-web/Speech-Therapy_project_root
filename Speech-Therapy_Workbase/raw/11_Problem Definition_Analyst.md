# 문제 정의서 (Problem Definition) — 실무자 리뷰
## 아이 말이 늦는 것 같은 부모를 위한 온라인 교육 서비스

> **작성 기준**: 2026년 5월 | **리뷰 관점**: 실무 분석가 (3~5년차)
> **이 문서의 목적**: 분석 보고서 7개를 읽고 나서, "그래서 우리가 뭘 만드는 거죠?"에 대한 답을 한 장으로 정리

---

# 잠깐, 용어부터 정리하고 갑시다

분석 보고서에 전문 용어가 너무 많아서, 우리 팀원 누구나 알아듣도록 먼저 번역합니다.

| 보고서 용어 | 쉬운 말 |
|:-----------|:-------|
| TAM / SAM / SOM | 전체 시장 / 우리가 노릴 수 있는 시장 / 실제 잡을 수 있는 시장 |
| DTx (디지털 치료기기) | 식약처 허가 받아서 병원에서 처방하는 앱. 우리 서비스랑은 다른 길 |
| CAC | 고객 1명 데려오는 데 드는 비용 (광고비 등) |
| LTV | 고객 1명이 평생 우리한테 쓰는 돈 |
| M3 유지율 | 가입 후 3개월 뒤에도 쓰는 사람 비율 |
| KSF | 이거 못하면 망하는 핵심 조건 |
| 밸류체인 | 우리 서비스가 돈 버는 과정을 단계별로 쪼갠 것 |
| 전환율 | 무료 써본 사람 중 유료 결제하는 비율 |

# 1. 시장 상황 — 한 줄 요약

**"아이 발음이 걱정되는 부모는 많은데, 이 사람들한테 제대로 된 서비스를 파는 회사가 아직 없다."**

좀 더 자세히 풀면 이렇습니다.

### 시장은 어떤 상황인가요?

| 상황 | 실무적으로 무슨 뜻? |
|:-----|:-----------------|
| 언어치료 센터 대기 3~6개월 | 부모가 불안한 채로 반년을 기다림. **이 대기 기간이 우리 시장** |
| 센터 비용 회당 3~6만원 | 월 12~24만원. 우리 앱이 월 3~5만원이면 가격 경쟁력 있음 |
| 유튜브로 해결하는 부모 70~80% | **최대 리스크.** 대부분 "공짜로 대충" 하고 있음. 우리가 왜 더 나은지 증명해야 함 |
| 경쟁사 대부분 DTx에 올인 | 식약처 허가 받으려고 2~3년 매달리는 중. **지금 교육 앱 자리가 비어 있음** |
| 언어재활사 구하기 어려움 | 1급 합격률 17%. 전문가에 의존하면 확장이 안 됨 |

### 경쟁사는 뭐 하고 있나요?

솔직히 말하면, **우리 서비스랑 똑같은 걸 하는 회사는 아직 없습니다.** 비슷한 회사는 있는데, 각각 다른 걸 하고 있어요.

| 회사 | 뭐 하는 곳? | 우리랑 다른 점 |
|:-----|:-----------|:------------|
| **네오폰스** (토키랜드) | 자폐·언어지연 아이용 재활 앱 | 식약처 허가 받으려고 하는 중. **치료 쪽이라 우리랑 카테고리가 다름** |
| **와우키키** (하이동동) | 입모양+발성 분석 AI 앱 | 기술은 좋은데 아직 초기 스타트업. 매출 30억 목표인데 달성 여부 미확인 |
| **두부** (두브레인) | 아동 인지발달 앱 + 병원 연계 | 210억 투자 받음. 근데 **언어가 아니라 인지 쪽이 주력** |
| **송앤스타크** (스피치맵) | AI로 언어발달 수준 진단만 해줌 | **진단만 하고 교육은 안 해줌.** 진단 후 부모가 뭘 해야 하는지 모름 |
| **에이치투케이** (소중한글) | 한글 읽기/쓰기 교육 앱 | **한글 학습이 주력.** 발음 교정이나 언어발달 코칭은 안 함 |

**실무 관점 정리**: 진단만 하는 회사, 치료만 하는 회사, 한글만 가르치는 회사는 있는데, **"진단해주고 → 맞춤 교육 해주고 → 나아지는 걸 보여주는"** 한 묶음 서비스는 아무도 안 하고 있습니다.

### 돈 버는 구조는 뭔가요?

복잡한 밸류체인 분석을 실무 언어로 번역하면 이겁니다.

```
[STEP 1] 무료로 아이 발음 검사해줌  →  부모가 "어, 우리 아이 62점이네?" 하고 놀람
                ↓
[STEP 2] "맞춤 훈련 프로그램 해볼래요?"  →  월 3~5만원 구독 시작
                ↓
[STEP 3] 매주 "이번 주 /ㅅ/ 발음 62점→71점" 리포트 보내줌  →  부모가 "오 효과 있네" 하고 계속 씀
                ↓
[STEP 4] (선택) 전문가가 주 1회 텍스트로 코멘트  →  "전문가도 봐주네" 하고 프리미엄 결제
```

여기서 **진짜 중요한 건 STEP 1이랑 STEP 3**입니다.
- STEP 1(무료 진단)이 안 되면 → 사람이 안 들어옴
- STEP 3(발달 리포트)이 안 되면 → 3개월 안에 다 나감

# 2. 우리가 풀어야 하는 문제

이제 핵심입니다. **우리가 해결하려는 문제가 뭔지** 누가 물어보면 이렇게 대답하면 됩니다.

---

### 누구의 문제?

**"우리 아이 말이 좀 늦는 것 같은데..."** 하고 걱정하는 2~7세 아이 부모.

좀 더 구체적으로 말하면:
- 센터 가기엔 이른 것 같고
- 그냥 두기엔 불안하고
- 맘카페에 물어봤더니 "병원 가보세요" vs "괜찮아요" 의견이 반반이라 더 혼란스러운 부모

**대략 몇 명?** 한국에서 연 30~50만 가구로 추정. (2~7세 아동 약 240만 명 중, 언어발달 우려 경험 비율 15~20% 적용)

### 어떤 상황에서?

아이가 "사과"를 "타과"라고 말할 때. 어린이집 선생님이 "다른 애들보다 말이 좀..." 할 때. 명절에 친척이 "얘 아직 말 못 해?" 할 때.

그때부터 시작되는 루프:
```
맘카페 검색 → 불안해짐 → 센터 전화 → "3개월 대기요" → 
→ "일단 기다려보자" → 유튜브 틀어줌 → 효과 모름 → 다시 불안 → (반복)
```

### 뭐가 불편한 건데?

**세 가지인데, 하나로 요약하면 "기준이 없다"입니다.**

| 불편함 | 부모 입장에서 한 마디로 | 우리가 해줄 수 있는 것 |
|:-------|:--------------------|:------------------|
| **① 정상인지 아닌지 모름** | "62점이 나쁜 건지 괜찮은 건지 모르겠어" | 또래 평균 대비 점수 + "지금 개입 필요" or "지켜봐도 OK" 판정 |
| **② 뭘 어떻게 해줘야 하는지 모름** | "유튜브는 다 다른 소리 하잖아" | 진단 결과에 맞춘 맞춤 훈련 (이 소리 먼저, 저 소리 다음) |
| **③ 나아지고 있는지 모름** | "한 달째 시키는데 달라진 게 뭔지..." | 매주 점수 변화 그래프 → "지난주보다 9점 올랐어요" |

# 3. 실무 체크리스트 — "내일 당장 뭘 해야 하죠?"

분석 보고서에서 KSF(핵심 성공 요인) 5개가 나왔는데, 실무 우선순위로 재정렬하면 이렇습니다.

### 당장 해야 하는 것 (0~3개월)

| 할 일 | 왜? | 완료 기준 |
|:------|:----|:---------|
| **무료 진단 기능 프로토타입** | 사람을 데려오는 유일한 수단이니까 | 아이 음성 녹음 → 발음 점수 + 또래 비교 리포트 나오는 MVP |
| **100가정 파일럿 모집** | 숫자 없으면 전부 가설이니까 | 맘카페/인스타 모집, 3개월 무료 사용 조건 |
| **핵심 지표 측정 시작** | 전환율, 유지율 실측 데이터가 전부니까 | 무료→유료 전환율, 주간 접속률, M1/M3 유지율 추적 대시보드 |

### 그 다음 해야 하는 것 (3~6개월)

| 할 일 | 왜? | 완료 기준 |
|:------|:----|:---------|
| **발달 리포트 시스템** | 3개월 차에 사람이 빠지는 걸 막아야 하니까 | 주간 점수 변화 그래프 + 부모 알림 |
| **전문가 2~3명 확보** | 비동기 코멘트 실험해봐야 하니까 | 주 1회 텍스트 코멘트 A/B 테스트 (있는 그룹 vs 없는 그룹) |
| **학습 효과 데이터 정리** | "이거 효과 있어요?"에 답할 수 있어야 하니까 | 파일럿 100가정의 Before/After 발음 정확도 비교 |

### 나중에 해도 되는 것 (6개월 이후)

| 할 일 | 왜 나중이어도 되나? |
|:------|:-----------------|
| 유치원/어린이집 B2B 연계 | 먼저 B2C에서 효과 증명이 있어야 기관이 관심을 가짐 |
| DTx 인허가 검토 | 지금은 "교육" 포지셔닝이 맞음. 의료 쪽은 나중에 생각 |
| 전문가 네트워크 대규모 확장 | 유저 1만 명 넘기 전까지는 3~5명이면 충분 |

# 4. 이거 진짜 될까요? — 솔직한 리스크 체크

실무자로서 솔직하게 걱정되는 부분 정리합니다.

| 걱정 | 얼마나 심각? | 대응책 |
|:-----|:----------:|:------|
| "유튜브가 공짜인데 왜 돈 내요?" | 🔴 심각 | 무료 진단 리포트의 퀄리티로 승부. "유튜브는 점수 안 알려주잖아요" |
| "교육 앱 3개월이면 다 삭제하잖아요" | 🔴 심각 | 발달 리포트가 핵심. "6개월치 기록 날리기 아까워서라도 유지" |
| "AI 발음 분석이 정확한가요?" | 🟡 보통 | 파일럿에서 전문가 평가 vs AI 평가 일치율 데이터 확보 필수 |
| "의료법에 걸리면?" | 🟡 보통 | 절대 "치료", "재활" 단어 사용 금지. "교육", "훈련", "코칭"으로 통일 |
| "경쟁사가 갑자기 같은 거 하면?" | 🟢 낮음 | DTx 기업들은 2~3년은 인허가에 묶여 있음. 시간 있음 |

# 5. 한 줄 정리

> **"아이 말이 늦는 것 같아 불안한 부모한테, 무료로 진단해주고, 맞춤 훈련 시켜주고, 매주 나아지는 걸 보여주는 앱."**

이게 우리 서비스고, 이게 우리가 푸는 문제입니다.
나머지는 전부 이 한 줄을 실현하기 위한 디테일입니다.
