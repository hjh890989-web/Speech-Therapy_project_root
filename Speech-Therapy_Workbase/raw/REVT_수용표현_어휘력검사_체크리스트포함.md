## 1. 검사 개요

| 항목 | 내용 |
|---|---|
| 정식 명칭 | 수용·표현 어휘력 검사 (Receptive and Expressive Vocabulary Test) |
| 개발자 | 김영태, 홍경훈, 김경희, 장혜성, 이주연 (2009) |
| 출판 | 서울장애인종합복지관 / 학지사심리검사연구소 |
| 적용 연령 | **만 2세 6개월 ~ 만 16세 이상 성인** (광범위 연령) |
| 검사 시간 | REVT-R/E 각각 약 10~20분 (총 20~40분) |
| 시행 방식 | 1:1 개별 검사, 임상가 대면 시행 |
| 자격 | 언어재활사, 특수교사, 임상심리사 등 표준화 검사 시행 자격자 |

**개발 배경의 의미**
REVT는 기존에 한국 임상에서 널리 쓰이던 PPVT(Peabody Picture Vocabulary Test) 번안판의 한계를 극복하고자 개발됨. 한국어 어휘 빈도·습득 시기·문화적 맥락을 반영해 한국 아동 규준으로 표준화했고, 특히 **수용 어휘만 측정하는 PPVT와 달리 표현 어휘까지 함께 측정**한다는 점에서 임상적 의의가 큼. 또한 **2세 6개월부터 성인까지** 적용 가능해 평생 발달 단계에 걸쳐 사용 가능한 어휘력 도구로 자리 잡음.

## 2. 검사 구조

### 2.1 전체 구성

REVT는 **수용 어휘력(REVT-R)** 과 **표현 어휘력(REVT-E)** 두 개의 독립적 하위 검사로 구성됨.

```
REVT
├─ REVT-R (Receptive Vocabulary Test)
│   └─ 수용 어휘력: 듣고 그림 고르기 (4지선다)
│
└─ REVT-E (Expressive Vocabulary Test)
    └─ 표현 어휘력: 그림 보고 이름 말하기
```

각 하위 검사는 **약 185문항 내외**로 구성되어 있으며, 두 검사는 **별도의 자극·문항·규준**을 가짐. 동일 어휘를 수용/표현 양쪽에서 측정하지 않고, 각각 별개의 어휘 풀(pool)로 구성됨.

### 2.2 어휘 영역 구성

REVT는 단순히 무작위로 어휘를 모은 것이 아니라, **품사·의미 범주·습득 시기**를 균형 있게 배분함.

| 어휘 차원 | 주요 분류 | 비중 |
|---|---|---|
| 품사 | 명사, 동사, 형용사, 부사 | 명사 비중이 가장 높고 동사·형용사 순 |
| 의미 범주 | 사람, 사물, 동물, 자연, 행동, 속성, 추상 개념 등 | 발달 단계별로 비중 조정 |
| 난이도 | 초기 습득 어휘 → 후기 습득 어휘 → 학령기·성인 어휘 | 문항 번호 순으로 점진적 상승 |

문항 번호가 올라갈수록 추상도·문화적 특수성·학술 어휘 비중이 높아지는 구조임.

### 2.3 PRES와의 차이점 (보완 관계)

| 구분 | PRES | REVT |
|---|---|---|
| 측정 영역 | 의미·구문·화용 종합 | 어휘만 집중 측정 |
| 적용 연령 | 2;0 ~ 6;11 | 2;6 ~ 성인 |
| 문항 구성 | 90문항 (수용 45 + 표현 45) | 약 370문항 (수용 ~185 + 표현 ~185) |
| 어휘 측정 깊이 | 표면적 | 심층적·정밀 |
| 임상 활용 | 종합 언어 프로파일 | 어휘 정밀 측정·지연 진단 |

→ **두 검사는 경쟁 관계가 아닌 보완 관계**. 트랙 2 초기 평가에서 자주 함께 시행됨.

## 3. 시행 절차 (실제 검사 흐름)

### 3.1 시행 순서

일반적으로 **REVT-R(수용)을 먼저, REVT-E(표현)을 나중에** 시행함.

1. 수용 과제는 가리키기·번호 답하기로 가능해 부담이 적고
2. 표현 과제는 산출 부담이 있어 라포가 충분히 형성된 후가 적절하기 때문.

다만 임상가 판단에 따라 표현 검사를 먼저 하거나, 한 검사만 시행하는 것도 가능함.

### 3.2 시작점(Start Point) 결정

REVT는 **연령별 시작 문항**이 매뉴얼에 명시되어 있음.

- 예: 4세 아동 → 매뉴얼에 지정된 4세 시작 문항부터 시행
- 시작점에서 **연속 8문항을 통과하면 그 위로 진행**, 통과하지 못하면 한 단계 아래 시작점으로 하향 조정

이 방식 덕분에 모든 문항을 시행하지 않고도 효율적으로 어휘 수준을 측정할 수 있음.

### 3.3 기저선과 천장점

REVT의 일반적 규칙은 다음과 같음 (정확한 기준은 매뉴얼 우선).

- **기초선(Basal)**: 연속 8문항 정답 (이 아래는 모두 정답으로 간주)
- **최고한계선(Ceiling)**: 연속 8문항 중 6문항 또는 7문항 오답 (이 위는 모두 오답으로 간주)

기초선과 최고한계선이 확보되면 검사를 중단하고, 그 사이의 문항만 실제 채점에 반영함.

### 3.4 사용 도구

- **검사 그림책 (자극 그림판)**: REVT-R용과 REVT-E용 별도 구비
  - REVT-R: 한 페이지당 4개의 그림 (4지선다)
  - REVT-E: 한 페이지당 1개의 그림 (이름 말하기)
- **검사 기록지**: REVT-R/E 각각 별도
- **매뉴얼(지침서)**: 시행·채점·환산 기준
- **연령별 환산표**: 등가연령·백분위·표준점수 산출용

### 3.5 REVT-R (수용) 시행 방식

**핵심 절차**

1. 임상가가 검사 그림판을 펼쳐 4개의 그림을 보여줌
2. 임상가가 목표 어휘를 들려줌 (예: "○○를 가리켜 보세요" 또는 "○○는 어디 있을까요?")
3. 아동은 4개 그림 중 해당하는 그림을 가리키거나 번호를 말함
4. 임상가는 정답/오답을 기록 (정답 단서 제공 금지)

**주요 특징**

- 산출 부담이 없어 어린 아동, 표현 어려운 아동도 가능
- 단순 변별 과제이므로 추측 가능성 존재 (4지선다이므로 우연 정답률 25%)
- 가리키기·번호 말하기 모두 인정

### 3.6 REVT-E (표현) 시행 방식

**핵심 절차**

1. 임상가가 검사 그림판을 펼쳐 1개의 그림을 보여줌
2. 임상가가 "이게 뭐예요?" 또는 "이건 뭐 하는 거예요?" 등 매뉴얼 지시문 제시
3. 아동이 어휘로 답함
4. 임상가는 매뉴얼의 정답 목록과 비교해 채점

**주요 특징**

- 어휘 인출 능력까지 측정하므로 더 까다로움
- **수용 가능한 동의어·유사어 목록**이 매뉴얼에 명시되어 있어, 임상가는 그 범위 내에서 정답 처리
- 조음 오류로 인한 발음 부정확은 의미 전달 가능하면 정답 인정 (조음 자체는 별도 검사로 측정)
- 단서 제공 가능 범위(예: 의미 범주 단서)는 매뉴얼에 명시된 경우에만 허용

### 3.7 문항 유형 (예시 수준)

각 문항이 측정하는 능력 유형을 설명함 (실제 문항은 저작권으로 보호되므로 일반적 유형만 제시).

**REVT-R (수용) 문항 유형**

- 일상 사물·동물·음식 등 명사 변별
- 동작·상태 동사 변별 (그림 4장 중 "달리는" 그림 고르기 등)
- 형용사·부사 변별 (속성·정도 표현)
- 추상 개념 어휘 (감정, 시간, 관계어)
- 학술·문화 어휘 (학령기 이후 문항)

**REVT-E (표현) 문항 유형**

- 사물·동물·음식 이름 대기
- 동작 그림 보고 동사 산출
- 속성·상태 그림 보고 형용사 산출
- 추상 개념의 정의·명명
- 학술·문화 어휘 산출

## 4. 채점 방식

### 4.1 문항별 채점

**0/1 이분 채점**이 원칙임.

- REVT-R: 정확한 그림 선택 = 1점, 오답 = 0점
- REVT-E:
  - 매뉴얼의 표준 정답 또는 인정 범위 내 동의어 = 1점
  - 의미가 통하지 않는 응답·무반응 = 0점
  - "몰라요"는 0점 처리하되 별도 표기 권장
  - 조음 오류는 의미 전달 가능 시 정답 (예: 발음이 부정확해도 인식 가능한 경우)

### 4.2 원점수 산출

```
원점수(Raw Score) = (최고한계선 문항 번호) - (기초선 이후 오답 수)
```

기초선 이전 문항은 모두 정답으로 간주되어 자동 가산되고, 기초선과 최고한계선 사이의 오답만 차감하는 방식임.

### 4.3 환산점수 종류

REVT는 다음과 같은 환산점수를 제공함.

| 환산점수 | 설명 | 활용 |
|---|---|---|
| **등가연령(Age Equivalent)** | 원점수에 해당하는 평균적 연령 (개월 단위) | 발달 수준 직관적 파악 |
| **백분위(Percentile Rank)** | 동일 연령 집단 내 상대적 위치 | 또래 대비 위치 확인 |
| **표준점수(Standard Score)** | 평균 100, 표준편차 15 기준 | 통계적 진단 기준 |

### 4.4 진단 기준

REVT 표준점수와 -편차 기준에 따른 일반적 해석:

| 표준점수 / 편차 | 백분위 | 해석 |
|---|---|---|
| 평균 ±1SD 이내 (85~115) | 16~84%ile | 정상 발달 범위 |
| -1SD ~ -1.25SD | 약 10~16%ile | 약간 지연, 모니터링 필요 |
| -1.25SD ~ -2SD | 약 2~10%ile | 어휘 발달 지연 의심, 중재 권고 |
| -2SD 이하 (≤70) | < 2%ile | 명확한 어휘 발달 지연/장애, 중재 필수 |

**연령 차이 기준 (등가연령 활용)**

| 차이 (생활연령 - 등가연령) | 해석 |
|---|---|
| -6개월 이내 | 정상 범위 |
| -6 ~ -12개월 | 경계선, 모니터링 |
| -12개월 이상 | 어휘 지연, 중재 권고 |

또한 **수용-표현 어휘 격차**가 중요한 임상 정보임.

- **수용 ≫ 표현**: 어휘 인출(word retrieval) 어려움, 표현언어 특정 지연 가능성
- **수용 = 표현 (둘 다 낮음)**: 전반적 어휘 발달 지연
- **표현 > 수용**: 매우 드물며, 반향어·암기성 산출·자폐 스펙트럼 의심 단서

## 5. 결과 보고서 구성

REVT 시행 후 작성되는 평가 보고서는 보통 다음 항목을 포함함.

```
1. 의뢰 정보 (Referral Info)
   - 아동 인적사항, 생활연령, 의뢰 사유

2. 검사 시 행동 관찰
   - 라포 형성, 주의집중, 협조도, 추측 행동 여부

3. 검사 결과 (정량 지표)
   - REVT-R 원점수 / 등가연령 / 백분위 / 표준점수
   - REVT-E 원점수 / 등가연령 / 백분위 / 표준점수
   - 수용-표현 격차 분석

4. 영역별 분석 (정성 분석)
   - 품사별 강점/약점 (명사·동사·형용사·추상 어휘)
   - 의미 범주별 패턴 (구체 vs 추상, 일상 vs 학술)
   - 오반응 패턴 (의미적 오류, 음운적 오류, 무반응 등)

5. 진단적 결론
   - 정상/경계선/지연/장애 분류
   - 수용-표현 프로파일 해석

6. 권고사항
   - 추가 평가 필요 여부 (PRES, 자발화, 조음 등)
   - 중재 방향 (어휘 확장 전략, 인출 훈련 등)
   - 재평가 시점
```

## 6. 트랙 2 초기 평가에서의 활용

### 6.1 REVT의 임상적 위치

REVT는 **어휘력만을 정밀하게 측정하는 도구**임. 트랙 2 초기 평가에서 REVT가 제공하는 정보는 다음과 같음.

- **양적 어휘력 측정**: 또래 대비 어휘 수준 정량화
- **수용-표현 어휘 격차 진단**: 인출 어려움 vs 어휘 부족 구분
- **학습·학업 능력 예측 지표**: 어휘력은 읽기·학업 능력과 강한 상관

### 6.2 PRES와의 보완 관계

| 트랙 2 초기 평가 시나리오 | 권장 검사 조합 |
|---|---|
| 학령전 아동 종합 평가 | PRES + REVT (두 검사 모두) |
| 어휘력만 의심되는 사례 | REVT 단독 |
| 학령기 이후 아동 | REVT + 학령기용 종합 검사 |
| 어휘 외 영역(구문·화용) 의심 | PRES 우선, REVT 보조 |

### 6.3 다른 도구와의 조합

| 영역 | 보완 도구 |
|---|---|
| 종합 언어 능력 | PRES, LSSC (학령기 언어검사) |
| 조음·음운 | U-TAP, APAC |
| 화용·자발화 | 자유발화 표본 분석 (MLU, TTR, NDW 등) |
| 사회적 의사소통 | CCC-2 한국판 |
| 읽기·학업 | KOLRA, RA-RCP |

### 6.4 REVT의 강점과 한계

**강점**

- 수용/표현 어휘 분리 측정 → 인출 어려움 진단 가능
- 폭넓은 적용 연령 (2;6 ~ 성인)
- 시행 시간 짧음 (각 10~20분)
- 표준점수 제공으로 통계적 진단 기준 명확
- 한국 아동 규준 기반

**한계**

- **어휘력만 측정**: 구문·화용·담화 능력 평가 불가
- **단어 수준 평가**: 문맥 속 어휘 사용 능력은 측정 못 함
- 추측 가능성 (REVT-R은 4지선다라 우연 정답 가능)
- 그림 자극 의존도 → 시지각 문제 있는 아동에게 불리할 수 있음
- 다문화·이중언어 배경 아동에게는 해석 주의 필요

---

## 7. 정리: 실무 관점에서의 핵심

트랙 2 초기 평가에서 REVT를 활용할 계획이라면, 다음 세 가지를 의사결정 기준으로 잡으면 됨.

1. **REVT는 "어휘력 정밀 측정"의 표준 도구**다. 종합 언어 능력 평가는 PRES 등으로 별도 보완하라.
2. **수용-표현 격차 패턴이 임상적으로 중요**하다. 단일 점수보다 격차 해석이 중재 방향을 결정한다.
3. **표준점수와 등가연령을 함께 보라**. 등가연령은 직관적이지만, 통계적 진단은 표준점수(±SD) 기준으로 내려야 한다.

---

## 8. 추가 탐색 방향

다음 주제들이 후속 정리 후보임.

- REVT 결과를 어휘 중재 계획서로 연결하는 실무 흐름
- PRES + REVT + U-TAP 통합 해석 방법
- 자발화 분석 지표(NDW, TTR)와 REVT 결과 교차 검증
- 학령기 이후 어휘 평가에서 REVT의 위치 (LSSC, KOLRA와의 관계)
- 다문화·이중언어 배경 아동에서 REVT 해석 시 유의점

## 부록 A. 검사 전 준비 체크리스트

### A-1. 의뢰·접수 단계

- [ ] 의뢰 사유 확인 (어휘력 의심 vs 종합 언어 의심)
- [ ] 아동 생활연령 정확히 산출 (생년월일 기준 개월 수까지)
- [ ] 적용 연령(2;6 ~ 성인) 범위 내 여부 확인
  - [ ] 30개월 미만 → 다른 도구(M-B CDI-K 등) 검토
- [ ] 보호자 면담 자료 확보 (어휘 발달 이력, 가정 언어 환경)
- [ ] 청력검사 결과 확인
- [ ] 시지각 문제 여부 확인 (그림 변별 가능 여부)
- [ ] 다문화·이중언어 배경 여부 확인 (해석 시 반영 필수)
- [ ] PRES·다른 검사 동시 시행 여부 결정

### A-2. 검사 환경 준비

- [ ] 조용하고 산만하지 않은 검사실 확보
- [ ] 그림판을 펼쳐 놓을 충분한 책상 공간
- [ ] 조명 충분 (그림 식별 가능)
- [ ] 보호자 동석 여부 결정 (어린 아동은 동석 권장)
- [ ] 보호자 동석 시 정답 단서 제공 금지 사전 안내

### A-3. 검사 도구 준비

- [ ] REVT-R 검사 그림책
- [ ] REVT-E 검사 그림책
- [ ] REVT 매뉴얼(지침서)
- [ ] REVT-R 검사 기록지
- [ ] REVT-E 검사 기록지
- [ ] 환산표·규준표 (연령별)
- [ ] 필기구
- [ ] 강화제·아동 친화 도구 (스티커, 칭찬 카드 등)
- [ ] 녹음기 (선택, 사전 동의 필수)

### A-4. 검사자 준비

- [ ] 매뉴얼 시행 절차 재숙지
- [ ] 시작점·기초선·최고한계선 규칙 재확인
- [ ] REVT-E 표준 정답 및 인정 동의어 범위 사전 검토
- [ ] 표준 지시문 정확히 암기
- [ ] 단서 제공 허용 범위 확인 (매뉴얼 기준)

## 부록 B. 검사 시행 체크리스트

### B-1. 라포 형성 단계

- [ ] 아동 이름 부르며 친근하게 인사
- [ ] 가벼운 대화로 긴장 완화
- [ ] 검사 그림책에 대한 자연스러운 노출
- [ ] 아동 컨디션 관찰 (피로·배고픔·졸림·불안)
- [ ] 컨디션 부적절 시 검사 연기 검토

### B-2. REVT-R (수용) 시행

- [ ] 연령별 시작점 확인
- [ ] 표준 지시문 제시 ("○○를 가리켜 보세요")
- [ ] 정답·오답 즉각 기록
- [ ] 정답 단서 제공 금지 (시선·표정·강조)
- [ ] 추측 행동 별도 표기 (확신 없이 찍는 패턴)
- [ ] 기초선 확보 (연속 8문항 정답 기준 - 매뉴얼 우선)
- [ ] 최고한계선 도달 시 중단
- [ ] 모든 문항 반응 기록 확인

### B-3. REVT-R → REVT-E 전환

- [ ] REVT-R 완료 확인
- [ ] 짧은 휴식 제공 (필요 시)
- [ ] REVT-E 시작점 결정
- [ ] 아동 정서 상태 확인 (좌절감 여부)

### B-4. REVT-E (표현) 시행

- [ ] 그림 1개씩 명확히 제시
- [ ] 표준 지시문 제시 ("이게 뭐예요?" 등 매뉴얼 기준)
- [ ] 아동 응답 그대로 기록 (요약·해석 금지)
- [ ] 매뉴얼 정답 목록과 즉시 비교
- [ ] 동의어·유사어 인정 범위 매뉴얼 확인
- [ ] 조음 오류는 의미 전달 가능 시 정답 처리
- [ ] "몰라요" / 무반응 별도 표기
- [ ] 단서 제공은 매뉴얼 허용 범위 내에서만
- [ ] 기초선·최고한계선 확보 후 중단

### B-5. 검사 종료

- [ ] 모든 문항 반응 기록 확인
- [ ] 누락 문항·기록 오류 점검
- [ ] 비전형 반응(반향어, 회피 등) 별도 메모 확인
- [ ] 행동 관찰 기록 마무리
- [ ] 아동에게 종료 알림 및 격려
- [ ] 보호자에게 종료 안내

## 부록 C. 채점·해석 체크리스트

### C-1. 원점수 산출

- [ ] 기초선 확정 위치 확인
- [ ] 최고한계선 확정 위치 확인
- [ ] 기초선 이하 자동 정답 처리
- [ ] 기초선~최고한계선 사이 오답 수 계산
- [ ] 원점수 = 최고한계선 - 오답 수 (REVT-R, REVT-E 각각)
- [ ] 채점 의문 문항은 매뉴얼 재확인

### C-2. 환산점수 산출

- [ ] 연령별 환산표 적용
- [ ] 등가연령(Age Equivalent) 산출
- [ ] 백분위(Percentile Rank) 산출
- [ ] 표준점수(Standard Score) 산출 (평균 100, SD 15)
- [ ] REVT-R / REVT-E 각각 산출 확인

### C-3. 진단적 해석

- [ ] 표준점수 기준 분류 (±1SD / -1.25SD / -2SD)
- [ ] 등가연령과 생활연령 차이 분석
- [ ] 백분위 기준 또래 대비 위치 확인
- [ ] 수용-표현 격차 분석
  - [ ] 수용 ≫ 표현 (인출 어려움?)
  - [ ] 수용 = 표현 둘 다 저하 (어휘 부족 전반?)
  - [ ] 표현 > 수용 (반향어·자폐 스펙트럼 의심?)
- [ ] 품사별·범주별 강점/약점 분석
- [ ] 오반응 패턴 분석 (의미적 vs 음운적 vs 무관)

### C-4. 행동 관찰 통합

- [ ] 검사 중 주의집중 수준 기록
- [ ] 추측 행동 빈도 평가 (REVT-R 신뢰도 영향)
- [ ] 협조도·동기 수준 기록
- [ ] 점수 신뢰도 평가 (협조 부족 시 보수적 해석)

### C-5. 교차 검증

- [ ] 보호자 면담 정보와 검사 결과 일관성 확인
- [ ] PRES·자발화 분석 결과와 비교 (시행 시)
- [ ] 불일치 시 원인 분석 (검사 상황 vs 도구 한계)
- [ ] 다문화·이중언어 배경 영향 검토
- [ ] 시지각·청각 문제 영향 검토

### D-1. 필수 포함 항목

- [ ] 검사자 정보 및 자격
- [ ] 검사 시 행동 관찰
- [ ] REVT-R 정량 지표 (원점수, 등가연령, 백분위, 표준점수)
- [ ] REVT-E 정량 지표 (원점수, 등가연령, 백분위, 표준점수)
- [ ] 수용-표현 격차 해석
- [ ] 영역별 정성 분석
- [ ] 진단적 결론
- [ ] 권고사항
- [ ] 재평가 시점

### D-2. 작성 시 점검

- [ ] 표준점수와 등가연령 둘 다 제시
- [ ] 통계적 진단은 표준점수(±SD) 기준으로 명시
- [ ] 단정적 표현 지양 (특히 경계선 사례)
- [ ] REVT 결과를 절대 기준으로 제시하지 않기
- [ ] 보완 평가 필요성 명시 (어휘 외 영역)
- [ ] 강점도 함께 기술
- [ ] 개입 방향성 구체적으로 제시 (어휘 중재 전략)

### D-3. 권고사항 항목별 점검

- [ ] 추가 평가 필요 여부 (PRES, 자발화, 조음, 청력 등)
- [ ] 의료적 의뢰 필요 여부
- [ ] 중재 시작 권고 (시기, 빈도, 형태)
- [ ] 어휘 중재 전략 구체화 (의미 지도, 인출 훈련, 범주화 등)
- [ ] 가정·교육기관 협력 권고
- [ ] 재평가 시점 (보통 6개월~1년)

### E-2. 상담 중 점검

- [ ] 보호자 정서적 반응 관찰 및 케어
- [ ] 일방 통보가 아닌 대화형 진행
- [ ] 보호자 관찰과 검사 결과 연결
- [ ] 강점·약점 균형 있게 전달
- [ ] 어휘 중재 가능성·예후 현실적 안내

### E-3. 상담 후 후속 조치

- [ ] 필요 시 타기관 연계 의뢰서 작성
- [ ] 보호자 추가 질문 채널 안내

## 부록 F. 자주 놓치는 함정 체크리스트

REVT 검사·해석 과정에서 임상가가 자주 놓치는 지점을 별도로 정리.

- [ ] 생활연령 산출 오류 (개월 수 계산 실수)
- [ ] REVT-R에서 추측 행동을 정상 응답으로 처리 (4지선다 우연 정답 가능성 무시)
- [ ] REVT-E에서 동의어 인정 범위 매뉴얼 확인 누락
- [ ] 조음 오류를 일률적으로 오답 처리 (의미 전달 가능 시 정답)
- [ ] 정답 단서 비의도적 제공 (시선·표정·억양 강조)
- [ ] 다문화·이중언어 배경 미반영 해석
- [ ] 시지각 문제 가능성 무시
- [ ] 수용-표현 격차 분석 누락 (단순 점수 보고만)
- [ ] 등가연령만 보고 표준점수 기준 무시
- [ ] REVT 단독 결과로 종합 언어 능력 단정
- [ ] 어휘 외 영역(구문·화용) 보완 평가 권고 누락
