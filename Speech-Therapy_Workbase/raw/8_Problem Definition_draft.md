# 문제 정의서 (Problem Definition)
## 한국 온라인 언어발달·발음교정·의사소통 훈련 교육 서비스

> **작성 기준**: 2026년 5월 | **문서 유형**: 초안(Draft)
> **방법론**: 임팩트 비즈니스형 문제정의 기법
> **분석 기반**: Porter's Five Forces, 가치사슬 분석, 경쟁사 브리핑, KSF 분석, 실제 언어치료 세션 가이드

---

# 1. 산업과 시장영역 분석

**한국 온라인 언어발달·발음교정·의사소통 훈련 교육 서비스 시장**에 대한 우리의 분석 결과, 이 영역은 다음과 같다.

---

### 1) 기초 리서치: 시장의 거시적 트렌드 및 기본 양상

시장의 거시적 트렌드 및 기본 양상이 **'영유아 조기 개입 수요의 급증과 오프라인 대면 치료 인프라의 구조적 한계가 맞물려, AI 음성인식 기술 기반의 맞춤형 에듀테크·디지털 헬스케어로 빠르게 전환되는 과도기'** 에 있다.

| 트렌드 | 근거 |
|:-------|:-----|
| **영유아 조기 개입 니즈 급증** | 부모의 발달 민감도 증가, 만 3세 이전 언어 자극의 골든타임 인식 확산 |
| **오프라인 치료의 구조적 한계** | 센터 대기 3~6개월, 회당 3~6만원, 수도권 집중(60%), 1급 언어재활사 합격률 17% |
| **AI 기술의 교육 침투** | 아동 음성인식, 멀티모달 분석, 게이미피케이션 등 기술 성숙 → 에듀테크 앱 급증 |
| **DTx(디지털 치료기기) 경쟁 과열** | 네오폰스·말과학놀이터·두부·송앤스타크 등 주요 기업이 식약처 인허가에 집중 |
| **교육/치료 경계 흐려짐** | 순수 "교육/훈련" 서비스와 "의료기기" 서비스의 경계가 불분명해지는 규제 환경 |

---

### 2) Porter's Five Forces 분석: 경쟁 구조

경쟁도가 **중간~높음**이고 브랜드 충성도가 **매우 낮으며**(전환 비용 사실상 제로), 다음과 같은 구조적 특성을 가진다.

| Force | 강도 | 핵심 판단 |
|:------|:----:|:---------|
| **기존 경쟁자 간 경쟁** | ★★★☆☆ | 다수 스타트업이 활동하나 B2C 교육 영역에 명확한 카테고리 리더 부재 |
| **대체재 위협** | ★★★★★ | 부모 직접 교육, 유튜브 무료 콘텐츠의 사용률 70~80%. 전환 비용 제로 |
| **구매자(부모) 협상력** | ★★★★☆ | 극단적 "효과 중심(Outcome-Driven)" 의사결정. 효과 미체감 시 즉시 이탈 |
| **공급자(전문가) 협상력** | ★★★★☆ | 1급 언어재활사 합격률 17%, 활동 인원 ~10,000명. 구조적 희소성 |
| **신규 진입 위협** | ★★★☆☆ | 단순 앱 진입은 쉬우나, 아동 음성 AI + 임상 검증은 높은 기술 장벽 |

**핵심 발견**: 대부분의 유력 경쟁사(네오폰스, 두부, 송앤스타크)가 DTx 인허가에 리소스를 집중하고 있어, **비의료 "교육/훈련" 포지셔닝의 B2C 카테고리 리더십은 현재 비어 있는 상태**다.

---

### 3) Value Chain 분석: 핵심 가치 창출 구조

핵심 가치 창출 구조는 다음 **4가지 활동**으로 정의된다.

```
[1. 무료 AI 진단]  →  [2. 맞춤형 자동화 학습]  →  [3. 비동기 전문가 코칭]  →  [4. 연속 발달 리포트]
  (고객 유입)           (핵심 교육 엔진)          (신뢰 확보)              (유지/Lock-in)
```

| 가치 활동 | 내용 | 현재 시장 상태 |
|:----------|:-----|:-------------|
| **1. 무료 AI 진단 (스크리닝)** | 아동의 음성을 AI로 분석하여 발달 수준을 객관적으로 진단 → 부모의 "불안 인지 트리거" 역할 | 송앤스타크가 B2B로만 제공. B2C 무료 진단 부재 |
| **2. 맞춤형 자동화 학습** | 진단 결과에 기반한 개인화 커리큘럼 자동 생성 + 게임형 자가학습 | 에이치투케이가 한글 특화로 제공. 언어발달 특화는 부재 |
| **3. 비동기 전문가 코칭** | 주간 리포트에 대한 전문가 텍스트 코멘트 (1인당 200가정 커버) | 전체 시장 미개척. 대면/실시간 모델만 존재 |
| **4. 연속 발달 추이 리포트** | 주간·월간 발달 지표 시각화 대시보드 → M3 유지율 40% 달성의 핵심 | 1회성 진단만 존재. 연속 추적 제공 기업 없음 |

**핵심 발견**: 현재 시장에는 "진단→교육" 사이의 **밸류체인 단절**이 존재한다. 진단 기업(송앤스타크)은 교육을 제공하지 않고, 교육 기업(에이치투케이)은 진단이 약하다. 이 단절을 하나의 끊김 없는 경험으로 연결하는 기업이 시장을 선점한다.

# 2. 해결하고자 하는 문제

따라서,

---

### 누구의 문제인가 (Target User)

> **자녀(만 2~7세)의 말하기나 발음이 또래보다 늦는 것 같아 불안하지만, 전문 언어치료 센터 방문에 높은 심리적·경제적 허들을 느끼거나, 치료를 결심하고 대기 중인 '초기 개입 단계 및 대기 상태의 영유아 부모'**

이 사용자가,

### 어떤 상황에서 (Context)

> **가정에서 일상적으로 자녀와 상호작용하거나 언어 자극을 주려고 시도하는 상황, 또는 자녀의 발달 수준이 정상 범위인지 판단하려고 정보를 탐색하는 상황**

에서 겪는,

### 어떤 불편함인가 (Pain Point)

> 1. **진단 부재의 불안**: 우리 아이의 현재 언어 발달 수준이 또래 대비 어느 정도인지 **객관적으로 확인할 수 있는 접근 가능한 수단이 없어** 막연한 불안감을 안고 살아간다.
> 2. **방법론의 부재**: 불안감을 느껴도 **구체적으로 어떤 소리를, 어떤 순서로, 어떻게 연습시켜야 하는지** 과학적이고 체계적인 가정 내 교육 방법을 모른다.
> 3. **효과 확인의 불가능**: 유튜브 영상을 보여주거나 앱을 사용해보지만, **아이가 실제로 나아지고 있는지 객관적인 변화를 눈으로 확인할 수 없어** 지속할 동기를 잃는다.

을 **해결하는 것이 중요한 문제**이다.

# 3. 문제의 구조적 심각성 (Why This Matters)

이 문제가 단순한 불편이 아니라 **해결해야 할 핵심 문제**인 이유는 다음과 같다.

| 차원 | 심각성 |
|:-----|:------|
| **시간적 긴급성** | 언어 발달의 골든타임(만 3세 이전)을 놓치면 교정 비용과 난이도가 기하급수적으로 증가 |
| **경제적 부담** | 센터 치료 시 월 12~24만원(주 1회 기준). 연간 144~288만원의 지출이 수년간 지속 |
| **접근성 격차** | 전문가의 60%가 수도권 집중. 지방 거주 가정은 물리적으로 전문 서비스에 접근 불가 |
| **정보 비대칭** | 부모는 비전문가. 자녀의 발달 수준이 "정상 범위의 느린 편"인지 "전문 개입이 필요한 수준"인지 판단할 기준이 없음 |
| **대체재의 한계** | 유튜브·맘카페 정보는 개인화되지 않고, 체계적이지 않으며, 효과를 추적할 수 없음 |

# 4. 문제 해결의 방향성 (Solution Direction)

위 문제 분석과 KSF 도출 결과를 종합하면, 해결책은 다음 **3단계 가치 퍼널**로 설계되어야 한다.

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  [STEP 1]              [STEP 2]              [STEP 3]      │
│  무료 AI 진단           맞춤형 구독 교육        전문가 코칭    │
│  ─────────────         ─────────────         ───────────    │
│  "우리 아이 발음         "이 커리큘럼을          "전문가가      │
│   정확도 62%"            따라하세요"             확인했습니다"  │
│                                                             │
│  ▶ 불안 인지             ▶ 방법론 제공           ▶ 신뢰 확보   │
│  ▶ 전환 트리거           ▶ 핵심 수익원           ▶ 유지 엔진   │
│                                                             │
│              연속 발달 데이터 리포트 (관통)                    │
│              "이번 주 /ㅅ/ 정확도 62% → 71%"                  │
│              ▶ 효과 시각화 ▶ Lock-in ▶ 구전                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

| 해결 방향 | 대응하는 Pain Point | 대응하는 KSF |
|:----------|:-------------------|:------------|
| **무료 AI 진단으로 발달 수준 객관화** | ① 진단 부재의 불안 | KSF #1: 진단-교육 브릿지 퍼널 |
| **진단 결과 기반 맞춤 커리큘럼 자동 생성** | ② 방법론의 부재 | KSF #2: 학습 효과 과학적 검증 |
| **주간 발달 추이 리포트 + 비동기 전문가 코멘트** | ③ 효과 확인 불가능 | KSF #3·#4: 전문가 하이브리드 + 리텐션 엔진 |

# 5. 검증 과제 (Validation Agenda)

본 문제 정의의 핵심 가설은 파일럿 검증을 통해 다음 지표로 확인되어야 한다.

| 가설 | 검증 지표 | Go 기준 | No-Go 기준 |
|:-----|:---------|:--------|:-----------|
| 무료 진단이 전환 트리거가 된다 | 진단 완료 → 유료 전환율 | ≥ 8% | < 5% |
| 맞춤 교육이 효과를 만든다 | 3개월 사용 후 발음 정확도 변화 | 유의미한 향상 (p<0.05) | 변화 없음 |
| 발달 리포트가 유지를 만든다 | M3 유지율 | ≥ 40% | < 30% |
| 비동기 코칭이 신뢰를 만든다 | 코칭 만족도 / 유료 업셀 전환율 | ≥ 4.5/5.0 | < 4.0/5.0 |
| 사업이 성립한다 | LTV:CAC 비율 | ≥ 3.0x | < 2.0x |
