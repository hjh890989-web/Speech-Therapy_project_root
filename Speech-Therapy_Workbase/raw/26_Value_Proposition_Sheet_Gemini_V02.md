## 1. 고객별 Value Proposition 통합 정의

### 🎯 Core Segment 1: 불안형 탐색자 (Seg A)
가장 규모가 큰 핵심 타겟 (12~15만 가구)으로, 진단과 방법론의 공백에서 겪는 불안감을 해결하는 것이 관건입니다.

| 항목 | 내용 |
|:---|:---|
| **고객 핵심 문제 (Pain, Needs)** | **① 진단 공백:** 아이 발달이 정상인지 판단할 객관적 기준 부재 (소아과는 "지켜보자" 반복)<br>**② 방법론 부재:** "집에서 무엇을 어떻게 해야 하는지" 모름<br>**③ 장애 판정 회피 심리:** 센터에 가면 문제 아동 낙인이 찍힐까 두려움 |
| **목표 서술 (Goal, Job)** | 공식 진단이나 센터 방문 없이, 5분 내에 우리 아이 발달 수준의 **정상 범위 여부를 수치로 확인**하고 안심하고 싶다. |
| **고객이 원하는 Outcome** | - 5분 내 정상/비정상 여부 객관적 수치화 (또래 대비 포지션)<br>- 결과를 토대로 한 집에서 할 수 있는 구체적 주간 홈케어 미션 획득 |
| **솔루션의 핵심 제안 (VP)** | **"5분 무료 AI 진단으로 내 아이의 정확한 발달 위치를 확인하고, 맞춤 홈 랭귀지 코칭을 시작하세요."** |
| **기존 대안 (Substitute)** | - **맘카페/유튜브:** 수동적 시청, 개인화 안 됨, 정보 과부하로 불안 증폭<br>- **경쟁사 앱:** 진단 없이 단순 학습 기능 위주 제공 |
| **제공하는 차별적 가치** | 즉각적인 B2C 무료 AI 음성 진단(경쟁사 0개) 및 진단 결과와 연계된 자동화된 맞춤 커리큘럼 |
| **Proof (근거/검증)** | AOS 점수 4.0 (최고 우선순위 도출). 맘카페 검색 행동 패턴 분석 데이터 |

<br>

### 🎯 Core Segment 2: 센터 대기자 (Seg C)
골든타임을 보호해야 한다는 절박함이 있는 브릿지 타겟 (2~3만 가구)입니다.

| 항목 | 내용 |
|:---|:---|
| **고객 핵심 문제 (Pain, Needs)** | **① 대기 중 방치:** 3~6개월 센터 대기 중 골든타임을 허비한다는 죄책감<br>**② 비표준화된 홈케어:** 주관적인 관찰에 의존해 훈련 효과를 전혀 확인할 수 없음 |
| **목표 서술 (Goal, Job)** | 대기하는 수개월 동안 집에서 체계적으로 아이를 훈련시키고, 발달 상황을 추적하여 **향후 치료사에게 객관적 데이터를 제출**하고 싶다. |
| **고객이 원하는 Outcome** | - 대기 기간 중 주 단위 발달 수치 추적<br>- 센터 제출용 표준화된 홈케어 리포트 확보 |
| **솔루션의 핵심 제안 (VP)** | **"막연한 기다림은 끝. 센터 대기 기간을 성장을 준비하는 시간으로 바꾸는 체계적 홈케어"** |
| **기존 대안 (Substitute)** | 무작정 대기(불안 가중), 부모의 비표준화된 주관적 관찰 일지 작성 |
| **제공하는 차별적 가치** | 치료사에게 바로 공유 가능한 주 단위 객관적 수치 발달 리포트 제공 |
| **Proof (근거/검증)** | 오프라인 센터 평균 대기기간 3~6개월. 현재 대기자 대상 브릿지 프로그램 시장 완전 공백 상태 |

<br>

### 🎯 Adjacent Segment: 데이터 집착형 적극적 개입자 (Seg B)
구독 리텐션을 견인하고, 프리미엄 서비스 업셀링이 가능한 타겟 (3~5만 가구)입니다.

| 항목 | 내용 |
|:---|:---|
| **고객 핵심 문제 (Pain, Needs)** | **① ROI(효과) 확인 불가:** 기존 앱/학습지 사용 시 나아졌는지 판단 불가로 인한 이탈<br>**② 공유 욕구 미충족:** 노력의 성과를 가족 및 SNS에 증명/인정받고 싶은 욕구 해소 불가 |
| **목표 서술 (Goal, Job)** | 훈련의 효과를 주 단위로 명확하게 수치화하여 눈으로 확인하고, **SNS나 남편에게 공유하여 나의 노력을 인정받고 싶다.** |
| **고객이 원하는 Outcome** | 노력의 가시화, 지속적 효과 증명, 공유에 최적화된 시각화된 성적표 |
| **솔루션의 핵심 제안 (VP)** | **"62점→71점! 우리 아이의 빛나는 성장을 숫자로 증명하고 가족과 공유하세요."** |
| **기존 대안 (Substitute)** | 경쟁 언어발달 앱 (효과 추적 및 가시화 기능 부재로 리텐션 하락) |
| **제공하는 차별적 가치** | 성취감 및 공유 욕구를 자극하는 시각화된 연속 발달 리포트 (현재 시장 내 제공 기업 0개) |
| **Proof (근거/검증)** | B2C 교육 앱의 D30 리텐션 저조(2~3%) 문제를 극복하기 위한 유일한 생존 해법 (M3 유지율 40% 달성 엔진) |

<br>

### 🎯 B2B2C 파이프라인: 유치원/어린이집 원장 (Seg D)
CAC를 획기적으로 낮출 수 있는 강력한 유통 채널 (기관 약 5천여개)입니다.

| 항목 | 내용 |
|:---|:---|
| **고객 핵심 문제 (Pain, Needs)** | **① 부모 소통 갈등:** 언어 지연 의심 시 교사의 주관적 의견을 전달하면 반발과 민원 발생<br>**② 객관적 근거 부재:** 설득을 위한 제3자의 공신력 있는 데이터 부재 |
| **목표 서술 (Goal, Job)** | 주관적 판단이 아닌 **공신력 있는 데이터를 근거**로 학부모와의 갈등 없이 원활하게 치료 및 발달 훈련을 권유하고 싶다. |
| **고객이 원하는 Outcome** | 갈등 없는 학부모 상담 진행, 기관용 표준 스크리닝 리포트 및 법적 보호 장치(동의서) 확보 |
| **솔루션의 핵심 제안 (VP)** | **"선생님의 주관이 아닌 객관적인 데이터로 소통하세요. 기관용 AI 스크리닝 리포트"** |
| **기존 대안 (Substitute)** | 교사의 개별적이고 주관적인 의견 전달 (설득력 부족) |
| **제공하는 차별적 가치** | 기관 신뢰도를 높여주는 AI 분석 리포트 플랫폼 제공, 학부모 동의서 등 법적/행정적 템플릿 완비 |
| **Proof (근거/검증)** | 기관 1개 제휴 = 학부모 80가구 동시 노출. CAC(고객획득비용) 대폭 절감의 핵심 드라이버 |

## 3. 전략적 포지셔닝 선언문 (Positioning Statement)

> **"비의료 B2C 홈 랭귀지 코칭 (Home Language Coaching) 서비스"**
>
> 📌 **[대상]** 우리 아이의 언어 발달 지연이 걱정되어 매일 밤 맘카페를 서성이는 만 2~7세 부모에게,  
> 📌 **[정의]** **단 5분 만에 무료로** 발달 상태를 진단하고 맞춤형 훈련을 제공하는 B2C 교육 AI 솔루션으로서,  
> 📌 **[차별점]** 기존의 수동적인 유튜브 시청이나 값비싸고 긴 대기가 필요한 오프라인 센터와 달리,  
> 📌 **[핵심가치]** **집에서 즉시 시작할 수 있으며, 주 단위 발달 리포트를 통해 아이의 성장을 눈으로 확인할 수 있는 국내 유일의 완결형 플랫폼**입니다.
