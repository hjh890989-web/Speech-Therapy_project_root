# 경쟁사 UX 분석 (33-37) — 통합 요약

> **한 줄 요약.** 4그룹 14개 경쟁사의 UX 기믹 → MVP 적용 시사점 + **4대 UX 모순점 해결 원칙**. PRD V10의 21 Epic이 어떻게 UX 차원에서 구현되어야 하는지의 정본.

## 그룹 1 · 통신 3사 키즈 AI (raw 33)

| 기업 | 핵심 기술 | 우리 MVP 시사 |
|---|---|---|
| **LGU+ 아이들나라** | "꿈꾸는 AI 오디오북" — 부모 목소리 학습/복제 | F11 부모 목소리 복제 (교정 외 일방향 콘텐츠만) |
| **SKT ZEM** | LLM 챗GPT 기반 AI 캐릭터 + 발화 → AI 드로잉 | F12 즉각 시각적 보상 + F15 LLM 챗봇 |
| **KT 키즈랜드** | 미국 스콜라스틱 A-F 레벨 + **AI 화자 인식** (성인/아동 분리) | F2 권위 척도 (REVT/U-TAP) + **F9-b Zero-touch 화자분리의 직접 원형** |

### 5대 시사점
1. 부모 음성 복제 (Voice Cloning) → F11 (단, 교정 적용 금지)
2. 생성형 AI 발화 보상 (AI 드로잉) → F12 즉각 보상
3. 화자 분리 → F9-b Zero-touch
4. LLM 상호작용 챗봇 → F15
5. 권위 외부 척도 (스콜라스틱·K-CDI) → F2 백분위

## ⭐ 4대 UX 모순점 + 해결 원칙 (raw 37)

> 경쟁사 장점만 기계적 결합 시 발생하는 상충 → 우리만의 RPD 원칙 4종.

### ① 캐릭터 UX: 부모 목소리 vs 제3자 캐릭터
- **모순**: LGU+(부모 음성) ↔ 에듀테크(친근 캐릭터)
- **임상 문제**: 부모 음성 AI가 발음 지적하면 아이 혼란 + 실제 엄마에게 떼
- **💡 원칙**: **분리 설계** — 동화 등 **수용형 콘텐츠 = 부모 음성 (F11)** / **교정 메인 훈련 = 제3 중립 캐릭터 (F3)**

### ② 입력 UX: Zero-touch vs 체크박스 일지
- **모순**: 어린이집 교사 **Zero-touch** 사수 ↔ 자란다 체크박스 우수성
- **운영 문제**: 자란다는 1:1 방문, 어린이집은 1:15-20 동시 → 체크 요구 시 Zero-touch 붕괴
- **💡 원칙**: 데이터 수집 100% **마이크 화자 분리만** / 교사는 **"AI 자동 생성 알림장 [발송 승인]" 버튼만** → F9-b + F9-d

### ③ 보상 UX: 은밀한 난이도 조절 vs 타격감 보상
- **모순**: DTx (X 표시 숨김) ↔ 에듀테크 (폭죽 보상)
- **심리 문제**: 거대 보상 → 보상 없을 때(실패 시) 즉각 좌절
- **💡 원칙 (이중 보상)**:
  - **모든 발화 시도** = 작은 기본 보상 (작은 칭찬 파티클·별 1개)
  - **임상 기준 도달 성공** = 큰 보상 (폭죽·몬스터·아이템) → F12 직접 설계 가이드

### ④ 가치 제안: 임상 DTx vs 행정 경감
- **모순**: 임상적 권위 (CBT/ABA) ↔ 행정 경감·민원 방어 툴
- **세일즈 문제**: 톤 섞이면 정체성 붕괴
- **💡 원칙 (UI/UX 이원화)**:
  - **B2C (학부모 앱·리포트)**: **DTx 톤** — 데이터 중심, 권위, 진지
  - **B2B (원장·교사 대시보드)**: **오피스 툴 톤** — "알림장 편한 자동화", "민원 방어 증빙"
