# CJM Core — 요약

> **한 줄 요약.** Core 5 페르소나(이지수·박민정·최수현·김태희·정유나)의 5단계 여정(인식→탐색→의사결정→사용→유지)을 페인포인트와 개선 기회로 분해. **Phase별 이탈 리스크와 그 대응**이 핵심.

기반: [[product/sources/15-Persona-Spectrum]] Core 5명.

## 5개 여정의 단계 구조

```
[문제 인식] → [탐색] → [의사결정] → [사용] → [유지]
```

각 단계에서 페르소나별 행동·생각·감정·페인·개선 기회를 표 형식으로 분해.

## 페르소나별 전략적 핵심

| 페르소나 | 전략적 핵심 |
|---|---|
| **이지수** (Seg A) | **진입 장벽 최고 + 볼륨 최대**. 진단 결과의 무서움을 낮추는 언어 + 62점을 행동 처방전으로 즉시 연결하는 UX |
| **박민정** (Seg A→B) | **고LTV**. 월간 리포트가 외부 공유(어린이집·남편)로 → Word-of-Mouth 시작점 → **데이터 공유 = 마케팅 채널 플라이휠** |
| **최수현** (Seg C) | **이탈 시점 예측 가능 (센터 치료 시작)**. 선제적 "병행 가치" 전달 + 치료사 데이터 공유로 Lock-in |
| **김태희** (Seg A~B) | **Triage 기능(두 아이 비교 진단)이 진입 조건**. 5분 활동·간결 UX는 이 페르소나 기준 |
| **정유나** (Seg A) | **긴급도 낮음 + LTV 높음 + 바이럴 최대**. 앱 디자인 품질 + 인스타 공유 UX = 유기적 확산 핵심 |

## 단계별 핵심 페인 → 개선 기회 매핑

### [문제 인식]
- 페인: 정상/비정상 기준선 부재
- 개선: "만 N세 평균 발달 기준표" 콘텐츠 + 자가 체크리스트 무료 제공

### [탐색]
- 페인: 유튜브·맘카페 정보가 범용적, 내 아이에 맞지 않음
- 개선: "우리 아이 맞춤 발음 검사 — 3분, 무료" CTA

### [의사결정]
- 페인: "결과가 나쁘게 나오면" 두려움, 진단 회피
- 개선: "치료 판정이 아니에요. 발달 위치 확인" + **익명 진단 옵션**

### [사용 — 진단 직후]
- 페인: 점수 받았는데 의미·다음 행동 연결 안 됨
- 개선: 리포트 내 "이 점수의 의미" + "오늘부터 할 3가지 활동" 자동 제안

### [유지]
- 페인: 점수 변화 미미하면 포기 유혹 (3주 무변화)
- 개선: "이 나이 아이들은 다 이래요" 격려 푸시 + 전문가 코멘트 1회 무료

## 핵심 UX·기능 요구 (CJM에서 도출)

| 요구 | 근거 페르소나 | 설계 |
|---|---|---|
| **익명 진단 옵션** | 이지수 (의사결정 단계 회피) | 진단 시 개인정보 최소 |
| **음소별 추이 그래프** | 박민정 (사용 단계) | 정확도 라인차트 |
| **PDF 내보내기 + 공유 링크** | 박민정 (유지 단계) | 어린이집·남편 공유 |
| **전문가 코멘트 작성 가이드라인** | 최수현 (사용 단계) | "부모 눈높이 + 오늘 할 활동 1개 필수" |
| **Triage 비교 리포트** | 김태희 (의사결정) | 두 아이 동시 진단 → 우선순위 자동 |
| **5분 고정 + 준비물 없는 활동** | 김태희 (사용) | 활동 시간 상한 |
| **3교대 등 비정형 시간 알림** | 김태희 | 시간 커스터마이징 |
| **인스타 공유 포맷** | 정유나 | 발달 곡선 인포그래픽 |
| **연간 성장 리포트 + 인쇄 제본** | 정유나 (유지) | 업셀 |
| **센터 치료사 공유 리포트** | 최수현 (유지) | 이탈 방지 |
| **3주 무변화 시 격려 푸시** | 이지수 (유지) | 자동 트리거 |
