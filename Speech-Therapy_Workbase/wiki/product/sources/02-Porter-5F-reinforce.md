# Porter's 5 Forces 보강 분석 — 요약

> **한 줄 요약.** 기존 정성 Porter's 5F를 Unit Economics(LTV:CAC) 기반으로 정량 재구성. 산업 매력도를 **조건부 Medium-High** 로 재판정하며, 5개 성공 조건을 수치로 명시.

기반 문서: `1_Porter's 5 Force Analysis.md` (read만). 본 문서가 정량 보강된 최신본.

## 핵심 결론

```
LTV ≥ CAC × 3   AND   M3 유지율 ≥ 40%   AND   전문가 1인당 커버리지 ≥ 200가정
                                         ↓
                              산업 매력도 = Medium-High
```

조건 미충족 시 → Medium-Low로 하향.

## 5-Force 정량화

| Force | 기존 (정성) | 보강 (정량) |
|---|---|---|
| 대체재 위협 | "매우 높음" | 사용률 70~80% → 유료 전환 가능 풀은 TAM의 **20~30%** |
| 구매자 협상력 | "높음" | CAC 5~8만원, 예상 LTV 36~72만원 → LTV:CAC = **4.5~9.0x** |
| 공급자 협상력 | "중간" | 전문가 ~17,000명 / 확보 가능 풀 ~500명 → **AI 레버리지 필수** |

→ [[product/concepts/Porter-5-Forces-Analysis]] 에서 분석 종합.

## 전환 트리거 공식

```
유료 전환 = f(불안 인지 × 효과 체감 × 접근 편의 × 가격 수용)

핵심 전환 시점: 무료 진단 결과 리포트 수령 직후 (D0~D3)
72시간 내 60% / 7일 내 25% / 이후 15%
```
