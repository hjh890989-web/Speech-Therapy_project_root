# Problem Definition Final v1.0 — 요약

> **한 줄 요약.** Draft(#8) + VC(#9) + Strategist(#10) + Analyst(#11) 4종을 통합한 문제 정의 최종본. 시장 본질을 **"전문가 독점 서비스의 대중화 전환기"** 로 명명, "홈 랭귀지 코칭" 카테고리 신설을 결정.

## 핵심 진화점 (vs 09-VC 버전)

1. **시장 본질 명명**: "회색지대 부모의 페인" → "전문가 독점 → 대중화 전환기" (Talkspace, 로톡, Noom 패턴)
2. **카테고리 정의**: "비의료 B2C 교육 서비스" → **"홈 랭귀지 코칭(Home Language Coaching)"**
3. **3단계 가치 퍼널 명문화**: 무료 진단 → 맞춤 구독 → 주간 리포트 (+ 전문가 비동기 코멘트 보완)
4. **실행 로드맵 추가**: Phase 0(0-3) → 1(3-6) → 2(6-12) → 3(12+) 분기 명확화
5. **임상 매핑 강화**: "센터 세션의 핵심은 부모 코칭" 인사이트 — [[clinical/concepts/아동언어치료-핵심기법]] 4기법과 직접 매핑

## 시장 6대 팩트 (재확인)

| 팩트 | 수치 | 의미 |
|---|---|---|
| 센터 대기 기간 | 3~6개월 | **대기 중 부모의 불안 = 우리 시장** |
| 센터 비용 | 회당 3~6만원 (월 12~24만원) | 앱 구독 월 3~5만원 = 가격 경쟁력 |
| 무료 대체재 사용률 | 70~80% | 최대 리스크이자 최대 기회 |
| 1급 합격률 | 17% | 전문가 풀 구조적 부족 |
| 교육앱 D30 리텐션 | 2~3% | 우리 목표 40%(15-20x) — 사업 생사 |
| 실질 TAM | 1,080~1,800억원 | 비의료 교육 앱 한정 |

## 핵심 불편함 — 1뿌리 3가지

> **뿌리: "우리 아이가 정상인지 아닌지 모른다."**

| 가지 | 부모의 말 | 대응 | KPI |
|---|---|---|---|
| ① 진단 부재 | "또래 대비 몇 점인지 모르겠어" | 무료 AI 진단 | 전환율 ≥8% |
| ② 방법론 부재 | "뭘 시켜야 하는지 모르겠어" | 진단 기반 맞춤 커리큘럼 | 주간 완료율 ≥60% |
| ③ 효과 확인 불가 | "한 달째인데 나아진 건지" | 주간 발달 리포트 | M3 ≥40% |

→ 위키 정본: [[product/concepts/problem-definition]]

## 3단계 가치 퍼널

```
[1] 무료 AI 진단     → 불안에 이름 붙임   (고객 유입)
[2] 맞춤 구독 교육   → 부모에게 방법론     (핵심 수익)
[3] 주간 발달 리포트 → 효과 가시화         (리텐션)
[보완] 전문가 비동기 코멘트 → "혼자 아냐" (신뢰)
```

## 실행 로드맵

| Phase | 기간 | 할 일 | 완료 |
|---|---|---|---|
| 0 | 0~3개월 | 무료 진단 MVP + 100가정 파일럿 + 지표 측정 | 전환율·유지율 실측 |
| 1 | 3~6개월 | 발달 리포트 + 전문가 2-3명 비동기 코멘트 A/B + Before/After | M3 확인, 효과 정량 |
| 2 | 6~12개월 | 정식 런칭 + 마케팅 + B2B2C 5개소 파일럿 | 월 1,000가정 |
| 3 | 12개월+ | 전문가 확장 + 대학 공동연구 + 카테고리 리더십 | LTV:CAC ≥3.0x |

## 한계
- "전문가 독점의 대중화" 비유(Talkspace 등)는 자극적이나, 언어재활은 *아동 음성·발화 자극* 이라는 물리적 상호작용 요소가 있어 디지털 대체율 80%가 실증된 수치는 아님.
- M3 유지율 40% / 전환율 8%는 여전히 미검증 가설.
- TAM 1,080~1,800억은 상한, 실질 SOM은 [[product/concepts/customer-segmentation]] 에서 5,000~12,500가구 / 21~52.5억 (1년차).
