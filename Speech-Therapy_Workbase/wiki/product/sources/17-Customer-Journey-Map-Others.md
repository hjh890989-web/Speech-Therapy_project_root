# CJM Others — 요약

> **한 줄 요약.** 13명 페르소나 중 Core 5명 외 8명(Adjacent 3 + Extreme 2 + Non-user 3)의 5단계 여정. **Non-user는 "사용→유지" 단계 없이 "이탈 지점·진입 전략"** 으로 구조 변경. Core CJM([[product/sources/16-Customer-Journey-Map-Core]])의 보완.

## Adjacent 3명 (B2B2C / 파트너 / 다문화)

### Adjacent-1 오한솔 (유치원 원장) — B2B2C
- **이탈 위험**: 학부모 동의 절차 복잡 → 도입 포기
- **개선**: 부모 동의서 템플릿 + PIPA 보증 문서
- **유지**: 연 1회 전체 원아 스크리닝 + 부모 배포 → 이듬해 재계약 + 추천
- → [[product/entities/persona-오한솔]]

### Adjacent-2 손지훈 (아동심리상담사) — 전문가 파트너
- **이탈 위험**: 임상 근거 없으면 추천 불가 / 부모 동의 없으면 진행 데이터 확인 불가
- **개선**: 파트너 전용 임상 자료 + 추천 링크 + 선택적 데이터 공유 + 상담사 대시보드
- → [[product/entities/persona-손지훈]]

### Adjacent-3 이미란 (다문화 가정) — Seg A 변형
- **이탈 위험**: 다국어 UI 부재 / 이중언어 환경 가이드 부재
- **개선**: 다국어 UI(베트남·중국·영어) + "이중언어 환경 아이 발달 가이드" 무료 + 다문화 카카오방 공유
- **유지**: 다문화 커뮤니티 바이럴 + 추천 리워드
- → [[product/entities/persona-이미란]] ⭐ 황금 교차점 4명 중 하나

## Extreme 2명 — 포용적 설계 기준

### Extreme-1 황보름 (40세, ASD 경계선 자녀)
- **이탈 위험**: AI가 비전형 발화 인식 못함 → 사용 자체 불가
- **개선**: ASD 경계선 전용 진단 트랙 + **48h 내 치료사 리뷰 보장 SLA** + PDF/공유 링크 원클릭
- **유지**: 센터 데이터 연동 → 통합 케어. ASD 경계선 부모 커뮤니티 공유 (강한 WOM)
- **설계 핵심**: "이 사용자를 만족시키는 AI + 치료사 레이어 = 일반 사용자 자동 만족"

### Extreme-2 강지방 (28세, 강원도 농촌)
- **이탈 위험**: 구형폰 앱 구동 불안정 / 음성 업로드 실패 / LTE 데이터 부담
- **개선**: **PWA 경량 앱 + 오프라인 캐시** + 원클릭 설치 + 저용량 음성 압축 + 자동 재시도
- **유지**: 보건소·지역 맘카페 공유 ("우리 지역 엄마들도 이런 게 있는지 몰라")
- **마케팅**: "농어촌 가정 무료 지원 프로그램" CSR

## Non-user 3명 — "이탈 지점·진입 전략" 구조

> Non-user는 "사용→유지" 단계까지 가지 않으므로 **여정 표 구조가 다름** — 4단계: 인식·탐색·**⚠️ 이탈 지점**·접근 전략.

### Non-user-1 윤성민 (41세, 아버지)
- **⚠️ 이탈 지점**: 아내의 구독을 "왜 이런 거에 돈 써?"라며 **해지 요청** → 가정 내 구독 해지 주요 원인
- **접근 전략**: 직접 타깃 불가. **아내를 통한 간접 설득** — 리포트에 "배우자 공유 버튼" 필수 + "아빠 전용 활동" + "아빠 참여 시 효과 2배" 데이터

### Non-user-2 송혜경 (45세, 외할머니)
- **⚠️ 이탈 지점**: 앱 설치 자체 거부 또는 설치 후 방치 — "기계가 어떻게 애를 알아?"
- **접근 전략**: 직접 타깃 불가. 딸(엄마) 설득 + **"할머니도 할 수 있는 쉬운 활동" 별도 설계** + "오늘의 가정 활동 카드" 인쇄물 형태 + **소아과 신뢰 앵커**

### Non-user-3 김민지 (32세, 워킹맘) — SAM 70-80%
- **⚠️ 이탈 지점**: "내 아이 데이터 넣기 싫다" 진단 진입 거부 (프라이버시 + 귀찮음)
- **전환 가능 시나리오**: 진단 결과 "또래 하위 25%" 충격 → 행동 변화
- **접근 전략**: **익명 진단 옵션** + "유튜브만 했을 경우 vs 맞춤 훈련 시" 비교 시뮬레이션 + 충격 요법 마케팅
- → [[product/entities/persona-김민지]]

## 종합 인사이트 (단계별 최대 이탈 + 핵심 트리거)

| 구분 | 최대 이탈 지점 | 핵심 전환 트리거 | Phase |
|---|---|---|---|
| **Core 5명** | 진단 결과 해석 막막 | 무료 진단 + 즉각 처방 연결 | Phase 0 MVP |
| **Adjacent 3명** | B2B 도입 복잡 / 신뢰 부족 | 전문가 파트너십 + 임상 근거 | Phase 2-3 |
| **Extreme 2명** | 기술 한계 (AI 인식 불가 / 구형 기기) | 치료사 레이어 + 경량 앱 | Phase 3+ |
| **Non-user 3명** | 진입 자체 거부 | 간접 전략 (가족 공유 / 소아과 / 유튜브 비교) | Phase 1-2 |
