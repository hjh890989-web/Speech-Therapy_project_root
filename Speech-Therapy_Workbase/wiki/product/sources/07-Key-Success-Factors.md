# Top 5 KSF — 요약

> **한 줄 요약.** Porter's 5F + Value Chain + 경쟁사 브리핑 + 임상 가이드 4종을 종합하여 신규 진입자가 충족해야 할 5개 성공 요인을 도출. 5개 KSF는 **순차적 의존 관계**이며 실행 순서는 #1 → #2 → #4 → #3 → #5.

기반: [[product/sources/02-Porter-5F-reinforce]], [[product/sources/05-Competitive-Briefing-Merged]], [[product/sources/06-Competitive-Value-Chain]], [[clinical/sources/0-언어치료-실제-세션-상세가이드]].

## 5개 KSF (우선순위 순)

| # | KSF | 대응 Force/구간 | 미충족 결과 | 시급성 |
|---|---|---|---|---|
| 1 | **진단-교육 브릿지 퍼널** | 대체재 위협 + 구매자 협상력 + 밸류체인 단절 | 고객 획득 실패 | 즉시 |
| 2 | **학습 효과 과학적 검증** | 구매자 효과 중심 의사결정 | 대량 이탈, 맘카페 부정 후기 | 6개월 내 |
| 3 | **전문가 하이브리드 모델** | 공급자 희소성 | 확장 병목, 비용 선형 증가 | 12개월 내 |
| 4 | **연속 발달 데이터 리포트** | 낮은 전환비용 + Unit Economics | M3 < 30%, LTV:CAC 붕괴 | 6개월 내 |
| 5 | **비의료 카테고리 선점** | DTx 쏠림 | 경쟁사 B2C 전환 시 포지션 상실 | 24개월 내 |

→ [[product/concepts/Key-Success-Factors]] 에서 각 KSF의 상세 근거와 판단 기준 종합.

## KSF별 판단 기준 (정량)

| KSF | 핵심 지표 | 임계값 |
|---|---|---|
| #1 퍼널 | 무료 진단 완료율 / 진단→유료 전환율 / 체험→구독 소요일 | ≥30% / ≥8% / ≤14일 |
| #2 효과검증 | 파일럿 100가정 Before/After / 3개월 정확도 향상률 / 대학 공동연구 | 확보 / 정량 / 1건+ |
| #3 전문가 | 1인당 커버리지 / 코칭 만족도 / 분기 이탈률 | ≥200가정 / ≥4.5/5.0 / <20% |
| #4 리포트 | M1/M3/M6 유지율 | ≥50% / ≥40% / ≥25% |
| #5 카테고리 | 앱스토어 키워드 순위 / 맘카페 인지도 | Top3 / 1위 |

## 순차 의존 관계

```
[KSF #1 퍼널]    KSF #1 없으면 고객이 없음
       ↓
[KSF #2 효과]    효과 입증 안 되면 KSF #4 데이터가 없음
       ↓
[KSF #4 리포트]  리텐션 없으면 KSF #3 전문가 코칭이 무의미
       ↓
[KSF #3 전문가]  확장 단계에서 활성화
       ↓
[KSF #5 카테고리] 24개월 내 골든타임 활용
```

## Clinical 기둥 cross-link

- KSF #2 효과 검증의 임상적 표준 = [[clinical/entities/REVT]], [[clinical/entities/U-TAP]], [[clinical/entities/SELSI]] 등 표준화 검사. 본 KSF가 "임상 수준의 발달 추적"을 명시한 근거.
- KSF #3 비동기 코칭의 임상적 원형 = [[clinical/concepts/한국-언어치료-트랙비교]] §트랙2 매 세션 5~10분 부모 상담. 이 시간 모듈을 비동기로 전환하는 것이 KSF #3의 본질.
- KSF #4 연속 데이터 리포트 = [[clinical/concepts/한국-언어치료-트랙비교]] §재평가 (3~6개월 주기) 의 압축적 디지털 재현. 임상은 6개월 1회, 우리는 주간/월간.
- KSF #5 비의료 카테고리 = [[clinical/concepts/한국-언어치료-트랙비교]] §트랙2 (사설/비급여) 와의 보완재 포지션. 의료 영역(트랙1)을 회피.

## 한계

- 5개 KSF는 가설. 파일럿 100가정 실측 전에는 우선순위 자체가 변동 가능.
- KSF #2의 "임상적 신뢰도" 정의가 모호 — 어떤 수준의 임상 검증이 부모 의사결정을 바꾸는지 미증명.
- KSF #3 "비동기 코칭 1:200"의 운영 가능성은 전문가 인터뷰 필요. 임상 현장의 5~10분 직접 상담 vs 비동기 텍스트 코멘트의 질적 동등성 미검증.
