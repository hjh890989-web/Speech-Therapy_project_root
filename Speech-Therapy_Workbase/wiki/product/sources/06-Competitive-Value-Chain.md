# 경쟁사 Value Chain 분석 — 요약

> **한 줄 요약.** 5개 주요 경쟁사를 Porter's Value Chain으로 분해 후, 시장 가치사슬을 3개 유형으로 묶고 **"진단→교육 브릿지"** 가 신규 진입 최적 포지션이며 **송앤스타크가 가장 취약한 경쟁사**임을 도출.

## 5개 경쟁사 가치사슬 비교

| 항목 | [[product/entities/네오폰스]] | [[product/entities/와우키키]] | [[product/entities/두부]] | [[product/entities/송앤스타크]] | [[product/entities/에이치투케이]] |
|---|---|---|---|---|---|
| 밸류체인 위치 | 교육+치료 | 진단+교육 | 치료+교육 | **진단 특화** | **교육 특화** |

| 한계비용 | 중 | 중 | 높음 | **매우 낮음** | 낮음 |

## 시장 가치사슬 3개 유형

### 유형 A: "진단 게이트키퍼" — 송앤스타크
```
[음성 입력] → [AI 자동 진단] → [리포트 출력] → (끝)
```
- 한계비용 극히 낮음, 마진율 높음
- **리스크**: 교육/치료 연계 부재 → Lock-in 약함

### 유형 B: "풀스택 O2O" — 두부, 네오폰스
```
[병원 진단] → [AI 교육/훈련] → [전문가 개입] → [병원 모니터링] → 순환
```
- 다층 수익(구독 + 코칭 + DTx 처방료)
- **리스크**: 전문가 의존 → 확장 병목, 번 레이트

### 유형 C: "AI 자가학습" — 에이치투케이, 와우키키
```
[AI 진단] → [맞춤 커리큘럼] → [게임형 자가학습] → [리포트] → 반복
```
- 한계비용 낮음, 스케일업 유리
- **리스크**: 학습 효과 검증 약함 → 부모 신뢰 확보 난

## 신규 진입 최적 포지션: "진단-교육 브릿지"

```
[진단]          [교육/훈련]         [치료/관리]
  │                 │                  │
송앤스타크      에이치투케이         네오폰스
(B2B only)      (한글 특화)          (DTx)
                와우키키              두부
                    │
              ┌─────┴─────┐
              │           │
        ⚠️ 공백 영역 ⚠️
   "진단→교육 연계"    "부모 코칭"
   "발달 리포트"       "비동기 전문가"
```

| 포지션 | 전략 | 경쟁 강도 |
|---|---|---|
| 무료 AI 진단 → 유료 맞춤 교육 | 송앤스타크 진단 가치 흡수 + 에이치투케이 자가학습 결합 | 낮음 |
| 부모 코칭 레이어 | 모든 경쟁사가 "아동 대상". 부모 비동기 코칭 미개척 | **매우 낮음** |
| 주간/월간 발달 리포트 | 송앤스타크 1회성 vs 우리 연속 추적 | 낮음 |

## 가장 취약한 경쟁사: 송앤스타크

| 취약 요인 | 상세 |
|---|---|
| 밸류체인 단절 | 진단 후 교육·치료 연계 부재 |
| B2C 전환 지연 | 가정용 앱 2027 예정 (2년 공백) |
| Lock-in 부재 | 1회성 진단 → 반복 사용 동기 약함 |

> **공격 전략**: 송앤스타크의 2027 B2C 전환 전 "진단+교육" 통합 모델로 진입 → 진단 영역 선점 + 교육 확장.

## Clinical 기둥 cross-link

- 두부·네오폰스의 "전문가 개입 30~40%" = [[clinical/concepts/한국-언어치료-트랙비교]] §트랙2 1:1 모델의 디지털 재현. 트랙2 부모 상담의 임상 원형이 풀스택 O2O 비즈니스 모델로 구체화됨.
- 송앤스타크의 5분 AI 진단 vs 임상 표준 검사 60-90분([[clinical/concepts/실어증]]) — 시간·정확도·임상적 신뢰도의 삼중 trade-off.
- "전문가 1인당 200가정 커버리지"의 임상적 적정성 → 트랙2 1:1 모델과의 질적 차이는 핵심 검증 항목.
