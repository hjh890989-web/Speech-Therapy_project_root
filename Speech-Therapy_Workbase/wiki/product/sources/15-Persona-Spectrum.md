# Persona Spectrum — 요약

> **한 줄 요약.** Seg A·B·C·D를 13명의 페르소나(Core 5 + Adjacent 3 + Extreme 2 + Non-user 3)로 구체화. **"극단을 만족시키면 핵심은 자동 만족"** 원칙 + 비활성을 통해 진입 장벽 학습.

기반: [[product/sources/14-Market-Segmentation]] 의 4세그먼트.

## 페르소나 스펙트럼 구조

| 유형 | 수 | 전략적 목적 |
|---|---|---|
| **Core (핵심)** | 5명 | 주력 타깃, 매출 기반. Seg A·B·C 중심 |
| **Adjacent (확장)** | 3명 | 유사 문제 + 다른 맥락. Phase 3-4 B2B2C |
| **Extreme (극단)** | 2명 | 제약·극단 사용자. **포용적 설계 기준** |
| **Non-user (비활성)** | 3명 | 미사용·회피 집단. **진입 장벽 학습** |

## Adjacent 3 (요약)

| 페르소나 | 직무 | 핵심 시사 |
|---|---|---|
| 오한솔 (42세, 유치원 원장) | B2B2C 채널 — 원장 1명 → 80가구 노출 | Phase 4 B2B2C 핵심 |
| 손지훈 (35세, 아동심리상담사) | 전문가 채널 파트너 — "전문가 추천 앱" | 신뢰 앵커 |

## Extreme 2 (포용적 설계 기준)

| 페르소나 | 제약 | 설계 시사점 |
|---|---|---|
| 황보름 (40세, ASD 경계선 자녀) | 비전형 발화 → AI 인식 실패 | **AI 모델 다양화 + 치료사 리뷰 레이어** |
| 강지방 (28세, 농촌 거주) | 차로 왕복 4시간, 구형폰, LTE 부담 | **경량 앱 + 오프라인 캐시 + 절약 모드** |

## Non-user 3 (진입 장벽 학습)

| 페르소나 | 거부 요인 | 우회 전략 |
|---|---|---|
| 윤성민 (41세, 아버지) | "아내 담당" + 비용 저항 | **아빠 참여 콘텐츠**, 커플 공유 리포트 |
| 송혜경 (45세, 외할머니) | AI 불신 + 전통 양육 자부심 | **소아과 신뢰 앵커** 필수 |
| 김민지 (32세, 워킹맘) | 유튜브 거짓 안심 (방어기제) | **충격 요법 마케팅** ("뇌 언어 영역 활성화") |

## 9개 제품 설계 시사점

| 인사이트 | 근거 페르소나 | 설계 방향 |
|---|---|---|
| 진입 장벽 = "호들갑 부담" | 이지수 | 무료·비공개 진단, "부담 없이 확인만" |
| 리텐션 = 수치 가시화 | 박민정 | 음소별 정확도 추이, 주간 변화 강조 |
| 전문가 신뢰 앵커 필수 | 최수현·송혜경 | "언어재활사 검토" 배지 + 소아과 파트너십 |
| 간결함이 경쟁력 | 김태희 | 5분 활동, 알림 최소, 직관 UX |
| 아버지 이탈 방지 | 윤성민 | 파트너 공유 리포트, 아빠 콘텐츠 |
| 비전형 발화 대응 | 황보름 | AI 다양화 + 치료사 리뷰 |
| 저사양·지방 접근성 | 강지방 | 경량 + 오프라인 + LTE 절약 |
| B2B2C 채널 | 오한솔·손지훈 | 기관용 스크리닝 + 전문가 파트너 |
| 유튜브 거짓 안심 타파 | 김민지 | "영상 vs 상호작용" 효과 차이 진단 |
