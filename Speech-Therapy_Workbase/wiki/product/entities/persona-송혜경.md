# 페르소나 · 송혜경 (45세, 외할머니)

> "옛날에는 다 그렇게 컸어"

| 항목 | 내용 |
|---|---|
| 직무·상황 | 만 3세 외손녀의 외할머니. 딸 부부 맞벌이로 평일 양육 담당. 본인은 자녀 3명을 키운 경험 있음. AI·디지털 도구 사용 빈도 낮음 |
| 세그먼트 | **Non-user · Seg A 변형 (전통 양육 권위 군)** |
| 전략적 위상 | ⚠️ **Q3 과잉투자 경계** (DOS **-0.4** ← 음수). 직접 전환 매우 어려움. 그러나 **딸의 결정에 영향력 큼** — Seg A 어머니의 결제 게이트키퍼 |

## 핵심 문제 (회피 요인)

3축 회피:
1. **AI 불신**: "기계가 아이 발달을 어떻게 알아"
2. **전통 양육 자부심**: "내가 자식 셋 키워봤어" → 외부 권위 거부
3. **본인 디지털 사용 부담**: 앱 설치·로그인·음성 업로드 자체가 마찰

## 감정
권위 손상 우려 + AI 회의 + 본인 양육 경험 자부심

## 대체 솔루션 (현재)
- 본인 양육 경험 직접 적용 (가장 강력한 신념)
- 동네 지인 어머니 네트워크 (1세대 선행)
- 소아과 정기 검진 (트랙 1 의료 신뢰만 부분 인정)

## Pain/Goal 평가

| 항목 | 값 |
|---|---|
| Pain 중요도 | **2** (Goal 자체 약함 — 본인이 양육 잘하고 있다고 인식) |
| 대체 만족도 | **4** (자기 경험에 만족) |
| **AOS** | **0.4** (낮음) |
| Market Relevance | 0.2 (조부모 양육 가구 ≈ 한국 25%) |
| **DOS** | **-0.4** ⚠️ (음수 = 본 영역 투자 시 ROI 마이너스) |
| 사분면 | **Q3 · 과잉투자 경계** |

→ Q3 의미: **본 페르소나 직접 타깃 0순위 후순위**. 그러나 Seg A 어머니의 의사결정 영향력 큼 (딸이 시어머니/친정엄마 의견 청취 후 결제 결정).

## Clinical 매핑
- [[clinical/concepts/한국-언어치료-트랙비교]] § "소아과 신뢰 앵커" = 본 페르소나가 부분적으로 신뢰하는 유일한 외부 권위. 트랙 1 의료기관과의 연계 필요성 (B2C 직접 진입 회피).
- [[clinical/concepts/아동언어치료-핵심기법]] § 부모 코칭 = 조부모 코칭으로 일부 변형 가능 (예: 평행 발화·확장·기다리기). 단, "아이 학습"이 아닌 "함께 즐겁게 노는 법" 프레이밍 필수.
- 본 페르소나의 "전통 양육 자부심" = 임상에서 자주 만나는 가족 갈등 패턴 — 임상가들이 가족 상담을 별도로 진행하는 영역.

## 이탈/도입 리스크
- **딸 결제 → 외할머니 거부 → 중도 해지**: Seg A 어머니가 친정엄마/시어머니 의견 청취 후 "AI 사기" "전자기기 노출 죄책감" 압력으로 해지 가능성. **본 페르소나는 deactive Lock-in 게이트** (1-2개월차 가족 갈등 트리거).
- **앱 직접 사용 0 가정**: 본인이 앱을 사용하지 않더라도 결제·운영을 비판할 수 있음.
- **충격 요법 마케팅 부작용**: "뇌 언어 영역 활성화" 등 [[product/entities/persona-김민지]] 대상 카피가 본 페르소나에는 역효과 — 마케팅 채널 분리 필수.

## 보강 필요
- 100가정 파일럿에서 조부모 양육 가정 비율 측정 + 가족 갈등 사유 인터뷰.
- "조부모 친화 콘텐츠" 별도 트랙 비용 분석 — DOS -0.4이므로 단독 ROI 음수, 가족 단위 Lock-in 효과로 정당화해야.
- 소아과 협력 마케팅 채널 PoC.
- 외할머니/시어머니 별도 차별화 — 한국 가족 구조에서 친정 vs 시댁 영향력 차이.
