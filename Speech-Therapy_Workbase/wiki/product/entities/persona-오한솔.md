# 페르소나 · 오한솔 (42세, 유치원 원장)

> "제 말이 주관적이라고 하는 부모님들이 계세요"

| 항목 | 내용 |
|---|---|
| 직무·상황 | 사립 유치원 원장. 원아 80명. 매년 2-3명 언어 지연 발견. |
| 세그먼트 | **Adjacent / Seg D · 기관 연계 수요** |
| 전략적 위상 | **DOS 1위 (3.0)** ⭐⭐ — B2B2C 채널 / 1명 설득 = 80가구 노출 |

## 핵심 문제
교사의 주관적 판단으로 부모에게 "센터 케어/지원 권유"하면 갈등. **AI 발달 확인 리포트 = 제3자 객관 데이터** 로 부모 갈등 없이 전문 기관 연계.

## 목표
- "이 리포트에 따르면 전문 기관 상담이 도움이 될 수 있어요" 데이터 기반 소통
- 부모 항의 없이 원활한 안내

## 감정
책임감 + 부모 관계 관리 부담 + 객관적 근거 필요

## 대체 솔루션 (현재)
- 담임교사 관찰 의견서
- 학기 초 발달 체크리스트 (자체 제작)
- 지역 언어 발달 지원 센터 안내문 배포

## 전환 트리거
> 부모와의 소통 갈등 직후 + 같은 문제 반복 경험

## JTBD 시뮬레이션 데이터 (Card ⑥)

| 항목 | 값 |
|---|---|
| **Job Statement** | 객관 데이터로 부모와 갈등 없이 언어 지원 권유 |
| **Desired Outcome** | "이 리포트에 따르면…" 데이터 제시 + 부모 항의 없는 소통 |
| **AOS** | 3.0 (Imp 5, Sat 2) |
| **DOS** | **3.0** ⭐⭐ (TAM 1.0 — 1명 설득 = 80가구 노출) |
| **Push** | "선생님 주관적 아닌가요?" 부모 반발 경험 |
| **Barrier** | **학부모 동의 없이 음성 녹음 법적 문제** + 예산 항목 분류 + 교육청 승인 |

### 인용 (시뮬레이션, 합성)
> "제 말이 주관적이라고 하는 부모님들이 계세요. 데이터가 있으면 '제가 이상하게 보는 게 아니에요'라고 말할 수 있잖아요."
>
> "아이 음성 녹음하는 게 동의서가 필요한지 그게 제일 걱정이에요."

## 의사결정 구조
- 원장 **단독 결정 가능** (예산 항목 = 교육 활동비 분류 시 학부모 동의 없이 집행 가능)
- 단, 아동 음성 녹음은 별도 학부모 동의서 필요 가능성

## 제품 설계 시사점

| 요구 | 설계 |
|---|---|
| 학부모 동의서 템플릿 | 기관용 패키지에 동봉 |
| 법적 안전 가이드 | 개인정보·녹음 동의 절차 표준 문서 |
| 원장→부모 리포트 공유 UX | 기관용 대시보드 + 부모 알림 흐름 |
| 교육청 승인·CSAP | 인프라부터 공공 클라우드 규격 (→ [[product/sources/05-Competitive-Briefing-Merged]] §규제 대응) |
| 가격 정책 | 원당 패키지 (교육 활동비 항목 정합) |
