# 에이치투케이 (소중한글)

KAIST 출신이 2017년 창업한 AI 유아 한글 파닉스 교육 앱. 가치사슬 유형 C(AI 자가학습)의 대표.

| 항목 | 내용 |
|---|---|
| 설립 | 2017년 (KAIST 출신) |
| 위치 | 대전 |
| 인력 | ~16명 |
| 자본 | 25억+ 투자 (ESG 펀드: 카카오·SKT) |
| 핵심 서비스 | 모바일 앱 (iOS/Android) + 초등 방과후 교구 |
| 타깃 | 미취학 아동 (난독증 포함) + 부모 |
| BM | B2C 구독/이용권 + B2G 교구 협업 |
| 핵심 기술 | 자체 아동 음성인식 AI + 소리 중심 한글 파닉스 알고리즘 |
| AI 자동화 | 85%+ |

## 강점
- 한글 파닉스 특화 니치 확보
- AI 자동화율 높아 한계비용 낮음
- ESG 투자 유치 — 사회적 가치 인정
- 부모 개입 최소 설계 → 사용 빈도·구독 유지에 유리

## 약점
- "한글 학습"에 특화 → 언어발달 지연 진단/치료와 거리
- 대전 기반 — 수도권 네트워크 약함

## 우리에게 주는 시사
- "특화 니치 + AI 자동화"의 모범 사례
- **카테고리 인접**(한글 학습 vs 언어발달)이라 직접 경쟁 강도는 낮음
- 우리는 "발음/조음" 영역으로 명확히 차별화 가능
