# 페르소나 · 강지방 (28세, 농촌 거주 어머니)

> "차로 4시간 왕복인데 데이터도 부담"

| 항목 | 내용 |
|---|---|
| 직무·상황 | 만 3세 딸. 거주지에서 가장 가까운 사설 센터까지 차량 왕복 4시간. 구형 안드로이드폰 (RAM 3GB) + LTE 무제한 아닌 요금제 |
| 세그먼트 | **Extreme · Seg C 변형 (지역·인프라 제약 군)** |
| 전략적 위상 | **황금 교차점 4명** ⭐ (Pain 5 × Sat 1) + Q2 포용 설계 (AOS **4.0** — 공동 1위) |

## 핵심 문제

**물리적 접근 차단**. 인구 5만 미만 군 거주 — 사설 센터·공공기관 모두 1시간+ 거리. 디지털 보완마저도 (1) 구형폰 호환성, (2) LTE 데이터 부담, (3) 잦은 네트워크 단절로 사용 어려움.

## 목표
- **차량 이동 없이 집에서 가능한 진단·훈련**
- 저사양·저데이터 환경에서도 작동하는 앱
- 오프라인 모드 (네트워크 단절 시에도 미션 진행)

## 감정
체념 + 죄책감 ("우리 동네에 사니 어쩔 수 없지") + 분노 (정책 격차)

## 대체 솔루션 (현재)
- 유튜브 (가장 가벼움, but 비표준)
- 보건소 영유아 검진 (1년 1회, 진단 깊이 부족)
- 거의 무용 — 이동 거리·비용 부담으로 사설 센터 이용 불가

## 제품 설계 시사점 — Q2 포용 설계의 핵심

| 요구 | 설계 |
|---|---|
| **경량 앱** | 번들 크기 ≤30MB. 이미지 lazy load. 영상 콘텐츠는 외부 CDN + 옵셔널 |
| **오프라인 캐시 (PWA)** | 첫 진단 후 1주일치 미션 + 결과 사전 캐싱. 네트워크 복원 시 sync. **D5 Descope 부활 시 핵심 기능** ([[product/concepts/MVP-descope-plan]]) |
| **LTE 절약 모드** | "데이터 절약" 토글 → 음성 압축 강화 + 이미지 저해상도 + 자동 동기화 OFF |
| **저사양 안드로이드 호환** | minSdk 24 (Android 7), RAM 2GB 환경 테스트. Capacitor 보강 ([[product/concepts/MVP-descope-plan]] § D2) |
| **CSR (Phase 3)** | 농촌 가구 무료 1년 라이선스 (B2B2C 정부 협력 트랙) |

## 이탈/도입 리스크
- **첫 다운로드 실패**: 구형폰 + LTE 환경에서 앱 다운로드·설치 자체가 5-10분 소요. 첫 마찰점.
- **데이터 한도 초과 → 자동 이탈**: 음성 업로드 1회 = 1MB. 월 미션 30회 + 가족 공유 리포트 = 50-100MB. LTE 4GB 가구는 부담.
- **네트워크 단절 발생률 ≥30%**: 5G 비커버리지 지역 — 음성 업로드 실패 시 graceful 처리 필수.

## 보강 필요
- D5 (PWA 오프라인) Descope 부활 조건 — 본 페르소나가 부활 트리거 가능성 높음.
- 100가정 파일럿 농촌 가구 1-2 의도 모집.
- 정부 CSR (보건복지부 발달재활 + 농어촌공사 협력) 가능성 검토.
- AOS 4.0이지만 시장 협소 (MR 0.1) — 단독 BM 어려움 = B2G 또는 CSR 필수.
