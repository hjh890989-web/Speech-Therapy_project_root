# 페르소나 · 이지수 (34세, 전업주부)

> "검색만 하다가 3개월이 지났어요"

| 항목 | 내용 |
|---|---|
| 직무·상황 | 만 3세 아들. 남편 맞벌이 전 육아 전담. 인스타·맘카페 주요 채널. |
| 세그먼트 | **Seg A · 불안형 탐색자** |
| 전략적 위상 | **진입 장벽 가장 높음 + 볼륨 가장 큼** ⭐ |

## 핵심 문제
"이 정도면 기다려도 되는 건지" 막연. 센터 정식 검사가 '장애' 판정으로 이어질까봐 **진단 회피**. 맘카페 자가진단표로 안심하다가 다시 불안의 악순환.

## 목표
- 아이 언어 수준이 정상 범위인지 객관 확인
- 필요 시 가정에서 해줄 수 있는 방법 알기

## 감정
불안 + 죄책감 ("내가 말을 덜 걸어줬나?") + 정보 과부하 피로감

## 대체 솔루션 (현재)
- 맘카페 게시글 정독
- 유튜브 "말이 늦는 아이" 채널
- 소아과 검진 시 의사 질문

## 전환 트리거
> "무료로 아이 발음 검사해드립니다" — 부담 없이 시도 가능

## 5단계 여정 (CJM)

| 단계 | 행동·생각 | Pain | 개선 |
|---|---|---|---|
| 인식 | 또래 비교 → 막연한 불안 | 정상/비정상 기준 없음 | 자가 체크리스트 무료 |
| 탐색 | 맘카페·유튜브·소아과 | 범용 정보 → 내 아이 매칭 ↓ | 맞춤 발음 검사 CTA |
| **의사결정** | 진단 페이지 1-2분 망설임 | "결과 나쁘면" 두려움 | **익명 진단 옵션** + "치료 판정 아님" |
| 사용 | 62/100점 수령 | 점수 의미·다음 행동 단절 | 리포트 내 "오늘 3가지 활동" |
| 유지 | 주간 활동 5분 + 재측정 | 3주 무변화 시 포기 유혹 | "이 나이는 다 이래요" 격려 + 전문가 1회 무료 |

## 제품 설계 시사점
1. **진입 장벽 = 호들갑 부담** → 익명 옵션 + "부담 없이 확인" 카피
2. **점수 → 행동** 즉시 연결 UX
3. **3주 무변화 격려 자동화** (이탈 방지)
4. 매스 마케팅 채널: 네이버 맘카페(65%) + 인스타(20%)

## 예상 Unit Economics
- CAC: 2-3만원 (맘카페 타깃 광고)
- ARPU: 3.5만원/월
- LTV: 12.6-31.5만원 (3.6-9개월)
- LTV:CAC: 4.2-10.5x → Go 기준(≥3.0x) 충족 가능

### 인용 (시뮬레이션, 합성)
> "선생님이 말씀하셔서 찾아보긴 했는데, 맘카페 보면 볼수록 더 불안해지고... 정확히 어느 정도인지 숫자로 알고 싶은데 그게 없잖아요."
>
> "앱에 올리면 누가 듣는 건지, 그게 좀 걸려요."

### MVP 함의
- 랜딩 카피: "치료 판정 아닌 발달 위치 확인"
- 결과 화면 "정상 범위" 강조 필수
- 온보딩 1단계: 보안·익명화 안내 전면
