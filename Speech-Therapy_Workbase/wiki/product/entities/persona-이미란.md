# 페르소나 · 이미란 (29세, 다문화 가정 어머니)

> "한국어가 먼저인지 모국어가 먼저인지 모르겠어요"

| 항목 | 내용 |
|---|---|
| 직무·상황 | 베트남 출신. 한국 남편과 결혼 7년. 만 4세 아들. 집에서는 베트남어+한국어 혼용. |
| 세그먼트 | **Adjacent · Seg A 다문화 변형** |
| 전략적 위상 | **황금 교차점 4명** ⭐ (Pain 5 × Sat 1) + **Q2 포용 설계** (AOS 4.0 — 공동 1위) |

## 핵심 문제
이중언어 환경 vs 언어지연 **구분 불가**. 상담받고 싶지만 한국어로만 설명하는 전문가와의 소통 어려움. 한국어 발음이 약한 아이를 어떻게 도와야 하는지 정보 부재.

## 목표
- 아이의 한국어 발달 수준 객관 파악
- **이중언어 환경에서의 적절한 가이드**

## 감정
고립감 + 문화적 불안 + 자기 비난

## 대체 솔루션 (현재)
- 다문화가족지원센터 (대기 길고 접근 불편)
- 유튜브 한국어 동요

## Pain/Goal 평가

| 항목 | 값 |
|---|---|
| Pain 중요도 | **5** (Goal 달성 완전 차단 — 이중언어/지연 구분 안 되면 어떤 개입도 방향 설정 불가) |
| 대체 만족도 | **1** (거의 무용 — 다문화 센터 대기 + 한국어로만 소통 + 이중언어 가정 전용 가이드 없음) |
| **AOS** | **4.0** ⭐ (Imp 5 × (1-1/5)) — 13명 중 공동 1위 |
| Market Relevance | 0.3 (다문화 가정 한국 전체 10%+) |
| **DOS** | 1.2 |
| 사분면 | **Q2 · 니치/포용 설계** (AOS 4.0이지만 DOS 중간) |

## 황금 교차점 4명 중 하나 ⭐

[[product/concepts/opportunity-quadrants]] § 황금 교차점 (Pain 5 × Sat ≤2):
- 이지수 (5,2)
- 박민정 (5,2)
- 최수현 (5,2)
- **이미란 (5,1)** ← Pain 1점이 가장 높음

→ Phase 0 100가정 파일럿에 **반드시 포함**되어야 할 4명 중 한 명. 단, 100가정 중 다문화 가정 비율을 인구 비례(10%+) 이상으로 의도적으로 모집해야 본 페르소나의 Pain이 검증됨.

## 제품 설계 시사점 — Q2 포용 설계의 핵심

| 요구 | 설계 |
|---|---|
| **이중언어 환경 발달 평가** | 한국어 단독 평가 + 모국어 환경 가중치 알고리즘. "이중언어 가정" 옵션 |
| **다국어 UI 지원** | 베트남어·중국어·우즈벡어 등 다문화 가정 주요 언어 (단, 콘텐츠는 한국어 발달 중심) |
| **다문화 전용 가이드** | "한국어/모국어 분리 환경 vs 혼합 환경 어느 쪽이 좋은가?" 같은 임상 권고 콘텐츠 |
| **다문화가족지원센터 파트너십** | 신뢰 앵커 + 도달 채널 |
| **부모용 학습 콘텐츠** | 한국어가 약한 어머니가 자녀와 한국어 상호작용을 늘릴 수 있는 부모용 마이크로러닝 |

## 차별화 가치

> "다문화 가정이 한국 전체 10% 이상. 이 세그먼트 전용 콘텐츠는 강력한 차별화 요소."

## 이탈/도입 리스크
- **언어 장벽**: 한국어로만 운영되면 Pain 해소 불가. UI 다국어화는 도입 조건.
- **다문화 가정 동질성 가정 위험**: 베트남·중국·필리핀 등 출신국별 한국어 노출 환경이 다름. 일률 적용 어려움.
- 모국어 vs 한국어 평가 균형의 임상적 정합성 미검증 — KSF #2 효과 검증 시 별도 트랙 필요.

## 보강 필요
- 100가정 파일럿에서 다문화 가정 비율 의도 모집 후 실측 인터뷰 필요 (현재 페르소나는 합성).
- 한국 다문화 가정 통계 정확화 (10%+ 출처 미명시).
- 다문화가족지원센터 협업 가능성 검토.
