# 페르소나 · 김태희 (38세, 간호사)

> "센터 케어 비용이 너무 부담스러운데 효과는 원해요"

| 항목 | 내용 |
|---|---|
| 직무·상황 | 병원 3교대 간호사. 만 4세 **쌍둥이** (둘 다 말이 느림). 합산 월 40-60만원 = 한 명만 가능. |
| 세그먼트 | **Seg A~B · 비용 민감형** |
| 전략적 위상 | **Triage 기능 진입 조건 + 5분 UX 기준 페르소나** |

## 핵심 문제
비용 부담으로 두 아이 모두 센터 케어/지원을 받지 못함. "누구를 센터 보내고 누구를 집에서?" 결정을 위한 **신뢰할 수 있고 저렴한 사전 발달 확인(Triage) 도구** 절실.

## 목표
- 센터 다니는 아이와 비슷한 효과를 가정에서 (비용 효율)

## 감정
죄책감 ("한 명한테 소홀") + 피로 + 비용 압박

## 대체 솔루션 (현재)
- 바우처 신청 → 소득 기준 초과
- 유튜브 틀어주기

## 전환 트리거
> "오늘의 5분 활동" 간결 가이드 + 월 3만원대 합리적 가격

## 5단계 여정

| 단계 | 행동·생각 | Pain | 개선 |
|---|---|---|---|
| 인식 | 쌍둥이 둘 다 → 비용 계산 → 좌절 | 한 명만 가능한 경제 제약 | **쌍둥이 플랜 할인** / 두 자녀 패키지 |
| 탐색 | 바우처 탈락 → 앱 검색 | "헛돈 쓰는 건 아닌지" | 비용 효과 인포그래픽: "센터 12만 vs 앱 3만, 효과 비교" |
| **의사결정** | **두 아이 모두 무료 발달 확인 → 점수 비교** → 어느 아이 센터, 어느 아이 앱 결정 | 두 아이 정확 비교 가능해야 진입 | **Triage: 두 아이 동시 발달 확인 + 비교 리포트 + 우선순위 가이드 자동** |
| **사용** | 3교대 후 피로 → "오늘의 5분 활동" → 잠자리 실행 | 10분 넘거나 준비물 필요 시 즉시 포기 | **5분 고정 + 준비물 없는 구어 활동** |
| 유지 | 주간 변화 확인 | 발전 느리면 "역시 앱은 안 되나" | 3개월 발달 데이터 요약 |

## 제품 설계 시사점
1. **Triage 기능이 진입 조건** (다자녀 동시 발달 확인 + 비교 리포트 + 우선순위)
2. **5분 고정 활동 + 준비물 없음** = 모든 활동 설계의 기본 제약
3. **3교대 등 비정형 시간 알림 커스터마이징**
4. 가격대: 월 3만원대 핵심 ARPU 기준
5. **다자녀 패키지** 별도 설계 (1명+1명 = 1.5명 가격 수준)

## 예상 Unit Economics
- ARPU: 3.5만원/월 (다자녀 시 비례)
- CAC: 낮음 (절박도 높음 → 검색 광고 효율)
- 이탈: 가격 인상 시 즉시 이탈

| 항목 | 값 |

| **Desired Outcome** | 동일 기준 비교 + "센터 vs 홈케어" 명확 가이드 |

| **DOS** | 1.2 (TAM 0.4) |

| **Barrier Top** | 직업적 특성상 **AI 정확도에 대한 높은 기준** ("앱보다 전문가가 낫다") |

### 인용 (시뮬레이션, 합성)
> "둘 다 비슷한 것 같은데 누가 더 급한지 모르니까... 아무래도 간호사라서 그런지 근거가 있어야 판단이 서요."
>
> "월 3만원은 괜찮아요, 근데 정말 정확한 건지가 문제죠."

### MVP 함의
- **"두 아이 동시 등록 할인"** 프로모션 효과적
- 발달 확인 신뢰도 보완 → MVP 5대 기능 #4 "비동기 전문가 코멘트 (배지)"의 핵심 anxiety 해소
- 간호사 직업 특성: 수치·근거에 강한 신뢰. **"언어재활사 검토 포함" 문구 필수**
- Triage 비교 기능은 AOS 4.0이지만 DOS 0.8 → MVP 후 Phase 1 후속 (jtbd-insights 정본)

> 미세 차이: 시뮬에서는 34세·만 3세 (페르소나 정의는 38세·만 4세). 직업/쌍둥이 본질 동일.
