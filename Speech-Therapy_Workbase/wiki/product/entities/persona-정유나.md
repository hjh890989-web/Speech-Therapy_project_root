# 페르소나 · 정유나 (33세, 프리랜서 디자이너)

> "아이 성장 기록을 남기고 싶어요"

| 항목 | 내용 |
|---|---|
| 직무·상황 | 재택 프리랜서 디자이너. 만 2세 딸. 인스타 육아 일기 운영. |
| 세그먼트 | **Seg A · 예방적 니즈형** |
| 전략적 위상 | **(Q4 재조정 ⚠️)** Core-5로 분류되어 있으나 AOS 1.2 / DOS 0.0 → **Q4 부차적 영역**. 바이럴 가치는 인정되나 **MVP 직접 타깃에서 제외**. |

## 핵심 문제
문제 해결보다 **'안심'을 위한 정기 진단**. 건강검진처럼 "이번 달도 정상" 확인 도장 원함. 진단 자체가 아이 스트레스 없는 가벼운 놀이 형태이길.

## 목표
- 월별 언어 발달 스냅샷
- 성장 곡선 포트폴리오 — "나중에 아이에게 보여줄 수 있는 데이터"

## 감정
호기심 + 기록 욕구 + **낮은 긴급도** (문제보다 관심의 영역)

## 대체 솔루션 (현재)
- 육아 앱 (성장 앨범류)
- 소아과 정기 검진

## 전환 트리거
> "월간 언어 발달 리포트" + 시각적으로 예쁜 성장 곡선 UI

## 5단계 여정

| 단계 | 행동·생각 | Pain | 개선 |
|---|---|---|---|
| 인식 | 인스타 육아 일기 → "언어 기록도" | 기록 정량 기준 부재 | 인스타 광고: "아이 언어 성장 포트폴리오" |
| 탐색 | 성장 앨범 앱 → 언어 기능 없음 → 소아과 1년 1회 | 정기 추적 도구 시중에 없음 | "월별 언어 발달 스냅샷" 강조 — 소아과 사이 공백 |
| **의사결정** | UI 스크린샷 → **발달 곡선 그래프 디자인에 반함** → 진단 시작 | 디자인·시각화 평범 시 즉시 이탈 | **앱 UI 최우선 투자** + 발달 곡선 = 예쁜 인포그래픽 + 인스타 공유 포맷 |
| **사용** | 매월 정기 진단 → **인스타 공유** → 팔로워 반응 | 긴급도 낮아 활동 완료율 ↓ | **인스타 공유 버튼 내장** → Viral. 활동보다 "기록"에 방점 |
| **유지** | 12개월 → "1년 성장 모음집" 다운로드 → 주변 추천 | 데이터 축적 = 자연 Lock-in | **연간 성장 리포트 + 프리미엄 인쇄 제본** (업셀) |

## 제품 설계 시사점
1. **앱 UI 디자인 품질 = Core-5 페르소나의 진입 조건**
2. **인스타 공유 포맷** (예쁜 인포그래픽) → 유기적 마케팅 채널
3. **연간 성장 리포트 + 인쇄 제본 업셀** 모델 구축 가능
4. 활동 완료율보다 "기록 연속성"으로 리텐션 측정
5. 페르소나 타깃 채널: **인스타그램 광고**

## 예상 Unit Economics
- ARPU: 3.5만 + 연간 인쇄 업셀
- LTV: 매우 높음 (12개월+ 지속, 데이터 축적 Lock-in)
- 바이럴 가치: 가장 큼 (인스타 노출 → 신규 유입)
