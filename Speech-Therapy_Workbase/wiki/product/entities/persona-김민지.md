# 페르소나 · 김민지 (32세, 워킹맘)

> "유튜브 보여주니까 괜찮아진 것 같아요"

| 항목 | 내용 |
|---|---|
| 직무·상황 | IT기업 워킹맘. 만 2세 아들. 약간 느리지만 "크면 다 하겠지" 낙관. 유튜브 육아 채널 구독. |
| 세그먼트 | **Non-user · Seg A 방관형** |
| 전략적 위상 | **SAM의 70-80%를 차지하는 최대 리스크 집단** + **직접 전환 불가, 외부 충격 필요** |

## 핵심 문제
"유튜브로 충분"하다고 자기 안심. **'좋은 부모로서의 도리'를 다했다는 감각**. 굳이 돈 내고 앱·센터 가야 하는 동기 없음.

## 목표
없음. **현재 상태 유지**가 목표.

## 감정
막연한 낙관 + **문제 현실화 회피 (방어기제)**

## 대체 솔루션 (현재)
- 유튜브 언어발달 콘텐츠 (주요)
- 인스타 육아툰
- "아직 어려서 그런 거" 가족 위안

## 전환 트리거 (만들기 어려움)
> Trigger 발굴 필요: 어린이집 면담 / 또래 급격 발달 목격 / 유튜브 보고 따라 말하지 않음을 부모가 인지

## JTBD 시뮬레이션 데이터 (Card ⑤)

| 항목 | 값 |
|---|---|
| **Job Statement** | 추가 비용·노력 없이 유튜브가 충분한지 확인 |
| **Desired Outcome** | "정상" 확신 유지 또는 최소 노력으로 해결 |
| **AOS** | **0.8** (Imp 4, **Sat 4**) — 만족도가 높아 개입 동기 없음 |
| **DOS** | **0.0** (시장 파급력 미미) ❌ |
| **Push** | 거의 없음. 단 한 번 지인 아이가 훨씬 잘해서 순간 불안 |
| **Barrier** | "별거 아닐 거야" **낙관 편향** + 유료 전환 동기 없음 + 남편 무관심 |

### 인용 (시뮬레이션, 합성)
> "유튜브 틀어주면 재미있어하긴 하는데... 따라 말하진 않아요. 그냥 보는 거죠."
>
> "아직 어려서 그런 거라고 하더라고요, 주변에서. 그래서 좀 더 지켜보려고요."

## 핵심 발견 #4 — Non-user는 직접 전환 불가

기능 추가나 가격 인하로는 김민지 유형 전환 불가. **외부 충격이 선행되어야 Satisfaction 하락 → 탐색 시작**.

### 외부 충격 마케팅 (Habit 균열)

> **"유튜브 시청 vs AI 인터랙션의 언어 발달 효과 비교"** 콘텐츠 마케팅 선행 필요

설계 방향:
- **광고 아닌 인사이트** 형태 ("뇌 언어 영역 활성화" 데이터 기반 콘텐츠)
- 맘카페 인플루언서 공동 콘텐츠 (광고가 아닌 개인 경험담 형태)
- "따라 말하지 않는다"는 **자각 트리거**를 일상 발견으로 노출 ("우리 아이도 그런가?" 자가 점검 체크리스트 무료)

### 마케팅 우선 시점
- 어린이집 면담 직후 시점 (트리거 활성)
- 명절 직후 (또래 비교 트리거)
- 무료 진단 CTA로만 접근 (구독 아님 — Anxiety 최소화)

## 페르소나 종합 비교에서의 위치

- 11개 Outcome 중 **"유튜브 충분성 확인" Outcome만 보유** (AOS 0.6, DOS -0.9)
- 본 페르소나의 진입은 **Phase 1 MVP 직접 타깃 아님**
- 단, **SAM 70-80% 점유** 전체 시장 활성화의 진입 장벽
