# 에듀템 (Edutem)

ELA(English Language Assessment)를 비롯한 음성인식·발음평가 API를 교육기업 대상으로 라이선싱하는 B2B 기술공급사. 카테고리 C(기술공급).

| 항목 | 내용 |
|---|---|
| 핵심 서비스 | ELA 솔루션 (음성인식, 발음평가 API) |
| BM | B2B SaaS / API 라이선싱 |
| 전략 | AI 교과서 개발 참여 + 교육기업 파트너십 |

## 우리에게 주는 시사
- **직접 경쟁자가 아니라 잠재 외주 파트너 후보** ⭐
- 자체 음성 AI 엔진 개발 vs 에듀템 API 외주의 결정 포인트 — [[product/concepts/Value-Chain-Analysis]] §본 프로젝트 가치사슬 참고
- API 외주 시 한계비용 낮음 + 초기 R&D 비용 절감 / 자체 개발 시 기술 해자 + 정확도 통제

## 결정 프레임 (자체 vs 외주)

| 기준 | 자체 개발 | 에듀템 API |
|---|---|---|
| 초기 비용 | 높음 | 낮음 |
| 정확도 통제 | 강 | 약 |
| 한국어 아동 음성 최적화 | 가능 | 의문 (확인 필요) |
| 데이터 자산화 | 가능 | 불가 |
| Time to Market | 느림 | 빠름 |

→ 본 프로젝트의 KSF #2(효과 검증)는 **아동 음성 정확도가 핵심** — 에듀템의 ELA가 한국어 아동 음성에서 어느 정도 성능을 내는지 PoC 필수.

## UX 인사이트 (raw 34 직접 경쟁 분석)

> [[product/sources/33-37-Competitor-UX-Analysis]] § 그룹 2

- **한국어 초성/중성/종성 음소별 정밀 발음 평가** + 연음·비음화 음운 규칙 판독 = **본 프로젝트 F1-a (음소 단위 STT) 와 F4 (음소 핀셋 분석 그래프) 의 핵심 기술 요구**. 임상 표준 = [[clinical/entities/U-TAP]] · [[clinical/concepts/조음장애]] (음운변동 평가).
- API 외주 결정 시 **한국어 아동 음성 정확도 PoC 필수** ([[product/concepts/Value-Chain-Analysis]] § 자체 vs 외주 결정 프레임).
