# 송앤스타크 (스피치맵)

2022년 설립 AI 언어발달 진단 특화 스타트업. 가치사슬 유형 A(진단 게이트키퍼). **본 프로젝트가 가장 직접적으로 공격 대상으로 삼는 경쟁사** — Value Chain 분석에서 "가장 취약한 경쟁사"로 식별.

| 항목 | 내용 |
|---|---|
| 설립 | 2022년 |
| 인력 | 초기 스타트업 (린 조직) |
| 자본 | 초기 단계 |
| 매출/가입자 | 매출 7억 / 가입자 2,000명 |
| 핵심 서비스 | AI 음성 분석 알고리즘 (스피치맵) — 5분 내 발달 수준 예측 |
| 타깃 | 언어재활센터(B2B) → 가정(B2C 2027 예정) |
| BM | B2B 센터 솔루션 + 데이터 분석 서비스 |
| 핵심 기술 | 언어학·조음학·음향학 통합 분석 모델 |
| AI 자동화 | **90%+** (인력 의존도 극히 낮음) |
| 규제 | **식약처 2등급 의료기기 인허가 추진** (2026 목표) |

## 강점
- 진단 특화로 명확한 포지션
- AI 자동화 90%+ → **한계비용 극히 낮음, 마진율 높음**
- 식약처 2등급 인허가 추진 — 규제 해자 가능성

## 약점 ⚠️ (우리의 공격 포인트)

| 취약 요인 | 상세 |
|---|---|
| **밸류체인 단절** | 진단 후 교육·치료 연계 부재 → 고객이 진단 후 이탈 |
| **B2C 전환 지연** | 가정용 앱 2027 예정 — **2년의 시간 공백** |
| **Lock-in 부재** | 1회성 진단 → 반복 사용 동기 약함 |
| **센터 영업 의존** | B2B 센터 채널에 묶여 있음 |

## 우리의 공격 전략

> 송앤스타크의 2027 B2C 전환 전 "진단+교육" 통합 모델로 진입 → 진단 영역 선점 + 교육 확장.

핵심 매핑:
- 송앤스타크의 진단 가치를 **무료 전환 트리거로 흡수** ([[product/concepts/Key-Success-Factors]] #1)
- 진단 후 [[product/concepts/Value-Chain-Analysis]] §AI 자가학습 콘텐츠로 연결 → Lock-in 확보
- 1회성 진단 vs 우리 **연속 발달 데이터 리포트** 차별화 (KSF #4)

## UX 인사이트 (raw 34 직접 경쟁 분석)
