# 두부 (舊 두브레인)

2017년 설립 디지털 헬스케어 기업. 시장 내 **가장 큰 자본력**(시리즈B 210억). 가치사슬 유형 B(풀스택 O2O).

| 핵심 서비스 | 두부팡(아동 앱) + 두부홈즈(부모 코칭 클래스) + 병원용 대시보드 |

## 강점
- **210억 자본력** — 시장 최대
- 병원-가정 연계 O2O 완성도
- 인지+언어 통합 솔루션
- 두부홈즈는 **부모 코칭 클래스** — 우리 KSF #3과 직접 경합 영역

## 약점
- 언어발달 "특화"보다 인지발달 "범용"
- 번 레이트 부담 (전문가 코칭 40%)
- 의료기기 등록 미완료

## 우리에게 주는 시사
- **자본력 격차 — 직접 정면 경쟁 회피**
- 두부의 약점("언어 특화 부족")이 곧 우리의 진입 기회 (언어 특화 B2C)
- 두부홈즈(부모 코칭) 모델 분석 필수 — 우리 KSF #3 비동기 코칭 설계 시 차별화 포인트 도출 필요
- 시리즈B 후 빠른 확장 가능성 → 골든타임 제약 중 하나

## UX 인사이트 (raw 35 DTx 분석)

> [[product/sources/33-37-Competitor-UX-Analysis]] § 그룹 3 (두부 = 두브레인 = 두부팡)

- **ABA(응용행동분석) 기반 인지 훈련 게임 + 알고리즘 자동 난이도 조절** = **본 프로젝트 F3-b 적응형 난이도 엔진의 임상 로직 원천**.
- "보이지 않는 난이도 조절" (실패 X 표시 숨김 + 자연스러운 단계 전환) = **F3-b 핵심 UX 원칙** ([[product/concepts/MVP-feature-spec]] § UX 모순 해결 ① 적용).
- **두부홈즈** (부모 코칭 클래스) = 우리 KSF #3 비동기 코칭의 직접 경쟁 영역 — 차별화 (실시간 클래스 vs 우리 비동기 코멘트) 필요.
