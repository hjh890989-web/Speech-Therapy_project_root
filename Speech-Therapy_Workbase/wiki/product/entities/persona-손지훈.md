# 페르소나 · 손지훈 (35세, 아동심리상담사)

> "언어가 아니라 정서인데, 언어도 같이 다뤄야 해요"

| 항목 | 내용 |
|---|---|
| 직무·상황 | 사설 아동심리상담센터 운영. 내담 아동 중 30%가 언어발달 문제 동반. |
| 세그먼트 | **Adjacent · 파트너 채널** (Seg D 인접) |
| 전략적 위상 | **Q1 혁신기회 (AOS 2.4 / DOS 1.4)** ⭐ — 신뢰 앵커 + 전문가 파트너 |

## 핵심 문제
연계할 만한 언어 발달 지원 기관 **대기가 길어 부모들이 방치됨**. 가정에서 할 수 있는 언어 자극 도구를 부모에게 추천하고 싶지만 **신뢰할 만한 앱 정보 부재**.

## 목표
- 심리상담 + 언어 자극 통합 지원 체계 구축
- **신뢰할 수 있는 언어 교육 앱을 공식 추천** (자신의 전문성 연장)

## 감정
전문성 확장 욕구 + 파트너십 니즈

## 대체 솔루션 (현재)
- 개별 언어재활사 비공식 연결 (일관성 없음, 결과 추적 불가)

## 전환 트리거
> "전문가 추천 앱" 포지셔닝 + 추천 후 결과 추적 가능한 대시보드

## Pain/Goal 평가

| 항목 | 값 |
|---|---|
| Pain 중요도 | **4** (Goal 달성 심각 저해 — 대기 중 방치가 심리상담 효과도 저해) |
| 대체 만족도 | **2** (불만족, 대안 적극 탐색) |
| AOS | 2.4 |
| DOS | **1.4** ⭐ |
| 사분면 | **Q1 · 혁신기회** |

## 전략적 의미

| 가치 | 활용 |
|---|---|
| **신뢰 앵커** | 전문가의 추천은 강한 전환율 → 부모 anxiety "AI 정확도 의심" 해소 |
| **파트너 프로그램** | Phase 2~3에서 활성화 — 본 페르소나가 핵심 파일럿 파트너 |
| **B2B2C 확산** | 1명 상담사 → 평균 50-80명 내담 부모 노출 (오한솔 80가구와 유사) |
| **결과 추적 대시보드** | 상담사 본인의 전문성 데이터 축적 (앱 사용 효과를 자신의 케이스에 통합) |

## 제품 설계 시사점

| 요구 | 설계 |
|---|---|
| 전문가 파트너 프로그램 | 개별 상담사·언어재활사가 "공식 추천 앱"으로 등록할 수 있는 프로그램 |
| 추천 후 결과 추적 대시보드 | 추천한 부모의 앱 사용 진행도·발달 변화를 (부모 동의 하) 상담사가 확인 |
| 추천 코드/링크 시스템 | 누가 누구를 추천했는지 추적 (커미션 또는 인센티브 가능) |
| "전문가 검증 배지" | 본 페르소나의 추천 기록을 마케팅 신뢰 자산으로 |

## 도입 리스크
