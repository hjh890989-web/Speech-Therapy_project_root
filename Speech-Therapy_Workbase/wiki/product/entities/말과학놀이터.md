# 말과학놀이터 (뉴로톡)

2021년 추정 설립 AI 장애음성 특화 발음교정 솔루션. 가치사슬 유형 B(DTx 지향).

| 항목 | 내용 |
|---|---|
| 설립 | 2021년 추정 |
| 자본 | 정부지원 기반 |
| 핵심 서비스 | AI 장애음성 특화 발음교정 |
| 타깃 | 조음장애 아동·성인·고령층 (전 연령) |
| BM | B2G 통합돌봄 + B2B + B2C |
| 핵심 기술 | **장애음성 특화 STT 엔진** |
| 전략 | 심뇌혈관센터 협력 의료인증 추진 |

## 우리에게 주는 시사
- 본 시장(B2C 영유아 언어발달) **직접 경쟁 강도 낮음** — 타깃이 전 연령(고령층 포함), 채널이 B2G 위주.
- 의료인증 추진 → DTx 카테고리에 속함 → 우리는 회피.

## UX 인사이트

> [[product/sources/33-37-Competitor-UX-Analysis]]

- 본 페르소나 33-37 직접 분석 대상은 아니나, **장애음성 STT 영역 (raw 35 DTx 그룹과 인접)** 패턴.
- 본 프로젝트는 일반 영유아 발화 중심이라 직접 경쟁 약함. 단, **Extreme-1 황보름 (ASD 비전형 발화)** 영역에서는 본 사의 STT 기술 라이선싱 가능성 검토 가치 있음 ([[product/entities/persona-황보름]] 미생성).
