# 페르소나 · 최수현 (36세, 초등교사)

> "전문가 말을 들어야 안심이 돼요"

| 항목 | 내용 |
|---|---|
| 직무·상황 | 초등 3학년 담임. 만 5세 아들. 직업상 발달 비교 안목 있음 → 조기 인지. |
| 세그먼트 | **Seg C · 센터 대기자** |
| 전략적 위상 | **이탈 시점 예측 가능 (센터 치료 시작)** — Lock-in 설계 핵심 |

## 핵심 문제
4개월 대기 중 "골든타임 놓치는 건 아닌지" 극도의 조급함. **정확한 진단 스냅샷 + 즉각적 응급 처방(가이드)** 원함.

## 목표
- 센터 치료 시작 전까지 가정에서 체계적 연습
- 센터 갈 때 "집에서 이렇게 훈련했어요" 데이터로 보여주기

## 감정
조급함 ("골든타임 놓칠까봐") + 전문성 신뢰 욕구

## 대체 솔루션 (현재)
- 언어치료사 유튜브 정주행
- 학교 특수교사 동료에게 비공식 조언

## 전환 트리거
> "전문 언어재활사가 주간 코멘트 제공" + "**센터 대기 중 활용 가능**" 메시지

## 5단계 여정

| 단계 | 행동·생각 | Pain | 개선 |
|---|---|---|---|
| 인식 | 학교 비교 → 조기 인지 | 빨리 알았지만 방법 모름 | "교사·전문직 부모 조기 개입 가이드" |
| 탐색 | 센터 → "4개월 대기" → 유튜브 정주행 | 공백 채울 공신력 도구 부재 | "센터 대기 중인 부모 브릿지" 광고 |
| **의사결정** | "전문가 코멘트" 메시지 → 빠르게 결제 | 자격 정보·코멘트 예시 부재 시 의심 | **전문가 프로필 공개 + 코멘트 예시 2-3개** |
| 사용 | 매주 진단 → 코멘트 → 가정 활동 | 코멘트 전문 용어 시 이해 ↓ | **가이드라인: 부모 눈높이 + 활동 1개 필수** |
| **유지 (이탈 위험)** | 센터 치료 시작 시점 | "이제 앱 필요 없잖아?" | **센터+앱 병행 가이드 + 치료사 공유 리포트** |

## 제품 설계 시사점
1. **센터 대기 부모 전용 포지셔닝**: "대기 기간 보완 서비스" 명시
2. **전문가 비동기 코멘트의 형식**: 자격증·경력 공개 + 부모 눈높이 + 오늘 할 활동 1개 필수
3. **이탈 방지 핵심**: 센터 치료 시작 시점에 선제적으로 "병행 가치" 전달 + 치료사 공유 리포트로 Lock-in
4. 검색 키워드 광고: "센터 대기 중", "언어치료 대기 중 할 일"

### 인용 (시뮬레이션, 합성)
> "3개월이 그냥 지나가면 안 된다는 생각에 뭐라도 해야겠다 싶었어요. 근데 뭘 해야 할지 모르겠는 거예요."
>
> "센터 가면 선생님한테 요즘 이런 거 했다고 말하고 싶은데, 그걸 정리해줄 무언가가 있으면 좋겠더라고요."

### MVP 함의
- **랜딩 카피**: "치료사가 인정하는 홈 트레이닝" → 발견 #3 "센터 + 앱"의 핵심
- 리포트에 **"센터 공유용" 버튼** = MVP 5대 기능 #5
- "3개월 기다리는 동안 무엇을 할 수 있는지" 콘텐츠 마케팅 (Habit 극복)
- 검색 광고 키워드: "센터 대기 중", "언어치료 대기 기간"
