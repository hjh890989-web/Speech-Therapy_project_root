# 와우키키 (하이동동)

2023년 추정 설립 멀티모달 AI 아동 언어치료 솔루션. 가치사슬 유형 C(AI 자가학습)에 속하나 진단 기능을 포함한 **진단+교육** 위치.

| 항목 | 내용 |
|---|---|
| 설립 | 2023년 추정 |
| 위치 | 서울 |
| 자본 | Seed/Pre-A 단계 (자본력 취약) |
| 매출 목표 | 2025년 30억 (미달 리스크 존재) |
| 핵심 서비스 | 부모용 + 교사용 + 아동용 **3개 앱 동시 운영** |
| 타깃 | 2~7세 언어발달 지연 아동 + 부모 + 교사 |
| BM | B2C 앱 (삼자 연동) |
| 핵심 기술 | **멀티모달 AI** (입 모양 + 발성 동시 분석) |
| AI 자동화 | 80%+ |
| 임상 협력 | 이대목동병원 |
| 파트너십 | 대교CNS 등 교육기업 |

## 강점
- **멀티모달 AI는 시장 내 독보적 딥테크** (음성 + 영상)
- 삼자 연동(부모-교사-아동) 모델 → 가정에서 교육기관으로 확산되는 바이럴 구조
- 병원 임상 레퍼런스(이대목동) 확보
- 본 프로젝트와 **타깃 연령 동일**(2~7세) — 가장 직접적 경쟁자

## 약점
- 자본력 취약 (Seed/Pre-A)
- 3개 앱 동시 운영 → 개발 부담
- 매출 목표 미달 리스크

## 우리에게 주는 시사
- **삼자 연동 모델은 모방·차용 가능** — 다만 우리는 부모 코칭에 더 무게(KSF #3)
- 멀티모달 AI는 진입장벽 — 우리는 **단일 모달리티(음성 중심)**로 시작 + 향후 멀티모달 옵션
- 직접 경쟁자이므로 **포지셔닝 차별화 필수** — 우리는 "진단 → 교육 브릿지" + "비동기 코칭" + "연속 리포트"로 KSF 4종 결합

## UX 인사이트 (raw 34 직접 경쟁 분석)
