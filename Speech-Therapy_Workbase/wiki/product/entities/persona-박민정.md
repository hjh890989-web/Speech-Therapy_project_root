# 페르소나 · 박민정 (31세, 마케터)

> "데이터로 확인해야 직성이 풀려요"

| 항목 | 내용 |
|---|---|
| 직무·상황 | 광고대행사 마케터. 만 4세 딸. 맞벌이 — 어린이집. **데이터·수치 판단 성향**. |
| 세그먼트 | **Seg A → Seg B 전환 가능성 높음** |
| 전략적 위상 | **고LTV + 바이럴 시작점** ⭐ |

## 핵심 문제
타인의 모호한 피드백("발음이 좀...") 견디지 못함. **데이터화된 진단** 원함 — 또래 하위 몇 %, 어떤 음소가 문제인지. 점수 낮아도 현실 직면이 다음 스텝.

## 목표
- 발음 정확도 수치 추적
- 월별 개선 데이터 — "이번 달 /ㅅ/ 85% → /ㅈ/ 72%"

## 감정
분석 욕구 + 자기효능감 추구 ("내가 직접 할 수 있다")

## 대체 솔루션 (현재)
- 발달 앱 2개 다운로드했다가 리텐션 없어 삭제
- 소아청소년과 발달 검사 예약

## 전환 트리거
> 주간 발달 추이 그래프 ("62점 → 71점") + 세부 음소별 분석 리포트

## 5단계 여정

| 단계 | 행동·생각 | Pain | 개선 |
|---|---|---|---|
| 인식 | 어린이집 담임 "발음 좀..." → 즉시 앱 2개 | 주관 피드백 = 데이터 아님 | 음소별 정확도 광고 소재 |
| 탐색 | 앱스토어 → 다 동영상 → 삭제 | 개인화 데이터 부재 | 키워드 "발음 정확도 측정" |
| 의사결정 | 음소별 샘플 리포트 확인 → 즉시 진단 | 샘플 없으면 신뢰↓ | 랜딩에 익명 샘플 + "/ㅅ/ 72→89% 4주" 사례 |
| **사용** | 주간 추이 그래프 모니터링 | 음소별 차이 원인 설명 부재 | 음소별 발달 연령 툴팁 + 전문가 코멘트 자동 |
| **유지** | **월간 PDF → 어린이집·남편 공유** | 외부 공유 막히면 활용성↓ | **PDF 내보내기 + 공유 링크** = 바이럴 트리거 |

## 제품 설계 시사점
1. **음소별 정확도 추이 그래프** = 핵심 차별화
2. **PDF 내보내기 + 공유 링크** → Word-of-Mouth 플라이휠 시작점
3. **데이터 리포트의 공유 기능 = 마케팅 채널** (광고비 없는 유기적 확산)
4. 샘플 리포트(익명)를 랜딩에 노출

## 예상 Unit Economics
- ARPU: 3.5만 → 5만 (프리미엄 업셀 시)
- LTV: 가장 높음 (+ 바이럴 가치)

### 인용 (시뮬레이션, 합성)
> "세 달을 썼는데 결국 나아졌는지 모르고 끊었어요. 뭔가 수치로 보여주면 좋겠다 싶었는데 그런 앱이 없더라고요."
>
> "리포트 같은 게 있으면 캡처해서 인스타에 올릴 것 같기도 하고요."

### MVP 함의
- **재유입 페르소나** — 온보딩에서 "기존 앱과 다른 점: 주간 수치 리포트" 차별점 전면 강조
- 7일 무료 체험 + 환불 보장 (anxiety 해소)
- **리포트 = 인스타 스토리·카톡 공유 최적화** = 바이럴 루프 트리거 ⭐

> 미세 차이: 시뮬에서는 36세 디지털 마케터·만 5세 자녀 (페르소나 정의는 31세 광고대행사·만 4세). 본질 동일, 추후 실측에서 보정.
