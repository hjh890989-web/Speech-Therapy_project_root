# Customer Journey — Core 5 (트랙A) + 트랙B 비측정 여정

> 🔄 **2트랙 재정렬(2026-06-22)**: 아래 Core 5 여정은 **트랙A(발음·발화 발달 "확인", 만 2~7세)** 모집단의 여정이다. 라이브 문해 트랙(CR-2026-009)을 위해 본 페이지에 **트랙B(읽기·말 "놀이·연습", 만 2~12세) 비측정 여정**을 신설한다(§"트랙B 비측정 여정"). 비대칭 불변: 트랙A=또래 비교 "확인"(표준화 규준) / 트랙B=점수·밴드·판정 없는 "놀이·연습"(engagement만, `bandShippable=false`) — **측정 vs 측정이 아니다**. 근거: 청사진 [[Speech-Therapy_App/docs/realignment/00_2track_realignment_blueprint|2트랙 재정렬 청사진]] §2·§3.

Core 5 페르소나(트랙A)의 5단계 여정(인식→탐색→의사결정→사용→유지) 종합. 각 단계별 페인을 제품 기능 요구로 변환.

> ⚠️ Adjacent·Extreme·Non-user 여정은 raw 17_Customer_Journey_Map_Others 미독 → 추후 보강.

## 5단계 여정 표준 모델 (트랙A — 발음 확인 기반)

> 본 표준 모델은 **트랙A(발음 확인)** 여정이다 — 측정 충격(또래 비교 "확인")에서 시작해 의사결정 이탈을 넘는 구조. 트랙B(문해) 여정은 **측정 충격이 아니라 "함께 놀 거리"**에서 시작하는 별도 모델이다(§"트랙B 비측정 여정").

```
[1. 문제 인식] → [2. 탐색] → [3. 의사결정] → [4. 사용] → [5. 유지]
   "느린 것 같은데"   "어떻게 해야"   "할까 말까"   "이걸로 되나"   "계속 할까"
```

## 페르소나별 전략적 핵심

### 트랙A — 발음 확인 (Core 5)

| 페르소나 | 정본 | 전략적 핵심 |
|---|---|---|
| 이지수 | [[product/entities/persona-이지수]] | **진입 장벽 최고 + 볼륨 최대**. 발달 확인 무서움 ↓ + 점수→처방전 즉시 연결 |
| 박민정 | [[product/entities/persona-박민정]] | **고LTV**. 외부 공유 (어린이집·남편) → Word-of-Mouth 플라이휠 |
| 최수현 | [[product/entities/persona-최수현]] | **이탈 시점 예측 가능 (센터 케어 시작)**. 선제 병행 가치 + 전문가 데이터 공유 |
| 김태희 | [[product/entities/persona-김태희]] | **Triage(두 아이 비교)가 진입 조건**. 5분·간결 UX 기준 |
| 정유나 | [[product/entities/persona-정유나]] | **긴급도↓ + LTV↑ + 바이럴 최대**. 디자인 + 인스타 공유 = 유기적 확산 |

### 트랙B — 읽기·말 놀이·연습 (신규, 2026-06-22)

> ⚠️ 트랙B 페르소나의 전략적 핵심은 **측정·점수·판정이 아니라 "활동 공백을 메우는 놀이 제공" + "꾸준함(engagement)"**이다. 어떤 행에도 점수·밴드·또래백분위·"측정/평가/확인(probe)" 어휘를 두지 않는다.

| 페르소나 | 정본 | 전략적 핵심 |
|---|---|---|
| 학령전 읽기준비형 (만 5~7세) | [[product/entities/persona-학령전읽기준비]] | **취학 전 읽기 놀이 시작 대표형**. "공부 아님" 톤 + 발달 단계에 맞춘 음운인식·해독 **놀이**로 진입 — 준비도 판정 없음 |
| 학령기 읽기 따라가기형 (만 8~9세) | [[product/entities/persona-학령기읽기따라가기]] | **발음 리포트 없는 단독 진입 대표형**. 받아쓰기·소리 내어 읽기가 아직 익숙하지 않은 가정 — "시험 아님" 톤 + engagement 유지 |

## 단계별 핵심 페인 → 개선 기회 매트릭스 (트랙A — 발음 확인)

> 본 매트릭스는 **트랙A(발음 확인)** 여정의 단계별 페인이다. 트랙B(문해 놀이·연습)의 여정은 측정·진단 프레임이 아니라 "활동 공백 → 함께 놀 거리 → 활동 습관" 구조로 별도 정리한다(§"트랙B 비측정 여정").

### 단계 1 · 문제 인식
- **공통 페인**: 정상/비정상 기준선 부재
- **개선**: "만 N세 평균 발달 기준표" 콘텐츠 + 자가 체크리스트 무료 제공

### 단계 2 · 탐색
- **공통 페인**: 유튜브·맘카페 정보 범용성 → 내 아이 맞춤 부재
- **개선**: 광고 카피 "우리 아이 맞춤 발음 검사 — 3분, 무료"

### 단계 3 · 의사결정 (가장 큰 이탈 지점)
- **이지수형 페인**: "결과 나쁘게 나오면" 두려움 → 발달 확인 회피
- **개선**: "판정이 아니에요. 발달 위치를 알려드려요" + **익명 발달 확인 옵션**
- **박민정형 페인**: 기존 앱이 데이터 없는 동영상만
- **개선**: 랜딩에 실제 샘플 리포트(익명) + "/ㅅ/ 72→89% 4주 변화" 사례
- **최수현형 페인**: "진짜 전문가가 검토?" 의심
- **개선**: 코멘트 작성 전문가 프로필(자격증·경력) 공개 + 예시 2-3개

### 단계 4 · 사용 (활성화)
- **공통 페인**: 점수 수령 후 의미 해석·다음 행동 연결 안 됨
- **개선**: 리포트 내 "이 점수의 의미" + "오늘 할 3가지 활동" 자동 제안
- **김태희형 페인**: 활동 10분 넘거나 준비물 필요 → 즉시 포기
- **개선**: 5분 고정 + 준비물 없는 구어 활동
- **박민정형 페인**: 음소별 차이 원인 설명 부재
- **개선**: 음소별 발달 연령 특성 툴팁 + 전문가 코멘트 자동 트리거

### 단계 5 · 유지 (리텐션 엔진)
- **이지수형 페인**: 3주 무변화 → 포기 유혹
- **개선**: "이 나이 아이들은 다 이래요" 격려 푸시 + 전문가 코멘트 1회 무료
- **최수현형 페인**: 센터 케어 시작 시점 = 이탈 위험 (예측 가능)
- **개선**: "센터+앱 병행 가이드" + 전문가 공유 리포트 → Lock-in
- **박민정형 페인**: 리포트 외부 공유 불가 시 활용성 ↓
- **개선**: PDF 내보내기 + 어린이집 공유 링크 → 바이럴 트리거
- **정유나형 페인**: 긴급도 낮아 활동 완료율 ↓
- **개선**: 활동 완료보다 "기록"에 방점, 인스타 공유 버튼 내장

## 트랙B 비측정 여정 (읽기·말 놀이·연습 · 신규 2026-06-22)

> 🔄 **2트랙 재정렬(2026-06-22)**: 트랙B(읽기·말 놀이·연습, 만 2~12세)는 트랙A의 "측정→처방→추이" 구조와 **대칭이 아니다**. 트랙B 여정은 **인지(읽기 고민) → 진입(측정 충격이 아닌 "함께 놀 거리") → 단계 라우팅 → 활동 습관(engagement) → 리텐션**으로 흐른다. 여정 어디에도 점수·밴드·또래백분위·정상/위험 판정·"측정/평가/확인(probe)" 어휘가 없다 — 산출은 **engagement(활동 횟수·활동일)**만이며 `referenceBand=null`·전 단계 `bandShippable=false`. 근거: 청사진 §3·§5, [[product/entities/persona-학령전읽기준비]] / [[product/entities/persona-학령기읽기따라가기]].

### 트랙B 여정 표준 모델 (비측정)

```
[1. 인지] → [2. 진입] → [3. 단계 라우팅] → [4. 활동 습관] → [5. 리텐션]
 "읽기를 어떻게   "검사·점수 없이   "우리 아이에 맞는   "오늘도 짧게      "이번 주도
  놀아줄까"        함께 놀 거리"      놀이 한 가지"        함께 놀았어요"      이어가요"
```

> ⚠️ 트랙A 여정의 "의사결정(할까 말까)" 이탈 지점이 **트랙B에는 없다** — 트랙B 진입은 "결과 나쁘게 나오면" 두려움(측정 충격)으로 시작하지 않고, "함께 놀 거리"로 시작하므로 진입 마찰이 구조적으로 낮다.

### 트랙B 단계별 동력 → 개선 (engagement 중심)

#### 단계 1 · 인지 ("읽기를 어떻게 놀아줄까")
- **동력(페인 아님)**: 자녀의 연령·발달 단계에 맞는 읽기·말 놀이가 무엇인지, 어떤 순서로 함께할지 막막함. **"무엇을 측정하고 싶은 게 아니라, 무엇을 함께 놀지를 알고 싶음"**.
- **개선**: "집에서 놀이로 함께해요" 카피 — 점수·등급 없음. 학년/단계 라벨이 아니라 **놀이명**으로 안내(clin-2). (학령전: "글자 놀이 어떻게 시작" / 학령기: 받아쓰기·소리 내어 읽기가 아직 익숙하지 않은 일상 인지.)

#### 단계 2 · 진입 (`/literacy/start` — 측정 충격이 아닌 "함께 놀 거리")
- **동력**: "진입에 검사·점수가 필요할까" 망설임 + "학원·학습지는 부담".
- **개선**: **검사·점수 없이 바로 놀이 시작 — 발음 리포트 없이도 트랙B 단독 진입**(주간뷰 문해력-only 카드 노출, #109와 정합). 진입 동사는 "함께 놀 거리를 받는다"이지 "발달을 측정·확인한다"가 아니다.

#### 단계 3 · 단계 라우팅 (월령 → 단계 → 놀이)
- **동력**: 무엇을 어떤 순서로 해야 할지 모름(놀이 흐름 부재).
- **개선**: 월령(24~144) 입력 → 발달 단계(S0~S4) → 해당 연령에 **실제 적격**한 활성 놀이만 라우팅(`enabledGamesForAge`, dead-end 0). 단계는 **구인 분류·내부 표시용**이며 부모·자녀에게는 **놀이명만** 노출(clin-2). 플래그 off 게임은 목록에서 제외(미공개 콘텐츠 누출 0). 놀이 순서·난이도 위계는 발달 사실에서 **영감만** 차용한다(절단점·규준·백분위 차용 금지 — 음운인식 위계 운율→단어→음절→음소, [[clinical/concepts/읽기-선행지표-발달규준]] §2.A).

#### 단계 4 · 활동 습관 (engagement)
- **동력**: 길거나 준비물이 필요하면 중단 + "변화가 점수로 안 보이면 동기 저하".
- **개선**: 짧은 활동 + 준비물 최소 + "오늘의 읽기·말 놀이". 활동 1회 완료 = **활동 1건(완료=1)** — 점수·등급·또래백분위·판정 미산출(`referenceBand=null`). 주간 리포트는 `aggregateLiteracyWeekly`가 `totalSessions`·`activeDays`·`byStage`·`byGame`만 표시.

#### 단계 5 · 리텐션 (활동 습관의 지속)
- **동력**: 변화가 점수로 안 보여 동기 저하 + 학교 받아쓰기 압박 시 "시험 프레임" 도구로 이탈 위험(학령기).
- **개선**: **활동일·활동 횟수(engagement)로 꾸준함을 보여줌 — 판정 아님**(W-LER 보조지표, "완수율" 프레임 금지). "이번 주 5번, 3일 함께 놀았어요" 같은 engagement 카피로 응원. "시험/공부 아님" 톤 일관. Lock-in = 발달 단계 연속 활동·습관(점수 궤적 아님).

> ⚠️ **트랙B 여정 자가 가드**: 여정 종착점은 **놀이 지속**이다 — "판정·등급·또래 위치 확인"이 아니다. "62점→71점", "또래 상위 N%", "준비도 평가", "읽기 수준 확인" 같은 표현 사용 금지. engagement(활동 횟수·활동일) 표현만 허용.

### 트랙B 단계별 KPI (보조 W-LER · engagement)

> ⚠️ 트랙B KPI는 트랙A의 측정 기반 지표(완수율·전환율·검사 완료율)와 **대칭이 아니다**. 트랙B owner 지표는 **W-LER(주간 문해 활동률, engagement)** 보조지표이며, target은 **baseline 축적 후 산정**(≥60% 등 무근거 차용 금지 — 연습-only 자연 빈도가 발음 미션과 다름, 청사진 [[Speech-Therapy_App/docs/realignment/00_2track_realignment_blueprint|2트랙 재정렬 청사진]] §4 ADR-05 옵션 C 지향·A 1차).

| 단계 | KPI (engagement 기반) | 목표 |
|---|---|---|
| 인지 → 진입 | 문해 단독 진입률(`/literacy/start` 도달, 발음 게이트 비종속) | baseline 관찰 |
| 진입 → 단계 라우팅 | 라우팅 성공률(월령 입력 → 적격 활성 놀이 노출), dead-end | dead-end 0건 |
| 단계 라우팅 → 활동 | 첫 주 활동 시작률(활동 1건 이상) | baseline 관찰 |
| 활동 습관 | **W-LER (주간 문해 활동률, engagement)** — `activeDays`·`totalSessions` | baseline 후 target 산정 |
| 리텐션 | 주간 문해 활동 지속(주 단위 활동일 유지) | baseline 후 산정 |

> ⚠️ 위 표의 어떤 셀도 점수·밴드·또래백분위·"완수율/미션" 프레임을 두지 않는다 — 전부 engagement(활동 횟수·활동일·라우팅 결정성) 기반이다.
