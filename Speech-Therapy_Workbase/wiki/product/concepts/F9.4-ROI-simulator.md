# F9.4 ROI 시뮬레이터 — 매핑 + UI 설계 제안

VPS V08 §11-E 신규 + §13-2 B2B 영업 무기로 도입된 **원장(Seg D-1) 재무 논리 영업 도구**. 본 페이지는 (1) 현 88 Task 매핑 누락 식별 (2) 신규 task 분해 제안 (3) UI 설계안 (4) F9-a Epic 흡수 vs 독립 Epic 결정 분석.

> 제품 결정 후보: **본 페이지는 분석 + 제안**. 실제 task 신규 등록은 사용자 확인 필요.

## 핵심 가치 명제 (VPS V08 §11-E)

| 항목 | 값 | 출처 |
|---|---|---|
| **원아 1명 이탈 시 손실** | 월 보육료 50만 × 12 = **연 600만** | VPS V08 §11-E |
| **솔루션 도입 비용** | B2B 라이선스 연 50만 | VPS V08 §11-A |
| **방어 ROI** | 600만 ÷ 50만 × 100% = **1,200%** (보수: 1,100%) | VPS V08 §11-E |
| **인지 변환 효과** | "교육 도입" → **"경영 방어 투자"** | VPS V08 §13-2 |

> "원장(Seg D-1)은 교육적 가치보다 **재무 리스크 방어**에 확실히 지갑을 엽니다." — VPS V08 §11-E

[[product/concepts/requirements-traceability-matrix]] § Phase 2:

## 결정 1 — F9.4 = F9-a 흡수 vs 독립 Epic?

| 옵션 | 근거 | 단점 |
|---|---|---|
| **A. F9-a 흡수** (현 가정) | Epic 단순화. 12 SP에 ROI 계산기 1 컴포넌트로 포함 | F9-a 본 대시보드는 **로그인 후** / F9.4는 **영업 단계 무로그인** — 인증·접근 정책 충돌 |
| **B. 독립 Epic 승격 ⭐ 권장** | 무로그인 영업 무기 = **B2B 리드 캡처 퍼널의 입구** (Land 단계). F9-a 풀 대시보드는 도입 후 운영 도구 | Epic 22번째 신규 — 명세 일관성 깨짐 |
| **C. F9-a Sub-feature 표기** | F9-a.4 형태로 명시 + 별도 task 분해 | 명명 충돌 (다른 Epic 들 a/b/c/d 형식 vs 숫자 형식) |

→ **권장 = 옵션 B 또는 C**. Phase 2 도입 시 인증 경계 분리 명확화 필요.

### UI 원칙

| 원칙 | 적용 |
|---|---|
| **무로그인** | Step 1-2는 인증 0건. Step 3에서 리드 캡처만 (선택적) |
| **입력 ≤2개** | 원아 수 + 월 보육료 — F1-b 5분 진단 (입력 ≤3) 정합 |
| **충격 카피 → 안도 CTA** | "600만 원 증발" → "1,100% ROI" → "무료 PoC" 3단 |

| **ADR-04 정합** | "진단" 단어 배제 → "경영 시뮬레이션" / "발달 검사" 단어 배제 |

## 결론 — 제안 작업

1. **결정 1**: F9-a 흡수 vs F9.4 독립 Epic 승격. **B 옵션 권장** (무로그인 인증 경계 분리).

3. **REQ-FUNC 062~064 후보** SRS V07 후속 개정 시 추가.
4. **ADR-XX 신규**: F9.4 무로그인 분리 명시.
5. **KPI 4종 신규**: ROI 진입율 / PDF 전환율 / PoC 전환율 / B2B 결제 전환.
6. **RTM 갱신**: 본 페이지 결정 후 → 88 Task → 93 Task 보강.
