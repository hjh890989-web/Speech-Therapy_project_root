# Value Chain Analysis (본 프로젝트)

Porter's Value Chain 프레임워크로 5개 주요 경쟁사를 분해하고, 시장 가치사슬을 3개 유형으로 묶어 신규 진입 최적 포지션을 도출한 결과 페이지.

## 시장 가치사슬 3개 유형

### 유형 A · 진단 게이트키퍼
```
[음성 입력] → [AI 자동 진단] → [리포트 출력] → (끝)
```
대표: [[product/entities/송앤스타크]] (스피치맵)
- 한계비용 매우 낮음 (AI 자동화 90%+)
- **약점**: 진단 후 교육·치료 연계 부재 → Lock-in 약함

### 유형 B · 풀스택 O2O
```
[병원 진단] → [AI 교육/훈련] → [전문가 개입] → [병원 모니터링] → 순환
```
대표: [[product/entities/두부]], [[product/entities/네오폰스]]
- 다층 수익 (구독 + 코칭 + DTx 처방료)
- **약점**: 전문가 의존 → 확장 병목, 번 레이트

### 유형 C · AI 자가학습
```
[AI 진단] → [맞춤 커리큘럼] → [게임형 자가학습] → [리포트] → 반복
```
대표: [[product/entities/에이치투케이]], [[product/entities/와우키키]]
- 한계비용 낮음, 스케일업 유리
- **약점**: 학습 효과 검증 약함 → 부모 신뢰 확보 난

## 신규 진입 최적 포지션: 진단-교육 브릿지

```
[진단] ────────── [교육/훈련] ────────── [치료/관리]
  │                   │                     │
송앤스타크         에이치투케이            네오폰스
(B2B only)         (한글 특화)             (DTx)
                   와우키키
                       │
                 ┌─────┴─────┐
                 │           │
            ⚠️ 공백 영역 ⚠️
       "진단→교육 연계"   "부모 코칭"
       "발달 리포트"      "비동기 전문가"
```

| 진입 포지션 | 전략 | 경쟁 강도 |
|---|---|---|
| 무료 AI 진단 → 유료 맞춤 교육 | 송앤스타크 진단 가치 흡수 + 자가학습 결합 | 낮음 |
| 부모 코칭 레이어 | 모든 경쟁사가 "아동 대상". 부모 비동기 코칭 미개척 | **매우 낮음** |
| 주간/월간 발달 리포트 | 1회성 진단 vs 우리 연속 추적 | 낮음 |

## 가장 취약한 경쟁사: [[product/entities/송앤스타크]]

| 취약 요인 | 상세 |
|---|---|
| 밸류체인 단절 | 진단 후 교육/치료 연계 부재 |
| B2C 전환 지연 | 가정용 앱 2027 예정 (2년 공백) |
| Lock-in 부재 | 1회성 진단 → 반복 사용 동기 약함 |

> **공격 전략**: 송앤스타크 2027 B2C 전환 전 "진단+교육" 통합 모델로 진입.

## 본 프로젝트의 가치사슬 (잠정)

```
[무료 AI 진단]              ← 고객 획득 엔진 (KSF #1)
  ↓
[리포트 충격 → 유료 전환]
  ↓
[맞춤형 AI 자가학습 콘텐츠]   ← 유형 C 흡수
  ↓
[연속 발달 데이터 리포트]    ← 리텐션 엔진 (KSF #4)
  ↓
[비동기 전문가 코멘트]       ← 신뢰 보조 (KSF #3)
```

자체 핵심 활동: 진단 알고리즘 / 콘텐츠 + UX / 발달 데이터 시각화 / 전문가 코칭 운영.
외부 조달 후보: [[product/entities/에듀템]] ELA API (음성인식 외주), 클라우드 인프라.

## Clinical 근거

- 유형 B(풀스택 O2O)의 "병원 → 가정 → 병원" 순환은 [[clinical/concepts/한국-언어치료-트랙비교]] §트랙1+트랙2 결합형의 디지털화. 우리는 의도적으로 회피.
- 유형 C(AI 자가학습)의 "학습 효과 검증 약함"은 [[clinical/entities/REVT]], [[clinical/entities/U-TAP]] 등 임상 표준 검사로 검증 가능 — KSF #2의 핵심 솔루션.
- "비동기 전문가 코멘트"의 운영 가능성은 [[clinical/concepts/아동언어치료-핵심기법]] 의 4개 기법(평행발화·확장·기다리기·반응적상호작용)을 텍스트 코멘트로 재현 가능한지가 관건.
