# 문제 정의 (Problem Definition) — v1.1 (JTBD 시뮬 인사이트 반영)

> ✅ **v1.0 통합 완료** (2026-05-09 2차 ingest). 4개 문제 정의서(Draft, VC, Strategist, Analyst)가 [[product/sources/12-Problem-Definition-Final]] 로 수렴.
> ⭐ **v1.1 JTBD 보강** (2026-05-09 4차 ingest). [[product/sources/22-23-JTBD-Interview-Results]] 시뮬레이션 인터뷰의 4가지 핵심 발견 통합 — 특히 **"방법론이 실제 구매 이유"** 발견은 핵심 불편함의 가중치 재조정을 가져옴.

## 시장의 본질

> **"전문가 독점 서비스의 대중화 전환기"**

심리상담(→Talkspace), 법률자문(→로톡), 피트니스(→Noom)와 동일한 패턴. 언어재활사만 할 수 있다고 여겨지던 서비스의 80%가 실은 **정보·도구·데이터**만 있으면 부모가 가정에서 직접 수행 가능한 활동. 사설 센터 세션의 핵심도 아이를 직접 가르치는 것이 아니라 **부모에게 "이렇게 말을 걸어보세요"라고 코칭**하는 것 → [[clinical/concepts/아동언어치료-핵심기법]] 의 4기법.

## 누구의 문제인가

> 자녀(만 2~7세)의 말이 또래보다 늦는 것 같아 불안하지만, **센터에 갈 정도인지 판단이 안 서거나, 센터 치료를 결정했지만 대기 중인 부모.**

연 **30~50만 가구** (TAM 17~25만 SAM의 일부, → [[product/concepts/customer-segmentation]]).

이 부모의 심리는 단순한 불편이 아니라 **'좋은 부모가 되지 못하고 있다'는 죄책감과 무력감의 혼합물**. 기능만 좋은 앱이 안 팔리는 이유.

## 어떤 상황에서

> 아이가 "사과"를 "타과"로 말하거나 어린이집 선생님이 "말이 좀 느린 것 같다"고 할 때. 센터 전화 → "3개월 대기" → "일단 지켜보자" → 밤마다 **"골든타임을 놓치는 건 아닌지"** 불안.

```
맘카페 검색 → 불안 증가 → 센터 전화 → "3개월 대기"
→ "일단 기다리자" → 유튜브 → 효과 모름 → 다시 불안 → (반복)
```

## 핵심 불편함 — 하나의 뿌리, 세 가지 가지

> **뿌리 문제: "우리 아이가 정상인지 아닌지 모른다."**

| 파생 불편함 | 부모의 말 | 비즈니스 대응 | 핵심 지표 |
|:---|:---|:---|:---|
| ① 진단 부재 | "또래 대비 몇 점인지 모르겠어" | 무료 AI 진단 → **유입 엔진** | 전환율 ≥ 8% |
| ② 방법론 부재 ⭐ | "뭘 어떻게 시켜야 하는지 모르겠어" | 진단 기반 맞춤 커리큘럼 → **실제 구매 이유** | 주간 완료율 ≥ 60% |
| ③ 효과 확인 불가 | "한 달째인데 나아진 건지 모르겠어" | 주간 발달 추이 리포트 → 리텐션 엔진 | M3 유지율 ≥ 40% |

→ 이 셋을 해결하는 것이 본 사업의 **핵심 문제**.

> ⭐ **v1.1 JTBD 인사이트 반영** ([[product/concepts/jtbd-insights]] 발견 #1):
> 시뮬레이션 인터뷰에서 **이지수·최수현·김태희 3명 공통 발언**: *"뭘 어떻게 해야 할지 모르겠는 거예요"*. 부모는 진단 결과 자체로 돈 내지 않고, **방법론 부재가 실제 구매 이유**. 진단=유입(①), 방법론=구매(②), 리포트=유지(③) — 셋 중 ②번이 *돈을 내는 이유*. 진단을 stand-alone으로 두면 송앤스타크 함정.

## 사업적 유효성 검증 (요약)

| 검증 질문 | 답 | 판정 |
|---|---|---|
| 부모가 돈을 내는가? | 센터 월 12~24만원 지불 중 | ✅ |
| 기존 대안 부족? | 센터 = 비싸고 길다 / 유튜브 = 개인화·추적 부재 | ✅ |
| 경쟁사 미해결? | DTx 쏠림으로 B2C 교육 방치 | ✅ |
| M3 ≥ 40% 가능? | **미검증**. 평균 D30 = 2~3% (15-20x 갭) | ❌ |
| 전환율 ≥ 8% 가능? | **미검증** | ❌ |

> **결론**: 문제는 존재. 지불의사 있음. 그러나 **"불안이 구독으로 전환되는가"는 100가정 파일럿으로만 답할 수 있음.**

## 해결 방향 — 한 문장 정의

> **"아이 말이 늦는 것 같아 불안한 부모에게, 무료로 진단해주고, 맞춤 훈련을 제공하고, 매주 나아지는 걸 보여주는 서비스."**

### 3단계 가치 퍼널 + 신뢰 보완

```
[STEP 1] 무료 AI 진단        →  "/ㅅ/ 발음 정확도 62점"     [고객 유입]
                                불안에 이름을 붙여준다

[STEP 2] 맞춤 구독 교육       →  "이번 주는 /ㅅ/ 소리 훈련"  [핵심 수익원]
                                부모에게 방법론을 준다

[STEP 3] 주간 발달 리포트     →  "62점 → 71점 (+9점)"      [리텐션 엔진]
                                효과를 눈으로 보여준다

[보완] 전문가 비동기 코멘트    →  "전문가도 확인했습니다"     [신뢰]
                                혼자가 아니라는 안심
```

### 카테고리 정의

> **"홈 랭귀지 코칭(Home Language Coaching)"** — 새 카테고리 정의 + 소유.

DTx와 보완(진단 연계, 치료 전후 훈련). [[clinical/concepts/한국-언어치료-트랙비교]] § 트랙 2 진입 직전 + 대기 단계의 디지털 보완재.

## 실행 로드맵

| 단계 | 기간 | 할 일 | 완료 기준 |
|:---:|:---:|:---|:---|
| Phase 0 | 0~3개월 | 무료 진단 MVP + **100가정 파일럿** | 전환율·유지율 실측 |
| Phase 1 | 3~6개월 | 발달 리포트 + 전문가 2~3명 비동기 코멘트 + Before/After | M3 확인, 학습 효과 정량 |
| Phase 2 | 6~12개월 | 정식 런칭 + 마케팅 + 유치원/어린이집 B2B2C 5개소 | 월 1,000가정 |
| Phase 3 | 12개월+ | 전문가 네트워크 + 대학 공동연구 + 카테고리 리더십 | LTV:CAC ≥ 3.0x 안정 |

## Go/Pivot/Kill (100가정 파일럿)

| 지표 | Go | Pivot | Kill |
|---|---|---|---|
| 무료진단 → 유료 전환율 | ≥8% | 5~8% | <5% |
| M3 유지율 | ≥40% | 30~40% | <30% |
| LTV:CAC | ≥3.0x | 2.0~3.0x | <2.0x |
| 부모 NPS | ≥50 | 30~50 | <30 |
| 3개월 발음 정확도 변화 | 유의미 향상 | 미미 | 변화 없음 |
