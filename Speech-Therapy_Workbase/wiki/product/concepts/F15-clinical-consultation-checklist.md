# F15 KOPLAC 임상 자문 체크리스트 — Phase 1 진입 전 게이트

[[product/concepts/Phase-1-future-tasks-decomposition]] § F15 LLM 대화형 발화 유도 챗봇의 임상 안전망. **Phase 1 진입 직전 임상가 자문 시 검토할 13 항목** (54차 ingest 보강) + ASD 회피 경계 + 연령별 적응 + 데이터 활용 정합 + 한국 임상 측정 단위 통합 + **한국 임상 자문 풀 7 그룹 매트릭스**.

> 보강 필요 항목: "F15 KOPLAC 영감 임상 자문 (Phase 1 진입 전)" — **본 페이지가 그 임상 자문 가이드라인 정본**.
>
> **54차 ingest 변동 (2026-05-10)**: 9 항목 → **13 항목** 확장 (10. 8 추론 유형 정본 + 11. 난이도 위계 정본 + 12. 한국 임상 측정 단위 라이브러리 + 13. 한국 임상 자문 풀 매트릭스). 7 disorder clinical 페이지의 본문 보강 결과 통합.

## F15 위치 — 임상 영감 vs 진단 회피의 경계

### F15 명세 요약 (현 SRS V06)

| 항목 | 명세 |
|---|---|
| **Epic** | F15 LLM 대화형 발화 유도 챗봇 |
| **REQ-FUNC** | 039~040 |
| **기술** | Vercel AI SDK `useChat()` + Gemini Pro 1.5 (D6 pgvector 미사용 = 단일턴 컨텍스트) |
| **목적** | 자연 발화 데이터 무자각 수집 |
| **임상 영감** | [[clinical/entities/KOPLAC]] § 화용언어능력 평가 (의사소통 의도 / 담화 관리 / 상황 맥락) |

### ⚠️ 임상 영역 회피 경계 (ADR-04 정합)

```
KOPLAC 임상 영역                F15 디지털 변형 (MVP 영역)
================                ================
화용 결손 진단                  → 회피 (ADR-04 의료 용어 배제)
ASD 화용 결손 평가              → 회피 ([[clinical/concepts/자폐-화용중재]] 회피)
임상가 직접 관찰                → "발화 유도 챗봇" 으로 단순화
표준화 절단점                   → 회피 (백분위·통계만)
공식 보고서                     → 회피 (의료 진단 결과 0건)
```

→ F15는 **"임상 평가 도구의 영감"**일 뿐, **"임상 평가 실행"이 아님**. KOPLAC = 임상가 도구, F15 = 자연 발화 수집·유도 도구.

## 9 임상 자문 체크리스트

### 1. 화용 영역 4축 매핑 검증

KOPLAC 표준 4 영역 → F15 챗봇 시나리오 매핑 적정성:

| KOPLAC 영역 | F15 챗봇 시나리오 (제안) | 임상 자문 검토 |
|---|---|---|
| **의사소통 의도** | "비누가 떨어졌어. 너는 어떻게 할래?" → 요청·도움 의도 발화 유도 | 자연 발화 vs 인위 유도의 임상적 동등성 검증 |
| **담화 관리** | "그 다음에 어떻게 됐어? 더 얘기해 줄래?" → 차례 지키기·이야기 확장 | 챗봇 응답 빈도 (5초 이상 침묵 시 개입 vs 30초 이상 침묵 시 개입) 임상 권고 |
| **상황 맥락** | 이미지 + 텍스트 멀티모달 ("이 사진에서 무슨 일이 일어나고 있어?") | 멀티모달 인지 부담 (영유아 만 2-3세) 임상 권고 |
| **관점 취하기** ⚠️ | (만 5세+ 영역) — Phase 1 도입 시점 결정 | **만 2-4세는 회피 영역** (인지 발달 미성숙) |

**자문 결정 항목**: 4 영역 모두 Phase 1 도입 vs 점진 도입.

### 2. 연령별 적응 가능성 검증

| 연령 | KOPLAC 적용 여부 | F15 챗봇 적용 임상 권고 |
|---|---|---|
| 만 2-3세 | KOPLAC 미적용 (3세 미만) | ⚠️ **F15 도입 신중** — 발화 길이 짧음 + 멀티모달 부담 |
| 만 4-5세 | KOPLAC 시작 연령 | ✅ F15 핵심 영역 (의사소통 의도 + 담화 관리) |
| 만 6-7세 | KOPLAC 표준 영역 | ✅ F15 + 관점 취하기 추가 |

**자문 결정 항목**: F15 활성화 연령 하한 결정 (만 3세? 만 4세?).

### 3. ADR-04 의료 용어 배제 정합 검증

F15 시스템 메시지·UI 카피에서 다음 단어 자동 차단 검증:

| 차단 대상 | F15 대체 표현 |
|---|---|
| 진단 / 검사 / 평가 | "발화 놀이" / "이야기 시간" |
| 화용 / 의사소통 의도 | "친구와 대화" / "재미있는 이야기" |
| 결손 / 지연 / 장애 | (사용 안 함) |
| ASD / 자폐 / 발달장애 | (사용 안 함) |

**자문 결정 항목**: 임상가가 F15 시스템 프롬프트 직접 검토 → 의료 뉘앙스 0건 인증.

### 4. 자연 발화 vs 인위 유도 — 임상 동등성

KOPLAC 임상 원칙: "자연 발화 관찰 + 표준 자극 = 가장 정확". F15는 챗봇 인위 유도 = **부분 한계**:

| 측면 | KOPLAC (임상) | F15 (디지털) |
|---|---|---|
| 자극 일관성 | 표준화 자극 ✅ | LLM 응답 변동 ⚠️ (시드 고정 권고) |
| 자연 발화 | 임상가 비유도 관찰 ✅ | 챗봇 인위 유도 ⚠️ |
| 평가 신뢰도 | 표준화 절단점 ✅ | 통계만 (절단점 사용 금지) ✅ ADR-04 정합 |

**자문 결정 항목**: F15 챗봇 응답 시드 고정 (재현성) + 비유도 자연 발화 모드 (옵션) 추가 가능성.

### 5. 데이터 활용 — model_retraining_data 통합

F15 대화 로그가 [[product/concepts/HITL-retraining-pipeline]] 에 흘러갈 때:

| 단계 | 임상 자문 검토 |
|---|---|
| F15 대화 → 점수 산출 (linguistic 영역) | 임상 등가 연령 매핑 (REVT/PRES 정합) |
| HITL 큐 등록 (confidence < 70) | 화용 영역 보정 시 KOPLAC 절단점 참조 권고 |
| groundTruthScore 환류 | F15 발화 데이터의 모델 환류 적정성 (인위 유도 = ground truth로 적합한가?) |
| T4-a 동의 시 재학습 | 임상 데이터 동의 범위 확인 |

**자문 결정 항목**: F15 대화 로그가 model_retraining_data에 포함되는지, 별도 트랙으로 분리할지.

### 6. ASD 회피 경계 명확화

[[clinical/concepts/자폐-화용중재]] § MVP 회피 영역. F15는 ASD 진단·중재 회피하되 **ASD 경계선 가구 (황보름 페르소나)** 부분 영역 노출:

| 시나리오 | 임상 자문 결정 |
|---|---|
| F15 사용자가 ASD 의심 발화 패턴 (반향어·운율 평탄·비표준 음운변동) | confidence 60% 강제 게이트 → HITL 우선 큐 + 임상 권고 ([[product/entities/persona-황보름]] 정합) |
| F15 결과가 화용 결손 의심 | "발달이 또래보다 N% 느린 영역이 있어요. 전문가 상담 권장" 표현 (ADR-04 정합) |
| 부모가 ASD 직접 질문 | 챗봇 자동 응답 차단 → "전문가 임상 상담만 가능합니다" |

**자문 결정 항목**: ASD 의심 발화 패턴 자동 감지 알고리즘 정합성 (false positive 위험).

### 7. 부모 코칭 통합 가능성

F15 = 자녀 발화 유도. 부모 코칭 ([[clinical/concepts/아동언어치료-핵심기법]] § 4기법 = 평행 발화·확장·기다리기·반응적 상호작용) 와 통합 가능:

| 4기법 | F15 통합 시나리오 |
|---|---|
| **평행 발화** | F15 챗봇이 "엄마/아빠도 말해보세요" 유도 후 부모 발화 수집 |
| **확장** | 자녀 발화 → 챗봇이 "1단어 더 길게 해보면 어때?" |
| **기다리기** | 5초 침묵 후 챗봇 자동 개입 vs 30초 임상 권고 |
| **반응적 상호작용** | 자녀 흥미 따라가는 토픽 자동 전환 (Gemini context) |

**자문 결정 항목**: F15 부모 코칭 모드 통합 vs F11 (부모 음성 클로닝) + F15 분리.

### 8. F15 안전 제한 (가드레일)

| 위험 시나리오 | 가드레일 |
|---|---|
| 부모 vs 자녀 식별 부족 → 음성 보호 미달 | F15 시작 시 "자녀 단독 모드" 강제 (B2B Zero-touch와 동등) |
| LLM 환각 → 부정확 발화 모델 제공 | Gemini 응답 의료 용어 검열 + 시드 고정 |
| 챗봇 의존 → 자연 양육 상호작용 감소 | 일 사용 시간 제한 (≤15분/일 권고) |
| F15 결과를 임상 진단으로 오해 | 결과 페이지 Disclaimer 강제 + "임상 평가는 전문가에게" 명시 |

**자문 결정 항목**: 가드레일 기준 임상 권고 (시간 제한·의료 용어 검열 임계 등).

### 9. KOPLAC 표준 도구의 디지털 윤리

KOPLAC = 한국 표준화 검사. 본 도구의 임상 영감을 차용하되 **출처·저작권 검증**:

| 항목 | 검토 |
|---|---|
| KOPLAC 저작권 | 한국언어재활사협회 또는 출판사 (정확한 출처 확인 필요) |
| F15 챗봇이 KOPLAC 자극 직접 사용 | ❌ 금지 (저작권 침해 + ADR-04 위반) |
| F15 챗봇이 KOPLAC 4 영역 영감 차용 | ✅ 가능 (임상 원리 ≠ 표준화 자극) |
| F15 결과를 KOPLAC 등가 점수로 표현 | ❌ 금지 (표준화 절단점 사용 = DTx 영역) |

**자문 결정 항목**: KOPLAC 출처 명시 + 직접 자극 비복제 인증.

### 10. F15 시나리오 8 추론 유형 정본 ⭐⭐ (54차 ingest 통합)

[[clinical/concepts/내러티브-담화-추론-중재]] § D 박후임 (2008) 17차시 추론 활동 프로그램 직접 매핑:

| # | 추론 유형 | F15 챗봇 시나리오 예시 발화 | 임상 자문 검토 |
|---|---|---|---|
| 1 | **제목 → 내용** | "오늘 그림 보고 어떤 이야기일까?" | 만 4세+ 활성 적정 |
| 2 | **인물 말·행동 → 성격** | "이 아이는 어떤 친구일까?" | 만 5세+ |
| 3 | **인물 감정 상태** | "지금 어떤 기분일 것 같아?" | ⚠️ 감정 추론 = ASD 핵심 결함 ([[clinical/concepts/자폐-화용중재]] § D-10 최숲 2007 PDD 감정 추론 결함) — **활성 신중** |
| 4 | **이어질 내용** | "다음에 무슨 일이 일어날까?" | 만 4세+ 활성 적정 |
| 5 | **생략된 내용** | "그림 사이에 빠진 부분은?" | 만 6세+ |
| 6 | **원인-결과** | "왜 그랬을까? / 그래서 어떻게 됐을까?" | 만 5세+ |
| 7 | **배경 추론** | "여기 어디일까? 언제 일어난 일?" | 만 5세+ |
| 8 | **주제 추론** | "이야기에서 알게 된 것은?" | 만 6-7세+ |

→ ADR-04 정합: UI 표현은 "치료" X, "이야기 만들기 / 같이 보기"

**자문 결정 항목**: 8 유형 중 만 4세+ 활성 4 유형 (1·4·6·7) vs 만 5-7세 활성 4 유형 (2·5·8 + 신중한 3) 분리.

### 11. F15 난이도 위계 정본 (3 출전 통합) ⭐⭐

[[clinical/concepts/내러티브-담화-추론-중재]] § A 김혜정 (2010) + [[clinical/concepts/학습장애-언어재활]] § B 유경진 (2017) + [[clinical/concepts/자폐-화용중재]] § D-10 최숲 (2007) 통합:

```
[Level 1: 명시적 + 사실적 정보 이해]   → 텍스트에 답이 명시 (이해 질문 위주)
   대상: 만 4세+
        ↓
[Level 2: 암시적 + 응집성 추론 / 예측 추론]   → 단서 통합 (근접 추론)
   대상: 만 5-6세
        ↓
[Level 3: 함축적 + 정교 추론 / 배경지식 추론]   → 배경지식·마음이론 동원 (원접 추론)
   대상: 만 6-7세
        ↓
⛔ 회피: 평가적 추론 (학령기 영역) + 감정 추론 (PDD 위험 영역, ADR-14 만 4세+)
```

→ **F3-b 적응형 난이도 엔진** 직접 임상 토대 ([[product/concepts/MVP-feature-spec]] § F3-b).

**자문 결정 항목**: Phase 1 도입 시 Level 1만 vs Level 1+2 vs Level 1-3 전체 결정.

### 12. 한국 임상 측정 단위 통합 라이브러리 ⭐ (54차 ingest 통합)

54차 ingest 누적 7 disorder 페이지 정독으로 식별된 **한국 학령기·영유아 임상 측정 단위**:

| 단위 / 도구 | 영역 | 출전 페이지 | F1-a/F4 적용 |
|---|---|---|---|
| **C-unit + MLC-w + MNC** | 발화 분석 (대화·설명) | [[clinical/concepts/단순언어장애-SLI]] § B (이현정 2008) | F1-a linguistic 보강 |
| **T-unit + MLT-w + NDW** | 쓰기 분석 | [[clinical/concepts/지적장애-언어중재]] § I (박수진 2019) | (학령기 영역, MVP 회피) |
| **CIU (Correct Information Unit)** | 이야기 정보 분석 | [[clinical/concepts/자폐-화용중재]] § D-8 (김소망 2017) | F1-a 자연 발화 정보 측정 후보 |
| **이야기문법 5 + 결속표지 5** | 서사담화 분석 | [[clinical/concepts/내러티브-담화-추론-중재]] § C (김현진 2021) | F4 진전도 측정 후보 |
| **내포문 5 유형 사용률** | 구문 산출 | [[clinical/concepts/지적장애-언어중재]] § B (한수진 2011) | F1-a linguistic 영역 |
| **추론 4 유형 + 오류 4 유형** | 추론 능력 | [[clinical/concepts/학습장애-언어재활]] § B (유경진 2017) | F15 시나리오 위계 + 비계 패턴 |
