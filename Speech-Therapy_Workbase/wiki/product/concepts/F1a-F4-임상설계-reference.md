# F1-a / F4 원본 기능 임상 설계 reference — 기초학습 구인 기반

> ## ⚠️ 저작권·사용 경계 (반드시 먼저 읽기)
> 본 페이지는 [[clinical/concepts/NISE-B-ACT-학습장애검사]]의 **구조·구인·채점 *방식*** (= 사실·방법론, 저작권 보호 대상 아님)을 근거로 **당신 앱의 *원본* 기능을 설계**하기 위한 reference다. 아래 3선은 **앱에서 넘지 않는다**:
> 1. ❌ NISE-B·ACT의 **문항·지문·자극·정답을 복사**(또는 미세 변형 후 사용) — 저작물 복제
> 2. ❌ 앱을 **"NISE-B·ACT"라 칭하거나 그 규준(norms)·타당도를 주장** — 명칭·규준은 국립특수교육원 귀속
> 3. ❌ 앱이 NISE-B·ACT를 **시행·복제하는 진단 도구**라 표시 — 자격자 시행 + 비의료 카테고리([[product/concepts/architecture-decisions]] § ADR-04) 위배
>
> ✅ **허용**: 측정하려는 **임상 구인**(예: 음운 인식, 해독, RAN — 이는 NISE-B 소유가 아닌 분야 표준 지식. [[clinical/entities/Scarborough]]·[[clinical/concepts/학습장애-언어재활]])을 근거로 **자체 문항·자극·콘텐츠를 직접 제작**하고 자체 척도로 채점. 이는 본 프로젝트 기존 결정과 정합: NISE-B·ACT = "MVP 부분 **영감**(만 5-7세 음운인식·해독), 자극 직접 사용 X".
>
> 📌 NISE-B·ACT 자체(문항·규준·이름)를 앱에 쓰려면 → **국립특수교육원 라이선스/허가 + 법률 검토 필요** (상업적 사용). 본 reference는 그것을 대체하지 않는다.

## 목적

표본을 넘어 **전수 구조 + 채점 척도**를 정리하여(개정안 2025 기준), 앱의 F1-a(3축 음성 분석)·F4(음소 핀셋 분석)·F15(발화 유도 챗봇)가 측정·설계할 **구인과 위계**를 임상 근거 위에 올린다. **출력물은 "원본 기능 설계 지침"이지, 복붙용 검사 콘텐츠가 아니다.**

## 1. NISE-B·ACT 전수 구조 + 채점 척도 (개정안 2025 — 구조 사실)

> 출처: [[clinical/sources/2026-06-07-NISE-BACT-개정연구보고서-2-4년차]] (raw 보고서 요약). 채점 척도 = 보고서 §실시방법.

### 읽기 검사 (5 소검사 · 채점 **0/1**, RAN·유창성은 시간/개수)

| 소검사 | 측정 구인 (분야 표준) | 과제 유형 (일반 명칭) |
|---|---|---|
| **음운과 음절** | 음운·음절 인식, 음운 인출 자동화 | 음절 합성·탈락·변별·대치, 음소 변별, [[clinical/entities/RAN-빠른자동이름대기]](사물/색깔, 1분) |
| **글자·단어 인지** | 자소-음소 대응·해독 | 글자 인지, 단어 인지(규칙/불규칙, 의미/무의미) |
| **유창성** | 자동화된 음독(속도·정확·표현) | 이야기글·설명글 — 1분간 정확히 읽은 음절 수 |
| **어휘** | 양적·질적 어휘 | 단어 이해, 반대말, 비슷한 말, 유추, 빈칸 채우기 |
| **읽기 이해** | 문장·담화 이해·추론 | 문장·짧은글·중간글·긴글 — 사실·추론·비판·평가적 이해 |

### 쓰기 검사 (3 소검사 · 채점 **0/1/2** = 정확/부분/오답)

| 소검사 | 측정 구인 | 과제 유형 |
|---|---|---|
| **글씨쓰기** | 쓰기 준비도·운필 | 글씨쓰기 기초(선 따라 그리기·글자 모양 찾기·자모 지식·낱말 만들기) + 바르게 쓰기(모양·비율·띄어쓰기) |
| **맞춤법** (←철자하기) | 표기 처리·단기기억 | 받아쓰기 + 철자 지식(고쳐쓰기·혼동 단어) + 보고 기억해서 쓰기 |
| **글쓰기** | 작문(양적+질적) | 글쓰기 지식(어순·접속사·호응) + 기초 글쓰기(문맥 단어·쓰기 유창성·단락) + 긴 글쓰기(개요·문단, 구상시간 포함) |

### 수학 검사 (4 소검사 · 채점 **0/1**, 문항당 1-2분)

| 소검사 | 4 수준 위계 |
|---|---|
| **초기 수학**(신규) / **수와 연산** / **도형과 측정** / **수학적 탐구** | 기초적 이해 → 기능적 수행 → 개념적 이해 → 응용과 추론 |

> ⚠️ 2017 원판 책자는 읽기에도 0/1/2를 쓰는 문항이 있었으나, **개정안(2025)은 읽기 0/1·쓰기 0/1/2·수학 0/1**로 정리됨([[clinical/sources/2026-06-07-NISE-BACT-읽기-쓰기-검사방법]] = 원판).

## 2. 구인별 → 앱 원본 기능 설계 가이드 (MVP 핵심·영감 영역)

> 각 항목: **구인**(왜 측정) → **자체 콘텐츠 제작 지침**(어떻게 *원본*으로 만들지) → **자체 채점 척도** → **앱 기능 매핑**. 문항 자극은 전부 자체 제작.

### A. 음운 인식 → F1-a linguistic + F4
- **구인**: 음절/음소 합성·분절·변별·대치 능력 = 읽기 발달의 핵심 선행 지표(분야 표준, [[clinical/concepts/학습장애-언어재활]] 음운인식↔읽기).
- **자체 제작 지침**: 한국어 **고빈도 2-3음절 단어 풀을 자체 구축** → 합성(분절음 듣고 단어 만들기)·탈락(특정 음절 빼기)·대치(음절 바꾸기) 미니게임을 **직접 설계**. NISE-B 단어 목록·순서 미사용.
- **자체 채점**: 정/오 0/1 (분야 표준 방식). 자기교정(SC) 3초 내 허용 옵션.
- **앱 매핑**: F1-a 음소 단위 STT 분석의 사용자 사전 과제 / F4 음소 핀셋 그래프의 '음운인식' 축.

### B. 해독(자소-음소 대응) → F1-a articulation
- **구인**: 규칙/불규칙·의미/무의미 단어를 정확히 소리내어 읽기 = 한글 음운변동 처리([[clinical/entities/U-TAP]] § 음운변동, [[clinical/concepts/조음장애]]).
- **자체 제작 지침**: **자체 무의미 음절/단어 생성기**로 음운 처리 검증(통째 암기 배제). 어두/어중/어말 위치별 자체 자극.
- **자체 채점**: 정/오 0/1 + 실제 오반응 기록(기능적 기록 — 중재용).
- **앱 매핑**: F1-a articulation 3축 점수, 음운변동 오류 분류([[product/concepts/HITL-system-flow]] groundTruthScore).

### C. 읽기 유창성·자동화(RAN) → F1-a acoustic
- **구인**: 정확·속도·자동화 / RAN = 음운 인출 자동화(난독 예측, 이중결손 가설 [[clinical/entities/RAN-빠른자동이름대기]]).
- **자체 제작 지침**: **자체 이야기글/설명글 작성**(추천 도서 직접 인용 X) → 1분 읽기. RAN은 **자체 사물·색깔 배열판**(NISE 보드판 미복제).
- **자체 채점**: 1분 정확 음절 수 / RAN 완료 시간(시간·개수 기반).
- **앱 매핑**: F1-a acoustic(말 산출 속도·자동화) 부분 영감.

### D. 추론·담화 → F15 발화 유도 챗봇
- **구인**: 사실·추론·비판·평가적 이해 4수준([[clinical/concepts/내러티브-담화-추론-중재]]).
- **자체 제작 지침**: **자체 짧은 시나리오** 기반 추론 질문을 챗봇 prompt로 생성. NISE 지문 미사용.
- **앱 매핑**: F15 챗봇 추론 시나리오 위계.
