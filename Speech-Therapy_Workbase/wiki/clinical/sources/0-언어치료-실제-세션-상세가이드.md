# 언어치료 실제 세션 상세 가이드 — 요약

> **한 줄 요약.** 한국에서 실제로 이루어지는 언어치료를 두 트랙(병원 기반 성인/청각 재활 vs 사설 센터·복지관 기반 아동 발달)으로 나누고, 트랙별 세션 단계·활동·평가 도구·치료 기법·비용 구조를 종합적으로 기술한 가이드.

## 다루는 범위

### 트랙 1: 병원 기반 성인 언어재활
- **1-A. 실어증(Aphasia)** — 의뢰 → 평가([[clinical/entities/K-WAB]], [[clinical/entities/K-BNT]]) → 30~40분 세션 (도입/본활동/마무리). 본활동: 이름대기, 따라말하기(MIT 포함), 읽기(ORLA), 쓰기(CART). → [[clinical/concepts/실어증]]
- **1-B. 마비말장애(Dysarthria)** — 호흡·발성·공명·조음·운율 5개 하위체계 단계적 훈련. → [[clinical/concepts/마비말장애]]
- **1-C. 인공와우 청능재활** — 매핑 → 청능훈련 4단계 위계(감지·변별·확인·이해) → 부모 코칭(청각 우선·음향 강조). → [[clinical/concepts/인공와우-청능재활]]

### 트랙 2: 사설 센터/복지관 기반 아동 발달
- **2-A. 일반 절차** — 초기 상담/평가([[clinical/entities/SELSI]], [[clinical/entities/PRES]], [[clinical/entities/REVT]], [[clinical/entities/U-TAP]], [[clinical/entities/KOPLAC]]) → 치료 계획 → 40~50분 치료 + 5~10분 부모 상담 → 3~6개월 재평가.
- **2-B. 조음장애** — 보물찾기/요리놀이/입모양 퀴즈, 단독 음소→음절→단어→구→문장→대화 위계. → [[clinical/concepts/조음장애]]
- **2-C. 언어발달지연** — 어휘 확장(범주 분류·역할 놀이·그림책), 문장 구성(징검다리·환경 조작·사진 보고 말하기). → [[clinical/concepts/언어발달지연]]
- **2-D. ASD 화용·사회적 의사소통** — 의사소통 의도 확장(방해물·부분 제공·선택하기, [[clinical/entities/PECS]] 활용), 차례 지키기, 역할연기, 관심공유. → [[clinical/concepts/자폐-화용중재]]

## 핵심 시사점

1. **트랙별 세션 시간 구조의 차이.** 트랙 1은 30~40분 1:1 구조화. 트랙 2는 40~50분 치료 + 5~10분 부모 상담이 표준. → [[clinical/concepts/한국-언어치료-트랙비교]]
2. **부모 상담은 트랙 2의 명문화된 구성 요소.** 매 세션 직후 5~10분 부모 코칭이 치료의 일부로 정착. 가정 연계 과제 부여가 일반적.
3. **위계 기반 훈련이 도메인 공통 원리.** 이름대기 단서 위계(의미적→시각적→음소적→따라말하기), 청능훈련 4단계(감지→변별→확인→이해), 조음 6위계(단음→대화) 등 거의 모든 활동이 단계적 위계로 구조화됨.
4. **평가 도구의 표준화.** 8개 한국형 표준화 검사가 진단·재평가의 근거.
5. **비용/제도의 이원화.** 병원은 건강보험 급여, 사설 센터는 비급여(회당 3~6만 원) + 발달재활서비스 바우처(만 18세 미만, 중위소득 180% 이하).

## 치료사 핵심 기법 (아동)

세션 활동을 관통하는 4개 기법: **평행 발화 / 확장(Expansion) / 기다리기 / 반응적 상호작용**. → [[clinical/concepts/아동언어치료-핵심기법]]

## 한계와 보강 포인트

- 본 가이드는 "공개된 의료·교육 자료 종합"으로 작성됨. 1차 임상 연구·표준 진료 지침과의 일치 여부는 향후 임상 sources ingest로 보강.
- 실어증·마비말장애 외 다른 신경언어장애(예: 말실행증 AOS, 우반구 손상 의사소통장애)는 다루지 않음.
- 인공와우 매핑·하드웨어 절차는 표면 수준만 기술됨.
- MIT(멜로디 억양 치료) / ORLA(소리 내어 읽기) / CART(그림-기억 쓰기 기법) 등 실어증 치료 기법의 원전·근거 수준은 별도 자료로 보강 필요.
