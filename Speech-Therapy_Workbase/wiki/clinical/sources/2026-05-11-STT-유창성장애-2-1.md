# STT 유창성장애(2-1) — 45분 강의 정본

`faster-whisper base` STT 변환 — (2-1) = 청각장애 1교시 마무리 + 유창성 본격 시작. 152 segment.

## 한 줄 요약
유창성 정의 4 요소 + WHO 말더듬 정의 (행동·정서·인지) + 빙산 모델 정본 + 정상 vs 병리 단위별 결정 규칙.

## 핵심 내용

| 영역 | 핵심 |
|---|---|
| **유창성 4 요소** | 지속성·말 속도·노력·리듬 |
| **WHO 말더듬 정의** | 어순적으로 알고 있지만 **불수의 반복·연장·멈춤** |
| **말더듬 3 요소** | 행동·정서·인지 (빙산 모델 ⭐) |
| **빙산 모델** | 위 = 행동 (반복·연장·멈춤) / 아래 = 정서·인지 (불안·자화상) |
| **정상 vs 병리 단위** | 다음절 단어 전체 반복 = 정상 / 단어 부분·일음절 = 병리 |
