## DLD 단계적 중재 체계 (자료 6 통합)

### 3 단계 발달 가이드

```
[제1단계: 어휘 확장 + 수용 언어 증진]
  - 의미적 매핑 (Semantic mapping): 사물 ↔ 기호 자의적 연결
  - 0-11개월 영아: 옹알이 → 단어 인지
  - 무발화·심각 지연 (2-3세 조기 식별)
    → 발음 완벽보다 발화 의도 수용·강화 우선
    → 조기 식별 시 2년 이내 눈에 띄는 개선 가능
        ↓
[제2단계: 단어 결합 + 구문론적 문장]
  - 50단어 표현 어휘 확보 후 두 단어 결합
  - 명사+동사 / 형용사+명사
  - 작업 기억 능력 향상 ("공 주고 컵 가져와")
        ↓
[제3단계: 화용론적 응용 + 담화 능력]
  - EMT (Enhanced Milieu Teaching) 환경 중심 언어중재
  - 환경 조작 (Environment arrangement): 흥미 사물 손 닿지 않는 곳에
  - 반응 요구하기 (Mand-model)
  - SLI + 공동주의 결함 아동 통합 중재
```

### 4 핵심 기법 (모든 단계 공통)

| 기법 | 정의 | 부모 코칭 적용 |
|---|---|---|
| **평행 발화** (Parallel Talk) | 아이의 행동·관심사를 아이 시각에서 언어로 표현 | "공 잡았네 / 공 던지자" |
| **확장** (Expansion) | 아이의 짧은 발화를 문법적으로 완성 | 아이 "맘마" → 부모 "맛있는 맘마 먹자" |
| **기다리기** (Wait Time) | 아이의 발화 시도를 위한 5-10초 침묵 | 질문 후 즉답 X, 5-10초 기다림 |
| **반응적 상호작용** (Responsive Interaction) | 아이의 흥미 따라가는 토픽 전환 | 아이가 자동차 흥미 → 부모도 자동차 토픽 |

→ **F11 윤리 화이트리스트 (ADR-09) 임상 근거**: 4 핵심기법 모두 부모-아이 자연 상호작용 → 음성 클로닝 = 일방향 동화만 ALLOWED. 교정 콘텐츠 = 4 핵심기법 위배 (가족 ≠ 치료자) → 강제 차단.

## NISE-B·ACT (자료 7) — 신규 영역, MVP 부분 중첩

> ⚠️ **2026-06-07 갱신** — 본 § 구조 요약(읽기 I/II·쓰기·수학 평면)은 텍스트 요약본 기준이며 **2017 원판**에 해당. 실물 검사도구·2025 개정안(음운처리→음운과 음절, 철자하기→맞춤법, 수학 4영역 재편) 정본은 [[clinical/concepts/NISE-B-ACT-학습장애검사]] + [[clinical/sources/2026-06-07-NISE-BACT-읽기-쓰기-검사방법]] + [[clinical/sources/2026-06-07-NISE-BACT-개정연구보고서-2-4년차]] 참조.

| 항목 | 내용 |
|---|---|
| **풀이** | National Institute of Special Education Basic Academic Competence Test |
| **개발** | 국립특수교육원 |
| **목적** | **읽기·쓰기·수학 도구적 기술 (Tool Skills) 정밀 진단** — 학습장애 (Learning Disability) 평가 |
| **적용 연령** | 만 5세+ 학령전 ~ 학령기 (정확히 만 5세-만 14세 추정) |
| **하위 영역** | 읽기 I (해독·유창성) + 읽기 II (이해) + 쓰기 + 수학 |
| **점수 체계** | 원점수 → **연령 규준** + **학년 규준** (이중) |
| **온라인 채점** | nise-test.com 플랫폼 + 자동 진단 보고서 |

### MVP 위치

- ⚠️ **MVP 영유아 만 2-7세와 부분 중첩 (만 5-7세)** — 핵심 회피 영역은 아니지만 본 위키의 영유아 핵심 타깃 외 영역
- [[clinical/concepts/한국-언어치료-트랙비교]] § 트랙 1·2 외 **트랙 3 (학습장애·특수교육)** 으로 신규 분류 가능
- **MVP 회피 영역**: NISE-B는 학교·특수교육 영역이지 가정 홈케어 X. ADR-04 (의료 용어 배제) 정합 — "학습장애 진단" 단어 회피.

→ 본 위키에서 NISE-B는 **"MVP 회피 영역 + 부분 영감"** 으로 처리: 만 5-7세 음운인식·해독 영역만 F1-a articulation에 부분 영감 (특히 "음소 단위 정밀 분석" 매핑).

## Product Cross-link 대규모 매핑

### F1-a 3축 AI 음성 분석 엔진 (REQ-FUNC-001~007)

| 3축 | 임상 표준 도구 |
|---|---|
| **articulation** ⭐⭐ | **U-TAP/U-TAP2** (음운변동 + 자음정확도 PCC + 한국어 자음 발달 순서) |
| **linguistic** | SELSI (양육자 보고식) + PRES (수용/표현) + REVT (어휘 R/E 분리) |
| **acoustic** | (임상 표준 도구 없음 — 기술 영역 / NISE-B § 음운인식 부분 영감) |

→ **F1-a 3축 AI는 한국 표준 4 도구 통합 디지털 변형**. ADR-04에 따라 UI 표현은 "스크리닝/백분위/놀이"만.

### F1-b 5분 진단 웹뷰 (REQ-FUNC-008~011)

- SELSI **양육자 보고식** = F1-b 무로그인 입력 폼의 임상 토대 (60-90분 SELSI → 5분 간이)
- PRES 시작점·기저선 → F1-b 입력 ≤3 항목 정합 (효율적 측정)

### F11 부모 음성 클로닝 동화 (REQ-FUNC-036~037, ADR-09)

- ⭐ **4 핵심기법 임상 근거 = ADR-09 윤리 화이트리스트 강화**:
  - 평행 발화·확장·기다리기·반응적 상호작용 = 모두 부모-아이 **자연 상호작용**
  - 음성 클로닝으로 **교정 훈련** 적용 시 4 기법 위배 (가족 ≠ 치료자 임상 원칙)
  - ALLOWED_CONTENT_TYPES (storybook, lullaby) = 4 기법과 정합 (일방향 콘텐츠만)

### F15 LLM 챗봇 (REQ-FUNC-039~040)

- ⭐ **EMT (환경 중심 언어중재) 영감**:
  - 환경 조작 → 챗봇 시나리오 (흥미 사물 가상 배치)
  - 반응 요구하기 (Mand-model) → 챗봇 발화 유도
  - DLD 3단계 § 화용 담화 = F15 만 4세+ 활성 (ADR-14) 정합

### F3-a 숏폼 미션 + F3-b 적응형 난이도 (REQ-FUNC-015~023)

- DLD 3단계 (어휘 → 문장 결합 → 화용) → 적응형 난이도 단계화
- U-TAP 음운변동률 PCC → F3-b 난이도 자동 조정 (PCC 65% 미만 = 하향 / 80%+ = 상향)
