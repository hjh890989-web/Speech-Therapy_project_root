# S003 — 11주 학습장애 언어재활 게시 (음운인식·읽기 중재)

> 학습장애 아동의 음운인식 발달과 자소-음소 대응, 음운규칙을 위계적으로 지도하는 읽기 중재 강의자료(29쪽).

> ✅ **원문 정독 검증 완료(2026-06-09)**: 추출 전문(`.ingest/txt/S003`) 대조 — 음절분절 4세 50%/5세 80%·음소 5세후반 50%(김영태 2006)·홍성인 2001 위계(단어 50→99·음절 34→96·음소 8→51)·음운규칙 지도순서(7종성→연음화→경음화→ㅎ탈락) 전부 원문 일치.

## 핵심 내용

- **음운인식 발달 위계**: 운율 → 단어 → 음절 → 음소 (큰 단위 → 작은 단위). 과제 난이도 = 수세기 → 변별 → 합성 → 탈락 → 대치.
- **연령 규준**(이차숙 1999·김영태 2006 인용): 음절 분절 4세 ≈ 50% → 5세 ≈ 80%; 음소 분절 5세 후반 ≈ 50%.
- **읽기 지도 확장**: 자소-음소 일치형 낱말 완성 후 → 불일치형(음운규칙 적용). 단어 → 낱말+조사 → 어근+어미 → 어절 → 문장 → 문단으로 맥락 확장.
- **음운규칙 지도 순서**: 7종성 규칙 → 연음화 → 경음화 → ㅎ탈락.
- **활동 기반 중재**: 노래·음악(음절 수 표현·라임 개사), 게임(음절 박수·음소 동전·끝소리 깃발), 동시(라임 동요).

## 시사점 (앱)

- **CL-08 음운인식 게임**: 게임 위계 = 음절 합성 → 탈락 → 대치 → 음소 변별. 만 5세 음소 과제 50% 정상.
- **CL-09 해독 게임 / F4 음운변동**: 일치형 → 불일치형 위계, 음운규칙 지도 순서 차용.
