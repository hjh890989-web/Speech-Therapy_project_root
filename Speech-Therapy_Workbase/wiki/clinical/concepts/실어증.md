# 실어증 (Aphasia)

뇌졸중·뇌손상 등으로 언어 기능이 손상된 성인 환자에게서 나타나는 후천적 의사소통 장애. 한국에서는 재활의학과 전문의의 의뢰 하에 병원 언어치료실에서 다뤄지며, 건강보험 급여 적용이 가능하다.

## 평가
- [[clinical/entities/K-WAB]] (한국판 웨스턴 실어증 검사) — 유무·유형·중증도 판별의 표준
- [[clinical/entities/K-BNT]] (한국판 보스턴 이름대기 검사)
- 실어증 선별검사
- 평가 시간 약 60~90분, 말·언어 이해력 / 표현력 / 따라말하기 / 읽기·쓰기 종합

## 치료 목표 설정
- **장기 목표** (예: 일상 대화 수준의 의사소통 회복)
- **단기 목표** (예: 고빈도 명사 20개 이름대기)
- 환자의 직업·가정·관심사를 반영한 **기능적 목표** 우선

## 정기 세션 (30~40분, 주 2~5회)

| 단계 | 시간 | 내용 |
|---|---|---|
| 도입 | 5분 | 인사·컨디션 확인, 자유 대화 워밍업 |
| 본활동 | 20~30분 | 이름대기 / 따라말하기 / 읽기 / 쓰기 |
| 마무리 | 5분 | 활동 정리, 보호자/간병인에게 가정 연습 안내 |

### 이름대기(Naming) 훈련
- **직면 이름대기**: 사물·그림카드를 보고 이름 산출
- **반응 이름대기**: 기능 설명으로 단어 유도 ("머리를 빗을 때 쓰는 것은?")
- **단계적 단서 위계** (못 떠올릴 경우):
  1. 의미적 단서 ("부엌에서 쓰는 거예요")
  2. 시각적 단서 (첫 글자, 입 모양)
  3. 음소적 단서 (첫 음절: "사~")
  4. 치료사가 말하고 환자가 따라말하기

### 따라말하기(Repetition) 훈련
- 단어(고빈도 1~2음절 명사) → 구·문장 → **MIT(멜로디 억양 치료)**: 노래하듯 리듬을 넣어 말하기 → 역할극

### 읽기(Reading) 훈련
- 그림-글자 짝짓기 → **ORLA(소리 내어 읽기)**: 치료사와 리듬에 맞춰 함께 읽기 → 지시문 수행 → 내용 이해

### 쓰기(Writing) 훈련
- 따라 쓰기 → 빈칸 채우기 → **CART**: 그림 보고 이름 쓰기 → 보지 않고 기억해 쓰기 → 기능적 쓰기(이름·주소·전화번호)
