# 실어증 (Aphasia)

뇌졸중·뇌손상 등으로 언어 기능이 손상된 성인 환자에게서 나타나는 후천적 의사소통 장애. 한국에서는 재활의학과 전문의의 의뢰 하에 병원 언어치료실에서 다뤄지며, 건강보험 급여 적용이 가능하다.

## 평가
- [[clinical/entities/K-WAB]] (한국판 웨스턴 실어증 검사) — 유무·유형·중증도 판별의 표준
- [[clinical/entities/K-BNT]] (한국판 보스턴 이름대기 검사)
- 실어증 선별검사
- 평가 시간 약 60~90분, 말·언어 이해력 / 표현력 / 따라말하기 / 읽기·쓰기 종합

## 치료 목표 설정
- **장기 목표** (예: 일상 대화 수준의 의사소통 회복)
- **단기 목표** (예: 고빈도 명사 20개 이름대기)
- 환자의 직업·가정·관심사를 반영한 **기능적 목표** 우선

## 정기 세션 (30~40분, 주 2~5회)

| 단계 | 시간 | 내용 |
|---|---|---|
| 도입 | 5분 | 인사·컨디션 확인, 자유 대화 워밍업 |
| 본활동 | 20~30분 | 이름대기 / 따라말하기 / 읽기 / 쓰기 |
| 마무리 | 5분 | 활동 정리, 보호자/간병인에게 가정 연습 안내 |

### 이름대기(Naming) 훈련
- **직면 이름대기**: 사물·그림카드를 보고 이름 산출
- **반응 이름대기**: 기능 설명으로 단어 유도 ("머리를 빗을 때 쓰는 것은?")
- **단계적 단서 위계** (못 떠올릴 경우):
  1. 의미적 단서 ("부엌에서 쓰는 거예요")
  2. 시각적 단서 (첫 글자, 입 모양)
  3. 음소적 단서 (첫 음절: "사~")
  4. 치료사가 말하고 환자가 따라말하기

### 따라말하기(Repetition) 훈련
- 단어(고빈도 1~2음절 명사) → 구·문장 → **MIT(멜로디 억양 치료)**: 노래하듯 리듬을 넣어 말하기 → 역할극

### 읽기(Reading) 훈련
- 그림-글자 짝짓기 → **ORLA(소리 내어 읽기)**: 치료사와 리듬에 맞춰 함께 읽기 → 지시문 수행 → 내용 이해

### 쓰기(Writing) 훈련
- 따라 쓰기 → 빈칸 채우기 → **CART**: 그림 보고 이름 쓰기 → 보지 않고 기억해 쓰기 → 기능적 쓰기(이름·주소·전화번호)

### B. 뇌 해부 — 좌반구 언어 영역 (본 STT) ⭐⭐

#### B-1. 핵심 3 영역

| 영역 | 위치 | 기능 |
|---|---|---|
| **브로카 영역** | 좌반구 전두엽 | 말 표현 (산출) 담당 |

→ ⭐ **궁상속 = "활꼴 다발" 또는 "궁형속"** — 시험 자주 출제 명칭

#### B-2. 좌·우 반구 연결

- **뇌량 (Corpus Callosum, 매량)** = 좌반구 ↔ 우반구 정보 전달 교량
- 좌반구 = 언어 (대다수 인구)
- 우반구 = 비언어 영역 → RHD = 신경 인지 의사소통장애

### C. 전도성 실어증 (Conduction Aphasia) ⭐ — 궁상속 손상 정의

본 STT 직접 인용:
> "**궁상속의 손상은 따라말하기 과제를 못하게 하는 그런 특징이 있어요... 베르니케와 브로카가 직접적으로 다친 게 아니기 때문에 각각의 이해력이나 표현력은 거의 양호한데 따라말하기가 유도가 안 되는 게 전도성 실어증이 되죠.**"

| 영역 | 전도성 실어증 |
|---|---|
| 이해력 (베르니케 양호) | ✅ 정상 |
| 표현력 (브로카 양호) | ✅ 정상 |
| **따라말하기** (궁상속 손상) | ❌ **결함** ⭐ |

→ ⭐ **임상 진단 핵심**: 이해 + 표현 양호 + 따라말하기 결함 = 전도성 실어증

### D. 뇌혈관 + 실어증 유발 부위 ⭐⭐ — 본 STT (book 잠재 cross)

본 STT 직접 인용:

#### D-1. 뇌혈관 위계

```
대동맥
   ↓
완도동맥
   ↓
[총경동맥 + 세골하동맥]

```

#### D-2. MCA vs ACA — 실어증 유발 핵심

| 동맥 | 영역 | 손상 시 |
|---|---|---|
| **중대뇌동맥 (MCA)** ⭐ | **베르니케 + 브로카 둘 다 공급** | **실어증 가장 잘 유발** (베르니케·브로카 실어증 모두 가능) |
| **전대뇌동맥 (ACA)** | 전두엽 앞쪽 + 일부 브로카 | 마비말장애 + 부분 브로카 실어증 |
| **후대뇌동맥** (PCA) | 후두엽 (시각·시각언어) | 시각 인지 결함 |

→ ⭐ **임상 결정 규칙**: "실어증 가장 잘 올 수 있는 손상은 = 중대뇌동맥" (시험 빈출)

### G. 신경언어장애 원인 — 뇌졸중·외상성 뇌손상 (TBI) ⭐⭐

본 STT 강의 정본 (한국 자격시험 출제 핵심):

> "실어증의 원인이 될 수 있는 건 이렇게 뇌졸중이나 이제 외상성 뇌 손상이 있다."

#### G.1 뇌졸중 (Stroke) 2 분류

| 유형 | 정의 | 위치별 |
|---|---|---|
| **출혈 (Hemorrhage)** | 혈관이 **터지는** 것 | 뇌출혈 (intracerebral) vs 뇌외 출혈 (subarachnoid) |
| **경색 (Infarction)** | 혈관이 **막히는** 것 | (위치 X, 원인별 분류) |

#### G.2 경색 원인 2 종 ⭐

| 원인 | 정의 |
|---|---|
| **혈전증 (Thrombosis)** | 혈관 자체에서 침전물이 점점 쌓여 막힘 — "원래 그 자리에서 쌓이고 있는 것" |
| **색전증 (Embolism)** | 어딘가에서 생성된 혈전이 떨어져 떠돌다가 좁아진 혈관 막힘 |

> "혈전은 그 자리에서 계속 쌓고 있던 거고, 색전은 지나가다가 막히는 거."

#### G.3 동맥류 (Aneurysm)

→ 부풀어 있다가 터짐 → **출혈의 원인** (뇌혈관 약점 부위 풍선 모양 확장).

#### G.4 TIA (일과성 허혈 발작, Transient Ischemic Attack) ⭐

> "특히 색전인 경우에 나타나기 쉽다. 일시적으로 혈관 막혀서 뇌경색 증상 발생 → 하루 안에 증상 사라지는 것."

→ ⭐ **임상 경고**: TIA = 본격 뇌경색 위험신호 → 증상 사라져도 빠르게 병원 방문 필요.

#### G.5 외상성 뇌 손상 (TBI, Traumatic Brain Injury)

> "외상성 뇌 손상은 바깥에서 뇌를 다친 경우. 뇌출혈이나 뇌경색과 다르게."

→ ⭐ **두 가지 유형 (상세):**
- **개방성 TBI** — 두개골 관통 (총상·외상)
- **폐쇄성 TBI** — 두개골 손상 없이 뇌 흔들림 (가속·감속·회전)

### H. 연하장애 (Dysphagia) 4 단계 ⭐⭐⭐ — 본 STT 정본

본 STT 강의 정본 (한국 자격시험 출제 핵심):

| 단계 | 핵심 작용 |
|---|---|
| **1. 구강준비** (Oral Preparatory) | 음식 인식·잘게 부수기·식괴 (bolus) 형성 |
| **2. 구강** (Oral) | 식괴를 혀로 후방 이동 → 인두 입구 도달 |
| **3. 인두** (Pharyngeal) ⭐ | **자동·반사적** — 입·비강·성대 폐색 + 후두 상승·전방화 + 식도 괄약근 개방 |
| **4. 식도** (Esophageal) | 인두 연동운동 → 식도 → 위 |

> "상부식도 괄약근까지 가면 인두 단계의 끝… 식도부터 시작되면 이제 식도 단계."

#### H.1 인두 단계 — 안전한 삼킴 5 작용

본 STT 강의 핵심:

> "왜? 비강까지 다 열려있으면 구강 압력이 약하잖아요. 삼킴할 때는 압력 세져야 음식물 꿀꺽 뒤로 넘긴다."

| 작용 | 목적 |
|---|---|
| **입 닫기** | 구강 압력 확보 |
| **연인두 폐쇄** (비강 폐색) | 구강 압력 + 비강 역류 방지 |
| **설골·후두 상승+전방화** | 식도 입구 개방 + 후두 보호 |
| **상부식도 괄약근 (UES) 개방** | 식괴 식도 진입 |
| **후두 폐쇄 (3중 보호)** | 기도 보호 |

#### H.2 후두 3중 기도 보호 작용 ⭐⭐

본 STT 강의 정본 (한국 자격시험 핵심):

**해부 순서** (음식물 입장 방어 순서):
```
1. 후두개 (Epiglottis) ← 1차 방어 (위→아래 덮음)
2. 가성대 (False vocal cords / Vestibular folds) ← 2차 방어
3. 진성대 (True vocal cords) ← 3차 방어 (최종)
```

**실제 닫힘 순서** (생리학적):
```
1. 진성대 (먼저 닫힘) ← 가장 깊은 곳 우선
2. 가성대
3. 후두개 (마지막)
```

> "음식물 입장에서는 후두개 → 가성대 → 진성대 순으로 방어를 받았지만, 실제 우리가 삼킬 때 나타나는 작용은 **진성대가 가장 먼저 닫히고**, 그 다음에 가성대, 그 다음에 후두개가 닫혀요."

→ ⭐ **시험 함정**: 두 순서 구분 (방어 만남 순 vs 실제 닫힘 순) 필수 출제 주의점.

### I. 흡인 (Aspiration) vs 침투 (Penetration) ⭐⭐ — 연하장애 임상 결정 핵심

본 STT 강의 정본 (한국 자격시험 단골 출제):

| 용어 | 정의 | 임상 의미 |
|---|---|---|
| **침투 (Penetration)** | 음식물이 **기도로 들어왔지만 진성대까지는 못 들어간** 경우 | 진성대가 마지막 막아줌 → 경증 |
| **흡인 (Aspiration)** ⭐ | 음식물이 **진성대 아래까지 통과한** 경우 | 폐로 진입 → **중증** (흡인성 폐렴 위험) |

> "흡인은 후두개·가성대·진성대 다 뚫고 내려온 것. 침투는 기도로는 들어왔지만 진성대까지는 못 들어간 경우. 두 용어는 구분해야 돼요."

→ ⭐ **VFSS (비디오투시연하검사) 임상 결정 규칙**: 진성대 통과 = 흡인 / 진성대 윗부분 = 침투.

→ ⭐ **MVP F1-a 회피 영역 강화 임상 토대**: 연하장애 = **VFSS·FEES 검사 + 임상가 영상 판독 필수** → 영유아 음성·언어 화면 자동 측정 외 영역.


| 단계 | 정의 | 장애 |
|---|---|---|
| **1. 개념 형성** | 이 물건이 무엇인지 인지 (호박, 볼펜) | **치매** (인지장애) |
| **2. 부호언어화** | 개념 → 단어 상징 (호박→"호박") | **실어증** (언어장애) |
| **3. 운동 계획** | 단어 → 입·혀 순차 움직임 계획 | **말실행증 (AOS)** |
| **4. 운동 실행** | 근육으로 실제 발음 | **마비말장애 (Dysarthria)** |

> "이 흐름으로 알면 개념이에 말실행증과 마비말장애 개념 비교를 확실하게 해야 되는데, **말실행증은 계획의 실패**, **마비말장애는 근육의 마비 약화**라고."

- 호박 이미지 안 떠오름 → **치매**
- 호박 떠오름·이름 모름 → **실어증**
- 이름 알고 발음 계획 실패 → **말실행증**
- 계획 성공·근육 마비 → **마비말장애**

→ ⭐ **MVP F1-a 회피 영역 강화 임상 토대**: 신경언어장애 = 영상 (뇌 MRI·CT) + 신경과 협진 필수 → MVP 영유아 타깃 외.
