# 조음장애 (Articulation / Phonological Disorder)

목표 음소를 정확하게 산출하지 못하는 아동에 대한 중재 영역. 트랙 2(사설 센터)의 핵심 대상이며, 놀이 맥락 속에서 반복적 노출·연습을 통해 정확한 산출을 유도한다.

## 평가
- [[clinical/entities/U-TAP]] (우리말 조음음운평가) — 단독 또는 [[clinical/concepts/언어발달지연]] 평가의 일부로 시행

## 주요 활동

### 활동 1. 보물찾기 게임
- 목표 음소(예: /ㅅ/)가 포함된 단어 카드(사과·시계·소시지)를 방 안에 숨김
- 카드를 찾을 때마다 "사과 찾았다!", "시계 여기 있네!" 산출 유도
- 치료사 올바른 발음 모델링 → 아동 따라 말하기 기회 제공

### 활동 2. 요리하기/마트 놀이
- 목표 음소가 포함된 재료 그림 카드 (예: /ㅈ/ → 치즈·감자·가지)
- "치즈 주세요", "가지 넣어요" → **명확히 말해야 재료 사용 가능**이라는 규칙 → 산출 동기 강화

### 활동 3. 입 모양 퀴즈
- 소리 없이 입모양만 보여주고 어떤 소리인지 맞히기
- 같은 입모양 따라하기 → 소리 붙여 말하기

## 난이도 위계

```
단독 음소 → 음절 → 단어 → 구 → 문장 → 대화
```

본 위계는 **모든 음소·환자에 공통 적용되는 일반화 경로**이며, 제품 측 학습 콘텐츠 구조 설계의 핵심 매핑 포인트.
