## 임상 핵심 이슈

1. **언어차이 vs 언어장애 감별** — 이중언어 환경 아동의 한국어 지연이 정상 변이인지 DLD인지
2. **부모 한국어 능력**과 아동 언어발달 상관 (한-베 연구 직접 보고)
3. **어휘 다양성** — 동음이의어 이해, 연어(collocation) 능력 등 학령기 학업 언어 영역 결함
4. **서사담화** — 애니메이션 기반 이야기 과제에서 나타나는 다문화 아동 특성

### A. 다문화 어휘·의미 영역 — 단국대 그룹 ⭐

**Jang, Jeong, Hwang (2014), Comprehending and Defining Homonyms in School-Aged Children from Multicultural Families** (단국대 — 정미란·황민아)
- *Communication Sciences & Disorders* 학회지
- 초등 2-3학년 24명 (다문화 12 + 비다문화 12)
- 선정: **표준화 어휘력 + 문장이해력 정상 범주 매칭** ⭐
- 측정: **동음이의어 이해 + 정의 과제**
- 결과: **표준화 어휘력 정상 매칭에도 다문화 < 비다문화** — 깊은 어휘 지식 영역 결함

**Jo, Hwang, Jeong (2018), 학령기 다문화가정 아동과 일반가정 아동의 연어(連語) 능력** (단국대 — 황민아·정미란)
- *언어치료연구* 27(1) (KSHA)
- 초등 3-4학년 20명 (다문화 10 + 비다문화 10)
- **연어 (Collocation)** = 두 어휘소가 빈도·심리적 두드러짐을 가지고 결합되는 화용 어휘 지식
- 측정: **연어 표현 + 연어 이해** (각 24문항, 총 48)
  - 표현: 사전 청취 후 적절한 단어 산출
  - 이해: 4지선다
- 결과: **수행 IQ + 표준화 어휘력 정상 매칭에도 다문화 < 비다문화** ⭐
- → 화용 어휘 (실생활 어휘 사용) 영역 결함 — 표준화 검사로 포착 안 되는 미세 결함

### B. 한국어 음운·연음규칙 — 한-베 다문화 어머니-자녀 상관 ⭐⭐

**김선경, 김영태, 강로원, 김동준 (2020), 한국-베트남 다문화가정 아동의 읽기 및 쓰기에 나타나는 한국어 연음규칙 적용 특성과 부모의 한국어 능력과의 상관연구** (이화여대 — 김영태)
- *언어치료연구* 29(2) (KSHA)
- 한-베 다문화 아동 10 + 어머니 6 + 한국 단일언어 13 = 29명 (초등 1-2학년)
- 한국 교육부·NRF 지원 연구 (NRF-2018S1A3A2075274)

#### B-1. 측정 도구

| 영역 | 도구 |
|---|---|
| **연음규칙 적용 읽기·쓰기** | 단일언어는 5-6세부터 발달 |
| **음운조작 능력** | 음운 인식 |
| **비단어 따라말하기 (NRT)** | 작업기억 |
| **비단어 역순 따라말하기 (NRT 역순)** | 작업기억 부담 高 |

#### B-2. 핵심 발견 ⭐

| 비교 영역 | 다문화 vs 단일언어 |
|---|---|
| 연음규칙 정확도 | **다문화 < 단일언어** |
| 무의미 + 겹받침 조건 | 두 집단 모두 낮음 |
| **목표단어 문장 후반부** | **다문화만 더 낮음** ⭐ (작업기억 영향) |
| 읽기/쓰기 ↔ 음운조작·NRT | **단일언어**: 모두 상관 / **다문화**: NRT 역순만 |
| **자녀 ↔ 어머니 홑받침 읽기·쓰기** | ⭐⭐ **다문화 자녀-어머니 상관** |

→ ⭐⭐ **다문화 아동 한국어 음운 능력은 어머니 한국어 능력과 직접 상관**. 부모 교육의 임상적 중요성.

### C. 임상 함의 종합 — 다문화 아동 평가·중재의 4 원칙

### G. Rhea Paul Ch5 — 다문화 영역 임상 토대 ⭐⭐

#### G-1. 미국 다문화 통계 (book p.175)

본 텍스트 직접 인용:
> "미연방교육부는 **20%의 학생들이 영어를 제2언어로 배우고 있다**고 추산한다."
> "**미국 학교에 다니는 아동 40%가 문화적, 언어적으로 다양한 배경 출신**이다."
> "ASHA 2009: 인구의 24.9%가 인종적 소수자이지만 모든 언어치료사의 **단지 6.9%만이 인종적 소수자의 구성원**이다."

→ **임상 양극화 식별**: 다문화 아동 ↑ ↔ 다문화 치료사 ↓. **MVP 다문화 아동 임상 격차 해소 = 시장 기회**.

#### G-2. 표 5-2 — 고맥락 vs 저맥락 의사소통 방식 ⭐⭐ (Hall 1983 + Westby & Rouse 1985)

본 위키에서 처음 명시되는 다문화 의사소통 분류 정본:

| 영역 | **저맥락** (주류 문화) | **고맥락** (전통 문화) |
|---|---|---|
| 정보 전달 | 대부분 **말로** | 물질적 맥락·참가자 간 공유 지식 |
| 학습 방식 | **단어 통한** 학습 | **관찰 통한** 학습 |
| 사회 변화 | 급격, 미래 보상 위해 욕구 미루기 | 느림·예측 가능, 계획 거의 필요 X |
| 개인 역할 | **성취·능가** | **문화집단 구성원** (또래보다 뛰어나지 않아야) |
| 시간 개념 | **단일형** (한 번에 하나, 계획·일정 중요) | **복합형** (시각표 없음, 업무 완수가 중요) |
| 행동 시간 | 빡빡한 시간표 준수 | 시간 유연 |

→ ⭐⭐ **MVP 다문화 아동 임상 토대 정본**:
- F1-b 5분 진단 = **저맥락 (단어 기반) 평가** — 고맥락 출신 아동에 불리 가능
- F15 LLM 챗봇 = **저맥락 양식** — 고맥락 아동에는 단순화 + 시각 단서 강화 필요
- Persona 이미란 (다문화) = 고맥락 출신 가능성 ⭐ — 평가·중재 시 본 표 직접 적용

#### G-3. 내러티브 구조 — 문화에 따른 차이 (그림 5-1) ⭐

본 텍스트 직접 인용 (Westby 1989, Kaplan 1966):
> "**주제 중심 (topic-centered) 내러티브** = 주류 문화 (저맥락) — 영어 학교 문해성 직접"
> "**주제와 연관된 (topic-associating) 내러티브** = 전통 문화 (고맥락) — 다른 가지로 분기·연관"

→ "**주제 중심 내러티브를 거의 경험하지 못한 고맥락 문화 출신 아동들은 내러티브를 처리하고 생성하는 것이 필요한 많은 학문 과업에서 어려움**" (Westby 2005)

→ Bishop & Edmundson (1987) + Boudreau (2006) + Boudreau & Hedberg (1999): 주제 중심 내러티브 = **문식성 발달 + 학교 성공과 밀접 관련**

→ ⭐ **MVP F15 챗봇 다문화 적응 임상 토대**:
- F15 시나리오 = 주제 중심 내러티브 위주 → 고맥락 출신 ASD/다문화 아동에 어려움
- 대안: 주제 연관 내러티브 옵션 추가 (Fiestas & Peña 2004)
- [[clinical/concepts/내러티브-담화-추론-중재]] § E 추론 위계 통합 매트릭스 정합

#### G-4. 글상자 5-9 — CLD 아동 표준화 검사 수정 17 제언 ⭐⭐⭐

본 텍스트 직접 인용 (Goldstein & Iglesias, 2006; Erickson & Iglesias):

| # | 검사 수정 제언 |
|---|---|
| 1 | CLD 아동에게 없을 듯한 지식·경험 요구 항목 검토 |
| 2 | 팀 구성원에게 과업 수행 시켜 문화 편향 줄이는 법 제안 |
| 3 | 공동체 성인에게 검사 시행하여 항목 적절성 정보 수집 |
| 4 | 이전 CLD 아동 검사 결과 검토하여 문제 항목 식별 |
| 5 | 정상 표본에 CLD 배경 다수 포함하는 검사 식별 |
| 6 | 공동체 어휘 적절성 결정 — 지역 아동에게 적절한 어휘 |
| 7 | 그림 친숙도 검토, 낯선 것은 교체 |
| 8 | 지시어 바꾸어 말하기 |
| 9 | 추가 연습 항목 제공 |
| 10 | 추가 대답 시간 + 항목·지시 반복 |
| 11 | 끝내야 하는 한계선 이상으로 검사 계속 |
| 12 | 정성 분석 위해 의견·설명·반응 변화 기록 |
| 13 | **코드 전환 (code switching: 한 발화 내 언어 교체)** vs **언어 간섭 (language interference)** 관찰 |
| 14 | 검사 표준 + 방언·가정 언어·제2언어 학습 특징 모두 비교 |
| 15 | 그림 가리키기 검사 시 아동에게 이름도 부르게 함 |
| 16 | 검사 표준에 의해 대답 틀리다면 왜 그렇게 대답했는지 설명 요구 |
| 17 | 평가 정보 자세히 기록 + 수정 사항 모두 보고. **절대 평가 점수는 의뢰인 속한 집단에서 유효할 경우에만 신중 사용** |

→ ⭐⭐⭐ **MVP F1-a 다문화 적응 임상 토대 정본**:
- 17 제언 중 8, 10, 16 = F1-a UI 직접 적응 (지시 변경·시간 추가·왜 그렇게 답했는지 옵션)
- 13 = code switching 인식 — F1-a 모델 다중언어 데이터셋 후보
- 17 = "절대 평가 점수 신중 사용" = **AI 진단 false negative 방지** 임상 표준
- [[clinical/concepts/단순언어장애-SLI]] § F 측정 단위 통합 라이브러리에 본 17 제언 추가 후보

#### G-5. 가족 중심 실제 (family-centered practice) (book p.188+)

본 텍스트 직접 인용:
> "**우리 자신과 다른 문화적 배경을 지난 가족을 대상으로 하는 가족중심의 실제는 똑같은 원칙으로 작용한다**." (Donahue-Kilburg 1993; Hidecker et al. 2009; Pedersen & Vining 2009)

> "Hwa-Foerlich & Westby (2003), Peña & Fiestas (2009): **학습, 양육, 그리고 장애 등에 대한 가치와 신념 차이가 혼란과 오해를 부를 수 있다**. CLD 가족과의 상호작용에 우리 자신의 추정과 기대가 어떻게 영향을 미치는지 인식할 필요가 있다." (Kohnert 2008)

→ **MVP F11 부모 음성 클로닝 + HITL 임상 토대**:
- CLD 가족과의 상호작용 = 자신의 추정·기대 인식 필요
- HITL 자격자 다양성 모니터링 ([[product/concepts/expert-diversity-monitoring]]) = CLD 가족 매칭 가능성 확보 핵심
