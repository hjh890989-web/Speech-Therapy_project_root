# 읽기 선행지표 발달 규준 — 음운인식·해독·RAN·유창성·추론

> 만 4~7세 읽기 발달 선행지표(음운인식·해독·빠른이름대기·읽기유창성·음운규칙·추론)의 **연령별 정상 수준·난이도 위계·집단별 결함 양상**을 통합한 임상 근거. 본 프로젝트 읽기 미니게임(REQ-FUNC-**CL-08~11**, [[product/concepts/F1a-F4-임상설계-reference]])의 **난이도 위계·아이템 풀·잠정 해석 기준**의 grounding.

## 1. 핵심 — 읽기의 단순관점모델과 음운처리 3요소

- **단순관점모델(Simple View of Reading)**: 읽기이해 = **해독 × 언어이해**. 해독은 읽기이해의 필요조건이나 충분조건은 아님(외부 KB S090, 설아영 2016).
- **음운처리(phonological processing) 3대 구성**: **음운인식 + 음운기억 + 빠른이름대기(RAN)**. 세 요소는 서로 **독립적 예측력**을 가지므로 하나의 중재로 나머지가 자동 향상되지 않음(외부 KB S090·S133).
- **함의(앱)**: 음운인식·해독·RAN·유창성 게임은 **독립 축으로 분리 측정·기록**해야 하며(F4 음소 핀셋 다축), 단일 축 성공이 다른 축을 보증하지 않는다.

## 2. 구인별 발달 규준 (연령·난이도 위계)

### A. 음운인식 → CL-08 (음운인식 게임)
- **발달 위계**: 운율 → 단어 → 음절 → 음소 (큰 단위 → 작은 단위). 과제 난이도: **수세기 → 변별 → 합성 → 탈락 → 대치**(외부 KB S003, 이차숙 1999).
- **연령 규준**(외부 KB S003, 김영태 2006 / 홍성인 2001):
  - 음절 분절: **4세 ≈ 50%, 5세 ≈ 80%**
  - 음소 분절: **5세 전반 거의 불가, 5세 후반 ≈ 50% 정반응**
  - 4세→6세 급상승: 단어 합성·탈락 50%→99%, 음절 34%→96%, 음소 8%→51%
- **예측력**: 음운인식↔철자(일치자소 정확도) **r=.676** > 어휘력↔철자 **r=.435**(둘 다 p<.001; S160) → 음운인식이 어휘력보다 철자의 강한 예측 변인. (참고: 어휘력↔음운인식 r=.322 — 두 예측변인 간 상관. ⚠️ 외부 KB 요약은 이 .322를 "어휘↔철자"로 오귀속했던 것을 정정함.) 지능·어휘보다 단어재인과 더 높은 상관(S003).
- **앱 적용**: 게임 위계 = 음절 합성 → 음절 탈락 → 음절 대치 → 음소 변별 순. **만 5세 음소 과제는 50% 정상**임을 채점 해석에 반영(오답 ≠ 결함).

### B. 해독(자소-음소 대응) → CL-09 (해독 게임)
- **측정 4유형**: 의미낱말/무의미낱말 × 자소-음소 일치형/불일치형(외부 KB S181·S090). **무의미낱말** = 어휘 암기 배제한 순수 해독.
- **예측력(학년·집단 의존)**(외부 KB S090):
  - 저학년(1~2) 읽기부진: 해독 β=.287(12.9%) > 어휘 / 일반 저학년은 어휘(24%) > 해독(6.3%)
  - 해독↔유창성 상관: 읽기부진 **r=.788** vs 일반 r=.446 → 높을수록 **해독 자동화 미완성** 신호
- **중단 규칙**(부담 제한): 처음 5문항 연속 오반응 시 중단(외부 KB S181).
- **앱 적용**: 일치형 → 불일치형(음운규칙 적용) 위계. **위치별(어두/어중/어말) 자체 자극**. 정확도뿐 아니라 **반응속도(자동화)**를 함께 기록.

### C. 빠른이름대기(RAN) → CL-10 (RAN 게임)
- **정의**: 시각자극(숫자·글자·색깔·사물) 연속 명명 **시간(초)** — 낮을수록 우수. 음운인출 자동화 지표(외부 KB S006·S133).
- **자극유형별 중재 반응성**(외부 KB S133, 음운인식+음운작업기억 24회기):
  | 유형 | 변화 | 유의성 |
  |---|---|---|
  | 사물 | −4.25초 | 유의 |
  | 글자 | −3.23초 | 유의 |
  | 색깔 | −1.18초 | 유의 |
  | **숫자** | −0.68초 | **비유의** |
  → **숫자형은 간접훈련 반응성 낮음** = 자동화 속도 자체 표적 훈련 필요.
- **앱 적용**: 사물·색깔 유형 우선(어린 연령 친화). **정상 범위 절단점은 자체 파일럿 필요**(외부 KB도 만 2~4세 규준 빈약). 현재 코드(`lib/literacy/ran-content.ts`)의 "규준 미정"은 이 한계와 정합.

### D. 읽기유창성 → CL-10 (1분 읽기 게임)
- **3요소**: 정확도·속도·운율(외부 KB S033). 측정 = 1분(또는 10초 환산) **정확 음절 수**.
- **글 유형 분리**: 이야기글 vs 설명글(외부 KB S006, RA-RCP) — 장르별 프로파일 차이.
- **예측력(학년)**(외부 KB S090): 중학년 읽기부진 β=.346(16.8%), 고학년 일반 β=.522(37.7%). **고학년 읽기부진은 유창성이 일반 저학년 수준에 정체**(36.53 vs 31.47) → **학년이 아닌 읽기 발달 수준 기준** 해석 필요.
- **앱 적용**: 자체 작성 이야기글/설명글, 1분 정확 음절 수 기록. 정상/위험 경계는 **자체 파일럿이 최종 근거**(외부 KB로 잠정 위계만 제공).

### E. 음운규칙(음운변동) → F4 + CL-09 보강
- **습득 순서(철자 정확률)**(외부 KB S113, 초등 1~3): **경음화(94%) > 연음화(88%) > 격음화(73%) > 종성규칙(69%) > 구개음화(20%)**. 경음화 3학년 100%, **구개음화 8세+까지 지속**.
- **읽기 중재 권장 순서**(외부 KB S003): 7종성 → 연음화 → 경음화 → ㅎ탈락.
- **⚠️ 오류 해석의 역전**(외부 KB S160): 학령전기 **"소리 나는 대로 쓰기"(음운규칙 반영 오류)는 정상 발달 신호** — 정상(N) 집단에서 오류율 최고, 중증 지연(D-VPA)은 0%에 가까움(음소 인식조차 못 해 생략·대치 지배). **생략·무관 대치 비율이 높을 때가 진짜 위험 신호.**
- **앱 적용**: F4 음운변동 분류 시 **정상 변동·발달적 오류를 결함으로 분류 금지**([[clinical/concepts/조음장애]] §C와 정합). 난이도 = 구개음화를 최상위.

### F. 추론 → CL-11 (추론 4수준, F15 발화 유도)
- **유형별 난이도 수렴**(외부 KB S100·S129·S142): **사실정보이해(가장 쉬움) < 예측/연결추론 < 감정추론 < 평가적·정교화추론(가장 어려움)**.
- **배경지식이 핵심 자원**: 배경지식 제공 시 취약집단 추론 수행 유의 향상(외부 KB S145·S129). 특성확인질문 제시 시 4~6세 SLI 예측추론이 일반아동 수준으로 향상(S144).
- **마음이론과 상관**: 간접추론 표지↔마음이론 r=.278(외부 KB S149).
- **앱 적용**: F15는 **유도만, 채점 X**([[product/concepts/F1a-F4-임상설계-reference]] §2.D). 시나리오에 **배경지식 활성화 단서**를 선행 제시. 4수준 위계 = 사실 → 추론 → 비판 → 평가.
