# 아동 언어치료 핵심 기법 4종

트랙 2(사설 센터 기반 아동 발달)의 모든 세션 활동을 관통하는 4개 기법. [[clinical/concepts/언어발달지연]], [[clinical/concepts/조음장애]], [[clinical/concepts/자폐-화용중재]] 모든 영역에서 공통 사용되며, **부모 코칭의 핵심 메시지**이기도 하다.

## 4개 기법

| 기법 | 설명 | 예시 |
|---|---|---|
| **평행 발화 (Parallel Talk)** | 아동의 행동을 옆에서 말해주기 | "우리 OO이가 자동차를 굴리고 있네" |
| **확장 (Expansion)** | 아동의 말을 문법적으로 올바르게 늘려주기 | 아동 "차 가!" → 치료사 "응, 빨간 차가 쌩쌩 가네" |
| **기다리기 (Waiting)** | 아동이 스스로 말할 시간을 충분히 제공 | 3~5초 이상 |
| **반응적 상호작용 (Responsive Interaction)** | 아동이 관심 보이는 것에 즉각 반응 | 아동이 고양이를 쳐다보면 → "고양이다! 야옹~" |

## 세션 단계별 적용

| 단계 | 적용 양상 |
|---|---|
| 도입 (5~10분) | 반응적 상호작용으로 라포 형성, 기다리기로 자발 발화 유도 |
| 본활동 (25~35분) | 평행 발화로 활동 어휘 노출, 확장으로 문법 모델링 |
| 마무리 (5분) | 반응적 상호작용으로 성취감 마무리 |
| 부모 상담 (5~10분) | 4개 기법 모두를 가정에서 재현하는 방법 코칭 |

## ⭐ EMT (Enhanced Milieu Teaching) 환경 중심 언어중재 — 53차 보강

[[clinical/sources/2026-05-09-한국-영유아-언어평가-DLD-NISE]] § raw 6 정독.

### 정의

자연주의적 중재 모델. 4 핵심기법을 **환경 조작 + 반응 요구하기**와 융합:

| 구성 | 설명 |
|---|---|
| **환경 조작 (Environment Arrangement)** | 아동의 흥미 사물을 손 닿지 않는 곳에 배치 → 자발적 의사소통 유도 |
| **반응 요구하기 (Mand-model)** | 아동의 반응 요구 (질문 · 모델 제시 · 기다리기 + 4 기법 통합) |
| **자연스러운 상호작용** | 임상실 외 일상 환경 속 적용 (가정 · 어린이집) |

### Hanen Centre 모델 ("It Takes Two to Talk") 정합

EMT는 본 위키 § 4 핵심기법 + Hanen "It Takes Two to Talk" 부모 코칭 프로그램의 한국 임상 변형. 본 위키의 4 기법 = Hanen 4 단계 (Observe / Wait / Listen / Respond) 의 압축된 표현.

### 적용 대상 — DLD 3단계 § 화용 담화

DLD ([[clinical/concepts/언어발달지연]]) 제3단계 (화용·담화) 핵심 중재 도구. 의미적 매핑 (1단계) → 단어 결합 (2단계) → EMT 환경 중심 (3단계) 단계적 적용.

### SLI + 공동주의 결함 아동 통합 중재

EMT는 SLI (단순언어장애) + 공동주의 결함 아동 모두에 적용. 공동주의 (Joint Attention) 결함 = ASD 경계선 지표 → [[product/entities/persona-황보름]] (HITL confidence 60% 게이트 + ADR-14 F15 안전 게이트) 정합.

### ⭐ ADR-09 (F11 윤리 화이트리스트) 임상 근거 강화 (53차 보강)

4 핵심기법은 모두 **부모-아이 자연 상호작용** 영역. 이는 **ADR-09 F11 윤리 화이트리스트**의 핵심 임상 근거:

| 4 기법 | F11 부모 음성 클로닝 정합 |
|---|---|
| 평행 발화 | 일방향 콘텐츠 (동화·자장가) → ALLOWED. 부모 목소리로 자연스러운 발화 시범 가능 |
| 확장 | 상호작용 영역 → 부모 클로닝 X (실시간 반응이 핵심, 녹음 동화 불가) |
| 기다리기 | 5-10초 침묵 = 상호작용 영역 → 부모 클로닝 X |
| 반응적 상호작용 | 아이 흥미 따라가는 토픽 → 부모 클로닝 X (예측 불가능) |
| **교정 훈련** (음운 교정) | ❌ **ALL 4 기법 모두 위배** → 가족 ≠ 치료자 (MIT 임상 원리) → ALLOWED_CONTENT_TYPES 차단 |

→ ADR-09 ALLOWED_CONTENT_TYPES = 'storybook' / 'lullaby' (일방향만) + ❌ 'articulation_correction' / 'phoneme_drill' / 'mission_mirror' = 4 기법 임상 정합.

→ 정본 [[product/concepts/architecture-decisions]] § ADR-09 + [[product/concepts/Phase-1-future-tasks-decomposition]] § F11.
