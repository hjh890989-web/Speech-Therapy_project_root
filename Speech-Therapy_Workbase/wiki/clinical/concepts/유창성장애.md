# 유창성장애 (Fluency Disorder)

말의 흐름·속도·리듬에 어려움을 보이는 장애. **말더듬(Stuttering)**과 **속화(Cluttering)**가 대표 하위 유형. 5대 의사소통장애 영역 중 하나.

### B. 유창성 정의 ⭐ — 4 판단 요소

본 STT 강의 직접 인용:
> "**유창성은 어떤 노력이나 머묵거림도 없이 쉽고 자연스럽게 말하는 것**"

판단 4 요소:
1. **지속성** — 말이 끊김 없이 흐름
2. **속도** — 너무 느리지 X (적절)
3. **노력** — 긴장·신경 X (편하게)
4. **리듬** — 단조롭지 X (적절한 리듬)

→ (시험 함정) "구문 구조" = 유창성 판단 요소 X (출제 빈출 오답)

### C. WHO 말더듬 정의 + 행동·정서·인지 3 영역 ⭐⭐

본 STT 강의 직접 인용 (WHO 정의):
> "**자신이 말하고자 하는 것을 분명히 알고 있지만 어휘적으로 무슨 말을 할지 만들어내서 유창하지 못한 것은 유창성장애가 아니다. 유창성장애는 내가 무엇을 말하고자 할지 어휘 단계를 충분히 파악·판단하고 있는데 말을 할 때 불수의적이고 통제가 안 된다. 반복·연장·멈춤으로 생기는 말의 리듬 장애**"

→ ⭐ **유창성장애 = 외국어 못함과 구별**: 어휘적 미숙 (외국어) X / 어휘는 충분하지만 말 행동 통제 안 됨 (말더듬)

### D. 빙산 모델 (Iceberg Model) ⭐⭐ — 행동 + 정서 + 인지

본 STT 강의 핵심 — 말더듬 통합 정의:

```
[빙산 윗부분 — 행동적 요소 (드러남)]
  - 반복 (Repetition)
  - 연장 (Prolongation)
  - 막힘 (Block)
  ↑ 핵심 행동 (Core Behaviors)
==================================
[빙산 아랫부분 — 정서·인지 (안 드러남)]
  - 정서적 요소: 말·상황 불안 + 공포
  - 인지적 요소: 부정적 의사소통 태도 + 부정적 자화상 ("나는 말더듬이")
```

→ **3 영역 통합 정의**: WHO 정의는 행동 요소만 다루지만, 임상에서는 **행동 + 정서 + 인지** 3 영역 모두 평가·중재 필수.

→ ⭐ MVP 회피 영역 정합: F15 LLM 챗봇 등은 행동적 발화만 측정 → **정서·인지 영역 = 임상가 자격자 영역** (회피)

### E. 유창성장애 분류 위계 ⭐

본 STT 강의 4 분류 축:

#### E-1. 정상 vs 병리적 비유창성

| 분류 | 다른 명칭 | 단어 위치 | 정상 비유창 예 |
|---|---|---|---|
| **정상적 비유창** | 전형적 비유창 / **단어 간 비유창** | 단어 사이 | 주저 (말 시작 전 멈거림) / 4일 (filler "어/음") / 미완성구 |
| **병리적 비유창** | 비전형적 비유창 / **단어 내 비유창** | 단어 안 | 음절 반복·연장·막힘 |

→ ⭐ **MVP F1-a 임상 토대 — 정상 비유창과 병리적 비유창 구별** (false positive 방지)

#### E-2. 발달성 vs 후발성 말더듬

- 발달성 (Developmental): 아동기 발현 (만 2-6세 대다수)
- 후발성 (Acquired): 신경학적·심인성·약물 등 후천적

#### E-3. 말더듬 vs 속화 (Cluttering)

- **말더듬**: 반복·연장·막힘 (행동) + 정서·인지
- **속화**: 빠른 속도·음소 연장·운율 문제·발성 문제 (음성적 특성) + **종성 < 초성 오류** 패턴

### F. 핵심 행동 vs 부수 행동

본 STT 강의 — 시험 빈출 영역:

| 행동 | 분류 | 예 |
|---|---|---|
| **핵심 행동** (Core) | 1차 말더듬 행동 | 반복·연장·막힘 |
| **부수 행동** (Secondary) | 학습된 회피·고난 행동 | 눈 깜빡임·머리 흔들기·발 구르기·회피 단어 |

### G. 원인 이론

본 STT 강의 핵심 이론 (시험 빈출):
- **진단기인 이론** (Diagnosogenic Theory, Johnson 1942) — 부모 진단·반응이 말더듬 유발·악화
- **요구 용량 모델** (Demands and Capacities Model) — 환경 요구가 아동의 언어·운동·인지·정서 용량 초과 시 말더듬 발생
- 기타 신경학적·심리적·학습 이론

### H. 진단 (Diagnosis) — 5 절차

본 STT 강의 진단 절차:

1. **간별 진단** (Differential Diagnosis)
   - 정상 vs 병리적 비유창
   - 말더듬 vs 속화
   - 발달성 vs 후발성
2. **간별 검사 도구** ([[clinical/entities/KOCS]] 등)
3. **반복 횟수·단위 반복수 분석** ⭐
4. **평가서 작성**
5. (잠재 — STT에 미명시) 부수 행동·정서·인지 평가

### I. 치료 원리 — 양적금법 (Treatment Approaches) ⭐⭐

본 STT 강의 핵심:

#### I-1. 간접 치료 vs 직접 치료

| 방식 | 대상 | 임상가 행동 |
|---|---|---|
| **간접 치료** | 학령전 아동 + 부모 | 환경 변화·부모 코칭·놀이 |
| **직접 치료** | 학령기·청소년·성인 | 말더듬 행동 직접 수정 |

#### I-2. 양적금법 2 종 — 직접 치료 표준 프로토콜

| 양적금법 | 영문 명칭 | 원리 | 대표 프로그램 |
|---|---|---|---|
| **유창성 형성법** | Fluency Shaping | 새 유창한 말 패턴 학습 (느린 속도·부드러운 시작) | Lidcombe Program (학령전) / Camperdown Program (성인) |
| **말더듬 수정법** | Stuttering Modification | 더 쉬운 말더듬 방식 학습 (Van Riper 접근) | MIDVAS (확인·둔감·변화·접근·안정화) |

#### I-3. 배상자 및 가족 상담

- 부모 매개 학령전 중재 = 간접 치료 핵심
- 가족 정서·인지 영역 지원

### M. 유창성 정의 4 요소 ⭐⭐

본 STT 강의 정본:

> "유창성 = 어떤 노력이나 머뭇거림도 없이 쉽고 자연스럽게 말하는 것."

| 요소 | 정의 |
|---|---|
| **1. 지속성** | 말이 끊김 없이 쭉 흘러나옴 |
| **2. 말 속도** | 적절한 속도 (너무 느리면 유창 X) |
| **3. 노력** | 긴장·신경 없이 편하게 줄줄 |
| **4. 리듬** | 똑같은 톤만 X — 적절한 리듬 |

→ ⭐ **시험 함정**: "구문 구조"는 유창성 판단 요소 아님.

### N. 말더듬 정의 (WHO 세계보건기구) ⭐⭐⭐

본 STT 강의 정본:

> "WHO 말더듬 정의: 자신이 말하고자 하는 것을 분명히 알고 있지만, **불수의적이고 통제 안 되는 반복·연장·멈춤**으로 생기는 말의 리듬의 장애."

→ ⭐ **임상 핵심**: 영어 비유창 ≠ 말더듬 (어순적 단계 문제 → 다른 차원). 말더듬 = 어순적으로 알고 있지만 발화 시 불수의적 통제 불가.

#### N.1 말더듬 3 요소 (행동·정서·인지) ⭐

> "WHO 정의는 핵심적으로 **행동적 요소**를 많이 설명하고 있지만, 사실 말더듬 정의는 행동적 요소만은 아니에요. 정서적 요소 (말이나 상황에 대한 불안·공포), 인지적 요소 (부정적 의사소통 태도·말더듬인이라는 부정적 자화상) 다 포함."

| 요소 | 내용 | 임상 식별 |
|---|---|---|
| **행동적** | 반복·연장·멈춤 (불수의) | 직접 관찰 가능 (빙산 위) |
| **정서적** | 불안·공포 (상황별) | 보고·관찰 (빙산 아래) |
| **인지적** | 부정적 자화상·태도 | 면담·체크리스트 (빙산 아래) |

### O. 빙산 모델 (Sheehan's Iceberg Model) ⭐⭐⭐ — 한국 자격시험 빈출

본 STT 강의 정본 (자격시험 단골):

```
┌────────── 행동적 요소 (눈에 보임) ──────────┐
│  반복 (sa-sa-sa)                           │  ← 빙산 윗부분
│  연장 (sssss)                              │
│  멈춤 (block)                              │
└──────────────────────────────────────────┘
═══════ 수면 ═══════════════════════════════
┌────── 정서적·인지적 요소 (눈에 안 보임) ──┐
│  불안·공포 (말이나 상황)                   │  ← 빙산 아랫부분
│  부정적 자화상 (말더듬인)                  │
│  부정적 의사소통 태도                      │
└──────────────────────────────────────────┘
```

> "빙산 그림과 같이 드러난 부분 = 행동적 요소, 드러나지 않은 부분 = 정서적·인지적 요소."

→ ⭐ **MVP F1-b 회피 영역 강화**: 양육자 보고로 빙산 윗부분 (행동)은 식별 가능, **아랫부분 (정서·인지)은 식별 불가** = 5분 진단 불가.

### P. 정상적 vs 병리적 비유창성 ⭐⭐ — 반복 단위별 임상 결정 규칙

본 STT 강의 정본 (자격시험 단골):

#### P.1 정상적 비유창성 유형

| 유형 | 정의 | 예 |
|---|---|---|
| **주저** (hesitation) | 말 시작 전 멈칫 | "...어..." |
| **삽입** (interjection) | 어휘 삽입 | "음·어" |
| **미완성구** | 말 끝내지 못함 | "그래서 — 아니" |
| **수정** | 말 도중 수정 | "어제, 아니 오늘" |
| **다음절 단어 전체 반복** ⭐ | 2+ 음절 단어 전체 반복 | "사과 사과 사과" |

#### P.2 병리적 비유창성 유형 ⭐⭐ — 반복 단위가 작을수록 병리적

| 유형 | 정의 | 예 |
|---|---|---|
| **일음절 단어 전체 반복** ⭐ | 1음절 단어 반복 | "강 강 강" |
| **단어 부분 반복** | 단어 일부 반복 | "사 사 사과" |
| **음절·음소 반복** | 음절·음소 반복 | "ㅅ ㅅ 사과" |
| **연장** | 음소 늘림 | "ssssss사과" |
| **폐색** (block) | 멈춤 | "...(긴 멈춤)... 사과" |

→ ⭐ **임상 결정 규칙**: 반복 단위 = **2음절 이상 단어 전체** = 정상 / **1음절 단어 또는 음절 이하** = 병리적.

→ ⭐ **MVP F1-b 회피 영역 강화**: 한국 보호자가 "사과 사과 사과" (정상)와 "사 사 사과" (병리적)를 구분 보고 불가능 → **임상가 직접 관찰 필요** → MVP 5분 자가 진단 회피.
