# 학습장애·언어재활 (Language-Learning Disability)

학령기 아동의 학업 언어(reading comprehension, 작문, 학습언어)와 도구적 학습 기술(해독·철자·계산)에 어려움을 보이는 영역. 트랙 2 (사설 센터) 학령기 + 트랙 3 (학습장애·특수교육) 경계 영역.

### A. 읽기이해부진 정교화추론 — 도구추론 ⭐

**박예슬 (2017), 읽기이해부진 아동의 정교화추론 특성 — 도구추론을 중심으로** (단국대 — 황민아 지도)
- 초등 3-6학년 읽기이해부진 15명 vs TD 15명
- **도구추론** = 정교화 추론의 한 유형 — 텍스트에서 도구가 명시 안 됐을 때 추론
- 측정: **어휘판단 과제**
  - 유도 문장 (특정 도구 연상 가능) 읽기
  - 다음 글자가 단어인지 비단어인지 판단
  - 조건: **관련 도구 단어 vs 무관련 도구 단어**
- **점화 효과(priming) 측정**: 반응 정확도 + **반응 시간**
- ⭐ **핵심 발견**:
  - **TD**: 무관련보다 관련 조건에서 어휘판단 반응시간 **빠름** → 정교화 추론 활성화 (도구 자동 활성)
  - **읽기이해부진**: 관련/무관련 조건 **차이 없음** → 정교화 추론 **실패**
- → **읽기이해부진 = 정교화 추론의 자동 활성화 결함**. 의식적 추론은 가능해도 자동 추론 부재 = 처리 효율성 저하

→ **MVP 영향**: F1-a linguistic 측정 시 **반응 시간** 변수 추가 검토 (단순 정확도 외)

### B. 초등 고학년 읽기이해부진 추론유형·오류유형 ⭐⭐

**유경진 (2017), 초등 고학년 읽기이해부진 아동의 추론유형과 오류유형에 따른 추론능력** (부산가톨릭대 — 김미배 지도)
- 초등 4-6학년 읽기이해부진 19명 + 일반 19명 (총 38명)
- 선정 기준 ⭐:
  - **한국 비언어성 지능검사-2 도형척도 ≥ 80** (정상 인지)
  - **한국어 읽기 검사 (KOLRA)** 해독·유창성 표준점수 ≥ 91
  - 읽기이해 표준점수 ≤ 90 (이해부진)

#### B-1. 추론 4 유형 위계 ⭐ (한국 학령기 표준)

| # | 추론 유형 | 정의 |
|---|---|---|
| 1 | **사실적 정보 이해** | 텍스트 명시 정보 확인 |
| 2 | **응집성 추론** (Coherence Inference) | 텍스트 내 정보 연결 |
| 3 | **배경지식 기반 추론** | 독자 지식 활용 |
| 4 | **정교한 추론** (Elaborative Inference) | 텍스트 + 지식 통합 |
| 5 | **평가적 추론** ⭐ | 텍스트 이해 + 독자 평가 — **가장 어려움** |

- 결과:
  - 일반·읽기이해부진 모두 사실 > 응집성 ≈ 배경지식 ≈ 정교 > **평가적 추론** (가장 어려움)
  - 4·5·6학년 동일 — 발달 위계 안정적

#### B-2. 추론 오류 4 유형 + 한국 임상 표준 ⭐

| # | 오류 유형 | 두 집단 모두 (50%+) | 이해부진만 (10%+) |
|---|---|---|---|
| 1 | **미숙한 추론** | ✅ | (공통) |
| 2 | **틀린 추론** | ✅ | (공통) |
| 3 | **이해 실패** | (10% 미만) | ✅ — 텍스트 정보 확인 자체 실패 |
| 4 | **무응답·모른다** | (10% 미만) | ✅ — 회피 반응 |

- ⭐ **임상 함의**: 읽기이해부진은 추론 오류 패턴이 **다르다**:
  - 일반 = 잘못된 추론 (시도는 하지만 틀림)
  - 읽기이해부진 = **이해 실패 + 무응답** = **텍스트 정보 확인 자체 실패** ⭐
- 이는 [[clinical/concepts/자폐-화용중재]] § D-10 최숲 2007 PDD 오류 패턴 (TD = "잘못된 추론" / PDD = "엉뚱한 응답")과 비교 가능

→ **MVP F15 챗봇 영향**: 추론 오류 패턴별 차별화된 비계 (scaffolding) 가능
- 미숙·틀린 추론 → 단서 제공 (응집성 추론 도와줌)
- 이해 실패 → 사실 정보 재확인 (텍스트 다시 읽기)
- 무응답 → 회피 동기 식별 (engagement 모니터링 — Zajic 2020 ASD writing engagement와 정합)

### C. 읽기이해부진 관용어 이해 — 학령기 어휘 영역 결함

**현혜숙 (2010), 읽기이해부진 아동과 일반 아동의 문맥 유무 및 관용어 유형에 따른 관용어 이해능력 비교** (이화여대 — 김영태 지도)
- 측정: 문맥 유무 × 관용어 유형 (**투명도** + **친숙도**)
- 결과 분석:
  - 과제제시 방법 (독립 vs 문맥) × 투명도 정답률
  - 과제제시 방법 × 친숙도 정답률
  - 오류 유형 빈도·비율
- → **관용어** = 읽기이해부진 학령기 어휘 영역 핵심 결함. 비유언어·간접화행 영역의 일부.
- → [[clinical/concepts/자폐-화용중재]] § D-7 최수영 2020 아이러니 이해와 비교 가능 — ASD vs LD 비유언어 결함 패턴 차이

### E. 추론 4 유형 + 추론 3 유형 통합 매트릭스 ⭐

### G. 단순 견해 (Simple View of Reading) — 그림 10-1 ⭐⭐⭐ (Kamhi 2009)

본 텍스트 직접 인용 (Catts, Adolf, & Weisrner 2006에서 재인용):

**2 차원 × 4 분면 분류**:

```
                 단어 인지
              서투름     잘함
이해  잘함 │ 난독증     │ 전형적 위기
      서투 │ 혼합 해독·이│ 특정 이해 장애
       름  │ 해 장애     │ (SCD)
```

| 분면 | 분류 | 특징 |
|---|---|---|
| 잘함·잘함 | **전형적 위기** | 정상 |
| 서투름·잘함 | **난독증** (Dyslexia) ⭐ | 단어 인지·해독 결함, 이해는 정상 |
| 잘함·서투름 | **특정 이해 장애** (SCD) ⭐ | 해독은 정상, 이해 결함 |
| 서투름·서투름 | **혼합 해독·이해 장애** | 둘 다 결함 |

→ ⭐⭐⭐ **학습장애 진단의 임상 표준 분류** — MVP 회피 영역이지만 Phase 4 학령기 확장 시 핵심 임상 토대

### H. 난독증 정의 — NICHD (Lyon, Shaywitz & Shaywitz 2003)

본 텍스트 직접 인용:
> "**난독증은 원인이 신경생물학적인 특정 읽기장애이다. 정확한 그리고/또는 유창한 단어인지의 장애와 서투른 철자하기 및 해독능력으로 특징지어진다. 이런 장애는 전형적으로 다른 인지능력과 효율적인 학급교수의 제공과 관련된 종종 예기치 않은 언어의 음운요소에서의 결함에 기인한다.**"

→ **난독증 = 음운 처리 결함 (Phonological Processing)** + 자모결합 원리 (alphabetic principle) 결함

### I. 음운 인식 ↔ 위기 (book p.497) ⭐⭐

본 텍스트 다수 연구 직접 인용:
> "음운인식이 위기 능력과 밀접하게 연관되어 있으며, 음운인식의 치료는 부호화 기능의 증대와 관련 있음" (Bradley & Bryant 1985; Gillon 2005b; Lieberman 1990; Mann 1984; Noble & McCandliss 2005; Scarborough 2003; Schuele & Boudreau 2008; Snowling & Nation 1997; Stackhouse & Wells 1997)

→ ⭐ 음운인식 중재 = 학령전 → 학령기 읽기 발달 이행 핵심

### J. 학령기 평가 — Ch11 표준 도구 (book p.527)

| 도구 / 영역 | 특징 |
|---|---|
| **빠른 이름대기 (RAN, Rapid Automatized Naming)** | Catts, Zhang, Tomblin 2002 — 음운 처리 결함 식별 |

| **1. 지시적** (Directive) | 자기-지시 (행동 모니터링·집중·앞일 계획) + 타인-지시 (보여주기·지시·앞일 계획·협력 예측) |
| **2. 해석적** (Interpretive) | 현재/과거 사건 보고 (이름하기·정교화·연관짓기·부조화 인식·순서 인식) |
| **3. 추론** (Reasoning) | 이유 인식 + 원리 인식 |
| **4. 투사적** (Projective) | 예측 + 감정이입 + 상상 (역할극) |
| **5. 관계적** (Relational) | 자기-주장 (욕구·정당화·비판·위협) |
| **6. 상호작용적** (Interactional) | 자기-강조 + 타인-인식 |

→ ⭐ **MVP F11 학령기 부모 매개 임상 토대 — 화용 6 기능 다양성 평가 표준**.

→ 출전: Tough J. (1977) The Development of Meaning, Halsted Press.
