# 학령전 언어평가 도구 비교 — SELSI · PRES · REVT · U-TAP/U-TAP2

[[clinical/sources/2026-05-09-한국-영유아-언어평가-DLD-NISE]] § raw 5 (62KB 학령전 4도구 통합 심층 가이드) 정독 기반. **트랙 2 영유아·학령전 평가 시 어느 도구를 선택·병행할 것인가**의 결정 정본.

## 4 도구 통합 비교 매트릭스

| 항목 | **SELSI** | **PRES** | **REVT** | **U-TAP / U-TAP2** |
|---|---|---|---|---|
| **풀이** | Sequenced Language Scale for Infants | Preschool Receptive-Expressive Language Scale | Receptive & Expressive Vocabulary Test | Urimal Test of Articulation and Phonology |
| **개발자** | 김영태·김경희·윤혜련·김화수 | 김영태·성태제·이윤경 | 김영태·홍경훈·김경희·장혜성·이주연 | 김영태·신문자 (원판) / + 김수진·하지완 (U-TAP2 2020) |
| **적용 연령** | 4-35개월 | 2;0-6;11 (24-83개월) | 2;6-성인 (16세+) | 2;6-6;11 (원판) / 2;6-7세 (U-TAP2) |
| **검사 유형** | **선별 (Screening)** | **종합 진단 (Comprehensive)** | **어휘 특화** | **조음·음운 특화** |
| **시행 방식** | 양육자 보고 + 일부 직접 | 1:1 직접 | 1:1 직접 | 1:1 직접 |
| **소요 시간** | ~30분 | 60-90분 | 30-45분 | ~30분 |
| **하위 영역** | 수용 + 표현 (4 영역 통합) | 수용 + 표현 (각 90문항, 4 영역 분배) | REVT-R + REVT-E (각 ~185문항, 별도 어휘 풀) | 단어 수준 + 문장 수준 (U-TAP2) |
| **채점 단위** | +/-/NO 3원 | 정답률 → 등가연령 + 표준점수 | 등가연령 + 표준점수 + 백분위 | PCC (자음정확도) + 음운변동률 + 백분위 |
| **임상 절단점** | -1 SD (경계) / -2 SD (지연) | -1.25 SD ↑ 정상 / -2 SD ↓ 심한 지체 | 등가연령 6개월+ 지체 시 의심 | PCC 80%+ 정상 / 65-80% 약간 / <65% 지연 |
| **MVP 매핑** | F1-b 양육자 보고식 영감 | F1-a linguistic 종합 | F1-a linguistic 어휘 + persona-박민정 "수치 증명" | ⭐⭐ **F1-a articulation 직접** + HITL |

## 도구 선택 알고리즘 (임상 의사결정)

### 시나리오별 권장

```
[연령별 1차 선택]

만 0-2;5 (영유아):
  → SELSI 단독 또는 + 자유발화 관찰
     - 양육자 보고식 = 영유아 직접 검사 어려움 회피
     - 만 4개월부터 가능 = 가장 빠른 선별

만 2;6-3;11 (영유아 후기):
  → SELSI (35개월) → PRES + REVT 전환 시점
     - SELSI 만 35개월까지 가능 / PRES 만 24개월부터 시작
     - 24-35개월 중첩 영역 = 두 검사 병행 가능

만 4-6;11 (학령전):
  → PRES (종합) + REVT (어휘 보강) 병행이 표준
     - 의심 영역 발견 시 U-TAP (조음) 추가
     - 화용 영역 의심 = KOPLAC 추가

만 7세+ (학령기 진입):
  → REVT 단독 (성인까지) + U-TAP2 (만 7세까지)
     - PRES 적용 종료 (만 6;11 한계)
     - NISE-B·ACT (학습장애 검사) 병행 가능 (만 5세+ 학령전~학령기)
```

### 의심 영역별 조합

| 의심 영역 | 권장 조합 |
|---|---|
| **언어 발달 전반 지연** | SELSI (영유아) 또는 PRES (학령전) **단독** 1차 |
| **어휘 발달 지연** | PRES + **REVT-R/E** 병행 |
| **조음·음운 지연** | PRES + **U-TAP/U-TAP2** 병행 |
| **화용·사회적 의사소통 지연** | PRES + KOPLAC ([[clinical/entities/KOPLAC]]) — 본 비교 외 영역 |
| **다영역 종합 지연** | PRES + REVT + U-TAP2 + KOPLAC **4종 병행** (가장 정밀) |
| **선별만 필요 (대기 중)** | **SELSI 단독** (양육자 보고식, 30분) |

## 보완 관계 — 4 도구의 임상 가치 분배

```
SELSI (선별)
   ↓
   ├─ 의심 시 PRES (종합 진단)
   ↓
PRES (수용+표현 종합)
   ├─ 어휘 정밀화 → REVT-R/E
   ├─ 조음 정밀화 → U-TAP/U-TAP2
   └─ 화용 정밀화 → KOPLAC

→ 4 도구는 모두 김영태 교수 그룹 개발 (한국 영유아 언어평가 표준화 영역의 일관된 학파)
```

## 검사 시간 vs 임상 가치 매트릭스

| 도구 | 시간 | 정보 풍부도 | 사용 빈도 |
|---|---|---|---|
| SELSI | 30분 | ⭐ (선별만) | 매우 높음 (영유아 1차) |
| PRES | 60-90분 | ⭐⭐⭐ (종합) | 높음 (학령전 표준) |
| REVT | 30-45분 | ⭐⭐ (어휘만) | **가장 흔히 사용** (PRES와 보완) |
| U-TAP | 30분 | ⭐⭐ (조음만) | 높음 (조음 의심 시) |

→ **REVT가 가장 흔한 이유**: (1) 짧음 (30-45분) (2) 어휘 = 가장 시각적 임상 지표 (3) 광범위 적용 (만 2;6-성인) (4) 공동 사용 (PRES와 자주 병행).

## MVP 디지털 통합 매핑

### F1-a 3축 AI = 4 도구 임상 표준 통합

| 3축 | 임상 도구 |
|---|---|
| **articulation** ⭐⭐ | **U-TAP/U-TAP2** (음운변동 + PCC + 한국어 자음 발달 순서) |
| **linguistic (수용)** | SELSI (양육자) + PRES (직접) + REVT-R |
| **linguistic (표현)** | SELSI + PRES + REVT-E |
| **acoustic** | (임상 표준 도구 없음 — 기술 영역) |

### F1-b 5분 진단 — SELSI 양육자 보고식 직접 영감

- SELSI = 30분 양육자 보고식 → F1-b = 5분 간이 양육자 보고식 + 음성 직접 수집
- 입력 ≤3 항목 = SELSI 시작점·기저선 메커니즘 단순화

### F4 주간 리포트 — 시계열 임상 지표

| 임상 지표 | F4 시각화 |
|---|---|
| PCC (U-TAP) 65 → 80% | "발음 정확도 65→80점 (8주 추이)" |
| REVT 등가연령 24월 → 30월 | "어휘 발달 6개월 향상" |
| PRES 표준점수 -1.5 SD → -1 SD | "또래 100명 중 50→70 위치" |

→ 박민정 페르소나 (Seg B 데이터형 "수치 증명") 직접 매핑.

## 도구별 저작권 + MVP 활용 정책

| 도구 | 저작권 | MVP 활용 정책 |
|---|---|---|
| SELSI | 한국언어재활사협회 (또는 출판사) | 자극·문항 직접 사용 X / 측정 능력 영감만 차용 (ADR-04) |
| PRES | 김영태 외 (출판사) | 동일 — 영감 차용만 |
| REVT | 김영태 외 (출판사) | 동일 |
| U-TAP/U-TAP2 ⭐ | 김영태·신문자·김수진·하지완 | **추후 협력 가능성** (53차 보강 후보) |

→ MVP는 4 도구 모두 **임상 영감만 차용**. 직접 자극·문항 사용 X. ADR-04 (의료 용어 배제) + ADR-14 (F15 임상 안전 게이트) 정합.
