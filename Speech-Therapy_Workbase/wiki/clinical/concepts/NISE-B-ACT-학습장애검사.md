# NISE-B·ACT — 국립특수교육원 기초학습능력검사

[[clinical/sources/2026-05-09-한국-영유아-언어평가-DLD-NISE]] § raw 7 (38KB NISE-B·ACT 통합 바이블) 정독 기반. **자폐 검사가 아닌 학습장애 (Learning Disability) 검사** — 도구적 기술 (읽기·쓰기·수학) 정밀 진단.

> 🆕 **2026-06-07 실물 보강** — 검사도구 실물 스캔([[clinical/sources/2026-06-07-NISE-BACT-읽기-쓰기-검사방법]], 2017 원판)과 개정 연구보고서([[clinical/sources/2026-06-07-NISE-BACT-개정연구보고서-2-4년차]], 2025 개정안)를 정독하여 **읽기 5영역·쓰기 3소검사·수학·실시방법·채점 체계**를 확정하고, **2025 개정 변경점**을 반영함(아래 §"검사 도구 실물 구조" / §"2025 개정안 변경점"). 기존 "미정독" 공백 해소.

## 핵심 정보

| 항목 | 값 |
|---|---|
| **풀이** | National Institute of Special Education **B**asic Academic Competence Test |
| **개발** | 국립특수교육원 (National Institute of Special Education, NISE) |
| **목적** | **읽기·쓰기·수학 도구적 기술 (Tool Skills) 정밀 진단** — 학습장애 평가 |
| **적용 연령** | 만 5세+ 학령전 ~ 학령기 (정확히 만 5세-만 14세 추정) |
| **시행 방식** | 1:1 직접 검사 (자격자) |
| **자격** | 특수교사 / 임상심리사 / 언어재활사 (특수교육 영역) |
| **온라인 채점** | nise-test.com 플랫폼 + 자동 진단 보고서 |

## 검사 구조 — 4 영역

NISE-B·ACT는 **읽기·쓰기·수학** 3개 검사로 구성된다(각각 별도 책자). 아래 표는 텍스트 요약본 기준의 초기 정리이며, **실물 구조는 아래 §"검사 도구 실물 구조"에서 확정**한다.

| 검사 | 하위 영역(요약본 기준) |
|---|---|
| **읽기** | 음운(처리) / 글자·단어 인지 / 유창성 / 어휘 / 읽기 이해 |
| **쓰기** | 글씨 쓰기 / 철자하기(맞춤법) / 글쓰기 |
| **수학** | (원판) 수와 연산 등 → (개정안) 초기 수학·수와 연산·도형과 측정·수학적 탐구 |

→ 초기(53차) ingest는 텍스트 "바이블" § 제1-2강(읽기 음운인식·해독)만 정독했으나, **2026-06-07 실물 정독으로 전 영역 구조 확정**(§ 아래).

## 검사 도구 실물 구조 (2026-06-07 보강)

> 출처: [[clinical/sources/2026-06-07-NISE-BACT-읽기-쓰기-검사방법]] (2017 원판 실물 책자) + [[clinical/sources/2026-06-07-NISE-BACT-개정연구보고서-2-4년차]] (2025 개정안). **저작권 검사도구이므로 구조·실시·채점 체계만 기술하고 문항 자극은 옮기지 않음.**

### 읽기 검사 — 5개 하위검사

| 하위검사 | 소검사(개정안 기준) | 측정 구인 |
|---|---|---|
| **음운과 음절**(원판: 음운처리) | 음절합성·음절탈락·음절변별·음절대치·음소변별·[[clinical/entities/RAN-빠른자동이름대기]](사물/색깔, 1분) | 음운인식·음운 인출 자동화 |
| **글자·단어 인지** | 글자 인지·단어인지(규칙/불규칙·의미/무의미) | 자소-음소 대응·해독·표기 |
| **유창성** | 이야기글·설명글 (읽은 음절 수 측정) | 속도·정확성·표현력 |
| **어휘** | 단어이해·반대말·비슷한 말·유추·빈칸 채우기 | 양적+질적 어휘 |
| **읽기 이해** | 문장·짧은 글·중간 글·긴 글 이해 | 사실적·추론적·비판적·평가적 이해 |

### 쓰기 검사 — 3개 하위검사

| 하위검사 | 소검사(개정안 기준) |
|---|---|
| **글씨쓰기** | 글씨쓰기 기초(선 따라 그리기·글자 모양 찾기·자모 지식·낱말 만들기)·바르게 쓰기(모양·비율·띄어쓰기) |
| **맞춤법**(원판: 철자하기) | 받아쓰기(⏱)·철자 지식(고쳐쓰기·혼동 단어 등)·보고 기억해서 쓰기(단기기억) |
| **글쓰기** | 글쓰기 지식(문장 구성·어순·접속사·높임말·호응)·기초 글쓰기(문맥 단어·쓰기 유창성·단락 완성)·긴 글쓰기(작문·개요, 문항당 2~7분) |

### 수학 검사 — 4개 하위검사 (개정안 전면 재구성)

**초기 수학**(신규) · **수와 연산**(연산 유창성 제외) · **도형과 측정** · **수학적 탐구**. 4단계 수준 위계: 기초적 이해 → 기능적 수행 → 개념적 이해 → 응용과 추론. 원판은 검사요강 예시로만 확인(계산·분수·도수분포표·비율 등).

### 검사 실시 방법 (검사요강)

- **실시 순서**(쓰기 예): 글씨 쓰기 → 철자하기/맞춤법 → 글쓰기. **학년별 시작점 차등**(유치원~초2=글씨쓰기부터 / 초3~=철자하기 1번부터). 수행 매우 낮으면 **역순 실시**로 결함 원인 확인.
- 소요 약 **30~50분**, 가능하면 한 회기, 분리 시 **일주일 이내** 완료 권장.
- 검사자는 표시된 지시문을 정확히 읽어주고, **결정적 단서는 금지**. 자극은 학생에게, 정답·채점 기준은 검사자 쪽으로.

### 채점 체계

- 문항 공통 4단 구조: **문항(자극) → 검사실시방법 → 평가기준 → 채점**.
- 문항별 **0/1/2** 또는 **0/1** 척도(RAN·유창성 등은 시간·개수 기반). **기능적(질적) 기록법**으로 실제 오반응 기록 → 중재 계획용.
- 기록지: `번호·문항정답·학생반응·점수·총점` 표. → [[clinical/entities/U-TAP]] 음운변동 질적 기록과 정합.

## 2025 개정안 변경점 (⚠️ 원판 → 개정안)

> [[clinical/sources/2026-06-07-NISE-BACT-개정연구보고서-2-4년차]] 기준. 2017 원판 실물(책자)과 2025 개정안(예비검사)의 차이.

| 영역 | 2017 원판 | 2025 개정안 |
|---|---|---|
| 읽기 | 음운**처리** | 음운**과 음절**로 개칭 (소검사 5종 명료화) |
| 쓰기 | **철자하기** | **맞춤법**으로 개칭 + 글씨쓰기 2분리(기초·바르게쓰기) + 글쓰기에 **긴 글쓰기(작문)** 신설 |
| 수학 | 수와 연산(연산 유창성 포함) 등 | **4영역 재구성**(초기수학 신규·수학적 탐구) + 4단계 수준 + 연산 유창성 **제외** |
| 공통 | — | 2022 개정 교육과정 반영 + **문화·종교·지역 편향 배제**(이주배경 고려) |

- 개정 절차: 1년차(2024 수요조사) → **2년차(2025 예비검사, 본 보고서)** → 3년차(2026 표준화, 2,000명+임상 200명) → 4년차.

## 점수 체계

| 점수 | 의미 |
|---|---|
| **원점수 (Raw Score)** | 맞힌 문항의 단순 합계 — 정오 분석을 통한 질적 진단 |
| **연령 규준 (Age Norm)** | 동일 만 연령 내 상대적 위치 — **발달 지체 진단용** |
| **학년 규준 (Grade Norm)** | 동일 학년 내 상대적 위치 — 학교 학습 진단용 |

→ NISE-B·ACT의 특징 = **연령 규준 + 학년 규준 이중 사용** (PRES/REVT는 연령 규준만).

## 읽기 I — 음운인식 (Phonological Awareness)

### 측정 항목

- 음절 인식 (예: "사과" = 2 음절)
- 음소 인식 (예: "사" = ㅅ + ㅏ)
- 음운 변동 인식 (예: "닭" → [닥] 종성 자음군 단순화)

### 정오 판정 + 기능적 기록법

| 표기 | 의미 |
|---|---|
| O / X | 단순 정오 |
| **기능적 기록** | 학생의 실제 발음 메모 (예: "닭" → [다]) → 추후 중재 계획 시 "종성 처리 능력 부족" 같은 구체적 진단 가능 |

→ ⭐ **U-TAP 음운변동 평가와 직접 정합** ([[clinical/entities/U-TAP]] § 음운변동 평가).

## 읽기 I — 낱말·비단어 해독 (Decoding)

### 측정 항목

- 낱말 해독: "사과" → /sa-gwa/
- **비단어 (Non-word) 해독**: "기쟈" 같은 의미 없는 글자 → /gi-jya/
  - 비단어 = 통째 외움이 아닌 **음운 처리 능력** 검증 표준 방법

## 읽기 I — 읽기 유창성 (Reading Fluency)

- 1분 내 정확히 읽은 음절 수 측정
- 자동화 수준 평가

## MVP 위치 — ⛔ 회피 영역 + 부분 영감

### 회피 사유

| 영역 | 사유 |
|---|---|
| **읽기·쓰기·수학 = 학교 학습 영역** | MVP는 영유아 만 2-7세 가정 홈케어 = 학교 영역 회피 |
| **학습장애 진단** | MVP는 비의료 카테고리 = "학습장애 진단" 단어 차단 (ADR-04) |
| **만 7세+ 영역** | MVP 영유아 핵심 타깃 (만 2-7세) 외 |

→ **MVP 영유아 만 2-7세와 부분 중첩 (만 5-7세)**. 핵심 회피 영역은 아니지만 본 위키의 영유아 핵심 타깃 외.

### 부분 영감 (만 5-7세 영역)

만 5-7세 음운인식·해독 영역만 F1-a articulation에 부분 영감:

| NISE-B 영역 | F1-a 매핑 |
|---|---|
| 음운인식 | F1-a articulation의 **음소 단위 정밀 분석** 영감 |
| 음운 변동 인식 | U-TAP 음운변동과 동일 (어두/어중/어말 위치별 정확도) |
| 종성 처리 능력 | U-TAP § final_consonant_deletion 정합 |
| **읽기 유창성** | F1-a acoustic 영역 (말 산출 속도·자동화) 부분 영감 |

→ MVP 만 5-7세 사용자 = NISE-B 도구 사용자와 부분 중첩. F1-a 결과 발표 시 "학교 학습 준비도" 메시지로 학부모 전환 가능 (단, ADR-04 정합으로 "학습장애" 단어 X).

## 트랙 분류 — 신규 트랙 3 추가 가능성

| 트랙 | 영역 | MVP 위치 |
|---|---|---|

| **트랙 2** (사설) | DLD·조음장애·자폐 화용 (영유아·학령전) | **MVP 핵심 타깃** ⭐ |

## NISE-B·ACT 학술 활용 가능성

[[product/concepts/HITL-operations-policy]] § IRB 사전 확보 § A 카테고리 대학과의 학술 협력 가능성:

- **음운인식·해독 영역** = MVP F1-a articulation 모델의 학습 데이터 잠재 가치
- **만 5-7세 한국어 음소 발달 규준** = MVP 모델 검증 표준
- 단, NISE-B 자극·문항 직접 사용 X (저작권) → 영감만 차용
