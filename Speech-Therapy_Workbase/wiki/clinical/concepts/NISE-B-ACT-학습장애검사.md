# NISE-B·ACT — 국립특수교육원 기초학습능력검사

[[clinical/sources/2026-05-09-한국-영유아-언어평가-DLD-NISE]] § raw 7 (38KB NISE-B·ACT 통합 바이블) 정독 기반. **자폐 검사가 아닌 학습장애 (Learning Disability) 검사** — 도구적 기술 (읽기·쓰기·수학) 정밀 진단.

## 핵심 정보

| 항목 | 값 |
|---|---|
| **풀이** | National Institute of Special Education **B**asic Academic Competence Test |
| **개발** | 국립특수교육원 (National Institute of Special Education, NISE) |
| **목적** | **읽기·쓰기·수학 도구적 기술 (Tool Skills) 정밀 진단** — 학습장애 평가 |
| **적용 연령** | 만 5세+ 학령전 ~ 학령기 (정확히 만 5세-만 14세 추정) |
| **시행 방식** | 1:1 직접 검사 (자격자) |
| **자격** | 특수교사 / 임상심리사 / 언어재활사 (특수교육 영역) |
| **온라인 채점** | nise-test.com 플랫폼 + 자동 진단 보고서 |

## 검사 구조 — 4 영역

| 영역 | 하위 검사 |
|---|---|
| **읽기 I (해독·유창성)** | 음운인식 / 낱말·비단어 해독 / 읽기 유창성 |
| **읽기 II (이해)** | (raw 7 § 제3강 미정독) |
| **쓰기** | (raw 7 § 제4강 미정독) |
| **수학** | (raw 7 § 제5강 미정독) |

→ 본 위키 53차 ingest는 § 제1강 + § 제2강 (읽기 I)만 정독. § 제3-6강 (읽기 II / 쓰기 / 수학 / 종합 보고서) 추후 보강 가능.

## 점수 체계

| 점수 | 의미 |
|---|---|
| **원점수 (Raw Score)** | 맞힌 문항의 단순 합계 — 정오 분석을 통한 질적 진단 |
| **연령 규준 (Age Norm)** | 동일 만 연령 내 상대적 위치 — **발달 지체 진단용** |
| **학년 규준 (Grade Norm)** | 동일 학년 내 상대적 위치 — 학교 학습 진단용 |

→ NISE-B·ACT의 특징 = **연령 규준 + 학년 규준 이중 사용** (PRES/REVT는 연령 규준만).

## 읽기 I — 음운인식 (Phonological Awareness)

### 측정 항목

- 음절 인식 (예: "사과" = 2 음절)
- 음소 인식 (예: "사" = ㅅ + ㅏ)
- 음운 변동 인식 (예: "닭" → [닥] 종성 자음군 단순화)

### 정오 판정 + 기능적 기록법

| 표기 | 의미 |
|---|---|
| O / X | 단순 정오 |
| **기능적 기록** | 학생의 실제 발음 메모 (예: "닭" → [다]) → 추후 중재 계획 시 "종성 처리 능력 부족" 같은 구체적 진단 가능 |

→ ⭐ **U-TAP 음운변동 평가와 직접 정합** ([[clinical/entities/U-TAP]] § 음운변동 평가).

## 읽기 I — 낱말·비단어 해독 (Decoding)

### 측정 항목

- 낱말 해독: "사과" → /sa-gwa/
- **비단어 (Non-word) 해독**: "기쟈" 같은 의미 없는 글자 → /gi-jya/
  - 비단어 = 통째 외움이 아닌 **음운 처리 능력** 검증 표준 방법

## 읽기 I — 읽기 유창성 (Reading Fluency)

- 1분 내 정확히 읽은 음절 수 측정
- 자동화 수준 평가

## MVP 위치 — ⛔ 회피 영역 + 부분 영감

### 회피 사유

| 영역 | 사유 |
|---|---|
| **읽기·쓰기·수학 = 학교 학습 영역** | MVP는 영유아 만 2-7세 가정 홈케어 = 학교 영역 회피 |
| **학습장애 진단** | MVP는 비의료 카테고리 = "학습장애 진단" 단어 차단 (ADR-04) |
| **만 7세+ 영역** | MVP 영유아 핵심 타깃 (만 2-7세) 외 |

→ **MVP 영유아 만 2-7세와 부분 중첩 (만 5-7세)**. 핵심 회피 영역은 아니지만 본 위키의 영유아 핵심 타깃 외.

### 부분 영감 (만 5-7세 영역)

만 5-7세 음운인식·해독 영역만 F1-a articulation에 부분 영감:

| NISE-B 영역 | F1-a 매핑 |
|---|---|
| 음운인식 | F1-a articulation의 **음소 단위 정밀 분석** 영감 |
| 음운 변동 인식 | U-TAP 음운변동과 동일 (어두/어중/어말 위치별 정확도) |
| 종성 처리 능력 | U-TAP § final_consonant_deletion 정합 |
| **읽기 유창성** | F1-a acoustic 영역 (말 산출 속도·자동화) 부분 영감 |

→ MVP 만 5-7세 사용자 = NISE-B 도구 사용자와 부분 중첩. F1-a 결과 발표 시 "학교 학습 준비도" 메시지로 학부모 전환 가능 (단, ADR-04 정합으로 "학습장애" 단어 X).

## 트랙 분류 — 신규 트랙 3 추가 가능성

[[clinical/concepts/한국-언어치료-트랙비교]] § 트랙 1 (의료기관) / 트랙 2 (사설 센터) 외 **트랙 3 (학습장애·특수교육)** 신규 분류 가능:

| 트랙 | 영역 | MVP 위치 |
|---|---|---|
| **트랙 1** (의료) | 실어증·마비말장애·인공와우 (성인 + 영유아 의료) | 회피 (DTx) |
| **트랙 2** (사설) | DLD·조음장애·자폐 화용 (영유아·학령전) | **MVP 핵심 타깃** ⭐ |
| **트랙 3** (학습장애·특수교육) ⭐ 신규 | 읽기·쓰기·수학 (학령전~학령기) | 회피 + 부분 영감 (만 5-7세) |

→ 한국-언어치료-트랙비교 § 트랙 3 보강 후보.

## NISE-B·ACT 학술 활용 가능성

[[product/concepts/HITL-operations-policy]] § IRB 사전 확보 § A 카테고리 대학과의 학술 협력 가능성:

- **음운인식·해독 영역** = MVP F1-a articulation 모델의 학습 데이터 잠재 가치
- **만 5-7세 한국어 음소 발달 규준** = MVP 모델 검증 표준
- 단, NISE-B 자극·문항 직접 사용 X (저작권) → 영감만 차용

## ADR 정합

| ADR | NISE-B·ACT 정합 |
|---|---|
| **ADR-04 의료 용어 배제** | "학습장애" 단어 차단 — UI에서 "학습 준비도" 같은 표현 사용 |
| **ADR-14 F15 임상 안전 게이트** | NISE-B 시작 연령 (만 5세) = F15 활성 연령 (만 4세+)와 정합 |

## 자격·윤리

NISE-B·ACT 시행 자격 = 특수교사 · 임상심리사 · 언어재활사 (특수교육 영역). 본 위키 [[product/concepts/HITL-operations-policy]] § Expert pool에서 **트랙 3 자격자 별도 풀 가능성** (Phase 2+ 학습장애 영역 확장 시).
