### A. 한국 ID 화용언어 — 평가 표준 ⭐

**Kim, Kim, Kim & Song (2018), 시청각 담화과제(KOPLAC)를 통한 경도 지적장애 아동의 화용언어 특성** (이화여자대학교)
- *Communication Sciences & Disorders*. 36명 (12 mild ID + 12 CA-TD + 12 LA-TD)
- 선정 기준: K-ABC II 비언어성 IQ 55-70 + REVT 어휘력
- KOPLAC 3 하위영역: **의사소통 조율 / 담화·이야기 정보 추론 / 상위언어 인식**
- 결과:
  - CA-TD > ID, LA-TD: 의사소통 조율(대화상대·상황 조율) + 아이러니/은유
  - **ID = LA-TD**: 대부분 과제 (언어 연령 매칭 시 차이 사라짐)
  - **ID < CA-TD AND LA-TD on 이야기 산출** ⭐ — 언어 연령 매칭에도 이야기 결함 잔존 = ID 특이적 결함
- 임상 함의: ID는 단순한 언어 지연이 아니라 **이야기 산출 영역에 진정한 화용 결함** 보유 → 평가·중재 필수

**Cheon & Kim (2021), 경도지적장애 청소년의 마음이론과 화용언어의 연관성** (대구대학교)
- *Audiology and Speech Research*. 40명 (20 mild ID 청소년 19-21세 + 20 LA-matched)
- K-WAIS-IV FSIQ 70 이하 + 한국 청소년 대상 (단순 아동 X)
- 마음이론 평가: faux pas (실수로 상대 기분 상하게 한 말 인지) + 이차순위 마음읽기 + 애매한 행동 의미 파악 + 함축 의미 이해
- 결과: ID 청소년 < TD on 마음읽기 + 화용언어. **비언어 의사소통 ↔ faux pas 양 상관**
- 임상 함의: **청소년기 ID도 마음읽기 능력 중재 필요** — 학교·직업 적응의 사회적 토대

### B. 한국 ID 중재 — 4 패러다임 ⭐⭐

본 5편 정독에서 **한국 ID 언어중재의 4 핵심 패러다임** 식별:

#### 1. 사회적 의사소통 집단중재 (Group Intervention)

**장선미 (2014), 경도지적장애 청소년의 언어능력에 대한 사회적 의사소통 집단중재프로그램의 효과** (대구대 — 김화수 지도)
- 평가: 수용·표현 어휘력 + 구문의미 이해력 + **언어문제해결력 (원인이유·해결추론·단서추측 3유형)**
- 집단 중재 프로그램 구성 → 사전·사후 비교
- 결과: 3 유형 질문 모두 능력 향상 + 어휘력 향상

#### 2. 이야기 바꾸어 쓰기 (Story Rewriting)

**박성희 (2018), 이야기 바꾸어 쓰기 활동이 경도지적장애 청소년의 문제해결하기 능력에 미치는 효과** (대구대 — 최양규 지도)
- 동일한 **언어문제해결력 3 유형** 평가 (한국 ID 청소년 표준 측정)
- 이야기 바꾸어 쓰기 → 사전·사후 + 질적 분석
- 결과: 3 유형 모두 향상

#### 3. 애니메이션 동화 활용 (Animation-based Storytelling)

**이혜영 (2016), 애니메이션 동화를 활용한 말하기 지도가 지적장애아동의 일상적 언어능력 향상에 미치는 효과** (영남대 — 정은 지도)
- 단일대상 사전·사후 (3명)
- 근거: 지적장애아동 약 40%+가 3세 이후 첫 발화 (김영환 2000) + 수용·표현 모두 2-3년 지체 (Graham 1976)
- **흥미 유발 + 짧은 주의집중 호환** = 애니메이션 매체의 ID 적합성
- 결과: 수용·표현 어휘력 모두 향상 (품사별 분석)
- → [[clinical/concepts/내러티브-담화-추론-중재]] § 애니메이션 활용 중재 임상 근거 핵심

#### 4. 생각말하기 (Think-Aloud)

**송영옥 (2008), 생각말하기가 지적장애아동의 언어문제해결력에 미치는 효과** (대구대 — 권도하 지도)
- 한국 ID 생각말하기 중재의 효시 — 본문 추출 부분 손상 (제목·구조만 명확)
- 후속 연구의 토대 — § (1) 사회적 의사소통, § (2) 이야기 바꾸어 쓰기 모두 본 패러다임의 변형

### C. 한국 ID 연구 핵심 그룹

**대구대학교 언어치료학과**가 한국 ID 언어중재 연구의 중심:
- 김화수 (Kim Whasoo) — KOPLAC 적용 + 청소년 화용 + 다수 석사 지도
- 권도하 — 송영옥(2008) 생각말하기 지도
- 최양규 — 박성희(2018) 이야기 바꾸어 쓰기 지도
- 우혜진 (2021) — 어휘 의미추론 (범주·형태·주제)

이화여자대학교 (김영태 그룹) — KOPLAC 표준화 + 통합 연구

### E. ID 화용 ↔ ASD 화용 감별 ⭐

| 영역 | ID (Cheon & Kim 2021) | ASD ([[clinical/concepts/자폐-화용중재]]) |
|---|---|---|
| 마음이론 결함 | 있음 (청소년기까지 잔존) | 핵심 결함 |
| 이야기 거시구조 | 결함 (Kim 2018) | 결함 (King 2014) |
| 비언어 의사소통 | faux pas와 상관 | 표정·눈맞춤 결함 |
| 언어 연령 매칭 시 | 대부분 영역 차이 사라짐 | 거시구조·script-vs-non-script 차이 잔존 |
| 핵심 차별점 | **인지 능력 결함이 1차**, 화용은 2차 | **사회적 인지 결함이 1차**, 언어는 다양 |

→ ID와 ASD 모두 KOPLAC·언어문제해결력 검사 사용하지만, **ID는 인지 매칭 시 결함 약해지고 ASD는 잔존**.

| 이혜영 2016 — 애니메이션 동화 효과 | F15가 아닌 [[clinical/concepts/내러티브-담화-추론-중재]] § 애니메이션 활용에서 직접 매핑 |

#### G-1. 장은영 (2021) — 경도지적장애 성인 카툰 문식성 (대구대 — 김화수 지도)

- 신규 매체(카툰) 대상 ID 성인 문식성 연구
- 측정 영역:
  - **카툰에 나타난 추론이해능력**
  - **카툰 말풍선 채우기 표현 특징**
- → 본 위키 § B 4 패러다임 외 **신규 매체 영역** — § B에 5번째 패러다임 추가 후보

#### G-2. 박수진 (2019) — 경도 지적장애 학생 자기 표현적 글쓰기 (대구대 — 김화수 지도)

- **자기 표현적 글쓰기** = ID 학생의 정서·자아 표현 통합 영역
- ⭐⭐ 한국 ID 쓰기 평가 표준 측정 단위:
  - **T-unit** (Terminable unit — 종결 가능 단위 — Hunt 1965 Mervyn 적용)
  - **MLT-w** (Mean Length of T-unit in words — T-unit당 평균 낱말 수)
  - **NDW** (Number of Different Words — 다른 낱말 수, 어휘 다양성)

→ **MVP F1-a linguistic 영역 측정 단위 후보** — 영유아용으로는 단순화 필요 (T-unit → 발화 단위, MLT-w → 평균 발화 길이 MLU).

#### G-3. 이수진 (2021) — 경도 지적장애 성인 구문인식능력 (대구대 — 김화수 지도)

### J. 한국 ID 발달 위계 (본 11편 종합) ⭐

본 11편 통합으로 도출된 한국 ID 영역의 **발달 위계 정본**:

```
[학령전기]
  - 언어발달 지연 (어휘·구문 단순화)
  - 화용 결함 (이야기 이해·정보 전달 어려움)
        ↓
[학령기]
  - 화용언어 결함 잔존 (KOPLAC) — 박지혜·Kim 2018
  - 추론 결함: 언어유추 → 시각유추, 범주 → 반의어 → 기능 (김화수 외 2019)
  - 구문 결함: 내포문 사용 단순 (한수진 2011)
        ↓
[청소년기 (19-21세 기준)]
  - 마음이론 결함 잔존 (Cheon 2021) ← 사회 적응 핵심
  - 사회적 의사소통 집단중재 효과 (장선미 2014)
        ↓
[성인기]
  - 구문인식 결함 잔존 (이수진 2021) — 문법성 판단·오류수정
  - 카툰 등 문식성 영역 어려움 (장은영 2021)
  - 이야기 산출 구어·문어 차이 (논문번호 26)
```

→ ID는 **학령기 → 청소년 → 성인까지 결함이 잔존**하며 **자가 회복 X**. 지속적 중재 필요.
→ **MVP 위치**: 영유아 만 2-7세 = 본 위계의 **학령전기 진입 단계**. 조기 식별 + 부모 코칭이 핵심. 이후 단계는 트랙 3 (특수교육) 영역.

### K. AAIDD (2010) 지적장애 정의 ⭐⭐⭐ — Rhea Paul Ch4 직접 출전

본 텍스트 직접 인용 (Schalock et al. 2010 / [AAIDD](http://www.aaidd.org)):

> "**지적장애란 지적 기능과 적응 행동 모두에 심각한 제한을 나타내는 것이 특징인 장애로, 여기에는 많은 일상의 사회적 및 실용적 기술들이 포함된다. 장애는 18세 이전에 시작된다.**"

**진단 4 추가 요구사항** (AAIDD 2010):
1. 기능의 제한은 개인의 **연령 · 또래 집단 · 문화**에 맞는 전형적 환경 맥락 내에서 고려
2. 타당성 있는 평가는 **언어적 · 문화적 차이** 고려
3. 개인에게는 **한계점과 동시에 강점이 공존**
4. 한계점 기술의 중요한 목적은 **요구되는 지원의 프로필** 명시

→ ⭐⭐⭐ **본 위키 § A KOPLAC 정의에 ID 진단 표준 출전 정본 추가**:
- 본 § A (Kim 2018)에서는 K-ABC II IQ 55-70 사용 — AAIDD 정의 § "지적 기능" 측정 정합
- **AAIDD 4 요구사항 § 3 (한계점 + 강점 공존)** = MVP F1-b의 "현재 강점·요구 평가" (Sparks 1989) 정합
- AAIDD 4 요구사항 § 2 (언어·문화 차이) = [[clinical/concepts/다문화-언어발달]] § G CLD 검사 17 수정 제언 정합

### L. 다운증후군 언어 프로파일 (book p.134) — Rhea Paul Ch4 § 직접 인용

본 위키에서 처음 명시 — ID 하위 유전적 원인 영역:

| 영역 | 다운증후군 특징 (Down Syndrome) |
|---|---|
| **수용 vs 표현** | **표현 > 수용 손상** (Laws & Bishop 2003) |
| **형식 (음운·구문)** | 어군 축약·종성 생략·**말실행증**·중이 감염 인한 명료도 ↓ |
| **내용 (어휘)** | 표현 어휘 < 수용 어휘. **음운 작업기억 제한** (Jarrold 2009) |
| **화용 = 강점 영역** ⭐ | 상호 눈맞춤·발성·양육자 상호작용 + **대화 응답하기 + 주제 유지** 강점 (Beeghly 1991; Tager-Flusberg 1991) |
| **이야기 산출** | 줄거리·주제 요소 산출 많음 (그림책 자극) |
| **청소년기 퇴행** | 구문 이해의 전반적 인지·어휘량 대비 손상 + 청소년기 후반 고른 퇴행 (Laws & Gunn 2004) |

→ ID 영역에 다운증후군 = 독자적 언어 프로파일 인정 (단순 "ID" 일반화 ⛔)

### M. 취약 X 염색체 증후군 (FXS, Fragile X Syndrome) — Rhea Paul Ch4 § (book p.139) ⭐

본 텍스트 직접 인용 핵심 발견:

- **여아 > 남아 언어 능력** (성차 무뚜렷)
- **음운 인식 백분위수 10% 이하** (대다수 FXS 아동)
- **음운 단기기억 손상** (Baker 2011)
- **화용 = 결함 영역** (다운증후군과 정반대 ⭐):
  - 주제 벗어남
  - 보속어·반복 구어
  - 지연된 반향어
  - 전형적인 구의 사용
- **틀린 믿음 과제 (false belief task)** 결함 — but 사회 이해보다는 **작업기억·집행 조절 결함** 원인 (cf. ASD에서는 사회-인지 결함이 원인) ⭐⭐
- **FXS + ASD 동반 흔함** — 치료사는 ASD 동반 여부 반드시 확인

→ ⭐⭐ **본 위키 [[clinical/concepts/자폐-화용중재]] § ASD ↔ ID 감별 표 보강**:
- 마음이론 결함 원인 차이: **ASD = 사회-인지 결함 / FXS-ID = 작업기억·집행 조절**
- 화용 결함 패턴 동일하지만 **원인 메커니즘 다름** → 중재 접근 달라야

### N. 진단 범주의 임상 가치 3 가지 (book p.129)

Rhea Paul Ch4 직접 인용 — MVP ADR-04와 정합:

1. **서비스·교육 지원 접근 확보** — 언어치료·특수교육 진입을 위한 라벨 필요
2. **평가·중재 우선영역 힌트** — 예: ASD = 화용 영역 우선 평가
3. **임상 보고서·진료 기록 해석** — 진단명을 알면 다학제 팀 소통 가능

→ 동시에 **주의점** 명시 (book p.129-130):
- "**진단명이 평가나 중재에 있어 특정 아동의 요구를 언제나 정확하게 지시하는 것은 아니다**"
- "**아동은 하나의 진단적인 분류에 깔끔하게 맞아 들어가지 않는다**" — 다양성 존재
- "**언어장애의 본질에 대해 기술하는 것이 임상 치료에서 더 중요**" (vs 진단명 자체)

→ ⭐ **MVP ADR-04 직접 정합 정본**:
- MVP는 진단명 라벨 X — Rhea Paul의 "본질 기술" 접근 정합
- 단, 진단명 가치 3 가지 인정 → HITL 자격자에게는 진단명 정보 제공 가능 (전문가 의사결정 지원)

### O. APD (Auditory Processing Disorder) — 분과별 진단 분기 (book p.146)

본 텍스트 직접 인용:
> "주의를 잘 하지 못하고 언어 지연이 있는 아동은 **청각사에 의해 APD로 진단**받을 수도 있고, **언어병리학자에 의해서는 언어발달지체**로, **소아과 의사에게서는 ADHD**로 진단될 수도 있다."

→ Dawes & Bishop (2009): **APD가 하나의 독립된 진단 분류가 될 수 있는 자료가 없다**

→ ⭐ **MVP HITL 양 관점 명시 필수** (Jamie 사례와 정합):
- 동일 아동이 분과에 따라 다른 진단 가능
- HITL 자격자 풀의 다양성 ([[product/concepts/expert-diversity-monitoring]]) = 분과 편향 방어 메커니즘
- F1-a 단일 점수 X — 다층적 영역 결과 + HITL 통합 의견 필수

### 후속 ingest 잔여 (지적장애 영역)

본 11편 (5편 1차 + 6편 2차) 외 약 14편 미정독:
- 우혜진(2021) 어휘 의미추론 — 본 6편과 같은 대구대 김화수 그룹 (학위논문, 본문 일부 손상)
- 송영옥(2008) 생각말하기 — 본문 손상 (텍스트 레이어 부족)
- 인터넷 애니메이션 동화 — 지적장애 이야기·구문 (이미 D-3 이혜영과 유사)
- 배경지식 추론 듣기 — 학령기 정신지체
- 정신지체 듣기 추론 특성 (참고한 논문)
- 이야기 과제 — 경도지적장애 성인 구어·문어 산출
- 경도지적장애 학생의 이야기 쓰기 분석 (참고한 논문)
- 지적장애·자폐 단어유추추론 (이미 § F § E에 매핑)
- 인터넷 애니메이션·상황중심 이야기 꾸미기 등 중재 연구 일부 잔여
- → 본 영역 약 50% 본문 정독 완료. 다음 ingest 진행 또는 다른 영역으로 이동 가능.
