# 내러티브·담화·추론 중재 (Narrative-Discourse-Inference Intervention) ⭐ Synthesis

이야기담화(narrative discourse) 산출·이해·추론 영역의 cross-cutting synthesis. **단일 disorder가 아니라 ASD·SLI·지적장애·다문화·읽기부진·청능재활** 등 다양한 임상군에 공통 적용되는 중재 영역. 애니메이션·만화·이야기책 등의 자극 매체 활용이 한국 임상에서 활발.

> ⚠️ **본 페이지는 스텁(stub) — synthesis category** — 35+ 편의 추론·내러티브 논문이 분포. 후속 ingest에서 본문 보강 예정.

### A. 추론 발달 — 학령기 일반아동 ⭐

**김혜정 (2010), 학령기 아동의 동기 추론 능력에 관한 연구** (용인대 — 강정숙 지도)
- 초등 4학년 + 6학년 일반아동 각 20명 (총 40명)
- 3 이야기 유형 × 2 과제 유형 설계:
  - 이야기: **명시적 / 암시적 / 함축적**
  - 과제: 이해 질문 / 다시 말하기
- 핵심 발견:
  - 학년 ↑ → 동기 추론 능력 ↑ (4학년 < 6학년)
  - **이야기 유형 위계: 명시적 > 암시적 ≈ 함축적** ⭐
  - 과제 위계: 이해 질문 > 다시 말하기
  - 이야기 이해 ↔ 동기 추론 강한 상관 — 동기 추론은 이야기 전체 이해의 핵심 변인
- → **임상 적용**: 동기 추론 중재는 **명시적 → 암시적 → 함축적** 위계로 단계화 권장 (=F3-b 적응형 난이도 임상 토대)

**이지현 (2015), 학령기 아동의 증거성표지 발달과 마음이론 간의 관계** (부산가톨릭대 — 이희란 지도)
- 부산 초등 2·4·6학년 일반아동 72명
- 증거성표지(evidentiality) = 화자가 청자에게 정보 출처를 표시하는 언어 장치 (한국어 -더-, -데-, -겠-, -대-, -단다 등)
- 3 유형: **직접경험 / 간접경험 / 간접추론**
- 핵심 발견:
  - 학년 ↑ → 증거성표지 발달 (간접경험·간접추론에서 유의, 직접경험은 차이 없음)
  - 학년 ↑ → 마음이론 발달 (모든 학년 간 유의)
  - **마음이론 ↔ 간접 증거성표지 양 상관** — 직접경험은 무관 ⭐
- → **임상 함의**: 학령기 화용 평가 시 증거성표지 + 마음이론 통합 측정 필요. 한국어 특이적 화용 발달 지표.

### B. 임상군 추론 결함 — 양식 효과 ⭐

**백재은 (2013), 이야기 과제 양식(읽기·듣기·애니메이션)에 따른 언어학습장애 아동의 추론 능력** (이화여대 — 김영태 지도)
- LLD 아동 vs 학년일치 일반아동
- **3 양식 비교: 읽기 / 듣기 / 애니메이션 보기**
- 추론 유형: **근접추론 / 원접추론** (텍스트 기반 vs 텍스트 외 지식 활용)
- 추론오류 5유형 빈도·비율 분석
- → **임상 적용**: 양식별 차이 분석으로 LLD 아동의 강점 양식 식별 → 중재 계획 개별화

### C. 다문화 아동 서사담화 — 한국 임상의 신규 영역

**김현진 (2021), 학령기 다문화 아동의 단편 애니메이션 기반 이야기 과제에 나타난 서사담화 요소 특성** (대구대 — 김화수 지도)
- 학년(저학년/고학년) × 집단(다문화/단일문화) 2 × 2 설계
- **분석 영역**:
  - 이야기문법 5 하위범주: **배경 / 계기사건 / 시도 / 내적반응 / 결과**
  - 결속표지 5 하위범주: 지시적 대용 / 보조사 / 어휘적 결속 / 접속사 / 연결어미
- → 한국어 서사담화 분석의 표준 틀 제공
- cross-link: [[clinical/concepts/다문화-언어발달]] § 서사담화

### D. 애니메이션 활용 중재 패러다임 — F15 직접 영감 ⭐⭐⭐

**박후임 (2008), 애니메이션 텍스트를 활용한 추론 능력 신장 방안 연구** (광주교대 — 임성규 지도)
- 초등 국어 교육 — **17차시 추론 활동 프로그램** 개발 + 사전·사후 검증
- 핵심 추론 **8 유형**:

| # | 추론 유형 | 활동 예시 |
|---|---|---|
| 1 | **제목 통한 내용 추론** | 제목만 보고 이야기 예측 |
| 2 | **인물 말·행동 → 성격 추론** | 발화·행동 단서 종합 |
| 3 | **인물 감정 상태 추론** | 표정·맥락 단서 |
| 4 | **이어질 내용 추론** | 다음에 일어날 일 |
| 5 | **생략된 내용 추론** | 중간 빠진 사건 |
| 6 | **원인-결과 추론** | 인과 관계 |
| 7 | **배경 추론** | 시간·공간 단서 |
| 8 | **주제 추론** | 전체 의미 종합 |

- 결과: 실험반 사후 검사 추론적 이해 영역 가장 큰 향상 (낱말·내용·추론 3 영역 중)
- 함의: **애니메이션의 일시성·일과성 → 낱말 이해는 낮은 향상**, 추론은 큰 향상
- → 학생들이 애니메이션을 **무의식적·수동적으로 수용**하던 습관 → **능동적·적극적 매체 분석 태도** 변화 (메타인지 효과)

### E. F15 LLM 챗봇 직접 임상 토대 ⭐⭐

본 페이지는 [[product/concepts/MVP-feature-spec]] § F15의 **임상 토대 정본**:

**F15 챗봇 시나리오 8 유형 (박후임 2008 추론 8유형 직접 매핑)**

| 추론 유형 | F15 챗봇 시나리오 영감 |
|---|---|
| 제목 → 내용 | "오늘 그림 보고 어떤 이야기일까?" |
| 인물 성격 | "이 아이는 어떤 친구일까?" |
| 인물 감정 | "지금 어떤 기분일 것 같아?" |
| 이어질 내용 | "다음에 무슨 일이 일어날까?" |
| 생략된 내용 | "그림 사이에 빠진 부분은?" |
| 원인-결과 | "왜 그랬을까? / 그래서 어떻게 됐을까?" |
| 배경 | "여기 어디일까? 언제 일어난 일?" |
| 주제 | "이야기에서 알게 된 것은?" |

→ ADR-04 정합: UI 표현은 "치료" X, "이야기 만들기 / 같이 보기"

**F15 난이도 위계 (김혜정 2010 + 박후임 2008 통합)**

```
[Lv 1: 명시적 이야기]  → 본문에 답이 명시됨 (이해 질문 위주)
       ↓
[Lv 2: 암시적 이야기]  → 단서 통합 필요 (근접 추론)
       ↓
[Lv 3: 함축적 이야기]  → 배경지식·마음이론 동원 (원접 추론)
```

→ F3-b 적응형 난이도 엔진의 임상 토대.

**F15 평가 지표 (만 4-7세 영유아 적응)**
- 박후임의 17차시 = 학령기 대상 → MVP는 **만 4-7세 영유아 단순화**:
  - Lv 1 (만 4세) — 명시적 + 8유형 중 4개만 (성격·감정·이어질·원인결과)
  - Lv 2 (만 5-6세) — 암시적 + 8유형 중 6개 (배경·주제 추가)
  - Lv 3 (만 7세) — 함축적 + 8유형 전체 (생략·제목 추가)

**F15 자문 체크리스트 추가 항목 후보 5개**:
1. 8 추론 유형 모두 시나리오에 포함되는가?
2. 명시적 → 암시적 → 함축적 위계로 단계화되는가?
3. 한국어 증거성표지(-더-, -데-, -겠-) 발달 단계 정합?
4. 다문화 아동 서사담화 (이야기문법 5 + 결속표지 5) 측정 가능?
5. LLD 아동 강점 양식 (읽기·듣기·애니메이션) 선택 옵션?
