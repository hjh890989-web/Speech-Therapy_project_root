# 인공와우 청능재활 (Cochlear Implant Aural Rehabilitation)

인공와우 수술 후 아동 또는 성인이 소리를 의미 있는 언어로 받아들일 수 있도록 훈련하는 과정. 트랙 1(병원 기반)에 속하며, 매핑(기기 조정)과 청능훈련(언어치료실)이 병행된다.

## STEP 1: 매핑(Mapping)

수술 후 기기 착용 시 청신경에 전기적 자극을 주는 **소리 지도**를 주기적으로 조정. 아동의 청각 수준에 맞게 최적의 소리 환경을 설정하는 기초 작업이며, 이후 모든 청능훈련의 전제 조건이 된다.

## STEP 2: 청능훈련 4단계 위계

본 위계는 청능재활 전체의 뼈대이자, 제품 측 학습 콘텐츠 난이도 설계에 그대로 매핑될 수 있는 핵심 구조다.

| 단계 | 목표 | 구체적 활동 예시 |
|---|---|---|
| **1. 감지 (Detection)** | 소리의 유무 인지 | 악기·환경음 → "소리 들렸어?" → 고개 돌리기, 손 들기 |
| **2. 변별 (Discrimination)** | 두 소리의 같고 다름 구분 | '음~' vs '아~' 길이/크기 차이 구별, 긴 소리 vs 짧은 소리 |
| **3. 확인 (Identification)** | 들은 소리가 무엇인지 인지 | 그림 카드 2~3개 중 치료사가 말한 단어 카드 고르기 (**Closed Set**) |
| **4. 이해 (Comprehension)** | 대화 속 의미 파악 | 다단계 지시 수행("식탁 위 사과를 가져와 바구니에 담아주세요"), 그림책 듣고 질문 응답 |

## STEP 3: 세션 진행 흐름 (1회 약 40~50분)

| 단계 | 시간 | 내용 |
|---|---|---|
| 도입 | 5분 | 인공와우 장치 작동 확인, 배터리 점검, 좋아하는 소리(노래·악기)로 주의 집중 |
| 본활동 | 30~40분 | **놀이 중심 활동** — 초기: 소리 찾기 놀이("어! 무슨 소리지?" → "띠띠빵빵 자동차!") / 중기: 단어 카드 고르기, 소리 대조 / 후기: 이야기 나누기, 다단계 지시 |
| 부모 코칭 | 5~10분 | **청각 우선(Auditory First)**, **음향 강조**(중요 단어 느리거나 강조해서), 일상 소음 줄이기 |

## 부모 코칭 핵심 메시지
- **청각 우선**: 시각 단서 전에 먼저 소리로 자극
- **음향 강조**: 중요 단어를 느리거나 강조해서 ("우리 **빨간** 자동차 타자~")
- **소음 통제**: TV·음악 등을 줄여 청각적 집중 환경 조성

### C. 핵심 용어 정의 (한국어판) ⭐

본 영역 용어 위계 — 본 위키에서 처음 명시:

| 용어 | 정의 | 대상 |
|---|---|---|
| **청능재활 (Aural Rehabilitation)** | 청력손실로 잃은 듣기·의사소통 기능을 **회복**시키는 중재 | **성인** (이전에 청력 보유) |
| **청능자활 (Aural Habilitation)** | 듣기·말·언어기술이 **발달되지 않은** 사람들에게 새로 능력을 개발하는 중재 | **아동** (선천성 청각장애) |
| **청각재활 (Audiologic Rehabilitation)** | 청능재활의 동의어이지만, 청각기기(보청기·인공와우) 제공·관리 강조 | 광범위 |

→ 엄밀히 말해 본 위키 § "인공와우 청능재활" 제목은 부정확 — **인공와우 영유아는 "청능자활"이 옳음**. 다만 한국 임상 현장과 본 교재 모두 두 용어를 혼용. 후속 ingest에서 페이지 alias에 "인공와우 청능자활" 추가 검토.

```
[손상 (Impairment)]                  ← 청각 시스템의 구조적·기능적 손실 (예: 와우 유모세포 손상)

[활동제한 (Activity Limitations)]    ← 신체구조·기능 손상으로 인한 개인 수준 변화 (예: 회의실 대화 이해 어려움)
        ↓
[참여제한 (Participation Restrictions)] ← 활동제한의 사회·환경적 결과 (예: 사회 모임 회피)
        ↓
[생활방식 변화]                      ← 직업·가족·사회생활 영향
```

→ **WHO는 "장애(handicap)" 용어는 경멸적·오명 의미로 사용 자제 권고** (본 교재 1장 명시). MVP ADR-04 (의료 용어 배제) 정합 — UI에서 "청각장애" 단어 회피.

2. 생활방식
3. 빈번한 의사소통 파트너 (가족 구성원처럼 자주 대화하는 사람) ⭐
4. 심리사회적 요인

→ **3 (빈번한 의사소통 파트너)** = 본 위키 § STEP 3 부모 코칭의 임상 토대. **MVP 부모 매개 중재 (ADR-09 4 핵심기법)** 직접 정합.

### E. 청능사 vs 언어치료사 역할 분담 (ASHA 2002)

미국말언어청각협회(ASHA, 2002) 청능재활 담당 실무진 위촉 — 두 전문가 협력 체계:

| 영역 | 청능사 (Audiologist) | 언어치료사 (SLP) |
|---|---|---|
| 청각 시스템 기능·질환 | ⭐ 주도 | 기본 지식 |
| 발달·인지 | 공통 | 공통 |
| 청각 평가 | ⭐ 주도 | 기본 지식 |
| 말·언어 평가 | 보조 | ⭐ 주도 |
| 청각기기 측정·관리 | ⭐ 주도 | 기본 이해 |
| 의사소통 수행력 평가 | 보조 | ⭐ 주도 |
| 청력보존·음향 환경 | ⭐ 주도 | 기본 이해 |
| 학제 간 협력 | 공통 | 공통 |

→ **MVP 영향**: HITL 자격자 정의 시 **언어재활사 1·2급** 외에 **청능사** 자격도 ASD 회피 영역 중재 시 협력 풀로 검토 가능. 단, 본 영역은 명시적 회피 영역이므로 직접 적용 X.

→ **학교 환경에서는 언어치료사가 주도**: 1:1 접촉 시간이 길고 아동을 잘 알 수 있음. 청능사는 보청기 점검·교실 청각보조기기 설치 담당. → 한국 트랙 2 (사설 센터 + 학교 통합)와 정합.

#### B-4. 분석적 vs 종합적 훈련 — 본 교재 정의

> **분석적 훈련 (analytic training)**: 음절이나 음소와 같은 말 신호의 분절적 요소에 초점. 예: coat vs goat의 유성성 유무 인지

> **종합적 훈련 (synthetic training)**: 모든 소리나 단어를 인지하지 못하더라도 말의 의미를 인지하는 방법. 음절-by-음절 분석 X

→ "분석적 훈련과 종합적 훈련은 명백하게 양분되지 않으며 오히려 **연속선상**에 있다" (book p.142)

#### B-5. 형식적 vs 비형식적 훈련 — 본 위키 § STEP 3 부모 코칭 임상 토대 ⭐

> **형식적 훈련 (formal training)**: 지정된 날짜·시간에 치료사와 학생 일대일·소그룹 수업. 고도로 구조화. 강화 포함

> **비형식적 훈련 (informal training)**: 가족 구성원이 일상 환경에서 소리에 주의 기울이게 함. 예: "아내는 남편이 경적·새소리에 주의를 기울이게 하여 특정한 소리 패턴을 하나씩 이해할 수 있도록 비형식적 지시"

> "**어린 아동들은 주로 비형식적 훈련**을 받지만 성인들은 비형식적 훈련보다 형식적 훈련을 더 많이 받는 경향이 있다" (book p.142)

→ ⭐ **MVP 영유아 직접 정합**: 만 2-7세는 **비형식적 훈련 = 부모 매개 일상 환경 중재 = 본 위키 § STEP 3 부모 코칭**의 임상 표준 출전.

#### B-6. 4 가지 계획 원칙 § 4 — 난이도 6 변수 ⭐ (그림 4-5, book p.142-143)

본 위키에서 처음 명시. F3-b 적응형 난이도 엔진의 6 변수 임상 토대:

| # | 난이도 변수 | 쉬움 ↔ 어려움 |
|---|---|---|
| 1 | **자극 형태** | 폐쇄형 (closed-set) ↔ 제한형 (limited-set) ↔ 개방형 (open-set) |
| 2 | **자극 단위** | 단어 ↔ 구 ↔ 완전한 문장 |
| 3 | **자극 유사성** | 비슷하지 않음 (How are you? vs Hi) ↔ 비슷함 (bee vs pea, team vs Tim) |
| 4 | **맥락** | 높음 (부엌에서 시리얼 박스 들고) ↔ 낮음 (사무실에서) |
| 5 | **과제** | 구조화됨 (자기 이름 들을 준비됨) ↔ 자연스러움 (자발적 대화) |
| 6 | **신호대잡음비** (S/N) | 좋음 (조용함) ↔ 나쁨 (배경소음·음악) |

→ **임상 운영 기준** (book p.143):
- **80% 이상 정확도** → 난이도 수준 ↑
- **50% 이하 정확도** → 난이도 수준 ↓

→ ⭐⭐ **MVP F3-b 직접 매핑 정본**: F3-b 적응형 난이도 엔진의 80%/50% 임계 + 6 변수 = Tye-Murray Chapter 4 직접 차용. ADR-04에 따라 UI 표현은 "쉬움/보통/어려움" + "보기 수 적응형".

### C. 분석적 훈련 — 모음·자음 위계 (book p.144-152)

#### C-1. 청능 훈련 시작 단계 (book p.144) ⭐ — 4 단계 위계 명시

본 텍스트 직접 인용:
> "청능 훈련 프로그램의 시작 단계에서 일반적 커리큘럼은 훈련 목적과 목표의 위계를 구체화하면서 개발 또는 채택이 이루어진다. 만약 학생에게 청각 기술이 거의 없다면, 일반적으로 훈련은 **소리 인식**을 발달시키는 것부터 시작한다."

> "**소리 인식이 확립되었을 때**, 초기 청능 훈련 활동들은 **실로폰을 활용하는** 다음의 예처럼 **음량·음조·속도에 대한 총체적인 변별**을 포함한다:
> - **음량**: 실로폰을 부드럽게 치면서 학생에게 소리가 '부드러운지' 또는 '시끄러운지' 물어본다
> - **음조**: 옥타브를 높이면서 소리가 '높아지고 있는지' 또는 '낮아지고 있는지' 물어본다
> - **속도**: 음들을 빠르게 치면서 패턴이 '느린지' 또는 '빠른지' 물어본다"

> "**이런 유형의 과제에 숙달되면 분석적 및 종합적 훈련 활동을 시작한다**"

→ ⭐⭐⭐ **본 위키 § STEP 2의 4단계 위계의 본 교재 직접 정합**:

| 본 교재 단계 (book p.144) | 본 위키 § STEP 2 |
|---|---|
| **소리 인식** (Sound Awareness) | **1. 감지** (Detection) |
| **변별** (음량·음조·속도) | **2. 변별** (Discrimination) |
| **분석적 훈련** (모음·자음 인지) | **3. 확인** (Identification) |
| **종합적 훈련** (의미 이해) | **4. 이해** (Comprehension) |

#### C-2. 변별 vs 확인 — 표 4-5·4-6 (book p.145+)

본 텍스트 직접 인용 (book p.145):
> "학생이 모음 인식을 보이면, 모음 훈련 목표들은 **모음 자극들을 변별하고, 그 다음 그것들을 확인하는 것**이다."

> "전형적인 **변별 훈련**은 처음 세 가지 목표를 달성하기 위해 학생 앞에 **2개의 그림** 예를 들면, **bat과 boot의 그림**을 놓는다. 치료사가 단어 중 한 가지를 말하면 학생은 해당하는 단어를 **가리킨다**."

→ 변별 → 확인 → 이해 위계가 본 교재에 명시. 본 위키 § STEP 2 4단계 위계의 **세부 활동 예시 직접 출전**.

### K. 부모 상담 5 단계 — 정서적 단계 (book p.521)

본 텍스트 직접 인용:

#### K-1. 부모 5 단계 (book p.521) ⭐

| 단계 | 특징 | 임상 대응 |
|---|---|---|
| **1. 충격** | 명함·혼란·당혹감 | 임상가는 명확하고 단순한 정보 제공 |
| **2. 부정** | 청력손실 사실·결과의 확실함 부정 | 가족 시간·지원 제공 |
| **3. 슬픔** | 정상적·건강한 반응. 시간 흐름에 따라 안정 | Montoya 2007: 적극적 듣기 등 |
| **4. 죄의식·분노** | 자녀의 청력 잃음 책임감 | 정서 공감 + 정보 제공 |
| **5. 수용** | 아동의 청능재활 계획 적극 참여 | 단계 도달 시 중재 계획 활성 |

→ **임상 자기평가 체크리스트 (Edwards 2003 인용, p.521)**:
- "나는 부모들의 말을 결론 내리는 일 없이 진심으로 듣는가?"
- "자신의 느낌을 표현할 수 있음을 행동으로 보여주는가?"
- "부모들의 걱정과 이야기를 꺼낼 적절한 시점에 대해 세심함을 보여 주는가?"
- "청력손실에 대한 내용뿐만 아니라 느낌도 공유할 수 있는 기회를 부모들에게 제공해 주는가?"
- "부모들의 느낌을 지지해 주는가?"
- "부모들에게 자신의 요구사항을 말하는 기술을 보다 개발시켜 주는 경험들을 그들에게 제공해 주는가?"

→ **MVP F11 부모 음성 클로닝 동화 + HITL 전문가 자문 임상 토대**: 부모 정서 5 단계 인지 + 본 6 체크리스트 = HITL 1·2급 자격자의 부모 응대 표준. ADR-09 화이트리스트 (자연 상호작용만, 교정 X) 정합.

### FF. 청시각 통합 3 단계 모델 (그림 5-5) ⭐

```
청각적 단서  ┐
              ├─► 통합 ─► 어휘 목록 ─► 단어 반응
시각적 단서  ┘
```

| 단계 | 처리 |
|---|---|
| **1. 단서 지각** | 청각 단서 + 시각 단서 독립 지각 |
| **2. 통합** | 두 단서 결합 (음소 표준 형성) |

- "노인과 젊은 성인의 통합 능력에는 약간의 차이만"
- "청력 정상 사람 vs 청력손실 사람 간 통합 능력 차이는 **없다**"

→ ⭐ **MVP 임상 토대**: 청시각 통합 능력 = **연령·청력 손실과 거의 무관 보존 능력** → 부모 매개 동화 활용 가능 핵심 임상 자원.

### KK. 말 명료도 평가 3 방법 (책 p.603-604) ⭐

| 방법 | 절차 | 장단점 |
|---|---|---|
| **1. 등급 척도** (Johnson 1975) | 5점 척도 청자그룹 (1=전혀 이해 못함 → 5=모두 이해) | ⛔ 청자 모집 어려움, 다양성 한계 |
| **2. 받아쓰기** (Wilkinson·Brinton 2003) | 청자그룹이 들은 단어 받아쓰기 → 정확 백분율 | ✅ 안면타당도 높음 |
| **3. 음성 전사** (임상 표준) ⭐ | 임상가 들은 메시지 음성적 전사 → 정확 단어/소리 백분율 | ✅ **가장 일반적 사용** |

### LL. 말 명료도 영향 4 변수 (그림 15-14, 책 p.604) ⭐

| 변수 | 영향 |
|---|---|
| **말 자료 유형** | 문단 > 관련 없는 문장 목록 (문맥 효과) |
| **청자 경험** | 청각장애 아동 말 들은 경험 있음 > 없음 |
| **청취 조건** (시각 단서) | 보면서 들음 > 듣기만 |
| **청취 조건** (소음) | 조용한 환경 > 소음 환경 |

### OO. 언어 샘플 분석 — TTR + MSL (책 p.608)

|---|---|
