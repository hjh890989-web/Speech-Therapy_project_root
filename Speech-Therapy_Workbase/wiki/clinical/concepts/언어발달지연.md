# 언어발달지연 (Language Delay / DLD)

또래에 비해 수용·표현 언어 발달이 뒤처진 아동을 대상으로 하는 영역. 트랙 2(사설 센터/복지관 기반 아동 발달)에서 가장 흔하게 다뤄지는 대상이며, 어휘 확장 → 문장 구성 → 담화 능력의 단계적 향상이 핵심 목표.

- [[clinical/entities/KOPLAC]] (한국어 화용언어능력검사)

## 주요 활동

### (1) 어휘 확장
- **범주별 분류 놀이**: 동물·과일·탈것 등 그림 카드를 바구니에 분류 → "사과" 등장 시 "빨간 사과", "맛있는 사과", "사과는 과일이야"로 정보 확장
- **역할 놀이 (병원·마트)**: 청진기·주사기 등 소품 → 명사(소품 이름) + 기능 동사(진찰하다·치료하다·아프다) + 상황 어휘
- **그림책 활용**: "강아지가 뛰어가네" → "갈색 강아지가 공원을 빠르게 뛰어가네"로 문장 확장하며 어휘 노출

### (2) 문장 구성
- **징검다리 카드 놀이**: 바닥의 단어 카드를 밟으며 완성된 문장 산출 후 다음 단계로 이동
- **전략적 실패 (환경 조작)**: 좋아하는 장난감을 투명 통에 넣고 뚜껑을 꽉 닫음 → "뚜껑 열어주세요", "자동차 주세요" 등 2~3어문 이상 요구 문장 유도
- **사진/그림 보고 말하기**: 아동 "자동차" → 치료사 모델링 "빨간 자동차가 달려요" → 주어+동사+목적어 구조 격려

### 진단 체계 — 표준화 측정 도구별 절단점

| 도구 | 절단점 | 의미 |
|---|---|---|
| **SELSI** | 평균 10.39, SD 0.81. **-1 SD (≤7.03)** = 경계선 / **-2 SD (≤5.04)** = 지연·지체 | 즉각 중재 권장 |
| **PRES** | -1.25 SD ↑ 정상 / -1.25 ~ -2 SD = 약간 지체 / -2 SD ↓ = 심한 지체 | 심한 지체 = 즉각 중재 |
| **REVT** | 등가연령 ≥ 6개월 지체 시 의심 | 어휘 영역 표준 |
| **U-TAP** | PCC 80%+ 정상 / 65-80% = 약간 / <65% = 지연 | 조음 영역 표준 |

→ **임상가는 SELSI/PRES/REVT/U-TAP 중 다수 절단점 동시 위반 시 DLD 확정 진단**.

### 3단계 발달 가이드 (raw 6 정독)

**제1단계: 어휘 확장 + 수용 언어 증진**
- **의미적 매핑 (Semantic mapping)**: 사물 ↔ 기호 자의적 연결성 인지
- 0-11개월 영아: 옹알이 → 단어 인지
- 무발화·심각 지연 (2-3세 조기 식별):
  - 발음 완벽보다 발화 의도 수용·강화 우선
  - 조기 식별 시 **2년 이내 눈에 띄는 개선** 가능
- 본 위키 § 활동 (1) 어휘 확장 = 본 단계 정합

**제2단계: 단어 결합 + 구문론적 문장 구성**
- 50단어 표현 어휘 확보 후 두 단어 결합
- 명사+동사 / 형용사+명사
- "공 주고 컵 가져와" 작업 기억 능력 향상
- 본 위키 § 활동 (2) 문장 구성 = 본 단계 정합

**제3단계: 화용론적 응용 + 담화 능력**
- ⭐ **EMT (Enhanced Milieu Teaching) 환경 중심 언어중재**:
  - 환경 조작 (Environment arrangement): 흥미 사물 손 닿지 않는 곳에 배치
  - **반응 요구하기 (Mand-model)**: 아동의 반응 요구
  - 자연스러운 상호작용 + 4 핵심기법 융합
- SLI (단순언어장애) + 공동주의 결함 아동 통합 중재

→ 정본 [[clinical/concepts/아동언어치료-핵심기법]] § EMT 추가 보강.

### A. DLD 진단·평가 핵심 정의 (Darley 1991)

| 용어 | 영어 | 정의 |
|---|---|---|
| **평가** | appraisal / assessment / evaluation | 기록·사례력·부모 면접·질문지·아동 직접검사로 자료를 **수집**하는 과정 |
| **진단** | diagnosis | 다양한 정보의 연구·해석으로 **최종 결정**. 문제 파악·labeling·원인 추론. 의학적 모델에서 진단=질병 분류 |

→ 평가와 진단은 **계속되는 과정**. 단일 시점의 결과 X — 종단적 추적 필수.

### B. 임상가 팀 접근 3 모델 ⭐

[[clinical/concepts/한국-언어치료-트랙비교]]의 트랙별 임상가 협력 모델 표준:

| 모델 | 특성 | 의사소통 |
|---|---|---|
| **Multidisciplinary** | 각기 다른 분야 전문가로 구성. **독립적 평가 → 개별 추천** | 통합 채널 X |
| **Interdisciplinary** | 다분야 전문가 + **공식적 의사소통 채널**. **Manager가 서비스 통합** | 명시적 채널 |
| **Transdisciplinary** ⭐ | 팀 일원이 **분야 간 정보·기술 공유**. 한 명이 주로 평가, 나머지는 관찰·제안. **상호 훈련** | 가장 통합적 |

→ **MVP 영향**: HITL 시스템 = Transdisciplinary 모델 정합 — 1차 AI(언어재활사 자격) → HITL 큐 → 청능사·임상심리 등 다분야 자문 가능. 트랙 2 사설 센터 = Multidisciplinary 또는 Interdisciplinary 일반.

### C. DLD 진단 기준 — Fey (1986) ⭐⭐

**핵심 발견**: 국제 DLD 진단의 표준 기준이 본 자료에서 직접 명시됨:

> **Fey (1986): SD -1.25 이하를 언어장애로 판정** ⭐

→ 이는 [[clinical/sources/2026-05-09-한국-영유아-언어평가-DLD-NISE]]에서 보고된 PRES 절단점과 정합:
- **-1.25 SD 이상** = 정상
- **-1.25 ~ -2 SD** = 약간 지체
- **-2 SD 이하** = 심한 지체

→ Fey 1986이 PRES 절단점의 출전. 본 위키에서 처음 확인된 표준 출전.

### D. 차이 → 방해 → 장애 3단계 위계 ⭐

본 자료가 명시한 임상 판단 3 단계:

```
[차이 (difference)]
   질문: 말소리가 다른가? 언제, 어떤 문맥에서 차이가 나타나는가?
        ↓
[방해 (disturbance)]
   질문: 말이 달라서 의사전달을 방해하는가?
        ↓
[장애 (disorder)]
   질문: 차이와 방해가 어떤 측면에서 장애 상황을 발생시키는가?
```

→ **MVP ADR-04 직접 정합**: UI에서 "장애" 단어 회피 + "차이"·"방해"·"백분위" 등 중립 용어 사용. 본 3단계가 임상 표준 위계.

→ [[clinical/concepts/다문화-언어발달]] § 임상 핵심 이슈 1번 ("언어차이 vs 언어장애 감별")의 임상 토대.

### E. 언어평가 과정 5 단계

**의뢰 → 초기 상담 → 질문지 → 관찰 → 공식 검사 → 자발화 수집**

(1) **의뢰·초기상담·질문지** — 주양육자 역할:
- 평가·중재 과정의 핵심 정보원
- 아동 기능수준·지각문제 초기 정보
- 어린 아동 = 검사 어려운 행동의 정보원
- ⚠️ **정보 정확도가 떨어질 수도 있음** — 단호한 태도의 질문이 중요

→ **MVP F1-b 5분 진단 (양육자 보고식) 임상 토대 직접**: SELSI도 양육자 보고식 + 본 자료의 한계 인지 정합.

(2) **관찰** (놀이 또는 소통)
(3) **공식 검사** (표준화 검사)
(4) **자발화 수집** — 트랙 2 핵심

### F. 평가 결정 영역 + 평가 방법

**평가 결정 영역 3 축**:

| 축 | 하위 |
|---|---|
| **Language Function** | 이해 + 산출 |
| **Domains of Language** | form + content + use (Bloom & Lahey 모델) |
| **기타 영역** | hearing + speech-motor assessment |

→ MVP F1-a 3축 (articulation·linguistic·acoustic)와 정합:
- linguistic = Language Function (이해·산출) + Domains (form·content·use)
- articulation = speech-motor 영역
- acoustic = (기술 영역, 본 자료에 없음)

**평가 방법 5 종**:
1. 표준화검사 (norm-referenced) — REVT·PRES·U-TAP
2. 인터뷰·질문지 — SELSI 양육자 보고식
3. 발달척도
4. **준거참조 (criterion-referenced)** — 개별화 진전 측정 ⭐
5. 행동관찰 — ADL (Activities of Daily Living) 포함

→ 본 위키 [[clinical/concepts/학령전-언어평가-도구-비교]]의 4 도구가 모두 **표준화검사(1)** 카테고리. 트랙 2 사설 센터에서는 **(2) 인터뷰 + (4) 준거참조 + (5) 행동관찰** 의 통합 사용 일반.

### G. 사례 정보 수집 — 4 핵심 영역

언어치료사 면담의 4 핵심 질문:

1. **주 문제** (main complaints)
2. **시작 시기** — 항상? 갑작스러운가? 점진적인가?
3. **심각도 변화** — 상황·사람에 따라 악화·동일한가?
4. **사회적 상호작용** — 학교·사회 환경 실패 인식? 식구들 반응?

→ **MVP F1-b 입력 폼 ≤ 3 항목 정합 (효율적 측정)** + F4 시계열 진전도 추적의 임상 토대.

### H. 언어평가 목적 4 가지 ⭐

| # | 목적 | MVP 매핑 |
|---|---|---|
| 1 | **Screening** | F1-b 5분 진단 |
| 2 | **Baseline 기능 설정** | F1-a 3축 1차 측정 |
| 3 | **중재 목표 설정** | F4 개별 학습 경로 + F3 미션 |
| 4 | **중재 시 변화 측정** | F4 시계열 진전도 + KSF #2 효과 검증 |

### I. 진전 측정의 중요성 — EBP·RTI·역동적 평가

본 자료의 끝부분 핵심 키워드 3:

| 약어 | 풀이 | 의미 |
|---|---|---|
| **EBP** | Evidence-Based Practice | 근거기반 실제 — [[product/concepts/architecture-decisions]] § ADR 정합 |
