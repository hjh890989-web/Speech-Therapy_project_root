# 언어발달지연 (Language Delay / DLD)

또래에 비해 수용·표현 언어 발달이 뒤처진 아동을 대상으로 하는 영역. 트랙 2(사설 센터/복지관 기반 아동 발달)에서 가장 흔하게 다뤄지는 대상이며, 어휘 확장 → 문장 구성 → 담화 능력의 단계적 향상이 핵심 목표.

## 주요 활동

### (1) 어휘 확장
- **범주별 분류 놀이**: 동물·과일·탈것 등 그림 카드를 바구니에 분류 → "사과" 등장 시 "빨간 사과", "맛있는 사과", "사과는 과일이야"로 정보 확장
- **역할 놀이 (병원·마트)**: 청진기·주사기 등 소품 → 명사(소품 이름) + 기능 동사(진찰하다·치료하다·아프다) + 상황 어휘
- **그림책 활용**: "강아지가 뛰어가네" → "갈색 강아지가 공원을 빠르게 뛰어가네"로 문장 확장하며 어휘 노출

### (2) 문장 구성
- **징검다리 카드 놀이**: 바닥의 단어 카드를 밟으며 완성된 문장 산출 후 다음 단계로 이동
- **전략적 실패 (환경 조작)**: 좋아하는 장난감을 투명 통에 넣고 뚜껑을 꽉 닫음 → "뚜껑 열어주세요", "자동차 주세요" 등 2~3어문 이상 요구 문장 유도
- **사진/그림 보고 말하기**: 아동 "자동차" → 치료사 모델링 "빨간 자동차가 달려요" → 주어+동사+목적어 구조 격려

### 진단 체계 — 표준화 측정 도구별 절단점

| 도구 | 절단점 | 의미 |
|---|---|---|
| **SELSI** | 평균 10.39, SD 0.81. **-1 SD (≤7.03)** = 경계선 / **-2 SD (≤5.04)** = 지연·지체 | 즉각 중재 권장 |
| **PRES** | -1.25 SD ↑ 정상 / -1.25 ~ -2 SD = 약간 지체 / -2 SD ↓ = 심한 지체 | 심한 지체 = 즉각 중재 |
| **REVT** | 등가연령 ≥ 6개월 지체 시 의심 | 어휘 영역 표준 |
| **U-TAP** | PCC 80%+ 정상 / 65-80% = 약간 / <65% = 지연 | 조음 영역 표준 |

→ **임상가는 SELSI/PRES/REVT/U-TAP 중 다수 절단점 동시 위반 시 DLD 확정 진단**.

### 3단계 발달 가이드 (raw 6 정독)

**제1단계: 어휘 확장 + 수용 언어 증진**
- **의미적 매핑 (Semantic mapping)**: 사물 ↔ 기호 자의적 연결성 인지
- 0-11개월 영아: 옹알이 → 단어 인지
- 무발화·심각 지연 (2-3세 조기 식별):
  - 발음 완벽보다 발화 의도 수용·강화 우선
  - 조기 식별 시 **2년 이내 눈에 띄는 개선** 가능
- 본 위키 § 활동 (1) 어휘 확장 = 본 단계 정합

**제2단계: 단어 결합 + 구문론적 문장 구성**
- 50단어 표현 어휘 확보 후 두 단어 결합
- 명사+동사 / 형용사+명사
- "공 주고 컵 가져와" 작업 기억 능력 향상
- 본 위키 § 활동 (2) 문장 구성 = 본 단계 정합

**제3단계: 화용론적 응용 + 담화 능력**
- ⭐ **EMT (Enhanced Milieu Teaching) 환경 중심 언어중재**:
  - 환경 조작 (Environment arrangement): 흥미 사물 손 닿지 않는 곳에 배치
  - **반응 요구하기 (Mand-model)**: 아동의 반응 요구
  - 자연스러운 상호작용 + 4 핵심기법 융합
- SLI (단순언어장애) + 공동주의 결함 아동 통합 중재

→ 정본 [[clinical/concepts/아동언어치료-핵심기법]] § EMT 추가 보강.

### A. DLD 진단·평가 핵심 정의 (Darley 1991)

| 용어 | 영어 | 정의 |
|---|---|---|
| **평가** | appraisal / assessment / evaluation | 기록·사례력·부모 면접·질문지·아동 직접검사로 자료를 **수집**하는 과정 |
| **진단** | diagnosis | 다양한 정보의 연구·해석으로 **최종 결정**. 문제 파악·labeling·원인 추론. 의학적 모델에서 진단=질병 분류 |

→ 평가와 진단은 **계속되는 과정**. 단일 시점의 결과 X — 종단적 추적 필수.

### B. 임상가 팀 접근 3 모델 ⭐

[[clinical/concepts/한국-언어치료-트랙비교]]의 트랙별 임상가 협력 모델 표준:

| 모델 | 특성 | 의사소통 |
|---|---|---|
| **Multidisciplinary** | 각기 다른 분야 전문가로 구성. **독립적 평가 → 개별 추천** | 통합 채널 X |
| **Interdisciplinary** | 다분야 전문가 + **공식적 의사소통 채널**. **Manager가 서비스 통합** | 명시적 채널 |
| **Transdisciplinary** ⭐ | 팀 일원이 **분야 간 정보·기술 공유**. 한 명이 주로 평가, 나머지는 관찰·제안. **상호 훈련** | 가장 통합적 |

→ **MVP 영향**: HITL 시스템 = Transdisciplinary 모델 정합 — 1차 AI(언어재활사 자격) → HITL 큐 → 청능사·임상심리 등 다분야 자문 가능. 트랙 2 사설 센터 = Multidisciplinary 또는 Interdisciplinary 일반.

### C. DLD 진단 기준 — Fey (1986) ⭐⭐

**핵심 발견**: 국제 DLD 진단의 표준 기준이 본 자료에서 직접 명시됨:

> **Fey (1986): SD -1.25 이하를 언어장애로 판정** ⭐

→ 이는 [[clinical/sources/2026-05-09-한국-영유아-언어평가-DLD-NISE]]에서 보고된 PRES 절단점과 정합:
- **-1.25 SD 이상** = 정상
- **-1.25 ~ -2 SD** = 약간 지체
- **-2 SD 이하** = 심한 지체

→ Fey 1986이 PRES 절단점의 출전. 본 위키에서 처음 확인된 표준 출전.

### D. 차이 → 방해 → 장애 3단계 위계 ⭐

본 자료가 명시한 임상 판단 3 단계:

```
[차이 (difference)]
   질문: 말소리가 다른가? 언제, 어떤 문맥에서 차이가 나타나는가?
        ↓
[방해 (disturbance)]
   질문: 말이 달라서 의사전달을 방해하는가?
        ↓
[장애 (disorder)]
   질문: 차이와 방해가 어떤 측면에서 장애 상황을 발생시키는가?
```

→ **MVP ADR-04 직접 정합**: UI에서 "장애" 단어 회피 + "차이"·"방해"·"백분위" 등 중립 용어 사용. 본 3단계가 임상 표준 위계.

→ [[clinical/concepts/다문화-언어발달]] § 임상 핵심 이슈 1번 ("언어차이 vs 언어장애 감별")의 임상 토대.

### E. 언어평가 과정 5 단계

**의뢰 → 초기 상담 → 질문지 → 관찰 → 공식 검사 → 자발화 수집**

(1) **의뢰·초기상담·질문지** — 주양육자 역할:
- 평가·중재 과정의 핵심 정보원
- 아동 기능수준·지각문제 초기 정보
- 어린 아동 = 검사 어려운 행동의 정보원
- ⚠️ **정보 정확도가 떨어질 수도 있음** — 단호한 태도의 질문이 중요

→ **MVP F1-b 5분 진단 (양육자 보고식) 임상 토대 직접**: SELSI도 양육자 보고식 + 본 자료의 한계 인지 정합.

(2) **관찰** (놀이 또는 소통)
(3) **공식 검사** (표준화 검사)
(4) **자발화 수집** — 트랙 2 핵심

### F. 평가 결정 영역 + 평가 방법

**평가 결정 영역 3 축**:

| 축 | 하위 |
|---|---|
| **Language Function** | 이해 + 산출 |
| **Domains of Language** | form + content + use (Bloom & Lahey 모델) |
| **기타 영역** | hearing + speech-motor assessment |

→ MVP F1-a 3축 (articulation·linguistic·acoustic)와 정합:
- linguistic = Language Function (이해·산출) + Domains (form·content·use)
- articulation = speech-motor 영역
- acoustic = (기술 영역, 본 자료에 없음)

**평가 방법 5 종**:
1. 표준화검사 (norm-referenced) — REVT·PRES·U-TAP
2. 인터뷰·질문지 — SELSI 양육자 보고식
3. 발달척도
4. **준거참조 (criterion-referenced)** — 개별화 진전 측정 ⭐
5. 행동관찰 — ADL (Activities of Daily Living) 포함

→ 본 위키 [[clinical/concepts/학령전-언어평가-도구-비교]]의 4 도구가 모두 **표준화검사(1)** 카테고리. 트랙 2 사설 센터에서는 **(2) 인터뷰 + (4) 준거참조 + (5) 행동관찰** 의 통합 사용 일반.

### G. 사례 정보 수집 — 4 핵심 영역

언어치료사 면담의 4 핵심 질문:

1. **주 문제** (main complaints)
2. **시작 시기** — 항상? 갑작스러운가? 점진적인가?
3. **심각도 변화** — 상황·사람에 따라 악화·동일한가?
4. **사회적 상호작용** — 학교·사회 환경 실패 인식? 식구들 반응?

→ **MVP F1-b 입력 폼 ≤ 3 항목 정합 (효율적 측정)** + F4 시계열 진전도 추적의 임상 토대.

### H. 언어평가 목적 4 가지 ⭐

| # | 목적 | MVP 매핑 |
|---|---|---|
| 1 | **Screening** | F1-b 5분 진단 |
| 2 | **Baseline 기능 설정** | F1-a 3축 1차 측정 |

### B. ASHA (1993) DLD 정의 — 본 교재 직접 인용 (book p.3-) ⭐⭐⭐

본 텍스트 직접 인용:
> "미국말언어청각협회 (American Speech-Language-Hearing Association, ASHA)는 언어장애를 '구어, 문어, 그리고 또는 기타 상징체계의 이해 그리고 또는 사용에서의 결함이다. 장애는 다음을 포함한다.
> (1) 언어의 형식 (form: **음운론·형태론·구문론**)
> (2) 언어의 내용 (content: **의미론**)
> 그리고 또는 (3) 의사소통의 언어 기능 (**화용론**)
> 또는 어떤 형태든 이들의 조합'(1993, P.40)이라고 정의하였다."

→ ⭐⭐⭐ **ASHA 1993 DLD 정의 = 본 위키 § 보강 필요 § DSM-5/ICD-11 진단 기준의 표준 출전**:
- **3 영역 매트릭스**: form (음운·형태·구문) / content (의미) / use (화용)
- **Bloom & Lahey (1978)** 모델의 ASHA 공식 적용
- 본 [[clinical/sources/2026-05-09-한국-영유아-언어평가-DLD-NISE]] § E의 "Domains of Language — form, content, use"는 ASHA 1993 직접 출전

### C. DLD 진단의 2 조망 — Tomblin (2008) ⭐⭐

본 텍스트 직접 인용:

#### C-1. 자연주의적 조망 (Naturalist View)

> "이 정의는 유사한 사람들의 집단에 의해 성취되는 평균 수준의 능력으로부터의 이탈로 손상(impairment)을 특징짓는다는 점에서 **자연주의적(naturalist) 조망 (Tomblin, 2008)**을 가정하는 것이다."

→ **Fey (1986) SD -1.25 절단점 = 자연주의적 조망의 직접 적용** (본 § C 1차 보강과 정합)

#### C-2. 규준적 조망 (Normative View) ⭐ — 본 위키에서 처음 명시

본 텍스트 직접 인용:
> "Tomblin (2008)은 이를 **규준적(normative) 조망**이라 하였는데, 이는 **개인의 행동에 대한 사회적 가치와 기대**를 고려하는 것이다. 그는 '아동의 언어 성취 수준이 바람직하지 못한 결과를 낳을 만큼의 수용 불가한 수준일 때 언어장애가 존재한다'라고 주장하였다 (P.95)."

> "**언어장애란 오직 이것이 현재 또는 미래에 사회적 기대에 부합하는 아동의 능력을 방해할 때에서야 비로소 진단될 수 있는 것이다**. 이것은 사회적 관계성, 학업성취, 그리고 미래의 고용의 기회와 관련된 결함을 포함하는 것이다."

→ ⭐⭐ **MVP ADR-04 (의료 용어 배제) 직접 정합 — 규준적 조망**:
- "장애" 라벨링 X, **사회적 기대 부적합** 으로 진단
- "차이 → 방해 → 장애 3단계 위계" (1차 보강 § D)의 임상 토대 정본
- MVP "회색지대 부모 30-50만" 타깃 = **규준적 조망의 사회적 의심** 단계 정합

### D. DLD 진단의 핵심 어려움 — 본 교재 직접 인용 (book p.3)

본 텍스트 직접 인용 (Jamie 사례):
> "Jamie라는 6살 아동은 9월에 언어평가에 의뢰되었을 때, 학교의 SLP인 Reese는 수용 및 표현언어 측면에서 **4세 수준**으로 기능하고 있다고 보고하였다."
> "학교심리학자: 비언어성 기술 IQ 검사가 **경계선급**이지만 전반적으로 지체되거나 특수학급 배치 보장되어야 할 만큼 낮지는 않다."
> "Reese 선생님: **언어기술이 명백히 생활연령 수준 아래** → 자신의 사례에 포함"
> "후임 Timmons 선생님: **정신연령 4세 2개월에 근거하여 Jamie가 기대되는 바의 언어수준으로 기능** → 사례에서 제외"

→ ⭐⭐ **MVP F1-a 임상 의사결정 핵심 모순**:
- 생활연령 기반 평가 (Reese) vs **정신연령 (인지) 기반 평가** (Timmons)
- 둘 다 임상적으로 정당 — 어느 것이 옳은가는 결정자에 따라 달라짐
- → **HITL 전문가 자문 시 양 관점 명시 + 부모 의사결정 지원 필수** ([[product/concepts/HITL-system-flow]] § groundTruthScore)

### E. DLD 분야의 30+ 년 합일점 결여 — 본 교재 직접 인용 ⭐

> "30여 년이 지난 지금도 어떤 다른 대륙에서는 우리 중 다른 이들이 마찬가지의 토론에 몰두하고 있을 것이라는 사실이다. 그리고 심지어 오늘날까지도 언어발달을 지원하는 기반과 기제에 대한 우리의 이해가 진보했음에도 불구하고, **우리는 여전히 언어발달장애가 무엇인지, 그리고 이를 어떻게 정의해야 하는지, 또는 이를 무엇이라 불러야 옳을지에 관한 거의 명확한 합일점을 아직 찾아내지 못하였다**."

→ Rhea Paul 자체가 DLD 정의의 합일점 결여를 학문 분야 전체의 특징으로 인정. CATALISE (2017) 시도 이후에도 아직 진행 중.

#### K-2. 영아 평가 5 영역

본 텍스트 직접 인용:
> "첫째, 영아가 직면한 위험요인이 어떤 것이 있는지..."

→ 영아 평가 다층 모델:
1. **위험요인 평가** (NICU 노출, 체중, 의료 상태)
2. **생리적 조직화 수준** (조산아 미숙)
3. (잠재 — 본 OCR에서 미추출) 의사소통 능력
4. (잠재) 의사소통 환경
5. (잠재) 가족 요구

### Y. 문해전 발달 (Preliteracy Development) — book p.336 ⭐⭐⭐

본 텍스트 직접 인용:
> "**초기 언어 기간은 전형적으로 정상 발달하는 아장이들이 책이나 인쇄물을 통해 중요한 경험을 확득하는 시점**" (Dodici, Draper, Peterson 2003)

> "**부모들로 하여금 자녀에게 책을 읽어주게 하는 일은 수용 및 표현언어 증가를 가져온다**" (Trivette, Dunst, Gorman 2010 메타고찰)

#### Y-1. 가족 매개 책 읽기 5 전략 (Bernadowski 2008 외)

1. **발달적으로 적합하고 매력적인 책**을 가족과 함께 선택
2. 그림-글 관련성 가리키기 + **정례화된 상호작용 위기** (예: "fill in" — 아동이 채워 넣도록 잠시 멈춤)
3. 부모가 **과장된 억양·강세** 사용 (중요 요소 강조)
4. 책 주제 관련 **놀이 활동** 개발 (예: One Fish Two Fish 후 집 안에서 빨간·파란 것 찾기)
5. **탈맥락화된 말 노출** (예: 아동이 물고기 본 횟수 말하기)

→ ⭐⭐⭐ **MVP F11 동화 콘텐츠 직접 임상 토대**:
- F11 음성 클로닝 storybook = 5 전략의 디지털 변형
- 정례화된 상호작용 (fill in) = F15 챗봇 발화 유도 패턴 정합 — Mand-Model의 책 버전
- ADR-09 화이트리스트 (storybook·lullaby ALLOWED) = 본 5 전략 직접 정합

→ ⭐ **장애 아동들이 책 노출 적게 받는 경향** (Goin, Nordquist, Twardosz 2004) — MVP 사회경제적 격차 해소 메커니즘 강화

### AD. MLU + IPSyn — 학령전 평가 표준 단위 ⭐⭐⭐

#### AD-1. Miller (1981) — MLU 분석 절차

- **MLU (Mean Length of Utterance)** — 평균 발화 길이
- 5 단계 (Brown's Stages): I·II·III·IV·V·V+

#### AD-2. Scarborough (1990) — IPSyn (Index of Productive Syntax) ⭐⭐⭐

> "**Scarborough(1990)는 Miller(1981)의 절차를 규준참조적으로 확대한 IPSyn을 제시. IPSyn은 50~100개의 발화표본에서 각 언어구조가 2개 출현하는 '표현성' 규준을 사용**"

| 단위 | MLU | IPSyn |
|---|---|---|
| 측정 | 발화 길이 (단순 평균) | 구문 구조 상세 (5 발달범주) |
| 출현 횟수 | 모든 발화 | **첫 2번만 계산** (효율적) |
| 정보 | 단순 수치 | 어떤 구조가 출현했는지 + 구문 진전 |
| 중재 추적 | 가능 | **더 정교한 진전 측정 가능** ⭐ |
| 소프트웨어 | — | **Computerized Profiling** (Long & Fey 2004) |

→ ⭐⭐⭐ **MVP F1-a + F4 임상 토대 정본**:
- **F1-a linguistic 측정**: MLU (기초) + IPSyn (정교)
- **F4 시계열 진전 추적**: IPSyn 구문 진전 패턴 = MVP F4 시계열 차트 임상 토대
- Long & Fey 2004 = 컴퓨터화 = **MVP F1-a 자동화의 임상 토대 표준**

### N. IDEA (장애인교육법) 'evaluation' vs 'assessment' 구별 (book p.30) ⭐

본 텍스트 직접 인용 (Individuals with Disabilities Education Improvement Act of 2004, PL 108-466):

### O. 평가 도구의 5 기준 (book p.50-51) ⭐⭐

본 텍스트 직접 인용:

1. **신뢰도** (reliability) — 동형검사 신뢰도 (예: Peabody A형 vs B형 일치도)
2. **타당도** (validity)
3. **진단 정확도** (diagnostic accuracy) — Dollaghan (2004) ⭐
4. **표준화** (standardization) — 규준 표본 ≥ **100명/연령대**, 다양성, 사회경제적·인종적 배경 포함
5. **표본 대표성** — 단일 지역·편협한 배경 X

→ ⭐⭐ **MVP F1-a 학습 데이터셋 구성 임상 토대 정본**:
- 모델 검증 시 **신뢰도 + 타당도 + 진단 정확도** 3축 동시 측정 필수
- 표준화 = **다양성 + ≥100명/연령대** = HITL 자격자 풀의 다양성 모니터링 ([[product/concepts/expert-diversity-monitoring]]) 정합

### X. CHAPTER 8 학령전기 말표본 분석 — Owens 2004 발화 분류 ⭐⭐

#### X.1 발화 분류 5 규칙 (Owens 2004)

| 규칙 | 활동 |
|---|---|
| **1.** 한 문장 = 한 발화 | "Mommy will go to the store... tomorrow" = 1 발화 |
| **2.** 한 명령문 = 한 발화 | "Go home!" = 1 발화 |
| **3.** "and"로 연결된 run-on 문장 = 첫 "and" 포함, 이후 추가 발화 | "We went... and we got... and we saw..." → 3 발화 |

#### X.2 MLU 계산 6 규칙 (Brown 1973, Chapman 1981) ⭐⭐

본 OCR 정본 (책 p.381 글상자 8-4):

| 단계 | 활동 |
|---|---|
| **1.** 말표본 발화 분류 | (§ X.1) |
| **2.** 각 발화를 다른 줄에 전사 | — |
| **3.** 연속적·명료 발화 **50개** 선택 (불명료 제외) | — |
| **4.** 형태소 계산 6 규칙 (a-f) | 아래 |
| **5.** 형태소 총 수 / 발화 수 (보통 50) | MLU |

**형태소 계산 6 규칙**:
- **a.** 자립 (낱말) + 의존 (활용어미: -s 복수, -'s 소유, -s 3인칭, -ed 과거, -ing 진행) 각각 1개
- **b.** 말 더듬·잘못 시작 = 각 낱말 1개. 강조 반복 ("No, no, no!") = 모두 계산
- **c.** 합성어 (birthday), 고유명사 (Mickey Mouse), 중첩어구 (night-night) = 1 형태소
- **d.** 불규칙 과거 (went, saw, came) = 1 형태소. 과잉일반화 (goed, comed) = 2 형태소
- **e.** 지소사 (doggie, toesie) = 1 형태소
- **f.** 조동사 (s, are, was, were, have, had, will, could, can, would, must, might, shall, should) 축약되어도 1개 (He's = 2 형태소)

→ ⭐ **MVP F1-a K-MLU 자동 산출 임상 토대 영문 표준**. 한국어 적용 시 조사·종결어미 별도 규칙 필요 ([[product/concepts/MVP-clinical-foundation]] § 2.4 한국어 특이성 잠재 후보).

#### X.3 MLU 보완 — NDW (Number of Different Words) ⭐

본 OCR 정본 (Eisenberg, Fersko, Lundgren 2001 / Klee et al 2004 / Leonard & Finneran 2003):

> "다른 낱말수 (NDW)와 같은 언어 표현에 대한 다른 정보와 함께 제시될 때, MLU는 여전히 아동의 언어 수준을 알려주는 가치 있는 방법이다."

→ ⭐ **MVP F1-a 임상 토대**: MLU + NDW 통합 = 한국 자격시험 출제 표준 + 자동 산출 가능.

- **MLU < 3** = 의미관계 분석 (Lahey 1988 의미-구문 절차)
- **MLU 3-4.5** = 형태·구문 표지 분석
- **MLU > 4.5** = 복합문 발달 분석

| 원칙 | 핵심 |
|---|---|

| **4. 흥미 기반** | 놀이 평가 결과 → 아동 현재 지식·흥미 |
