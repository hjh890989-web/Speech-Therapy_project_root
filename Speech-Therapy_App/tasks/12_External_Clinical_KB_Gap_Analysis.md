## 1. 핵심 발견 (요약)

1. **현재 스펙의 임상 근거 인용도는 약 60~70%.** 프로젝트 자체 wiki(`MVP-clinical-foundation`, `F1a-F4-임상설계-reference`, `조음장애`, `KOPLAC`)를 통해 F1-a·F4·F15의 상위 구인은 인용돼 있으나, **정량 기준(연령 규준·절단점·난이도 위계)과 1차 출처(논문/검사도구)가 비어 있는 항목이 다수.**
2. **외부 KB가 그 갭을 직접 메운다** — 특히 ① 읽기 선행지표 게임(음운인식·해독·RAN·1분읽기)의 **발달 위계·연령별 정상 수준·1차 논문**, ② F1-a 3축의 **조음(U-TAP/APAC/PCC)·음향(SMST-C·말과학)·어휘(REVT) 규준**, ③ F15 추론/화용의 **추론 유형 위계·KOPLAC 6과제 구조**.
3. **연령 비대칭 주의**: 외부 KB는 **만 5~7세(학령전 후기~초등) 읽기·추론 grounding은 매우 풍부**하나, **만 2~4세 영아 자료는 상대적으로 빈약**. 프로젝트 타깃(만 2~7세)의 하단부는 외부 KB로도 메우기 어렵다 → 자체 파일럿 규준이 여전히 필요.
4. **자체 설계로 근거 미인용인 항목**(음향 임계값·재학습 게이트·음소 핀셋 카테고리)은 외부 KB로도 직접 메우기 어렵거나 부분적 → 별도 표기.

## 3. 우선순위별 보강 권고

### 🔴 즉시 (Phase 1 진입 차단 해소 + 최대 ROI)

1. **읽기 선행지표 4게임 임상 grounding 이식 (CL-08~11)**
   - 외부 KB `maps/학습·읽기장애` + `concepts/{음운인식,해독,읽기유창성,추론능력,빠른이름대기,음운규칙}` + S003·S090·S113·S133·S160을 **프로젝트 clinical 기둥으로 선별 이식**하고 `F1a-F4-임상설계-reference` 및 SRS REQ-FUNC-CL-08~11에 cross-link.
   - 효과: 게임 난이도 위계·연령별 정상 수준·1차 출처가 채워져 ⚠️/❌ → ✅. 최근 4커밋(CL-08~11) 구현물의 인수기준 확정.

2. **RAN·1분읽기 규준 공백 명시 + 외부 KB 위계로 1차 보강**
   - 정상 범위는 **자체 파일럿이 최종 근거**지만, 외부 KB의 학년별 예측력(β값)·자극유형 반응성으로 **잠정 위계/해석 가이드**를 코드 주석·스펙에 즉시 추가(현재 "데이터 후" placeholder만).

### 🟡 Phase 1 전 (KOPLAC 자문과 병행)

3. **F1-a 3축 척도 근거 정리** — U-TAP/APAC/PCC(articulation)·SMST-C/말과학(acoustic)·REVT(linguistic)를 `groundTruthScore` 채점 기준 근거로 명문화. `lib/acoustic-score.ts`·`linguistic-score.ts` 주석에 출처 link.
4. **F15 추론 8유형·KOPLAC 6과제 매핑 상세화** — `concepts/추론능력`·`KOPLAC`·`언어문제해결력검사`로 SRS §10.2 상세 정의 보강.

### 🟠 장기 / 자체 영역

5. **Peña 데이터셋 구성(CL-13)** — 외부 KB는 원칙 보강용. `lib/peer-percentile.ts` 정상+지연 혼재 미준수 주석 + 정상 라벨 메커니즘은 **자체 파일럿 데이터** 필요.
6. **재학습 게이트 3단계·음소 핀셋 카테고리** — 외부 KB 직접 매칭 약함, 자체 설계 + 별도 임상 자문.
7. **만 2~4세 하단부 grounding 공백** — 외부 KB도 빈약. 영아 비공식검사·화용 초기발달은 자체 자문/파일럿으로 메워야 함(외부 KB로 해결 불가, 솔직히 표기).

## 4. 연령 비대칭 (반드시 인지)

| 연령대 | F1-a/F4 | 읽기 선행지표 | F15 추론·화용 |
|---|---|---|---|
| 만 2~3세 | △ (U-TAP/APAC 규준 경계) | ✗ 공식도구 대상 외 | ✗ 자료 빈약 |
| 만 4~5세 | ✓✓✓ | ✓✓ (음운인식·해독 일치형) | ✓ (예측추론·1차 마음이론) |
| 만 6~7세 | ✓✓✓ | ✓✓✓ | ✓✓ (연결·감정추론·간접화행) |

→ 외부 KB는 **만 5~7세 grounding은 강력**하나 **만 2~4세는 자체 보강 필수.** 타깃 페르소나(만 2~7세) 전 구간을 외부 KB만으로 커버한다고 오판 금지.

## 5. 저작권·운영 주의

1. **저작권 경계 유지** — NISE-B·ACT, REVT, KOPLAC, U-TAP 등은 **문항·지문·규준·명칭 복제 금지, 구인(construct)만 영감**(CON-05/ADR-18). 외부 KB 인용 시에도 동일.
2. **외부 KB는 별도 workbase** — `raw/` 불변 원칙 밖. **선별 이식 + cross-link** 방식(통째 복사 금지).
3. **이식 시 출처 귀속** — 외부 KB의 1차 source ID(S0xx)·저자·연도를 프로젝트 wiki sources 페이지로 보존.
