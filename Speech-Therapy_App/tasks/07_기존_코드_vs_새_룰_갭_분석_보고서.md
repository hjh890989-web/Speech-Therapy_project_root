### 2.3 🟡 P1 — `lib/env.ts` 부재 (303 §8)

#### 현황

환경변수 검증이 **각 모듈 분산**:

| 위치 | 검증 대상 |
|---|---|
| `lib/ai/gemini.ts:32-39` | `GOOGLE_GENERATIVE_AI_API_KEY` |
| `lib/supabase/client.ts:62-65` | `NEXT_PUBLIC_SUPABASE_URL`, `_ANON_KEY` |
| `lib/supabase/server.ts:12-15` | 동일 |

부팅 시 1회 검증하는 중앙 모듈 부재.

#### 영향

- 콜드 스타트 후 첫 요청까지 env 누락 발견 못 함
- DATABASE_URL / DIRECT_URL 검증 없음 → Prisma 호출 시점에 막연한 connection 에러

#### 수정 방안

```typescript
// lib/env.ts (신규)
import { z } from "zod";

const envSchema = z.object({
  DATABASE_URL: z.string().url(),
  DIRECT_URL: z.string().url(),
  NEXT_PUBLIC_SUPABASE_URL: z.string().url(),
  NEXT_PUBLIC_SUPABASE_ANON_KEY: z.string().min(1),
  GOOGLE_GENERATIVE_AI_API_KEY: z.string().min(1),
});

export const env = envSchema.parse(process.env);
```

`app/layout.tsx` 또는 server 측 진입점에서 import → 부팅 시 검증.

### 2.4 🔵 선택 — "의료적 판단" → "의료적 평가"

#### 분석

서브에이전트가 6곳에서 "의료적 판단" 을 위반으로 분류했으나, **strict reading 으로는 위반 아님**:
- AGENTS.md §2.1 금칙어: "치료", "진단", "장애" (**"판단" 미포함**)
- "판단" 과 "진단" 은 다른 단어 (judgment vs diagnosis)

#### 그러나 보수적 추천

"의료적 판단" 자체가 의료 행위 implicit imply. 사용자가 보수적 disclaimer 선호 시 "의료적 평가" 또는 "의료 행위" 같은 더 명확한 비의료 표현 권장.

본 보고서에는 변경 옵션으로 포함 (사용자 선택).

| `app/(public)/diagnose/DiagnosisForm.tsx` | 297 |

| `app/(public)/reports/page.tsx` | 37, 98 |
