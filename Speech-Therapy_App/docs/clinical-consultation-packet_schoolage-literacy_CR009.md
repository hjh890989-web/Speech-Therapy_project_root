# 임상 자문 패킷 — 학령기 문해력 '연습' 미니게임 5종 (CR-2026-009, S2~S4)

> **수신**: 언어재활사 / 임상 교수 — **읽기 발달·난독·학습장애·읽기이해 전문 풀** (SRS §10 자문 풀 + 읽기/학습 전문가)
> **발신**: Speech-Therapy 제품팀
> **목적**: 학령기(초1~6) **문해력 '연습'(평가·판정 아님) 미니게임 5종**의 콘텐츠·연령·난이도 설계가 임상적으로 **적절·비오도(非誤導)** 한지 **검토·서명** 받기 위함. 각 "검증 질문"에 답해 주시면 됩니다.
> **연계**: CR-2026-009 설계 [`tasks/13_Literacy_SchoolAge_Expansion_Design.md`](../tasks/13_Literacy_SchoolAge_Expansion_Design.md), 5단계 모델 [`lib/literacy/stages.ts`](../lib/literacy/stages.ts).
> **선례**: 만 5~7세 선행지표 패킷 [`clinical-consultation-packet_CL08-10_literacy.md`](clinical-consultation-packet_CL08-10_literacy.md)와 동일 형식.
> **원본성(법률)**: 별도 [`compliance-originality-brief_OPS-LIT-01.md`](compliance-originality-brief_OPS-LIT-01.md) — 본 패킷은 **임상 적절성**만.

---

## 0. 먼저 읽어 주세요 — 제품 성격 + 본 자문의 특수성 (검토 전제)

- 본 서비스는 **의료기기·진단 도구가 아닌 비의료 발달 놀이/안내**입니다 (ADR-04). UI 금칙어: "치료/진단/장애/지연/지체/난독/학습장애" → "읽기·말 놀이 / 또래와 함께 / 더 연습하면 좋은 영역"으로 치환. **(본 패킷 내부는 정확한 임상 용어 사용 — 검토 편의.)**
- **⚠️ 본 자문의 결정적 전제 — "연습-only"**: 사전 규준 검증(2026-06-22, 외부 임상 wiki 원문 대조)에서 **부모용 모집단 참고밴드로 출시 가능한 학령기 표준화 규준이 0건**으로 확인됐습니다(NISE-B·ACT 2025 예비검사·연구표본·임상대조군뿐). 따라서 5종은 **점수 등급/정상·위험 판정/또래 백분위를 산출하지 않는** *연습 활동*으로 설계됐습니다(완료 시 raw 정답수만 내부 저장, 부모에겐 활동량만 표시).
- 그러므로 본 자문은 "규준의 정확성"이 **아니라** 다음에 초점:
  1. **콘텐츠 적절성** — 자체 제작 문항·지문·낱말이 해당 연령·구인에 발달적으로 적절한가.
  2. **비오도성** — 부모가 "연습 활동"을 능력 판정으로 오해하지 않도록 하는 설계가 타당한가.
  3. **난이도 위계의 잠정성** — 아래 각 게임의 난이도 정렬(잠정)이 임상적으로 수용 가능한가(정렬용일 뿐 규준 아님).
  4. **위해(harm)·false-positive 회피** — 다문화·방언·개인차를 능력 부족으로 오해하게 하지 않는가.
- **대상 연령 확장**: 기존(만2~7)에 더해 **학령기(초1~6, 84~144개월)** 를 *조건부* 추가(연령 게이트, 월령 알 때만 강제). 전 게임 **플래그 default off** — 본 검증 서명 전 활성 금지.

## 0.1 자문 진행 (SRS §10)

- 자문 풀 중 **읽기 발달·읽기이해·형태소·난독 도메인 3~4인** / 일정 ~4주(서면 + 화상) / 비용 약 82만(1인 20~25만, CL-08~10 자문과 통합 진행 가능).
- 산출물: 각 검증 질문 서면 답변 + 말미 서명 → 제품팀이 게임별 플래그 활성화 결정에 반영. **검증 전 활성 금지.**

---

## 1. 받아쓰기 놀이 (spelling) — 철자/음운규칙 인식, S2(초1~3)

**제안 규칙:** 부모가 「소리」(예: [국쑤])를 들려주면 아이가 **바르게 쓴 철자**(국수)를 2지선다로 고름(오답 = 소리기반 표기). 자체 25문항 = 5 음운규칙(경음화·연음화·기식음화·종성규칙·구개음화) × 5. 채점 0/1 + 자기교정(SC) 3초. **점수밴드/판정 없음** — 활동량만 표시.

**난이도 위계(잠정·정렬용):** 외부 wiki 원문(S113, 초1-3 단어 철자 정확률) 순서 — 경음화 94% > 연음화 88% > 기식음화 73% > 종성 69% > 구개음화 20%. **이는 게임 진행 순서 정렬용이며 임상 참고밴드가 아닙니다.**

**검증 질문:**
1. 초1~3에서 위 5 음운규칙의 **철자 발달 순서·난이도**가 위 정렬과 임상적으로 부합합니까? 수정 권고는?
2. '옳은 철자 고르기'(2지선다, 소리 vs 바른 표기)가 초1~3 철자 **연습**으로 적절합니까? 입력 부담(직접 쓰기 대신 선택)이 구인 타당도를 해치진 않습니까?
3. 자체 낱말 풀(고빈도·친숙도)에서 피해야 할 항목·추가 권고는?
4. 다문화·방언 아동이 **불리하게 오해**되지 않도록 할 주의점은?

---

## 2. 소리 규칙 읽기 (read-rules) — 불일치형 해독, S2(초1~3)

**제안 규칙:** 낱말(예: 굳이)을 보여주고 **바른 소리**([구지])를 2지선다로 고름(오답 = 글자 그대로 읽은 소리 [구디]). 자체 25문항 = 5 규칙(경음화·연음화·비음화·기식음화·구개음화) × 5. 채점 0/1 + SC 3초. 받아쓰기(표기 고르기)의 **역**(소리 고르기 = 해독).

**임상 근거(wiki):** 해독 = 표기를 음운규칙 적용해 바른 소리로 읽기. 비단어/규칙어 음독은 순수 해독 측정 표준.

**검증 질문:**
1. 초1~3 해독 **연습**에서 다루는 5 규칙 선정·**난이도 정렬(잠정)** 이 적절합니까? (종성규칙은 표기 쪽이라 본 읽기 게임에선 제외하고 비음화를 포함 — 타당합니까?)
2. "글자 그대로 읽은 소리"를 오답 보기로 제시하는 설계가 임상적으로 오도 위험이 없습니까?
3. 음독을 **음성 입력(STT)** 이 아닌 **선택형**으로 측정하는 것의 한계·권고는?

---

## 3. 글 읽고 답하기 (reading-comprehension) — 사실적 읽기이해, S3(초3~4)

**제안 규칙:** 짧은 자체 창작 지문 + **사실 확인** 3지선다(정답이 지문에 직접 제시, look-back 권장). 자체 지문 3편 × 문항 3 = 9. **시간 제한 없음**(다시 읽기 허용), 채점 0/1(첫 정답 또는 재선택 정답).

**임상 근거(wiki):** 사실적 이해 = 글에 직접 제시된 정보 확인(추론·평가 이전 기초 수준).

**검증 질문:**
1. 자체 지문의 **길이·어휘·문장 복잡도**가 초3~4에 적절합니까? (샘플 3편 동봉 — 별첨)
2. 사실적(직접 제시) 문항만으로 구성한 것이 이 단계 **연습**으로 타당합니까? 추론 문항과의 경계 기준은?
3. look-back(다시 읽기) 무제한 허용이 임상적으로 적절합니까?

---

## 4. 숨은 뜻 찾기 (inference-reading) — 추론 독해, S4(초5~6)

**제안 규칙:** 자체 지문 + **추론** 3지선다(인물 마음·까닭·결과 유추, 정답이 지문에 **직접 노출되지 않음**). 자체 지문 3편 × 문항 3 = 9. 시간 제한 없음, 채점 0/1. *기존 만5~7 가이드형 `inference`(생각 나누기)와 별개*.

**임상 근거(wiki `clinical/concepts/내러티브-담화-추론-중재`):** 추론·평가적 이해 = 사실적 이해 다음 상위 수준.

**검증 질문:**
1. 초5~6에 **추론 독해 연습**이 발달적으로 적절합니까? 다루는 추론 유형(인물 정서·인과·결과 예측)이 타당합니까?
2. "정답이 지문에 직접 없음"을 원칙으로 한 문항이 **단일 정답성**(다중 해석 위험)에 문제가 없습니까? (샘플 별첨)
3. 추론은 정답이 갈릴 수 있는데, **오답 처리**가 아이에게 부정적이지 않게 하려면(격려 톤) 어떤 기준이 필요합니까?

---

## 5. 낱말 조각 놀이 (morphology) — 형태소 인식, S4(초4~6)

**제안 규칙:** 합성어 만들기(어근+어근) / 파생어 만들기(어근+접사) / 형태소 분석(공통 형태소·접사 의미) **3유형** 3지선다. 자체 15문항 = 3유형 × 5. 채점 0/1 + SC 3초. 난이도 정렬(잠정): 합성 < 파생 < 분석.

**임상 근거(wiki `clinical/concepts/형태소인식`, 원문 S114/S115):** 형태소 인식 = 낱말 내 의미 단위 인식·조작 → 어휘·읽기이해 상위 기여(학령기, 특히 초4~6).

**검증 질문:**
1. 초4~6 형태소 인식 **연습**으로 3유형(합성/파생/분석) 구성·**난이도 정렬**이 적절합니까?
2. 접사 의미 문항(예: '풋-'=덜 익은)의 **난이도·단일 정답성**이 적절합니까? (샘플 별첨)
3. 이 연령에 더 적절한 형태소 과제 유형 추가 권고는?

---

## 6. 공통 — 연령 게이트 · 위계 잠정성 · '연습-only' 설계

**검증 질문:**
1. **연령 게이트** — 각 게임의 연령 구간(받아쓰기·소리규칙 84~119 / 글읽기 108~131 / 숨은뜻 132~144 / 낱말조각 120~144)이 임상적으로 타당합니까? 조정 권고는?
2. **난이도 위계의 잠정성** — 위 모든 정렬은 "정렬용·임상밴드 아님"으로 명시했습니다. 규준 없이 *연습 순서*로만 쓰는 것이 수용 가능합니까?
3. **'연습-only' 설계의 임상적 정당성** — 표준화 규준이 없는 상태에서 점수밴드/판정 없이 **활동량만** 부모에게 보여주는 접근이, 부모를 오도하지 않는 책임 있는 설계라고 동의하십니까? 추가 안전장치 권고는?
4. **위해 회피** — 5종 전반에서 정상 발달 변이·다문화·방언을 능력 부족으로 오해하게 할 위험과 차단책은?

---

## 7. 검증 결과 + 반영 프로세스

> ⏳ **검증 대기.** 자문 3~4인 서면 답변 + 서명 수령 시 본 절에 기록.

- 검증 답변 수령 → 게임별 **플래그 활성화 결정**(`LITERACY_SPELLING_ENABLED` / `LITERACY_READ_RULES_ENABLED` / `LITERACY_COMPREHENSION_ENABLED` / `LITERACY_INFERENCE_READING_ENABLED` / `LITERACY_MORPHOLOGY_ENABLED`).
- **검증 전 활성 금지**(전 플래그 default off). 활성은 게임별 단계적(한 종 → 코호트 → 전체) 권고.
- raw 점수·저장은 불변, 부모 표시(활동량 카드)는 display 레이어만 — 발음 채점/HITL과 무관.
- 별첨 요청 시 제품팀이 각 게임 **전체 문항/지문 샘플**(자체 제작분)을 제공.

**연락처**: Speech-Therapy 제품팀 / 회신 = 각 검증 질문 번호에 서면 답변 + 말미 서명.
