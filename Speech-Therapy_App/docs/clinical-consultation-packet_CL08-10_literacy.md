# 임상 자문 패킷 — 읽기 발달 선행지표(CL-08~10) + F15 추론 위계(CL-11)

> **수신**: 언어재활사 / 임상 교수 — **읽기 발달·난독·학습장애 전문 보강 풀** (SRS §10 KOPLAC 자문 풀 + 읽기/학습 전문가)
> **발신**: Speech-Therapy 제품팀
> **목적**: 만 5~7세 **읽기 발달 선행지표**(음운 인식·해독·RAN·읽기 유창성) 측정·채점 규칙과 F15 추론 위계를 임상적으로 **검증·서명** 받기 위함. 각 "검증 질문"에 답해 주시면 됩니다.
> **연계**: SRS V07 §4.1 D 절 REQ-FUNC-CL-08~12, CR-2026-007(2026-06-08), 통합 설계 [`tasks/11_Literacy_Constructs_Expansion_Design.md`](../tasks/11_Literacy_Constructs_Expansion_Design.md).
> **선례**: 본 패킷은 [`clinical-consultation-packet_CL01-04_F15.md`](clinical-consultation-packet_CL01-04_F15.md)(2026-05-30 검증 완료)와 동일 형식.
> **근거 출처**: 각 항목의 wiki `clinical/*` 인용 — 검토 시 원자료 대조 가능.

## 0. 먼저 읽어 주세요 — 제품 성격 (검토 전제)

- 본 서비스는 **의료기기·진단 도구가 아닌 비의료 스크리닝/발달 안내**입니다 (ADR-04).
- UI 표현에서 **"치료/진단/장애/지연/지체/난독/학습장애"는 금칙어** — "발음·읽기 준비 확인 / 또래 비교 / 더 연습하면 좋은 영역"으로 치환합니다. **(단, 본 패킷 내부에서는 정확한 임상 용어를 사용합니다 — 검토 편의.)**
- 따라서 검증은 "의학적 진단의 정확성"이 아니라 **"또래 비교·발달 안내가 임상적으로 오도하지 않는가(특히 정상 발달 변이를 위험 신호로 오분류하지 않는가)"**에 초점.
- **신규 대상 확장**: 기존 조음(만 2~7세, ㄱ·ㄴ·ㅅ·ㅈ·ㄹ)에 더해, **만 5~7세 읽기 발달 선행지표**를 *조건부* 추가(만 4세 이하 미노출).
- **⚠️ 저작권 경계**: 모든 문항·자극·지문은 **자체 제작**이며 NISE-B·ACT의 문항·단어목록·규준·명칭을 복제·사용하지 않습니다. 본 자문은 **임상 구인의 타당성**만 검토하며, 콘텐츠 원본성은 별도 **법률 검토**([`compliance-lawyer-consultation-brief.md`](compliance-lawyer-consultation-brief.md))로 분리됩니다.

## 0.1 자문 진행 (SRS §10)

- 자문 풀 7그룹 + **읽기 발달/학습 전문가 보강** 중 **3~4인** 선정 / 일정 **~4주**(서면 + 화상 2회) / 비용 **약 82만원**(1인 20~25만).
- **풀 보강 권고**: CL-01~04(조음)와 달리 본 자문은 **읽기 발달·음운 인식·난독 예측** 도메인 → 학습장애-언어재활 전문가(예: 대구대 김화수 그룹) + 읽기 발달 연구자를 최소 1~2인 포함 권고.
- 산출물: 본 패킷 각 검증 질문에 대한 **서면 답변 + 서명** → 제품팀이 CR-2026-007로 반영(채점 로직 활성화). **검증 전 채점 활성 금지.**

## 1. CL-08 — 음운 인식 (phonological awareness) 사전과제

**제안 규칙:** 만 5~7세 진단에 **음운 인식 미니과제**(음절/음소 **합성·탈락·대치·변별**)를 추가. 자체 제작 한국어 **고빈도 2~3음절 단어 풀** 기반. 채점 **0/1**(정/오), **자기교정(SC) 3초 내 허용**. 점수는 부모 리포트의 '음운 인식 축'에 반영(또래 비교, 위험 단정 없음).

**임상 근거** (wiki `clinical/concepts/학습장애-언어재활` 음운인식↔읽기 · `clinical/entities/Scarborough`):
- 음운 인식 = 읽기 발달의 핵심 **선행 지표**(분야 표준). NICHD/Lyon(2003) 난독 정의의 음운 처리 결손과 연결.
- 단순 견해(Kamhi 2009): 읽기 = 해독 × 언어 이해 → 음운 인식은 해독 측 토대.

**검증 질문:**
1. 만 5~7세에서 과제 유형(**합성 / 탈락 / 대치 / 변별**)의 **발달 순서·난이도 위계**는 어떻게 됩니까? 어느 유형부터 측정해야 합니까?
2. **음절 단위 vs 음소 단위** — 만 5세는 음절, 6~7세는 음소 수준이 적절합니까? 연령별 측정 상한 권고는?
3. **자기교정(SC) 3초 허용**이 임상적으로 타당합니까? 무응답·부분정답 처리 기준은?
4. 한국어 특이적으로 **false-positive 위험**(방언·다문화 가정 입력 특성)이 큰 과제 유형이 있습니까?
5. 비의료 스크리닝에서 "음운 인식이 약함" 신호를 **부모에게 어떻게 안내**해야 오도하지 않습니까? (난독·학습장애 단정 회피)
6. 자체 단어 풀 구성 기준(음절 구조·빈도·친숙도·금기 단어)에 대한 권고는?

## 2. CL-09 — 해독 (자소-음소 대응, decoding)

**제안 규칙:** 만 5~7세에 **해독 과제** 추가 — 자체 **무의미 음절/단어 생성기**로 통째 암기를 배제하고 자소-음소 대응 처리를 검증. **어두/어중/어말** 위치별 자체 자극. 채점 **0/1** + **실 오반응 기록**(중재 참고용, 점수 아님).

**임상 근거** (wiki `clinical/entities/U-TAP` §음운변동 · `clinical/concepts/조음장애` · `clinical/concepts/학습장애-언어재활`):
- 규칙/불규칙·의미/무의미 단어의 정확한 음독 = 한글 음운변동 처리 능력.
- 비단어(무의미 단어) 읽기 = 어휘 기억이 아닌 **순수 해독** 측정의 표준 접근.

**검증 질문:**
1. 만 5~7세 한글 해독에서 **비단어(무의미 단어) 읽기**가 통째 암기 배제에 타당한 방법입니까? **연령 적정성**(5세부터? 6세부터?)은?
2. 자소-음소 대응의 **규칙성**(규칙/불규칙·받침 유무·겹받침)별 **난이도 위계** 권고는?
3. 무의미 단어의 **음절 구조·길이**(CV / CVC / 다음절) 권고 범위는?
4. 정상 음운변동(연음·비음화 등)이 해독 채점에서 **오류로 오분류되지 않게** 하려면(CL-01 정규화와 연계) 어떤 기준이 필요합니까?
5. 다문화/이중언어 아동의 해독 **false-positive 위험**과 권고는?

## 3. CL-10 — RAN(빠른 자동 이름대기) + 읽기 유창성

**제안 규칙:** **RAN** = 자체 **사물·색깔 배열판**, **완료 시간/개수** 측정. **읽기 유창성**(만 6~7세, 해독 선행 아동) = 자체 **이야기글/설명글** 1분 읽기, **정확 음절 수** 측정. 위험 신호는 또래 비교로만 표시(난독 단정 없음).

**임상 근거** (wiki `clinical/entities/RAN-빠른자동이름대기` 이중결손 가설 · `clinical/concepts/학습장애-언어재활`):
- RAN = 음운 인출 **자동화** 지표 → 난독·읽기 유창성 예측(이중결손 가설: 음운 인식 결손 + RAN 결손).
- 자체 자극(NISE 보드판 미복제), 시간 기반 측정.

**검증 질문:**
1. 만 5~7세 RAN 자극 유형(**사물 / 색깔 / 숫자 / 글자**) 중 비의료 스크리닝에 적절한 것은? (숫자·글자는 학습 의존 → **사물·색깔** 권고가 타당합니까?)
2. RAN **완료 시간**의 정상 범위·해석 기준은? (절대 cutoff 부재 시 **또래 비교만** 권고가 맞습니까?)
3. **이중결손**(RAN + 음운 인식 동시 약함) 신호를 어떻게 **통합 해석**해야 합니까? (단, 난독 단정 회피 — 부모 안내 톤 권고)
4. **읽기 유창성 1분 과제**는 만 6~7세 중 **해독이 선행된 아동**만 대상으로 하는 게 맞습니까? 연령/선행조건 권고는?
5. 자체 지문(이야기글/설명글)의 **난이도·길이·어휘 통제** 권고는?

## 4. CL-11 — F15 챗봇 추론 위계 (Phase 1, 만 5~7세)

> 기존 F15 13항목 체크리스트([`clinical-consultation-packet_CL01-04_F15.md`](clinical-consultation-packet_CL01-04_F15.md) §5)의 **추론 항목(#2)을 4수준 위계로 확장**.

**제안 규칙:** F15 발화 유도 챗봇이 추론 질문을 **4수준 위계**(사실 → 추론 → 비판 → 평가)로 자체 시나리오 기반 생성. **평가·채점이 아닌 유도**에만 사용.

**임상 근거** (wiki `clinical/concepts/내러티브-담화-추론-중재`):
- 사실·추론·비판·평가적 이해 4수준 + 8 추론 유형(인과/비교/분류 등).

**검증 질문:**
1. 만 5~7세에 4수준(사실/추론/비판/평가)이 **모두 발달적으로 적절**합니까? 어느 수준까지가 현실적입니까?
2. 8 추론 유형(인과/비교/분류 등)과 **4수준의 매핑** 권고는?
3. 챗봇이 추론을 **유도**(평가 아님)하는 선에서 위계를 어떻게 설계해야 합니까?
4. 자체 시나리오 작성 시 임상적으로 **위험한 패턴**(불안 유발·의료적 단정)과 차단책은?

## 5. 공통 — 연령 게이트 · 규준 표본 구성 · 원본성

**검증 질문:**
1. **연령 게이트** — 읽기 선행지표를 **만 5~7세**에만 노출하는 하한이 임상적으로 타당합니까? (음운 인식 일부는 5세 전에도 측정 가능?)
2. **규준 표본 구성**(AI 또래 비교의 토대) — 규준 표본은 **정상 발달 아동 위주**(연령대당 충분 수)로 구성하고, 검증 표본은 **정상 + 위험군 분리**해야 한다는 원칙(Peña 2006)이 본 선행지표에도 적용됩니까? 연령대당 최소 표본 권고는?
3. **원본성**(법률 교차) — 자체 제작 문항·자극·지문이 NISE-B·ACT 등 기존 검사와 **구별되는 원본**임을 임상적으로 보증할 수 있는 설계 원칙은? *(법적 판단은 변호사 자문으로 분리 — 본 항은 임상 설계 관점만)*

## 6. 검증 결과 + 반영 프로세스

> ⏳ **검증 대기.** 자문 풀 3~4인 서면 답변 + 서명 수령 시 본 절에 결과 기록.

- 검증 답변 수령 → **CR-2026-007**(Tier 3) 반영 → 채점 로직(CL-08~10) + F15 추론(CL-11) **활성화**(wiring).
- 구현 토대: `lib/diagnose/clinical/*` + 콘텐츠 task `MOCK-LIT-01~04`(자체 제작). 본 패킷 규칙안 = 그 구현의 임상 근거.
- **검증 전 채점 활성 금지** 원칙은 본 검증 서명으로 해제됨(CL-01~04 선례와 동일).
- 단계적 활성화 시 **적대적 검증**(채점 레이어 회귀 방지 — CL-02 escalation 회귀 선례 참조) 수행: literacy 점수는 **부모 표시·또래 비교 레이어**에 두고, 기존 조음 채점·HITL escalation·저장은 raw 불변 유지.
