# F15 챗봇 T4-c / IRB 해당성 판단 자료

> ## ⚠️ 본 문서는 컴플라이언스 **의사결정 지원 자료**이며 법적 단정이 아닙니다
> - 작성: AI 분석(3축 조사 → 판단 합성 → 적대적 검증 workflow, 2026-05-30) — SRS/ADR/코드 근거. 변호사 아님.
> - **목적**: "F15 활성에 IRB 가 무조건 선행되어야 하는가?"라는 회색지대를 정리하여, 조직/변호사가 **확정**할 수 있게 함.
> - 최종 판단은 **조직(System Admin) + 변호사 + (필요 시) SRS 저자/임상 자문위**의 몫.

## 질문
F15 발화 유도 챗봇(자녀 자유 발화 저장)이 **F10 동의 Tier "T4-c"(외부 협력)에 해당하여 IRB(ADR-15) 사전 통과가 `F15_CHAT_ENABLED` 활성의 *무조건* 선행조건인가?**

## 결론 요약 (verdict: 조건부 유지 + 단서)
**IRB 는 F15 활성의 "무조건 하드블록"이 아닙니다.** T4-c/IRB 는 **외부 제3자 제공/협력을 *수반할 때만* 발동하는 조건부 트리거**이고, F15 의 *현재 구현* 데이터 처리는 그 실질 요건에 미달합니다. **단, "IRB 불요"라고 단정해서도 안 됩니다** — 문서 내부 모순 + 설계 미확정 항목이 있어, **입증책임은 "기본 = ADR-14대로 IRB 포함, 조직이 본문 우선을 서면(CR)으로 확정해야 조건부로 강등"** 쪽에 둡니다.

→ **핵심 메시지: F15 게이트의 병목은 IRB 가 아니라, 어느 해석에서도 선행되는 4개의 no-regret 조치다**(아래 §4). 그 중 ①②는 *무조건 차단 게이트*다.

---

## §1. SRS 분류 — F15 는 무조건 T4-c 가 아니다 (단, 문헌 모순 존재)

| 근거 | 내용 |
|---|---|
| T4-c 정의 | "외부 임상가·학회 데이터 **공유/제공**(협력 연구기관 한정)" = 제3자 제공. (wiki F10-research-consent L59-61, SRS L1531/L1562) |
| IRB 트리거(§6.10.1) | 3개 이벤트 **시점**에만 발동: T4-c 외부협력 활성 / model_retraining 외부 ML 위탁 / T4-b 학술발표 |
| IRB 제외(§6.10.3) | T1·T2·T3(내부 처리)는 **IRB 제외** 명시 |
| 정본 본문(§4.1 L788, §10.1 L1805) | F15 활성 게이트 = "**KOPLAC 13항목 + 자문 4주 + 82만**" — **IRB 미포함** |
| 13항목 #11(L1821) | IRB 를 "**T4-c 외부 협력 *시***" 조건부로 한정 |
| §1049 RACI "IRB(ADR-15 T4-c)" | F15 챗봇이 아니라 **HITL 모델 재학습/배포** 파이프라인 표기(별개 트랙) |

### ★ 결정적 모순 (조직 확정 필요)
- **ADR-14 요약표(L1530)** 만 "13항목 + 자문 + 82만 + **IRB 통과 후 활성**"으로 IRB 를 무조건 게이트처럼 나열.
- **정본 본문(§4.1·§10.1)** 은 IRB 를 빼고 13항목·자문·82만만 무조건 요건으로 명시.
- SRS 규약 "§10 이 본문 확장(L1545·L1801)" → 본문 우선 해석 근거는 있으나, **ADR 은 SRS 의 최고 규범 계층**이라 ADR-14 표를 정본으로 보면 IRB 무조건으로 읽힌다.
- → **조직/SRS 저자가 둘 중 어느 것이 구속력인지 서면(CR)으로 확정**해야 IRB 필수 여부가 결정됨.

## §2. 양 해석 (균형)

### (가) IRB 불요 / 조건부 — 실질 해석
1. T4-c trigger 어구는 일관되게 "외부 제3자 제공/공유"인데, F15 실제 처리는 **외부 공유·학술발표·외부 연구자 접근 = 0건**(코드 확인).
2. §6.10.3 이 T1~T3 내부 처리를 IRB 제외로 명시 → F15 현 처리는 T3 이하 성격.
3. IRB 무조건 표현은 ADR-14 표 한 줄뿐, 본문은 IRB 제외 + "§10 본문 확장" 규약.
4. SRS 가 Gemini(미국) 전송을 **PIPA §17 국외이전(위탁)** 으로 분류(제3자 제공 아님, External Systems 표 L401·REQ-NF-026).
5. **선례**: 진단(transcript 영구저장 + Gemini)·F11(음성 클론 + ElevenLabs 국외이전) 모두 **IRB 없이 PIPA 동의(§22-6+§17)만으로** 운영/활성 중 — IRB 실질 트리거 = "외부 연구 협력" 단일 변수.
6. F15 는 7일 hard-delete(ADR-03)로 진단(영구저장)보다 보존 측면 보수적. *(부수적 — IRB 판단의 핵심은 보존기간이 아니라 처리 목적/취약집단성이므로 약한 논거)*

### (나) IRB 필수 / 보수 — 적대적 검증이 강화한 반박
1. **ADR-14(L1530)는 단순 표 셀이 아니라 "F15 임상 안전 게이트"라는 독립 ADR 결정** — ADR 은 최고 규범 계층. "본문이 표를 이긴다"는 SRS 저자 확정 없이는 spec 우회 리스크. → **입증책임 역전: 기본=IRB 포함, 명시 확정 시에만 조건부 강등.**
2. **F15 정본 위키(L95-104)가 "F15 대화 로그의 model_retraining_data 포함 여부"를 *미결 자문 항목*으로 명시** — T4 진입 경계가 **설계상 미확정**. "T3 이하 확정"은 과단정.
3. **진단(단어 채점) ≠ F15(자유 발화)** — 자유발화는 (i) 가족·위치·건강 등 **예측 불가 식별정보**를 아동이 자발 노출(정규식 pii-mask 로 완전 제거 불가), (ii) 발화 내용 자체가 발달·정서·가정환경 추론 가능. "진단=IRB불요" 선례의 단순 등치는 한계.

## §3. T4-c/IRB 가 *확실히* 발동하는 트리거 조건 (= 활성 후에도 재판단 필요)
- F15 발화 코퍼스를 **외부 임상가·협력기관·학회에 공유/제공**하는 흐름 추가 시 (T4-c 정의 직접 충족)
- F15 발화 데이터로 **익명 통계·논문·학회 발표** 진행 시 (§6.10.1 트리거 ③ T4-b)
- `submitChatUtterance`(ChatMessage)가 **model_retraining_data / 외부 ML 위탁 재학습**에 연결되는 순간 (트리거 ①②)
- **Phase 2 멀티턴(pgvector D6) 영속 코퍼스화** → "연구 활용 가능 데이터셋" 성격 (T4 영역 진입 재판단)
- **F10 T4-c granular consent 체크박스를 실제 노출/활성화**하는 제품 결정 시 (트리거 ① 문언 그대로)

## §4. ★ 권고 — IRB 해석과 무관한 No-Regret 선행 조치 (우선순위)

어느 해석(IRB 필수/불요)을 택하든 **반드시 선행되어야 할 무손실 조치**. F15 게이트의 실제 병목.

| 순위 | 조치 | 성격 | 현재 상태 |
|---|---|---|---|
| **1** | **F15 전용 13항목 임상 자문** 수행(자유발화 안전성 #5/#7~9 포함) | **무조건 차단 게이트**(본문) | ❌ 미수행 — 2026-05-30 자문은 **CL-01~04 진단 한정**(schema L575 박제), F15 미커버 |
| **2** | chat 경로 **PIPA 가드 배선** — `assertConsentedIfAuthenticated`(§17 국외이전) + `pii-mask`(R4) + INSERT 가드 | 활성 **절대 선결**(진단/F11 은 적용 중) | ❌ 미배선 — route.ts 에 persist·pii-mask·consent-guard 없음 |
| **3** | F15 발화데이터 **활용영역 설계 확정** — ChatMessage 를 model_retraining/HITL 파이프라인과 **코드·스키마 수준 격리**(환류 차단) | T4 진입 방지(13항목 #6) | ❌ 미확정(위키 L104 미결) |
| **4** | **ADR-14 모순 확정** — IRB 무조건(표) vs 조건부(본문) 중 구속력을 **서면 CR** 로 기록 | 거버넌스 | ❌ 미확정 |
| (5) | 변호사 재확인 — 기존 "문제 없음"(식약처/의료기기 한정)이 **F15 자유발화 국외이전(위탁 vs 제공)** 까지 cover 하는지 | 법률 | ❌ 미확인 |

**해석 분기는 ②③④ 이후**: 13항목 자문 산출물(§10.5 = "IRB 신청 권고 여부" 포함)을 받으면, IRB 필요성이 *자문 결과로* 확정됩니다. **즉 "IRB 불요"는 본 자료의 *결론*이 아니라, 13항목 자문에 회부할 *가설*입니다.**

## §5. 오판 리스크 (양방향)

- **과소 규제(IRB 없이 활성)**: ADR-14 표가 정본으로 판명 시 SRS 위반 / Gemini 전송이 '제3자 제공'으로 재해석 시 PIPA 위반(만 14세 미만 민감) / IRB 미통과 자녀발화 수집의 임상윤리·신뢰 훼손 / PIPA 가드 미배선이 겹치면 "진단보다 약한 보호로 더 민감한 자유발화 국외전송" 복합 갭.
- **과잉 규제(불필요 IRB 강제)**: IRB 5단계 최소 9주 + 외부기관 사전확보 6개월(§6.10.4) → 출시 분기 지연 / 외부협력 0건인데 IRB 요구 시 §6.10.3·진단/F11 선례와 불일치 / 심의할 연구 프로토콜 부재로 신청 반려·공전.
- **공통 완화책 = §4 의 ①~④** (no-regret).

## §6. 변호사/조직 확인 질문 (체크리스트)
1. ADR-14 요약표(L1530 'IRB 통과 후 활성') vs 본문(§4.1/§10.1, IRB 비포함) — 어느 것이 **구속력** 있는 요건인가? "§10 본문 확장 우선" 규약이 ADR 표보다 우위인가?
2. ADR-14 의 IRB 가 (A) F15 자유발화 데이터의 T4-c 등급 때문인가, (B) 풀버전(외부연구 포함) 상정한 보수적 일괄 게이트인가?
3. Gemini(미국) 자녀 발화 전송 = §17 국외이전 **위탁**인가, '국외 **제3자 제공**'으로 재해석 여지가 있는가? (IRB 가 아니라 §17 동의 강화 이슈일 가능성)
4. 2026-05-30 임상/변호사 자문 "문제 없음"이 **F15 를 cover** 하는가? (schema L575 = CL-01~04 한정) → F15 전용 13항목 자문 별도 수행 필요한가?
5. chat 경로 PIPA 가드(consent-guard + pii-mask + INSERT) 배선이 IRB 와 **별개로** F15 활성의 선행 필수인가? (진단/F11 은 적용 중)
6. F15 가 T4-c 를 발동시키는 **데이터-흐름 임계점**을 SRS 에 명문화해야 하는가?
7. 자유발화 우발 PII(학교명/병원명/실명)가 pii-mask 7패턴으로 충분한가, F15 전용 추가 패턴/임상안전 검증이 IRB 와 독립으로 선행되어야 하는가?
8. §1049 RACI 의 'IRB(ADR-15 T4-c)' 셀이 'F15 안전게이트'와 병기돼 'F15=T4-c=IRB 필수'로 오독될 소지 — SRS 문구 명료화 필요한가?
