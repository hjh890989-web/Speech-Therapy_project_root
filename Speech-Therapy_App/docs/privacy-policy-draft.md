## 제1조 (총칙)

**[📝 조직 입력: 회사명/상호]**(이하 "회사")은 「개인정보 보호법」(이하 "PIPA") 및 「정보통신망 이용촉진 및 정보보호 등에 관한 법률」 등 관련 법령을 준수하며, Speech-Therapy 서비스(이하 "서비스")를 이용하는 정보주체의 개인정보를 보호하기 위해 본 개인정보 처리방침을 수립·공개합니다.

본 서비스는 만 2~7세 자녀의 발음 발달을 부모(법정대리인)가 직접 확인·안내할 수 있도록 돕는 **발달 가이드용 보조 도구**이며, **의료기기가 아닙니다**(의료적 진단·치료·처방 미제공).

## 제2조 (수집하는 개인정보 항목)

| 구분 | 항목 | 수집 방법 |
|---|---|---|
| 회원 정보(인증 사용자) | 이메일, 자녀 월령(만 24~84개월), 관심 음소(선택) | 회원가입·온보딩 입력 |
| 발화 데이터 | 자녀 발화의 음성→텍스트 변환 결과(transcript), 발달 점수(조음/언어/음향, 0~100), 또래 백분위 | 서비스 이용 중 생성 |
| 자동 수집 정보 | 익명 사용자 ID(cookie·localStorage), IP 주소(감사 로그), User-Agent | 자동 생성 |
| B2B 기관 정보(해당 시) | 기관명, 원장/교사 이메일, 반 정보 | 기관 가입 입력 |

**미수집 항목(명시):** 자녀의 **이름·생년월일·주소·연락처는 수집하지 않으며**, 연령은 **월령** 단위로만 처리합니다. **음성 원본(raw audio)은 서버에 저장하지 않습니다**(클라이언트 측 음성→텍스트 변환 후 텍스트만 수신).

> [⚖️ 변호사 확인 — 브리프 §4.6] 자녀 발화 transcript 가 PIPA §23(민감정보) 또는 §24(고유식별정보)에 해당할 가능성, 발화에 우발적으로 포함되는 개인정보의 처리 책임. → 해당 시 본 조에 민감정보/고유식별정보 별도 동의·처리 항을 추가해야 함.

## 제3조 (개인정보의 수집·이용 목적)

1. 자녀의 발음 발달 확인 및 가이드 안내 제공(의료적 진단·치료 아님)
2. 회원 인증, 본인 식별, 부정 이용 방지
3. 주간 발달 추이 리포트 생성 및 발송
4. 서비스 품질 개선을 위한 통계 분석(개인 식별 정보 제거 후 집계)
5. 법령상 의무 이행 및 분쟁 대응(감사 로그)

---

## 제4조 (만 14세 미만 자녀의 개인정보 처리 — PIPA §22조의6)

본 서비스는 만 14세 미만 자녀의 개인정보(음성→텍스트, 발달 점수 등)를 처리하기 위해 **법정대리인(부모)의 동의**를 받습니다. 법정대리인의 동의 없이는 자녀의 개인정보를 처리·저장하지 않습니다.

- 인증 사용자: 회원가입 온보딩 단계 및 `/settings/privacy-consent` 에서 동의(동의 일시 보관).
- 익명(무로그인) 사용자: 진단 페이지(`/diagnose`)의 필수 동의 체크박스로 동의.

> [⚖️ 변호사 확인 — 브리프 §4.1] (1) "법정대리인(부모)" 표현 충분성(부/모 단독 가능 여부), (2) **무로그인 진단에서 본인 확인 절차 없이 체크박스만으로 §22조의6 동의 효력이 발생하는지**, (3) 명시해야 할 수집 항목 추가 여부, (4) 동의 철회 절차 명시 충분성.

## 제5조 (개인정보의 보유·이용 기간 및 파기)

| 정보 | 보유 기간 |
|---|---|
| 회원 정보 | 회원 탈퇴 시 즉시 파기 |
| 발화 transcript / 발달 점수 | 회원 탈퇴 또는 동의 철회 시 즉시 파기 |
| 음성 원본 | **저장하지 않음**(추후 음성 저장 기능 활성 시 7일 자동 폐기) |
| 감사 로그(AuditLog) | **[📝 조직 입력: 3년 등]** 보관(법령상 정황 보존) |

파기 방법: 전자적 파일은 복구 불가능한 방법으로 영구 삭제합니다.

> [⚖️ 변호사 확인] (1) transcript 의 **구체적 보존 기간**(현재 "탈퇴/철회 시 파기" — 일정 기간 자동 폐기 필요 여부), (2) 감사 로그 보유 기간의 법적 근거(전자금융거래법/통신비밀보호법 등 적용 여부), (3) 외부 처리자(Google 등) 보유 기간의 본 방침 명시 방식.

## 제6조 (개인정보 처리위탁 — PIPA §26)

회사는 서비스 제공을 위해 다음과 같이 개인정보 처리를 위탁합니다.

| 수탁자 | 위탁 업무 | 위치 |
|---|---|---|
| Supabase | 데이터베이스·인증 호스팅 | 미국/글로벌 |
| Vercel | 웹 호스팅·서버리스 실행 | 미국 |
| Resend | 트랜잭션 이메일 발송 | 미국 |
| Google(AI Studio Gemini / Cloud Speech) | 음성→텍스트 변환·안내 문구 생성 | 미국/글로벌 |

> [⚖️ 변호사 확인] 처리위탁(§26)과 국외 이전(§28의8/구 §17)의 **중복·구분** 처리 방식. 위 수탁자 중 국외 이전 동의 대상과 처리위탁 고지 대상의 경계.

## 제7조 (개인정보의 국외 이전)

발화 텍스트(transcript) 및 메타데이터는 다음 국외 서비스로 이전되며, 회사는 이에 대해 **별도 동의**를 받습니다(`/settings/privacy-consent`).

| 이전받는 자 | 국가 | 이전 항목 | 이전 목적 | 보유 기간 |
|---|---|---|---|---|
| Google Cloud Speech | 미국 | 자녀 발화 음성 | 음성→텍스트 변환(브라우저에서 직접 이전, 본 서버 미경유) | **[⚖️ 확인]** |
| Google AI Studio Gemini | 미국/글로벌 | PII 마스킹된 발화 텍스트 | 부모용 안내 문구 생성 | **[⚖️ 확인]** |
| Supabase / Vercel / Resend | 미국 | 회원·발화·이메일 데이터 | 호스팅·발송 | 서비스 이용 기간 |

거부 방법: 국외 이전 동의를 거부할 수 있으며, 이 경우 일부 서비스 이용이 제한될 수 있습니다.

> [⚖️ 변호사 확인 — 브리프 §4.2] (1) PIPA §28의8(국외 이전) **7개 고지사항**(이전받는 자·국가·일시·항목·목적·보유기간·거부방법) 완비 여부, (2) **Google Cloud Speech(브라우저→직접 이전, 본 서버 미경유)에 대해서도 회사가 동의 책임을 지는지**, (3) Supabase/Vercel/Resend 의 별도 국외 이전 동의 항목 필요 여부, (4) Google 캐시/보유 기간 표현의 약관 정합성.

## 제8조 (정보주체의 권리·의무 및 행사 방법)

정보주체(법정대리인)는 언제든지 다음 권리를 행사할 수 있습니다.

1. 개인정보 열람·정정·삭제·처리정지 요구
2. 계정 삭제: `/settings/account` 의 "계정 삭제"(즉시 처리, 잊혀질 권리 호환)
3. 데이터 다운로드: `/settings/account` 의 "데이터 다운로드"
4. 동의 철회: `/settings/privacy-consent` 또는 계정 삭제

> [⚖️ 변호사 확인] 권리 행사 시 **대리인 위임장·본인확인 절차** 명시 필요 여부.

## 제9조 (개인정보의 안전성 확보 조치 — PIPA §29)

회사는 다음의 안전성 확보 조치를 시행합니다.

- 접근 통제: 사용자별 데이터 격리(익명 ID 또는 인증 user id 기준), 서버 측 접근 권한 강제
- 전송 구간 암호화(TLS 1.2 이상)
- 외부 AI 전송 전 PII 마스킹(주민등록번호/신용카드/이메일/전화번호/URL/IP/상세주소 7패턴)
- 접속 기록 보관 및 위·변조 방지(감사 로그 PostgreSQL 트리거)

> [⚖️ 변호사 확인] PIPA §29 시행령상 **안전성 확보 조치 기준**(접속기록 보관 기간, 암호화 대상 등) 충족 여부.
