# CS 응답 카피 템플릿

> OPS-001 / REQ-NF-011 — CS 4시간 첫 응답 SLA 보조 자료.
> **CON-04 준수**: 의료 금칙어 0건. 대안: "발음 발달 확인", "발음 가이드", "발음 어려움".
> 모든 템플릿은 한국어 + 친근체. 변수 `{...}` 는 운영자가 발송 전 치환.

---

## §1 첫 응답 (4시간 이내 자동/수동)

**제목**: [Speech-Therapy] 문의를 잘 받았어요

```
{부모님 호칭 또는 "안녕하세요"},

문의 주셔서 감사해요. 잘 받았고, 영업시간 기준 4시간 안에 자세한 답변 드릴게요.

- 접수 번호: {ticket-id}
- 접수 시각: {receivedAt KST}
- 영업시간: 평일 10:00 ~ 19:00 (한국 시간)

원래 보내주신 내용은 그대로 보관하고 있고, 추가 정보가 필요하면 회신으로 여쭤볼게요.

본 서비스는 의료적 판단을 제공하지 않는 부모용 발음 발달 확인 도구예요.
혹시 자녀 발음에 대해 전문가 면담이 필요하시다면 가까운 발달 전문 기관 안내도
함께 도와드릴 수 있어요.

감사합니다.

```

## §2 버그 보고 → 재현 정보 요청

**제목**: [Speech-Therapy] 동작 확인을 위해 몇 가지 여쭤볼게요

```
{부모님 호칭},

말씀 주신 동작 결함을 빠르게 재현해 보려고 합니다. 다음 정보를 회신으로 알려주실 수 있을까요?

1. 발생 시각 (대략): {YYYY-MM-DD HH:MM}
2. 사용 기기 / 브라우저: 예) iPhone 14, Safari 17 / Galaxy S23, Chrome 121
3. 자녀 월령 (선택): 예) 만 4세 2개월
4. 어떤 화면에서 어떤 버튼을 눌렀을 때 발생했나요?
5. 화면 캡처 또는 짧은 영상이 있다면 첨부 부탁드려요.

본 정보는 동작 확인 목적으로만 사용하고, 자녀 식별 정보 (이름·생년월일·연락처) 는
요청하지 않습니다. 혹시 메일에 포함되었더라도 운영팀은 별도로 저장하지 않아요.

감사합니다.
```

## §3 기능 요청 → 우선순위 검토 안내

**제목**: [Speech-Therapy] 기능 제안 잘 받았어요

```
{부모님 호칭},

좋은 제안 주셔서 감사해요. 다음 단계로 진행할게요.

1. 내부 검토 회의에서 우선순위 라벨 (P0/P1/P2) 을 부여합니다.
2. 1주 안에 회신으로 결과와 도입 시점 (또는 보류 사유) 을 알려드릴게요.
3. 도입이 결정되면 출시 시점에 알림 메일을 한 번 더 드립니다.

비슷한 제안을 다른 부모님들도 주실 수 있어서, 같은 주제는 묶어서 우선순위에 반영해요.
양해 부탁드려요.

감사합니다.
Speech-Therapy 운영팀 드림
```

## §4 HITL 검토 진행 중 안내

**제목**: [Speech-Therapy] 발음 가이드를 한 번 더 살펴보고 있어요

```
{부모님 호칭},

{자녀 호칭, 예: "아이"} 의 발음 결과 중 자동 분석이 한 번 더 살펴봐야 한다고 판단한 부분이 있어,
협력 전문가가 직접 확인하고 있어요.

- 검토 기준 SLA: 48시간 이내 회신
- 진행 상황은 결과가 보강되는 대로 메일로 알려드릴게요.
- 그동안 기존 결과 화면은 그대로 보실 수 있고, 미션 진행도 정상 동작해요.

본 절차는 자동 분석의 신뢰도가 낮을 때 부모님께 더 정확한 가이드를 드리기 위한
이중 확인 과정이에요. 의료적 판단이 아닌 발음 발달 가이드 보강 목적입니다.

감사합니다.
Speech-Therapy 운영팀 드림
```

## §5 결과 안내 사후 보강 요청

**제목**: [Speech-Therapy] 발음 가이드를 보강해 다시 보내드렸어요

```
{부모님 호칭},

이전에 보내드린 발음 가이드를 전문가 검토 후 보강했어요. 결과 화면에서 새 점수와
가이드 텍스트를 확인하실 수 있어요.

- 갱신 항목: 3축 점수 (조음 / 언어 / 음향), 또래 비교 백분위, 전문가 코멘트
- 결과 보기: {결과 URL}

본 가이드는 부모님께 발음 발달 정보를 안내하기 위한 보조 도구예요. 발음에 대해
지속적으로 어려움이 느껴지신다면 가까운 발달 전문 기관 면담을 함께 권장드려요.

감사합니다.
Speech-Therapy 운영팀 드림
```

## §6 부재 자동 응답 (휴가 / 비상 시)

**제목**: [Speech-Therapy] 자동 응답 — {YYYY-MM-DD ~ YYYY-MM-DD}

```
안녕하세요,

문의 주셔서 감사해요. 운영팀이 {YYYY-MM-DD} 까지 자리를 비웠어요.
{복귀 일자 YYYY-MM-DD} 이후 순서대로 회신드릴게요.

급한 동작 결함은 영업 복귀 후 우선 처리하고, 일반 문의는 정상 응답 시간 안내드릴게요.

- 복귀 예정: {YYYY-MM-DD HH:MM KST}
- 비상 연락 (서비스 전체 중단 시): {emergency contact}

본 서비스는 의료적 판단을 제공하지 않는 부모용 발음 발달 확인 도구예요. 자녀 발음에
대해 즉시 전문가 면담이 필요하시면 가까운 발달 전문 기관 안내도 별도 도와드려요.

감사합니다.
Speech-Therapy 운영팀 드림
```

## 어휘 가드 (CON-04)

`lib/forbidden-words.ts` 의 정규식 단일 소스 (FR-C-005) 를 권위 참조로 한다. 본 문서는 의도적으로 금칙어 원문을 노출하지 않고, 코드 측 정규식이 차단하는 어휘 카테고리만 안내한다.

| 차단 카테고리 | 권장 대안 |
|---|---|
| (의료 행위) | 가이드 / 발음 연습 / 발달 확인 |
| (의료 판단) | 발음 발달 확인 / 결과 / 분석 |
| (의료 상태) | 발음 어려움 / 발달 차이 |
| 환자 | 사용자 / 자녀 / 부모님 |
| 처방 | 추천 / 안내 |

> 새 템플릿 작성 시 본 표를 참조하고, 발송 전 ESLint 또는 `lib/forbidden-words.ts` 정규식으로 1회 sanitize 검증 권장.
