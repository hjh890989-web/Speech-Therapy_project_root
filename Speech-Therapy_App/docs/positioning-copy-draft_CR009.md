# 포지셔닝 카피 초안 — 문해력 공개 런치 (CR-2026-009)

> **목적**: 문해력(만 2~12세 읽기·말 놀이)을 **공개 런치**할 때 적용할 포지셔닝 카피 초안. 현재 제품은 "만 2~7세 발음"으로만 포지셔닝돼 있음 → 연령 범위 + 도메인(문해력) 확장.
> **작성일**: 2026-06-22
> **⚠️ 적용 시점**: 학령기 게임 **플래그 on(공개 런치)과 동시**에 적용. 지금 적용하면 *미출시 기능 광고*가 되므로 **라이브 미반영**(본 문서 = 초안). 내부/제한 테스트는 카피 변경 없이 가능.
> **⚠️ 법률 재확인**: 약관/처리방침의 연령·도메인 확장은 2026-05-30 변호사 자문("만2-7 발음" 기준) 범위를 벗어남 → **PIPA/의료기기 변호사 재확인 후** 라이브. (랜딩 마케팅 카피는 법률 게이트 무관.)

## §2. 도메인 추가 카피 (랜딩 마케팅) — ✅ 게이팅 구현 완료 (2026-06-22)

랜딩(`app/page.tsx`)에 **읽기·말 놀이 마케팅 카피를 `literacyLive`(=`enabledLiteracyGames().length>0`) 게이팅으로 추가**. 플래그 off면 미노출(현재와 동일 = 미출시 광고 회피), 플래그 on + 재배포 시 자동 노출. CON-04 금칙어 0(컴플라이언스 테스트 통과).
- **히어로** — 게이트 배지 "📚 이제 읽기·말(문해) 놀이도 함께 — 만 2~12세".
- **기능 그리드** — 7번째 카드 "읽기·말 놀이"(→ `/literacy`).
- **신뢰 통계** — 대상 연령 `2-7` → `2-12`(literacyLive).
- **FAQ** — `LITERACY_FAQ`("읽기·말 놀이는 무엇인가요?") 1항목 append.

> ⚠️ 정적 페이지라 **빌드 시점 평가** — 공개 런치 = literacy 플래그 on + **재배포**. 히어로 headline 전면 재작성(발음 단독 → 발음·읽기)은 선택(추후 카피라이팅).
