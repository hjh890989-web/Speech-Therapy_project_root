## §2. 도메인 추가 카피 (랜딩 마케팅) — 런치 시 별도 작업

랜딩은 전면 **발음-중심**(히어로·CTA·밸류·HowItWorks·FAQ). 문해력 공개 런치 시 다음을 **읽기·말 놀이 포함**으로 보강(마케팅 카피라이팅 + 디자인 동반, 본 초안 범위 밖):
- `LandingHero.tsx` / `content.ts` hero(headline·sub·CTA) — "발음" 단독 → "발음·읽기" 또는 별도 섹션.
- `ValueProps.tsx` / `HowItWorks.tsx` — 읽기·말 놀이 가치 카드 추가.
- `content.ts` FAQ — "어떤 놀이가 있나요?"(문해력 단계 S0~S4 소개) 항목 추가.
- 비의료 disclaimer·금칙어(CON-04) 동일 적용.

> 권고: 도메인 카피는 **별도 마케팅 PR**로, §1 연령 카피 + 약관/처리방침과 함께 런치 번들로 묶어 반영.
