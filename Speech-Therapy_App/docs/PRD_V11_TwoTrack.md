## §0. 트랙 비대칭 선언 (본 문서의 최상위 불변 원칙)

> **"트랙A(발음)는 표준화 규준으로 또래를 비교해 '확인'하고, 트랙B(문해)는 점수·밴드·판정 없이 '놀이·연습'한다 — 측정 vs 측정이 아니다."**

| 항목 | **트랙A — 발음·발화 발달 "확인"** | **트랙B — 읽기·말 "놀이·연습"** |
|:---|:---|:---|
| 연령 도메인 | 만 2~7세 (24~84개월, diagnose 상한) | 만 2~12세 (24~144개월, `lib/literacy/stages.ts`) |
| 산출 | 또래 비교 점수·백분위·추이 (**확인 허용**) | **engagement 만** (활동 횟수·활동일), `referenceBand=null` |
| 임상 토대 | 표준화 규준 (U-TAP PCC 절단점, SELSI ±SD) | 발달 단계·선행지표·중재 위계 (규준 차용 ✗) |
| 핵심 동사 | 확인 / 비교 / 추이 | 놀이 / 연습 / 함께 / 단계에 맞춰 |
| 북극성 KPI | **W-AUR (주간 발음 미션 완수율) ≥ 60%** (불변) | **W-LER (주간 문해 활동률, engagement)** — 보조지표 신설 |
| Phase 2 검증 상태 | 표준화 규준 보유 → 출시 가능 | **출시 밴드 0건**(`bandShippable=false` 전 단계) → 연습-only 유지 확정 |

⚠️ **동사 분리 강제**: "확인(probe)·측정·평가·준비도 평가"는 **발음(트랙A) 전용**이다. 문해(트랙B)에는 절대 적용하지 않는다. 트랙B 산출 명칭은 "활동률 / engagement"로만 표기한다 — **"완수율 / 미션" 프레임 금지**. "읽기·말 발달 **확인**" 같은 표현도 사용 금지(확인은 발음 전용) — 트랙B 는 "읽기·말 발달 **가이드**", "읽기·말 놀이"로만 표기한다.

> **비대칭의 임상적 근거**: 발음은 만 7세경 발달이 완성되는 단일 타깃이고 한국 표준화 도구(U-TAP·SELSI) 규준을 보유 → "확인" 정당. 문해는 발달 순서가 연령에 묶여(음운인식→해독→유창성→이해) 5단계 사다리로 분기하나, 정량치가 전부 연구표본·NISE 2025 예비검사(비표준화)·임상대조라 일반 모집단 절단점·백분위가 없음 → "측정/평가" 불가, 놀이·연습만. (근거: VPS V10 §3-B · `stages.ts` `bandShippable=false` 주석.)

## 1. 개요 및 목표

### 1.1 문제 정의 (2트랙 모집단 분기)

PRD V10 까지의 문제 정의는 **만 2~7세 발음 단일 모집단**을 전제로 "내 아이가 또래만큼인지 5분에 객관화"하는 측정 패러다임에 종속돼 있었다. 그러나 라이브 서비스는 두 개의 분리된 부모 Job 을 동시에 떠안고 있다.

- **트랙A 부모(만 2~7세)**: "우리 아이 발음이 또래만큼인지 알 수 없어 불안하다." → 표준화 규준 기반 **또래 비교 확인**으로 해소.
- **트랙B 부모(만 2~12세, 학령기 포함)**: "집에서 연령에 맞는 읽기·말 놀이를 무엇을 어떻게 이어줘야 할지 모르겠다." → 발달 단계에 맞춘 **읽기·말 놀이를 매주 꾸준히** 잇는 것으로 해소.

> **핵심 선언**: **문해는 진단하지 않는다. 연령에 맞는 읽기·말 놀이를 매주 이어가게 한다.** 트랙B 의 가치는 "측정 충격"이 아니라 "연습 지속"이다.

#### 핵심 Pain Cluster 및 실패 KPI

> **트랙A(P1~P4)** = V10 4대 Core Pain 을 CON-04 금칙어("진단/치료/장애") 치환하여 계승. **트랙B(P5)** = 신설.

|:-:|:--:|:---|:---|:---|:---|:---|
| P1 | A | **발달 확인 기준 부재** | 또래 대비 발음 발달 위치를 즉시 알 도구 부재로 부모 불안 극대화 | 맘카페 탐색 `월 20h+`, 오프라인 초진 대기 `2~3개월+` | 가입 없이 `≤5분` 내 또래 발음 발달 위치 확인 | **F1-a/b, F2** |
| P2 | A | **대기 기간의 공백** | 센터 상담까지 발음 발달 활발한 시기에 집에서 무엇을 할지 막막 | 대기 기간 `평균 4.5개월`, 대기 중 홈 가이드 실행률 `<50%` | 매일 `1~3분` 맞춤 미션으로 즉시 시작 | **F3-a/b, F12** |

| P4 | A | **기관의 소통 부담 (B2B)** | 객관적 근거 부재로 교사·원장 학부모 소통 갈등 | 악성 민원 `연 3~5건`, 원아 연쇄 퇴소 `1~2명/분기` | Zero-touch 수집 + 원장 명의 발달 확인 리포트 | **F9-a/b/d, F10** |

> ⚠️ **P5 가드**: P5 의 산출은 "공백을 메우는 활동 제공"이지 "공백을 측정한 결과"가 아니다. P5 서술·실패 KPI 에 점수·밴드·또래비교·정상/위험 어휘 0건.

> **[ADR-001] W-AUR 북극성 선정 근거 (V10 계승)**: O-1(5분 발달 확인)은 일회성 유입 지표인 반면, O-2 의 "주간 발음 미션 완수율(W-AUR)"은 반복 사용(리텐션)과 직결되는 선행 지표 → 발음(트랙A) 북극성에 적합.

> **[ADR-05] 트랙B 보조 북극성 W-LER 신설 — 이원 북극성 (C 지향·A 1차)** *(신설)*
> - **결정**: 발음 W-AUR(불변) 옆에 **트랙B 보조지표 W-LER(주간 문해 활동률, engagement)**를 신설한다. 즉시는 **옵션 A**(W-AUR 불변 + W-LER 보조)로 baseline 을 수 주 축적하고, baseline 확보 후 **옵션 C**(트랙A W-AUR + 트랙B W-LER 동격 한 쌍)로 승격한다.
> - **대안 기각**: **옵션 B(통합 단일 WAE)** = 발음 미션 OR 문해 놀이를 단일 rate 로 평탄화 → 문해에 "완수/미션" 프레임 전이(CON-04 + 연습-only + `bandShippable=false` 충돌) + 발음 W-AUR 시계열 단절 → **비채택**.
> - **사유**: ① 두 집계가 코드에 이미 분리 존재(`waur-trend.ts` + `literacy-weekly.ts`)라 A/C 는 발음 산식 불변 + 문해 집계 함수 1개 추가로 회귀 0. ② W-LER 분모를 '문해 대상 가정(만 2~12)'으로 정의해 학령기·문해-only 가정을 owner KPI 에 가시화. ③ 연습-only 자연 빈도가 발음 미션과 달라 `≥60%` 무근거 차용 금지 → A 로 baseline 측정 후 target 산정.
> - **구현 가드**: W-LER 임계는 lib 상수 1곳(`W_LER_MIN_DAYS` / `W_LER_MIN_SESSIONS`)에 박고 owner 페이지·테스트가 참조 → 정의 표류 차단. 트랙B 명칭·카피는 **"활동률 / engagement"로만 — "완수율" 금지**.

## 2. 사용자와 역학 관계 (Users & Dynamics)

### 2.1 핵심 페르소나 요약

> 트랙A(Seg A~D) = V10 계승(금칙어 치환). 트랙B = 신규 페르소나(track 태그 B). 모든 트랙B 페르소나는 점수·밴드·판정·심각도 어휘 0건 + 문해 금칙어 0건. (정본: `Persona`·`customer-segmentation` 개정 문서, 청사진 §5.)

### 4-B. 트랙B — 문해 독립 Epic (14게임 · S0~S4 · 산출 = engagement)

> source of truth: `lib/literacy/registry.ts`(`LITERACY_GAMES` 실측 **14개**) + `lib/literacy/stages.ts`(5단계 S0~S4). **트랙B 는 발음 엔진(F1-a/F4)의 bolt-on 이 아니라 독립 Epic 군이다.** 각 게임의 **산출 = engagement(완료=1, 활동 1건)**, `referenceBand=null`, 단계 전부 `bandShippable=false`. #### 트랙B 라우팅 구조 (`/literacy/start` → 월령 → 단계 → 놀이)

#### 트랙B 산출 명세 (연습-only)

- **활동 단위 산출**: 놀이 1회 완료 = 활동 1건. raw 점수(정답수·완료시간 ms·완료 1)는 놀이마다 의미가 달라 **교차 합산 무의미** → 정확도 합산 ✗.
- **주간 집계**: `aggregateLiteracyWeekly` 가 `totalSessions`(총 횟수)·`activeDays`(활동일)·`byStage`(단계별 횟수)·`byGame`(놀이별 횟수)만 산출. **점수 등급·판정·임상 밴드 미산출.**
- **밴드 미노출**: `referenceBand=null` · 전 단계 `bandShippable=false` → 참고밴드(display) 미노출. (raw 점수·HITL·escalation·저장은 본 모델과 무관한 별도 활동 — display 레이어만 연습-only.)

#### 트랙B 4게이트 (연습-only 불변 — §5 정합)
각 게임은 ① 연습-only(`referenceBand=null`/`bandShippable=false`) ② 비복제(NISE-B·ACT/KOLRA/REVT/U-TAP 문항·지문·규준·명칭 복제 금지) ③ 플래그 게이팅(default off, `isEnabled()` on 일 때만 노출) ④ 연령 도메인 분리(문해 24~144 / 발음 ≤84) 4게이트를 **전부 통과한 상태에서만** 부모에게 노출된다.

### 5-T-B 거버넌스 — KOPLAC 자문 한정
트랙B 자문 = **채점/판정이 아니라** 활동 난이도 위계·연령 적합성·CON-04 톤 검토로 한정한다. `bandShippable=true` 플립 경로 = KOLRA·BASA-R 정식 매뉴얼 규준표 확보 또는 NISE 2026 표준화 최종규준 발표 시에만 재검토 — 그 전까지 **전 단계 연습-only 유지 확정**(`stages.ts` 주석 정합).

### 7.1 범위 정의 (In / Out of Scope) — 2트랙 + ADR-04 L88 충돌 해소

| 범위 (Scope) | 트랙 | 상세 내용 |
|:---:|:--:|:---|
| **In Scope** (포함) | A | • 발음 발달 확인: 영유아(만 2~7세, 24~84개월) 음성 기반 또래 비교 확인 (웹뷰/앱)<br>• B2C 홈 가이드: 대기 기간 즉시 실행 데일리 숏폼 미션 + 게이미피케이션 보상<br>• B2C 리텐션: 발음 발달 추이 리포트 + 가족 공유<br>• B2B 연동: Zero-touch 수집, 원장 발달 확인 대시보드, 전자 서명<br>• 품질 관리: 전문가 비동기 감수 (HITL) |

> **⚠️ ADR-04 L88 스코프 충돌 명시 해소** *(검증관 mustFix)*: `tasks/13` 계열 `F1a-F4-임상설계-reference.md` **L88** 은 "쓰기·수학·고학년 읽기이해 = ⛔회피(ADR-04 영유아 외)"로 명시했다. CR-2026-009 가 학령기 전면확장으로 이를 **상향대체**했으므로, 본 PRD V11 은 경계를 다음과 같이 **명문 구분**한다(암묵 화해 금지):
> - **In-Scope** = 학령기(만 8~12세) **읽기·말 놀이 콘텐츠 자체**(S2~S4 14게임, engagement 산출).
> - **Out-of-Scope (여전히 회피)** = 문해 **점수화·학년 판정·고학년 읽기이해 측정**.
> - 즉 L88 의 "회피"는 **'측정·판정'에 한정**되며, **'놀이 콘텐츠 제공'은 In-Scope** 로 상향대체됐다. ADR-04(의료 용어 배제)는 트랙B 에 여전히 적용된다 — 트랙B 는 점수·판정을 산출하지 않으므로 ADR-04 와 충돌하지 않는다.

## 11. 용어 사전 (Glossary)

> V10 §11 용어(W-AUR·HITL·AOS/DOS·DMU·CJM·JTBD·MoSCoW·ADR·CVR·CAC·LTV·M3·SLA·DTx·VAD·STT·NLP·ABA·U-TAP·REVT·TAM/SAM/SOM·VPS 등) 계승. 본 절은 **2트랙 비대칭 신규 용어**만 등재.

| 용어 / 약어 | 정의 |
|:---|:---|
| **트랙A (Track A)** | 발음·발화 발달 **"확인"** 트랙(만 2~7세, 24~84개월). 표준화 규준(U-TAP·SELSI) 기반 또래 비교 점수·백분위·추이 산출. 북극성 = W-AUR. |
| **트랙B (Track B)** | 읽기·말 **"놀이·연습"** 트랙(만 2~12세, 24~144개월). 점수·밴드·또래백분위·판정 **없음** — engagement(활동 횟수·활동일)만 산출. 보조 북극성 = W-LER. |
| **연습-only (Practice-only)** | 트랙B 의 불변 원칙. 측정·평가·확인(probe)·판정을 하지 않고 활동(놀이)만 제공·기록하는 모드. `referenceBand=null` · 전 단계 `bandShippable=false`. |
| **bandShippable** | `stages.ts` 의 단계 속성. `true` 면 임상 규준 참고밴드(display) 출시 가능, `false` 면 연습-only. ⚠️ Phase 2 규준검증(2026-06-22) 결과 출시 가능 밴드 0건 → **전 단계 `false` 유지 확정**. 플립 경로 = KOLRA·BASA-R 정식 규준표 또는 NISE 2026 최종규준 발표. |
| **referenceBand** | 트랙B 산출 시 참고밴드(또래 비교 표시) 값. 연습-only 동안 항상 `null`(밴드 미노출). |
| **W-LER** | Weekly Literacy Engagement Rate (주간 문해 활동률). 트랙B 보조 북극성. 활동일(`activeDays`)·활동 횟수(`totalSessions`) 기반 engagement 지표. ⚠️ **"완수율"이 아니다.** 임계 = `W_LER_MIN_DAYS`/`W_LER_MIN_SESSIONS`(lib 상수). |
| **engagement** | 트랙B 가치·산출의 단위. 점수·정답률이 아니라 **활동 빈도·활동 지속**(총 횟수·활동일·단계별·놀이별 분포). |
| **음운인식 (Phonological Awareness)** | 말소리를 인지·조작하는 능력. 위계 = 운율→단어→음절→음소(`.ingest` S003). 트랙B S0~S1 핵심 구인. |
| **해독 (Decoding)** | 자소-음소 대응으로 글자를 소리로 바꿔 읽는 능력. 트랙B S1~S2 핵심 구인. |
| **RAN** | Rapid Automatized Naming (빠른 이름대기). 친숙한 자극(그림·글자)을 빠르게 명명하는 속도 — 읽기 유창성 선행지표. 음운처리 3요소 중 하나(음운인식+음운기억+RAN, `.ingest` S090·S133). 트랙B S1 구인. |
| **SVR** | Simple View of Reading. 읽기이해 = 해독 × 언어이해(wiki 해독.md, S090). 트랙B S3~S4 이해 구인의 이론 토대. ⚠️ 상관≠인과, 정량치 신규 이식 시 원문 대조. |
| **clin-2** | 트랙B 표시 규칙. 학년/단계(stage) 라벨 대신 **놀이명만** 부모·자녀에게 노출(예: "초3~4" 미노출 → "또박또박 읽기"). |
| **CR-2026-009** | 문해력 학령기 전면확장(만 2~12세) 변경요청. 5단계 사다리(S0~S4) + 14게임, 2026-06-22 공개 런치. ADR-04 L88(영유아-only)을 학령기 놀이 콘텐츠 In-Scope 로 상향대체. |

## 12. 자가점검 (CON-04 · 연습-only · 연령 도메인 분리)

### 12-1. CON-04 금칙어 점검 (본 문서 본문 카피)
- 공통 금칙어 "치료/진단/장애": 본문 신규 제품 카피 **0건** (raw V10 의 '5분 진단'→'5분 발달 확인', '진단 리포트'→'발달 확인 리포트', '스크리닝'→'발달 확인 리포트', 그리고 §2.2 파이프라인·§3 Neg AC-1 의 '진단'→'발달 확인'으로 치환). §0·§4-A·§4-B·§10 의 금칙어 언급은 "금지 대상 명시"이며 제품 카피 아님.
- 문해 추가 금칙어 "학습장애·난독·읽기장애·지연·지체": 본문 제품 카피 **0건** (§10.1 표는 금지 명시).

### 12-2. 연습-only(트랙B) 점검
- 트랙B 산출: engagement(활동 횟수·활동일·단계별·놀이별 분포)만 — 점수·밴드·백분위·판정 0건. `referenceBand=null`·전 단계 `bandShippable=false` 명문(§0·§4-B·§5·§6·§11).
- 트랙B 동사: 놀이/연습/함께/단계에 맞춰만 — **"확인(probe)/측정/평가" 미적용**(발음 전용 분리). "읽기·말 발달 **확인**" 표기 0건 → "가이드/놀이"로만.
- 학년/단계 라벨 대신 **놀이명** 노출(clin-2) 명문(§4-B·§10.2·§11).
- 북극성 트랙B: "활동률/engagement"로만 — "완수율/미션" 프레임 0건. W-LER target 무근거 차용 금지(§1.3 ADR-05).

### 12-3. 비대칭·스코프 점검
- 비대칭 선언(확인 vs 놀이) §0 최상위 명문, 본문 전반 일관 유지.
- ADR-04 L88 스코프 충돌: §7.1 에서 "학령기 놀이 콘텐츠 In-Scope / 문해 점수화·학년 판정·고학년 읽기이해 측정 Out-of-Scope"로 경계 명문 해소(암묵 화해 아님).
- Pain P5(읽기·말 활동 부재) 신설 + 트랙B 보조 북극성 W-LER 신설 + 트랙B 독립 Epic(14게임, F1-a/F4 괄호 주석 제거→이관) 반영.

### 12-4. 연령 도메인 분리 점검
- 발음 규준 ≤84개월 / 문해 24~144개월 — 본문 전반 분리 유지, 상호 오염 0건(§0·§4-B·§5·§6·§7.1).
