# 콘텐츠 원본성 법률 자문 브리프 — 문해력 미니게임 (OPS-LIT-01)

> **목적**: 문해력 미니게임의 **자체 제작 콘텐츠**(문항·지문·낱말·자극)가 기존 표준화 검사(NISE-B·ACT, KOLRA, RA-RCP 등)의 저작권·상표권을 침해하지 않음을 **단발 법률 자문**으로 확인. 학령기 게임 **활성화(플래그 on) 전 통과 게이트**(CR-2026-007 OPS-LIT-01 / CR-2026-009 §7).
> **작성일**: 2026-06-22
> **범위 구분**: 본 브리프는 **콘텐츠 IP/원본성**만. PIPA·의료기기법은 별도 [`compliance-lawyer-consultation-brief.md`](compliance-lawyer-consultation-brief.md)(2026-05-30 "문제 없음" 자문 완료). 임상 적절성은 [`clinical-consultation-packet_schoolage-literacy_CR009.md`](clinical-consultation-packet_schoolage-literacy_CR009.md).
> **예상 비용/기간**: 단발 의견서 30~50만 원 / 2~4주 (사용자 확보).

---

## §1. 핵심 질문 (한 줄)

> **측정하려는 "구인"(음운인식·해독·음운규칙·읽기이해·형태소 등 = 분야 표준 학술 지식)을 근거로, 문항·지문·낱말을 100% 자체 창작하고 자체 척도로 채점하는 미니게임이, 동일 구인을 측정하는 기존 표준화 검사의 저작권/상표권을 침해하는가?**

제품팀의 자체 판단은 "침해하지 않음"(구인=비저작 아이디어, 콘텐츠=독립 창작)이나, 상업 출시 전 **법률 전문가 확인**이 필요.

---

## §2. 사실관계 — 무엇을 만들었고, 무엇을 하지 않았는가

### 2.1 제품 성격
- 만 2~12세 자녀의 읽기·말 발달 **놀이(연습)** 모음. 의료기기 아님. 표준화 검사를 **시행·복제·대체한다고 표시하지 않음**.
- 점수 등급/규준 백분위/판정 **미산출**(연습-only) — 특정 검사의 규준을 주장하지 않음.

### 2.2 콘텐츠 인벤토리 (전 14게임, 모두 자체 제작 / 활성화 대상 학령기 5종 굵게)
| 게임 | 구인 | 자체 콘텐츠 |
|---|---|---|
| 어휘/음운인식/비단어/해독/RAN/유창성/추론(가이드)/이야기/소리변신 (만2~7, 기존 9) | 어휘·음운처리 등 | 자체 단어·이모지·시나리오 |
| **받아쓰기(spelling)** | 철자/음운규칙 | 자체 25문항(고빈도 낱말, '옳은 철자 고르기') |
| **소리 규칙 읽기(read-rules)** | 불일치형 해독 | 자체 25문항(낱말→바른 소리) |
| **글 읽고 답하기(reading-comprehension)** | 사실적 읽기이해 | **자체 창작 지문 3편** + 문항 9 |
| **숨은 뜻 찾기(inference-reading)** | 추론 독해 | **자체 창작 지문 3편** + 문항 9 |
| **낱말 조각 놀이(morphology)** | 형태소 인식 | 자체 15문항(합성/파생/분석) |

### 2.3 명시적으로 **하지 않은 것** (코드 주석·설계서로 강제)
- ❌ NISE-B·ACT / KOLRA / RA-RCP / KOLPAC 등의 **문항·지문·단어목록·정답·자극 그림을 복사 또는 미세변형 후 사용**.
- ❌ 위 검사의 **명칭·로고·규준(norms)·표준점수**를 앱에 표시하거나 주장.
- ❌ 앱을 위 검사의 **한국어판/시행 도구**라 표기.
- ✅ 측정 **구인**(예: 음운규칙별 철자, 형태소 합성/파생)은 언어학·언어재활 분야의 **공개된 표준 지식**으로서, 이를 근거로 **독립 창작**.

### 2.4 원본성 보장 장치 (코드 레벨)
- 모든 콘텐츠 파일(`lib/literacy/*-content.ts`) 상단에 **자체 제작 + 비복제 주석** 고정.
- 난이도 위계에 외부 수치 인용 시 "정렬용·임상밴드 아님" 주석 + 출처 원문 대조.
- 금칙어(치료/진단/장애/학습장애/난독) 0 — 검사·진단 함의 차단(테스트 가드).

## §3. 자문 요청 항목

1. **아이디어/표현 이분법** — "음운규칙별 철자 측정", "형태소 합성/파생 측정" 같은 **측정 구인·과제 형식**은 저작권 보호 대상(표현)이 아니라 아이디어/방법으로 보아, 자체 창작 문항으로 구현하는 것이 적법한가?
2. **실질적 유사성** — 동일 구인을 다루면 표준화 검사와 **문항 형식이 유사**해질 수밖에 없는데(예: '옳은 철자 고르기', 지문+사실 질문), 자체 낱말·지문을 쓰는 한 저작권 침해(substantial similarity)에 해당하지 않는다고 볼 수 있는가? 유사성을 줄이기 위한 추가 설계 권고는?
3. **공통 낱말·예시어** — 음운규칙 예시어(예: 굳이/같이/국물)는 한국어에서 해당 규칙의 **대표 예**로 통용되는 일반 낱말이다. 특정 검사가 같은 낱말을 써도, 일반 낱말 사용이 침해가 되는가?
4. **명칭 사용** — "받아쓰기", "읽기", "형태소" 등 **일반 명사·교육 용어**를 게임명/설명에 쓰는 것은 상표권과 무관한가? 피해야 할 표현이 있는가?
5. **자체 창작 지문** — 글 읽고 답하기/숨은 뜻 찾기의 **자체 창작 지문**(동봉)이 기존 교재·검사 지문과 독립 창작으로 인정되기 위한 기준은?
6. **출시 전 체크리스트** — 콘텐츠 IP 관점에서 상업 출시 전 필수 확인 항목.
