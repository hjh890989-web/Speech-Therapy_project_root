# F15 발화 유도 챗봇 — KOPLAC 13항목 임상 자문 패킷 (활성 게이트)

> **목적**: F15 LLM 대화형 발화 유도 챗봇(`F15_CHAT_ENABLED`) 활성화의 **무조건 선행 게이트**인 KOPLAC 13항목
> 임상 안전 검증(SRS §10, ADR-14)을 위한 자문 의뢰 자료.
> **전제(중요)**: 기존 `clinical-consultation-packet_CL01-04_F15.md` §5 의 13항목 표는 **2026-05-27 작성(F15 코드 구현 *전*)**
> 이고, 2026-05-30 KOPLAC "문제 없음"은 **CL-01~04(진단 채점) 한정**(schema.prisma 박제). 본 패킷은 **F15 의 실제
> 구현 상태(아래 §0)** 를 근거로 13항목을 재구성한 것으로, 전문가가 *계획*이 아닌 *실제 상태*를 검증하게 함.
> **산출물(§10.5)**: 13항목 통과/미통과 보고서 + 미통과 시 시정 권고 + IRB 신청 권고 여부(T4-c, [[f15-t4c-irb-analysis]]).
>
> **응답 방식**: 각 항목 끝 **평가**란에 `☐ 타당 / ☐ 수정 필요 / ☐ 부적합`을 표시하고 **사유·권고**를 적어 주십시오.
> 질문은 우리 방침의 *적절성*만이 아니라 **한계·실패 시나리오**도 함께 평가해 주시길 부탁드립니다.

## §0. 제품 성격 + F15 실제 구현 상태 (검토 전제 — 정확성 중요)

- **제품**: 만 2~7세 자녀의 발음/발화 발달을 부모가 확인·안내하는 **발달 가이드용 보조 도구**(비의료기기). 평가/진단 아님.
- **F15**: 자녀가 즐겁게 더 많이 말하도록 **자연 발화를 유도**하는 대화 챗봇. 단일턴. **현재 `flag=false` 휴면.**

> **⚠️ 2026-05-31 갱신**: 이전 버전 §0-B 의 "미구현"(발화 저장·7일 폐기·R4 마스킹·PIPA consent-guard)은 **모두 배선 완료**되어 아래 (A)로 이동했습니다. 따라서 자문위는 이 항목들을 *실제 작동 상태*로 평가해 주시면 됩니다. (B)에는 Phase 2 / 자유발화 잔여 리스크만 남습니다.
