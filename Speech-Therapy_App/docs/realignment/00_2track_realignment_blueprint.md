## 1. 요약 — 무엇이 발음-종속이고 무엇을 바꾸나

전략 문서 전 계층(VPS·Persona·PRD·SRS·북극성·상류 5문서·표면 정본)이 **발음/언어발달 단일트랙의 "측정·진단·수치화"** 패러다임에 구조적으로 종속돼 있다. 부제·TAM(만2~7)·4대 Pain·Job-Feature·KPI·GTM 카피가 전부 발음 probe·채점·백분위 기반이고, 라이브 문해 트랙(만2~12, 14개 게임 플래그 ON, 2026-06-22 런치)이 매핑돼 있지 않거나 발음 엔진의 괄호 bolt-on으로만 종속돼 있다. 바꿀 핵심은 **2트랙 비대칭**의 명문화다: 트랙A(발음, 만2~7)는 표준화 규준(U-TAP·SELSI)에 근거해 또래 비교로 **"확인"**하고, 트랙B(문해, 만2~12)는 출시 가능 참고밴드 0건(stages.ts `bandShippable=false` 전 단계)이므로 점수·밴드·판정 없이 **"놀이·연습"**만 한다 — **"측정 vs 측정"이 아니다.** 코드 레이어(stages.ts·literacy-weekly.ts·LandingFaq)는 이미 비대칭에 정합하므로, 재정렬은 전략·표면 문서를 코드가 이미 도달한 진실로 따라가게 하는 작업이다.

## 3. 트랙 정의(비대칭)

> 핵심 불변 선언: **"트랙A(발음)는 또래 비교로 '확인'하고, 트랙B(문해)는 점수·밴드·판정 없이 '놀이·연습'한다 — 측정 vs 측정이 아니다."** 동사 일관 분리: 발음=확인/비교/추이, 문해=놀이/연습/함께/단계에 맞춰. (문해에 "확인(probe)" 적용 금지 — 검증관 PRD mustFix 반영.)

| 항목 | **트랙A — 발음·발화 발달 "확인"** | **트랙B — 읽기·말 "놀이·연습"** |
|---|---|---|
| 연령 도메인 | 만2~7세 (24~84개월) | 만2~12세 (24~144개월, stages.ts) |
| 산출 | 또래 비교 점수·백분위·추이 (확인 허용) | engagement만 (활동 횟수·활동일), **밴드=null** |
| 임상 토대 | 표준화 규준 (U-TAP PCC 절단점, SELSI ±SD) | 발달 단계·선행지표·중재 위계 (규준 차용 X) |
| 가치제안 | "또래 대비 발음 발달 위치를 5분에 확인" | "발달 단계에 맞춘 읽기·말 놀이를 매주 꾸준히" |
| 핵심 Job | "우리 아이 발음이 또래만큼인지 확인하고 싶다" | "집에서 연령에 맞는 읽기·말 놀이를 어떻게 이어줄지 모르겠다" |
| 대표 페르소나 | 발음 불안 부모(만2~7) | 취학전 읽기준비 부모 + 초저학년 읽기 어려움 부모(§5) |
| 가치 동력 | 측정 충격 → 가이드 → 추이 | 연습 지속 → 습관 → 리텐션(engagement) |
| Lock-in | 발음 점수 궤적 데이터 해자 | 발달단계 연속 활동·습관(engagement) |
| Phase 2 검증 | 표준화 규준 보유 → 출시 가능 | **출시밴드 0건** → 연습-only 유지 |

**비대칭의 임상적 근거**: 발음은 만7세경 발달 완성(단일 타깃) + 한국 표준화 도구 규준 보유 → "확인" 정당. 문해는 발달 순서가 연령에 묶여(음운인식→해독→유창성→이해) 5단계 사다리로 분기하나, 정량치가 전부 연구표본·NISE 2025 예비검사(비표준화)·임상대조라 일반 모집단 절단점·백분위 없음 → "측정/평가" 불가, 놀이·연습만.

## 4. 북극성 결정 (사용자 최종 결정 항목)

> source of truth: `lib/reports/waur-trend.ts` — `W_AUR_MIN_MISSIONS=4`, `W_AUR_TARGET_RATE=0.6`. 문해는 `aggregateLiteracyWeekly`가 engagement(totalSessions/activeDays)만 집계. **문제**: 현 W-AUR 분자(SessionLog missionId)·분모(진단∪미션) 모두 발음 트랙만 참조 → 문해-only 가정(만8~12)이 분자·분모 양쪽에서 구조적으로 배제됨.

| 옵션 | 정의 | 장점 | 단점 | 실측 가능성 |
|---|---|---|---|---|
| **A** 발음 W-AUR 유지 + 문해 보조 W-LER 신설 | 북극성=W-AUR 불변. 문해=보조 KPI(주간 문해 활동률, engagement) | CON 위반 0, 회귀 0, 즉시 실측 | 북극성이 여전히 발음 단일(과업 절반) | **즉시** (집계 함수 1개 추가) |
| **B** 통합 WAE (발음 미션 OR 문해 놀이) | 분자=발음≥4 OR 문해≥기준, 단일 rate | 단일 헤드라인, 모집단 일치 | 비대칭 평탄화 → **완수/미션 프레임 전이 위험(CON)**, 시계열 단절 | 발음 시계열 단절 |
| **C** 이원 북극성 (발음 W-AUR + 문해 W-LER 동격 한 쌍) | 트랙별 북극성 한 쌍, 각자 모집단·임계·target | 비대칭 가장 정직, 회귀 0, CON 0 | 단일 지표 통념 충돌, 종합 판단 규칙 필요 | 두 집계 이미 분리 존재, 함수 1개 추가 |

**추천 (1안): 옵션 C 채택, 옵션 A를 단계적 1차 착지점으로.** 즉시는 A로 W-LER을 보조지표로 신설해 baseline을 수 주 축적하고, baseline 확보 후 C로 동격 승격. **옵션 B는 비권장.**

**사유**: ① **불변 제약 정합** — B는 비대칭을 단일 rate로 평탄화해 문해에 "완수/미션" 프레임을 전이시킬 구조적 위험(CON-04 + 연습-only + bandShippable=false 충돌). C는 비대칭을 지표 구조에 보존. ② **즉시 실측** — 두 집계가 코드에 이미 분리 존재(waur-trend.ts + literacy-weekly.ts)라 A/C는 발음 산식 불변 + 문해 집계 함수 1개 추가로 회귀 0. ③ **모집단 갭 해소** — A/C는 W-LER 분모를 '문해 대상 가정(만2~12)'으로 정의해 학령기·문해-only 가정을 가시화(#109가 부모 표면엔 반영했으나 owner KPI엔 미반영인 갭과 대응). ④ **target 캘리브레이션** — 연습-only 자연 빈도가 발음 미션과 달라 **≥60% 무근거 차용 금지**. A로 baseline 측정 → target 산정 후 C 승격.

**구현 가드**: W-LER 임계도 lib 상수 1곳(`W_LER_MIN_DAYS`/`W_LER_MIN_SESSIONS`)에 박고 owner 페이지·테스트가 참조 → 정의 표류 차단. 트랙B 명칭·카피는 "활동률/engagement"로만 — "완수율" 금지.

- 부제 = "발음·발화 발달 확인(만2~7) + 읽기·말 놀이·연습(만2~12) 부모 가이드 서비스(비의료)". 비대칭 1문장 선언.
